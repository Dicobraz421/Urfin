Урфин — двухпанельный файловый менеджер для Windows 10 и 11 (64 бита).

1. Распакуйте архив в любую папку, установка и права администратора не нужны.
2. Запустите urfin.exe.
3. Файл urfin.portable включает переносной режим: настройки и состояние хранятся рядом, в папке data. Удалите его — Урфин будет хранить их в профиле пользователя.
4. Если Windows пишет «Система Windows защитила ваш компьютер», нажмите «Подробнее» → «Выполнить в любом случае».

Urfin is a dual-pane file manager for Windows 10 and 11 (64-bit).

1. Unpack the archive into any folder; no installation or administrator rights needed.
2. Run urfin.exe.
3. The urfin.portable file enables portable mode: settings and state are kept next to it, in the data folder. Delete it to keep them in your user profile.
4. If Windows says "Windows protected your PC", click "More info" → "Run anyway".
