## D-04 Встроенные строки
F5, F6, F7, F8, Shift+F6 (поле в строке), Ctrl+A, фильтр Ctrl+I, конфликт, отметка группы, быстрый поиск: накрывают нижнюю часть панелей, курсор не прячется (прокрутка); клавиши — на кнопках, keybar показывает только дополнительные. ## D-05 Меню
F9 — «мешочек» (корешок в любом месте верхнего края списка, вогнутые скругления 8; у края — прямой угол); контекстное меню — плашка без корешка; то же правило для всех выпадающих полей. Сортировка (Ctrl+F12), закладки (Ctrl+D), история (Alt+F12) — тот же «мешочек». Сцены: `screen-menu`, `-context`, `-sort`, `-bookmarks`, `-history`, `-usermenu`.

## D-06 Job-бар и терминал
Job-бар занимает место над командной строкой (строка 30, прогресс 4, «ждёт ответа» — `context_remote`); терминал под панелями (Ctrl+O, Ctrl+F1/F2) по `screen-terminal`, `-termhalf`; раскрытый список задач (Ctrl+J) — `screen-jobslist`; командная строка — `screen-cmdcomplete`, `-cmdhistory`; терминал — `-termsearch`, `-termshell` — в рамках S6, если отрисовка терминала ещё не готова.

По готовности соответствующих частей (search, S7). Сцены: `screen-search`, `-searchpanel`, `-searchgrep`, `-viewer`, `-viewerhex`, `-viewerenc`, `-editor`, `-editreplace`, `-editgoto`.
