## S6 — CLI

- **S6-01 Каркас term** — дельты: S0 №58 (зависимости без отдельного согласования при чистом `cargo deny`: `alacritty_terminal` — версию закрепить `=`, дубль `windows-sys` старой версии — в `skip` deny.toml с причиной; в PR — крейт, назначение, лицензия), S0 v3 №7 (`MsgSink::poke()`/`Runtime::waker()` уже есть — проверить и использовать). Команды и Fluent `cmd-term-*`, `cmd-cmdline-*`; `docs/COMMANDS.md` перегенерировать.
- **S6-02 ConPTY** — дельты: S0 №28 (свой ConPTY с откатом на системный), №54 (DLL ConPTY не входят в бюджет бинаря). Следствие: старт — на **системном** ConPTY; поставка `conpty.dll` + `OpenConsole.exe` (MIT, NuGet `Microsoft.Windows.Console.ConPTY`) — отдельным PR: откуда брать файлы (бинарники в git или шаг сборки дистрибутива) — вопрос владельцу. Офлайн-правило — только для рантайма. **Решено (S0 №76):** свежая сборка, вариант «б» — файлы скачивает шаг сборки дистрибутива из NuGet, в git их нет.
- **S6-03 unix PTY** — **не делаем** (№57).
- **S6-04 Pipeline сеанса** — дельты: S0 v3 №7 (poke без Msg), бюджеты 2026-10-16 (0 % CPU в простое).
- **S6-05 Кодировщик ввода** — дельты: S0 v3 №13 — имена клавиш не egui, а `Keystroke` gpui-kit (как в S3 после G-02); клавиши с буквой — на любой раскладке (S0 v4 №5).
- **S6-06 Рендер сетки** — дельты: ADR-0018 (GPUI, см. «Интерфейс»), шрифт — системный моно (выше), бюджет кадра ≤ 2 мс (2026-10-16). Приёмка «скриншот-тесты» — сцены `--screens` (рамки Far/mc, кириллица, CJK, эмодзи, 256 цветов, truecolor) + замеры в PR.
- **S6-07 Выделение, буфер, скролл** — без дельт (подтверждение многострочной вставки — inline-строкой, как черновики S5).
- **S6-08 Слои и Ctrl+O** — дельты: S0 v3 №11 (слои: терминал → панели → cmdline → оверлеи; PTY не ресайзится от панелей) в `gpui_shell`; №27 (вывод за панелями, зона снизу — опция `term.layout`); №52 (Ctrl+O: shell по умолчанию из настроек, иначе по статистике; подсказка «1 pwsh · 2 cmd · 3 wsl…», цифра выбирает только при ≤ числу shells и паузе ~250 мс).
- **S6-09 Обнаружение shells** — дельты: №57 (только Windows: cmd, pwsh, powershell, Git Bash, WSL-дистрибутивы).
- **S6-10 Менеджер сеансов** — дельты: №52 (выбор по умолчанию: настройка → статистика; следствие: при первом запуске без статистики — pwsh 7, если найден, иначе cmd — рекомендация S6 §12.1(б)); №51 (сообщения сеанса — тосты, не баннеры); `on_quit`-вето — как в S5-12 (`QuitDecision::Veto`, выбор `quit`); бюджет первого кадра < 250 мс (2026-10-16; в тексте задачи — 150).

- **S6-12 Интеграция cmd** — дельты: №29.
- **S6-13 Интеграция bash/WSL** — дельты: №29, №57 (только WSL и Git Bash; приёмка «bash 3.2 macOS» — снять).
- **S6-14 Синхронизация cwd** — без дельт.
