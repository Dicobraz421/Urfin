# S0 — решения владельца (ADR-0005)

Статус: 2026-10-14. Имеет приоритет над разделами «Решения для владельца» и мокапами в specs/S1–S9.

## Платформы (обновлено)
- **Windows — единственная активная платформа.** macOS — **в пассиве**: код остаётся кроссплатформенным (cfg-модули, CI собирает и тестирует macOS), но ручная приёмка, Mac-специфичные фичи и релиз macOS не планируются до реактивации владельцем. Linux — tier 2 без изменений.
- **Стенд разработки — Windows 11 владельца, нативно** (обновлено 2026-10-15, заменяет ВМ Debian 13), на нём работает Claude Code (см. HANDOFF-stand-windows.md). Проверка: L0 на стенде (MSVC-сборка, clippy, тесты) → L1 CI windows/ubuntu/macos → L2 ручная приёмка владельцем GUI (`win-manual`). Перф-бюджеты — только Windows. Linux — CI и при необходимости WSL2. Alpine — не стенд (musl), допустим только как headless Docker-образ.

## Принцип дизайна
- **DN/Far — источник функций и раскладки** (две панели, табы, cmdline, keybar F1–F10, F-клавиши), **не визуальный канон.**
- Визуальный язык — **Windows Fluent, ориентир WinUI Gallery (3.0)**. Вариант **A «Explorer-native» с правками**: без командной панели; строка F-клавиш обязательна; табы в заголовке окна (по набору на панель); breadcrumb-путь; иконки; строки 24 px; размеры КБ/МБ/ГБ, цифры tabular; акцент системы; светлая/тёмная по ОС.
- Шрифты: Segoe UI Variable + Segoe Fluent Icons из системы; вшиты JetBrains Mono (терминал/hex) и подмножество Fluent System Icons (MIT) для Win10/прочих ОС.
- Темы DN/Far — не по умолчанию, позже опцией. Превью/миниатюры — не делаем.

## Изменения задач
- **S1-15 Single-instance.** app/`ipc`: Windows — mutex + named pipe `\\.\pipe\urfin-<sid>`; mac/Linux — unix socket + `flock`. JSON `{argv,cwd}` → `tab.new`+`panel.go`, активация окна. Приёмка: <100 мс, stale lock чистится. Зависит: S1-07, S1-13.
- **S1-10:** `General.language` = BCP-47.
- **S2:** стили строк по №31, раскраска по №32.
- **S6:** история — persist/session-only по №30.
- **S9:** релиз M6 — только Windows (MSI, portable zip, winget); macOS-задачи (.dmg, notarization, universal2) — в бэклог «macOS реактивация». CI-джоб macOS остаётся (сборка + тесты).
- **Все сессии:** Mac-специфичные задачи (getattrlistbulk, FSEvents, clonefile, AppKit-меню и т.п.) — после Windows/Linux-аналогов, в конце очереди; cfg-заглушки обязательны, чтобы CI macOS был зелёным.
- **S7 (новая задача S7-21, M4):** подсветка синтаксиса по №46 — крейт `syntect` (features: `default-fancy` без onig, `regex-fancy`), вшитый SyntaxSet/ThemeSet через `dump`, маппинг scope→токены Fluent, фоновый инкрементальный highlighter с кэшем состояний парсера на каждые N строк, отключение > 16 МБ, переключатель `editor.highlight`. Применяется в редакторе и во вьювере (text-режим). Зависит: S7 rope/рендер. Хук подсветки из S7 заменяется этой задачей. deny.toml: проверить лицензии syntect/fancy-regex (MIT).
- **Журнал событий Windows (владелец, 2026-10-15; реализовано в S1-12):** падения, ошибки уровня Error (не больше 20 в минуту) и сбой старта дублируются в журнал «Приложение», источник `Urfin`, события 1000/1001/1002; файл лога остаётся основным. **S9:** MSI регистрирует источник (`HKLM\SYSTEM\CurrentControlSet\Services\EventLog\Application\Urfin`), иначе Просмотр событий пишет «описание не найдено».
- **Бюджеты старта и памяти (владелец, 2026-10-16, S1-14):** рендер wgpu DX12 (ADR-0012) сам стоит ~160 мс и ~150 МБ на стенде, поэтому бюджеты S.1 и S.3 разделены на «весь процесс» и «своё»:
  - S.1 первый кадр, тёплый старт — **< 250 мс** (было < 150); S.1a своё время старта без создания окна и устройства (`startup.paths…core`) — **< 20 мс**;
  - S.3 своя память Urfin (счётчик аллокатора, feature `count-alloc`, S9) — **< 50 МБ**, гейт; S.3a память процесса (private) — потолок **≤ 200 МБ**, ловит утечки и рост драйвера.
  - (владелец, 2026-10-18, S4-11) S.3a ≤ 200 МБ — для типовых каталогов до 100k записей. Для 1M действует только цель S4 §7 «peak RSS листинга < 110 МБ»; процесс тогда ~270 МБ (база DX12 ~162 МБ). Ужатие 1M: в S4-19 убрать копию записей в воркере листинга (#70); хранение записей блоками (меняет `Listing.entries`, ADR) — только если 1M не уложится в 110 МБ.
- **S10 Плагины (новая сессия, после M6):** бриф — WASM-хост, манифест, права (fs/net — по запросу пользователя), API: команды, панели (виртуальный Vfs), вьювер/редактор (форматтеры, линтеры), хоткеи. Не планируется до M6.
- **Зависимости i18n (владелец, 2026-10-17, S2-01):** к одобренным `fluent-bundle` и `unic-langid` (S0 v3) добавлены `sys-locale` 0.3 (язык ОС для `auto`) и `jiff` 0.2 (даты в системной зоне; на Windows вшивает tzdb). В S2-01 обошлись без (выбор исполнителя, не решение владельца): `fluent-langneg` (выбор языка — по тегу и языковому подтегу, свои 30 строк), `arc-swap` (смена языка редкая — `RwLock<Arc<_>>`), `arrayvec`/`itoa`, `intl-memoizer` напрямую. Лицензии MIT/Apache-2.0 (`jiff` — Unlicense OR MIT), новых дублей в графе нет.
- **`ui.draft` (владелец, 2026-10-17, S2-02, ADR-0013):** целевая команда — аргумент `command` (`ui.draft command=ops.mkdir arg=name`), т.к. `cmd` зарезервирован (S3 §2.2, `valid_key` core). S2 §3 читать с этой поправкой; пресеты S3 пишут `command=`.
- **Шрифты (владелец, 2026-10-17, S2-04; пересмотр S0 v4 №3 / v3 №12):** на Windows ничего не вшиваем — всё системное: интерфейс Segoe UI Variable (→ Segoe UI + Semibold), моно Cascadia Mono → Consolas (или `[ui] font_mono` путь), иконки Segoe Fluent Icons → Segoe MDL2 Assets (все кодовые точки S2 §1.6 есть в обоих, проверено на стенде). Вшитые JetBrains Mono и подмножество Fluent System Icons — в бэклог «macOS/Linux»; там пока шрифты egui и без иконок. Причины: Windows — единственная активная платформа, запас бинаря 1 МиБ, без внешних скачиваний.
- **Размеры (владелец, 2026-10-17, S2-08):** в колонках и подвале — не больше одного знака после запятой (`1,2 КБ`, `47,1 КБ`, `977 МБ`), как в мокапах S2 §2; точные байты — в свойствах (режим Инфо, подсказка подвала). Переопределяет «3 значащие цифры» S2 §2.1/§7 и приёмку S2-01 «1 024 → 1,00 КБ» (теперь `1,0 КБ`).
- **Бинарь и даты (владелец, 2026-10-17, S2-08):** на Windows местное время ячеек — через API ОС (`SystemTimeToTzSpecificLocalTimeEx` с динамическими правилами поясов), свой мини-strftime; jiff — только Linux/macOS (системная zoneinfo). Причина: jiff на Windows вшивает базу tzdb (≈ 0,57 МиБ; бинарь был 14,71 из 15). Бюджет бинаря пересмотреть под M4 (вьювер, редактор, подсветка ≤ 2 МБ по №46).
- **Гейт размера (владелец, 2026-10-17):** бюджет бинаря 15 МиБ блокирует CI только на Windows; Linux/macOS — предупреждение (Linux release 15,51 МиБ из-за x11/wayland). Linux и macOS — нюансы фиксируем, время не тратим.

- **R-02 (рендер, после R-01, до конца M1):** реализовать №50 — опция `ui.renderer`, цепочка отката DX12→WARP, обработка device lost, баннер, запись выбранного бэкенда в лог (`startup.renderer`). Приёмка: `ui.renderer=warp` стартует и работает; эмуляция отказа DX12 (env `URFIN_FORCE_DX12_FAIL=1`, только debug) → WARP + тост; CI зелёный; `win-manual` — владелец проверяет `warp` и `dx12`.
- **R-02b (после M2):** бенчмарк DX12 vs WARP на стенде владельца — кадр при скролле 100k на 1080p/1440p/4K, CPU, RAM, задержка ввода, 80 циклов разворота; решение об умолчании.

- **GPUI-миграция (ADR-0018):** задачи G-01…G-07 — `docs/TASKS-GPUI.md`. Спеки S2/S3/S7, где упоминают egui/eframe/wgpu, читать как «GPUI» до их ревизии; противоречия решает ADR-0018.
