# S2 — Дизайн и UI: спецификация (v2, Fluent)

Статус: draft v2 (2026-10-14). Владелец: S2. Заменяет v1 (DN/Far-визуал).
Основа: specs/S1.md, S0-contracts-v2.md (ADR-0004), S0-contracts-v3.md (ADR-0006), S0-decisions.md (ADR-0005, «Принцип дизайна»).
Принцип: DN/Far — источник функций и раскладки. Визуальный язык — Windows Fluent (ориентир WinUI Gallery 3.0, вариант A «Explorer-native» с правками).
Версии крейтов сверены с crates.io 2026-10-14. Возможности egui 0.36.2 проверены по docs.rs/changelog: `FontTweak.coords` (оси вариативного шрифта), хинтинг, `subpixel_binning`, `layout_job`, `ViewportBuilder::with_transparent/with_decorations/with_fullsize_content_view/with_titlebar_shown`.

## 0. Ключевые решения

- **Решение:** раскладка в логических пикселях на сетке 4 px, а не в символьных ячейках. Все размеры берутся из токенов §1 (отступы, высоты, радиусы). Масштаб даёт `pixels_per_point` ОС.
  **Почему:** Fluent — пропорциональная типографика и плотность 24/32 px. Сетка 4 px сохраняет ритм WinUI и чёткость при 100–200 % DPI.
- **Решение:** UI-шрифт и иконки берутся из системы (Segoe UI Variable, Segoe Fluent Icons) и читаются с диска один раз при старте, до первого кадра, в отдельном потоке параллельно с инициализацией Core. Вшиты только моноширинный JetBrains Mono (OFL, терминал и hex, ADR-0006 №12) и подмножество Fluent UI System Icons (MIT, Microsoft) как свой набор иконок для macOS/Linux и Windows 10 без MDL2.
  **Почему:** лицензия Segoe запрещает вшивать. Чтение с локального диска не нарушает офлайн. Иконки MIT дают тот же визуальный язык на всех ОС, около 20 КБ.
- **Решение:** тема и акцент берутся из ОС.
  - Windows: реестр (`AppsUseLightTheme`, `AccentPalette`, `EnableTransparency`) и пересчёт по `WM_SETTINGCHANGE("ImmersiveColorSet")`. WinRT `UISettings` не используем.
  - macOS: `NSColor.controlAccentColor` и `effectiveAppearance`, перечитываются при `ThemeChanged` и получении фокуса окном.
  **Почему:** крейт `windows` с WinRT утяжелил бы сборку и бинарь. Реестр даёт ту же палитру (8 оттенков акцента), а `windows-sys` уже в графе eframe.
- **Решение:** окно без системного заголовка, табы панелей рисуются в зоне заголовка.
  - Windows: `SetWindowSubclass`. `WM_NCCALCSIZE` убирает caption, но оставляет рамку ресайза. `WM_NCHITTEST` возвращает `HTCAPTION` для пустой зоны и `HTMAXBUTTON` для кнопки «развернуть», чтобы работали Snap Layouts Win11.
  - Mica: `DWMWA_SYSTEMBACKDROP_TYPE = DWMSBT_MAINWINDOW` (Win11 22H2+, сборка ≥22621).
  - macOS: `fullsize_content_view`, прозрачный titlebar, «светофор» слева.
  **Почему:** утверждённый вид требует табы в заголовке. `with_decorations(false)` ломает Snap, тень и ресайз, поэтому нужен subclass.
- **Решение:** Mica виден только на базовом слое: зона заголовка с табами, зазоры между панелями, полосы cmdline и keybar. Панели — карточки с почти непрозрачной заливкой `layer.panel`.
  **Почему:** так делают Explorer и WinUI Gallery. Читаемость не зависит от обоев. Прозрачность не мешает перф-бюджету: панели закрывают фон, overdraw минимальный.
- **Решение:** списки по-прежнему без `ScrollArea`/`show_rows`. Строка фиксированной высоты 24 px, окно `top..top+page` поверх `Tab::row(r)`, `top` хранит core (`panel.viewport`, ADR-0006 №3). Galley кэшируются (`RowCache`), цвет подставляется при отрисовке.
  **Почему:** O(видимых строк), курсор и выделение не перестраивают текст, кадр p50 ≤3 мс, p99 ≤6 мс при 100k (§6).
- **Решение:** цифры моноширинные (tabular). При загрузке шрифта проверяется равенство advance цифр `0–9`. Если они не равны, числа рисуются «по слотам»: каждая цифра центрируется в слоте ширины самой широкой. Числовые колонки выровнены вправо.
  **Почему:** egui 0.36 не даёт включить OpenType-фичу `tnum`. Проверка и эмуляция работают для любого системного шрифта.
- **Решение:** визуальные снапшоты делаются через `Canvas`-абстракцию с двумя реализациями: `EguiCanvas` (боевая) и `RecordCanvas` (пишет список `(rect, role, text)`). Сравнение — insta-YAML.
  **Почему:** CI без GPU и без wgpu (`egui_kittest/snapshot` требует wgpu). Раскладка и тексты проверяются детерминированно при любой ширине.
- **Решение:** i18n остаётся отдельным крейтом `urfin-i18n` (ADR-0006 №8). Сырые строки в UI запрещены типом `Tx` и `clippy::disallowed_methods`. Подписи keybar — `keybar-<id>` с фолбэком на `cmd-<id>` (ADR-0006 №14).
- **Решение:** анимации Fluent (hover, раскрытие меню, нажатие) заданы длительностью 83/167 мс и включаются только при `ui.animations = true` (по умолчанию выкл). Нет мигающего курсора. Repaint только по событию.
  **Почему:** бюджет «0% CPU в простое». Стандартные кривые Fluent сохранены, их можно включить без переделки.

## 1. Токены Fluent

Значения нейтральных цветов взяты из WinUI 3 Common theme resources. В S2-05 они сверяются с `generic.xaml` WinUI 3, результат фиксируется insta-снапшотом таблицы. Цвета записаны `#AARRGGBB` при наличии альфы.

### 1.5 Чтение темы, акцента и шрифтов ОС (офлайн)

**Windows** (модуль `urfin-ui::sys::windows`, `windows-sys`):
- Тема: `HKCU\Software\Microsoft\Windows\CurrentVersion\Themes\Personalize\AppsUseLightTheme` (DWORD, нет значения → light). Сверяется с `ctx.system_theme()` от winit.
- Прозрачность: там же `EnableTransparency`.
- Акцент: `HKCU\Software\Microsoft\Windows\CurrentVersion\Explorer\Accent\AccentPalette` (REG_BINARY 32 байта). Фолбэк — `HKCU\Software\Microsoft\Windows\DWM\AccentColor` (DWORD ABGR) с расчётом оттенков в OKLCH.
- Высокая контрастность: `SystemParametersInfoW(SPI_GETHIGHCONTRAST)` → токены из системных цветов `GetSysColor` (минимальный набор), Mica выкл.
- Изменения: `WM_SETTINGCHANGE` с `lParam == "ImmersiveColorSet"` ловит subclass окна → `Msg` → пересчёт токенов (`style_epoch += 1`).
- Шрифты:
  - путь из `HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Fonts` (имя «Segoe UI Variable (TrueType)» → `SegUIVar.ttf`), затем `HKCU\…\Fonts` (пользовательские, абсолютный путь), базовый каталог `%WINDIR%\Fonts`;
  - цепочка UI: `SegUIVar.ttf` → `segoeui.ttf` + `segoeuisb.ttf`;
  - иконки: `SegoeIcons.ttf` (Segoe Fluent Icons, Win11) → `segmdl2.ttf` (Segoe MDL2 Assets, Win10, те же кодовые точки для используемого набора) → вшитый Fluent System Icons;
  - fallback для символов вне Segoe: `seguisym.ttf`, CJK по системной локали (`YuGothM.ttc` / `msyh.ttc` / `malgun.ttf`) — фоновая загрузка после первого кадра.

**macOS** (`sys::macos`, `objc2-app-kit` / `objc2-core-text` 0.3 — версии из графа eframe):
- Тема: `NSApp.effectiveAppearance.bestMatch([.aqua, .darkAqua])`, событие `ThemeChanged` winit.
- Акцент: `NSColor.controlAccentColor` → `colorUsingColorSpace(sRGB)`. Перечитывается при `Focused(true)` (смена акцента в настройках не шлёт событие в winit).
- Шрифт: `CTFontCreateUIFontForLanguage(kCTFontUIFontSystem)` → `kCTFontURLAttribute` → чтение файла (SF Pro, вариативный, `wght`/`opsz`). Путь не хардкодится.
- Иконки: вшитый Fluent System Icons (SF Symbols лицензией к шрифтовому использованию в чужом рендере не предназначены).

**Linux:** тема по winit, акцент `#0078D4`, шрифт — встроенные шрифты egui (`default_fonts`), иконки — вшитые.

Все чтения выполняются в `app::boot` до создания окна (поток `font-probe`, параллельно с `Core::new`). Внутри кадра I/O нет. Нет файла → следующий в цепочке + `ConfigWarning` только если не нашёлся ни один.

| `━━━──` | прогресс-бар 4 px (Fluent ProgressBar): `accent.fill` / `stroke.divider` |
| `┊` | граница колонок списка (не рисуется, только отступ `space.l`) |
| `─ □ ✕` | кнопки caption Windows (46×40, ✕ hover = `#C42B1C`) |

1. Заголовок с табами (40).
2. Карточки панелей (остаток, зазор 8).
3. Job-бар (0–3 × 32).
4. Баннер-промпт (0 / 48 / 120).
5. cmdline (32).
6. keybar (24).

Слои (ADR-0006 №11): терминал → панели → cmdline → оверлеи.

## 5. Шрифты и DPI

- Источник UI-шрифта и иконок — §1.5. Вшиты: `JetBrainsMono-Regular.ttf` (OFL 1.1, около 270 КБ) и `FluentSystemIcons-subset.ttf` (MIT, около 40 глифов, около 20 КБ, генерируется `xtask icons-subset` из закоммиченного исходника). Лицензии лежат в `crates/ui/assets/fonts/`.
- Семейства: `ui`, `ui-strong`, `ui-caption`, `ui-subtitle` (§1.1), `icons` (системный → MDL2 → вшитый), `Monospace` = JetBrains Mono. В конце каждой цепочки — fallback-шрифты и шрифты egui (emoji).
- Прогрев до первого кадра: `layout` строк набора символов (ASCII, кириллица, цифры, `…›˄˅`, все используемые иконки) во всех семействах. Атлас заполняется заранее.
- Хинтинг включён. `subpixel_binning` — по умолчанию egui.
- Tabular-проверка цифр (§0) выполняется на старте для `ui` и `ui-caption`.
- DPI: per-monitor `pixels_per_point` от ОС. Масштаб пользователя — `ui.zoom` (`set_zoom_factor`, `zoom_with_keyboard = false`, ADR-0006 №13). Все прямоугольники округляются к физическим пикселям (`round_to_pixel`), линии толщиной 1 физ. px.
- При смене `pixels_per_point`/`zoom_factor` (переезд окна на другой монитор):
  - `style_epoch += 1`;
  - очищается `RowCache`;
  - пересчитывается раскладка;
  - `panel.viewport` получает новое число строк.
- Ширина отображения строк — egui (проп. шрифт). Для обрезки имени используется `TextWrapping { max_width, max_rows: 1, overflow_character: Some('…') }`.

## 6. Производительность: кадр p50 ≤3 мс, p99 ≤6 мс при 100k

Требования и метод из v1 остаются. Изменения касаются только пропорционального шрифта.

1. **Виртуализация:** на панель берутся строки `top..top+page` через `Tab::row(r)`, высота строки фиксирована (24 px × ppp). `panel.viewport` отправляется только при изменении `(rows, cols, top)`. В Brief/Medium — колонки по `rows_per_col`.
2. **`RowCache`:**
   - `FxHashMap<CellKey, CellEntry>`, ёмкость 4096;
   - `CellKey { tab, gen, idx, col: u8, width_px: u16 }`;
   - `CellEntry { fp: u64, galley: Arc<Galley>, group: u8, icon: u16, last_frame: u32 }`;
   - `fp` — FxHash `(size, mtime, attrs, kind, name)` (ловит `Patch.update`);
   - на промахе: форматирование в `ArrayString<128>`, `LayoutJob` (1 секция, `TextWrapping` с `…`, цвет-плейсхолдер) → `fonts_mut(|f| f.layout_job(job))`. Аллокации только на промахе;
   - очистка: `len > 4 × visible` → `retain(last_frame ≥ frame − 2)`;
   - полный сброс по `style_epoch`, `i18n::epoch()`, смене шрифта.
3. **Отрисовка:**
   - `painter.galley_with_override_text_color` (клон `Arc`);
   - фоны строки курсора и помеченных строк, пилюля, полоса панели — `rect_filled` со скруглением;
   - иконки — общий `Arc<Galley>` на пару «глиф × цвет» (≤30 штук, кэш на `style_epoch`);
   - примерно 2 × 45 строк × 4 колонки ≈ 360 текстовых шейпов + около 100 прямоугольников.
4. **Ресайз колонки:** промах по всем видимым ячейкам имени (около 90 layout'ов коротких строк, ≤0.5 мс). Во время перетаскивания `width_px` квантуется по 4 px.
5. **Статичные строки** (keybar, заголовки колонок, меню, кнопки баннеров) резолвятся из Fluent в `UiStrings` (`Arc<Galley>`) при смене языка или стиля. Динамические (футер, job-бар) кэшируются по входам `(count, bytes, epoch)`.
6. **Mica:** окно прозрачное, но карточки панелей непрозрачны. Лишний overdraw — только зазоры, стоимость GPU незначительна. Тень оверлеев рисуется только при открытом меню или тосте.
7. **Анимации выключены**, мигания нет. Часы не показываем. Repaint — по событию или 33 мс при активных задачах.
8. **Quick search:** проход по `order` от курсора без аллокаций (ASCII — `eq_ignore_ascii_case`, Unicode — `to_lowercase`-итератор). Цель <1 мс на 100k, иначе `spawn_cpu` с Gen-guard.
9. **Бенч** (S2-20): headless `Context::run` + `tessellate`, `FakeListing` 1k/100k. Сценарии: idle, cursor down, page down, 2 активные задачи, конфликт открыт, ресайз колонки. Цели: p50 ≤3 мс, p99 ≤6 мс на стенде (release, Windows; решение 2026-10-29), в CI ≤6 мс + регрессия ≤20 %.
10. **Аллокации:** считающий `GlobalAlloc`. Стационарный кадр даёт одинаковое число аллокаций для 1k и 100k (наш код — 0). «Page down» даёт не больше числа видимых ячеек.

## 7. i18n (Fluent)

Без изменений по сути относительно v1, с поправками ADR-0006.
- **Крейт `urfin-i18n`** (листовой, ADR-0006 №8). API: `init`, `set_language`, `current`, `epoch`, `available`, `I18n::{get, attr, fmt, has, lang}`, макрос `tr!`, `fmt::{bytes, bytes_exact, count, datetime}`. Бандлы `concurrent::FluentBundle` в `ArcSwap`.
- **Ресурсы:** `crates/i18n/locales/<lang>/{ui,cmd,keybar,core,vfs,ops,term,viewer,search}.ftl` вшиты `include_str!`. Пользовательские файлы в `config_dir/i18n/<lang>/` переопределяют вшитые или добавляют язык.
- **Ключи:**
  - `ui-*`;
  - `cmd-<id>` (атрибут `.menu-key`);
  - `keybar-<id>` (короткая подпись F-клавиши, фолбэк `cmd-<id>`, ADR-0006 №14);
  - `core-*`, `vfs-*`, `ops-*`, `err-*`.
- **Язык:** `general.language` (`auto` → `sys-locale`) → `fluent-langneg` → цепочка `[выбранный, en]`. Отсутствующий ключ → `⟨key⟩` + один warn.
- **`set_use_isolating(false)`** — иначе U+2068/2069 видны в egui.
- **Числа и размеры:** `fmt::bytes` даёт КБ/МБ/ГБ/ТБ с 3 значащими цифрами по локали (ru: `47,1 КБ`, en: `47.1 KB`, основание 1024, единицы как в Explorer). `bytes_exact` — с группировкой (Инфо, подсказки). Даты: `jiff` с системной зоной; ru — `14.10.26 09:12`, en — `10/14/26 9:12 AM` (по локали ОС).
- **Плюрали:** CLDR через `fluent-bundle`.
- **Смена языка на лету** (`ui.lang`): `epoch += 1`, кэши сбрасываются.
- **Линты (CI):**
  - parity en/ru (ключи, атрибуты, переменные);
  - `keys_used` (каждый ключ из кода есть в en);
  - `commands_i18n` (каждая команда реестра имеет `cmd-<id>` в en/ru; `keybar-<id>` — для команд с F-клавишами пресетов S3);
  - `no_raw_strings` (литералы в `toast(`, `Banner{`, `PromptSpec{title/body}`, `Choice{label}`);
  - в ui — тип `Tx = Key | Args | User` и `clippy.toml` `disallowed-methods` для текстовых API egui (`Ui::label/button/heading/small`, `RichText::new`, `WidgetText::from`, `Painter::text`) вне модуля `ui::text`.

Пример `ru/ui.ftl`:

```ftl
ui-footer-selected = { $count ->
    [one] { $count } выбран · { $bytes }
   *[other] { $count } выбрано · { $bytes }
}
ui-delete-trash = В корзину { $count } { $count ->
    [one] объект
    [few] объекта
   *[other] объектов
} ({ $bytes })?
ui-conflict-head = Конфликт { $index } из { $total } · { $job }
```
`ru/keybar.ftl`: `keybar-ops-copy = Копир.` · `ru/cmd.ftl`: `cmd-ops-copy = Копировать…` с `.menu-key = К`.

## 10. Заметки для других сессий (без изменения core)

- **S3:**
  - реализует `KeyHints`;
  - пресет Far: Alt+буква → `ui.qsearch`, F9 → `ui.menu`, Shift+F6 → `ui.rename`, F7 → `ops.mkdir` (draft), Gray± → `ui.draft cmd=sel.add|sel.remove arg=mask`, Ctrl+L/T/Q → `panel.mode`, Ctrl+J → `ui.jobs.toggle`, Ctrl+O — S6;

## 11. Запросы к S0

1. **Платформенный код в ui.** Разрешить `unsafe` в `urfin-ui::sys` (по аналогии с `sys` в vfs/ops/term) и зависимости `windows-sys` (фичи §8; версия — из графа eframe), `objc2*` 0.3/0.6 (cfg(macos)), `raw-window-handle` 0.6.

3. **Вшитые ресурсы.** Зафиксировать в ADR-0006 №12 выбор S2: моно — **JetBrains Mono** (Terminus не берём, он не сочетается с Fluent). Добавить вшитый `FluentSystemIcons-subset.ttf` (MIT) в список ресурсов и в `deny.toml`/LICENSES.

## 12. Решения для владельца

1. **Как отличать курсор и помеченные (Insert) файлы.** В Far это два разных цвета, в Fluent есть «текущий элемент» и «выбранные».
   - Варианты:
     - (а) курсор — пилюля акцента + серая заливка; помеченные — галочка, акцентный текст и лёгкая акцентная заливка (как в мокапах);
     - (б) как Explorer: помеченные — акцентная заливка строки; курсор — рамка фокуса 2 px.
   - Рекомендация: **(а)**. Курсор — главный объект в двухпанельной работе с клавиатуры и должен быть заметнее выделения.
2. **Раскраска файлов по маскам по умолчанию.**
   - Варианты:
     - (а) как Explorer: обычный текст, иконки по типу, скрытые приглушены; свои правила — в конфиге;
     - (б) мягкие цвета Fluent для исполняемых, архивов, временных (наследие Far).
   - Рекомендация: **(а)**. Тип уже несут иконки, лишний цвет спорит с акцентом.
3. **Сколько Mica.**
   - Варианты:
     - (а) Mica только на «каркасе» (заголовок с табами, зазоры, cmdline, keybar), панели — плотные карточки (как Explorer/Gallery);
     - (б) полупрозрачные панели (Mica просвечивает и под списками).
   - Рекомендация: **(а)**. Читаемость не зависит от обоев, и перф-бюджет надёжнее.
