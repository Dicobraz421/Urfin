# Urfin — роадмап и протокол сессий

## Протокол
1. Каждая сессия — отдельный чат в проекте Urfin. Старт: `Ты сессия Sx Urfin. Прочитай urfin/00-ARCHITECTURE.md и urfin/Sx.md.`
2. Сессия прорабатывает свой кусок и выдаёт: spec (`docs/specs/Sx.md`) + список задач для Code.
3. S0 «Джарвис» сверяет spec с архитектурой и контрактами; при конфликте — ADR.
4. Формат задачи для Code: ID (`Sx-NN`), цель, крейт, API (вход/выход), критерии приёмки, тест/бенч, зависимости.
5. Межсессионные контракты меняются только через S0.

## Вехи
Статус на 2026-10-30 (обновляется не реже раза в неделю).
- ✅ M0 Каркас (S1): workspace, окно, bus, CI (только Windows, №57; UI — GPUI, ADR-0018).
- ✅ M1 Навигация (S2+S3+S4): две панели, табы, листинг, сортировка, базовые хоткеи.
- ✅ M2 Операции (S5): copy/move/del/mkdir/rename, очередь, job-бар, конфликты, журнал, Корзина, докачка, клон ReFS.
- ✅ M3 CLI (S6): ConPTY (поставляется рядом с exe), сеансы и shells, сетка, cmdline, Ctrl+O, интеграция pwsh/cmd/bash/WSL, синхронизация cwd, выделение и прокрутка, история и Alt+F8, автодополнение, блоки команд, Enter по файлу, win32-input-mode.
- ⏳ Хвосты M1/M2: свои колонки (S2-19, ширины в сессии — класс B), перф кадра (S2-20: PgDn и ресайз окна сверх бюджета), бенч операций (S5-25, [perf/ops.md](perf/ops.md)), экраны поиска и вьювера (D-07).
- ⏳ Фичи: F-00 политики — разбор в core готов, подключение в app/ui дальше; F-01, F-02, F-03 — каркасы крейтов и команд («ещё не сделано»), дальше — по карточкам `docs/tasks/F*`.
- M4 Вьювер (S7). M5 Поиск/архивы (S8). M6 Релиз (S9): установка через winget, Scoop, MSIX (без покупки сертификата).

## Приоритетные фичи (владелец)
| ID | Фича | Суть | База |
|---|---|---|---|
| F-01 | Анализ места (как утилиты чистки диска) | Запуск — только явной командой: Ctrl+F9 / F9 → «Утилиты» → «Анализ места…» для текущей папки или диска, без фонового подсчёта. Вкладка `du:` в панели: список по размеру с полосой доли и %, Enter — внутрь, отметка и F8 как в панели; во второй панели — прямоугольная карта текущей папки, связанная с курсором и отметкой; кольцевой нет. Фильтры: По папкам / Крупные файлы / Типы / Старые / Дубликаты (размер, хэш — по «Проверить») / Временные (только подсказка, сами не отмечаются). Сводка «отмечено N · освободится X», F8 — в Корзину по правилам и политикам. Кэш на диске (`%LOCALAPPDATA%\Urfin\state\du\`), при открытии — сразу с датой и «Обновить»; пока вкладка открыта — живые изменения (`ReadDirectoryChangesW`), при повторном открытии — дочитка USN-журнала NTFS (нужны права), без прав — перепроверка папок со сменившимся mtime. Без прав администратора — «нет доступа: N папок»; «Досчитать с правами администратора» — отдельный процесс только для чтения размеров через UAC (ADR). | `vfs.dir_size` (S4, Alt+G), DeviceGate/Bulk (S5), хэши (S5) |
| F-02 | Менеджеры пакетов | Системные менеджеры: winget, scoop, choco — найденные на машине. Ctrl+F9 → «Пакеты…», вкладка `pkg:` в панели с фильтрами Установленные / Обновления / Найти. Поиск — строка внизу «Найти пакет [..] в [Все ▾]»; «Все» — параллельно во все менеджеры, результаты группируются по программе с вариантами (менеджер, версия, издатель, источник), новейшая выделена; порядок менеджеров — в настройках (winget > scoop > choco). Установка — Enter / отметка + F5, обновить, удалить — F8; ход — job-бар, вывод — терминал по запросу; всё асинхронно. «Вне менеджера» — программы, которые видит winget, но ставил не менеджер. Проверка обновлений по расписанию — Планировщик Windows (выкл. по умолчанию), итог — баннер при запуске; приоритет — выбранные пользователем программы (winget не различает обновления безопасности). Урфин запускает менеджер как внешнюю команду, сеть ходит сам менеджер; права — UAC самого менеджера. | S6 (PTY), S5 (job-бар) |
| F-03 | SSH: файлы и терминал | **Подключение:** профили (импорт `~/.ssh/config` и сеансов PuTTY); ключи Ed25519/ECDSA/RSA, пароль, keyboard-interactive (2FA); агент OpenSSH и Pageant (KeePassXC, 1Password, Bitwarden — через агент); проверка ключа сервера по `known_hosts`; jump-host (`ProxyJump`); переподключение, keep-alive. **Пароли:** кэш в Диспетчере учётных данных — опция, отключается полностью («не сохранять пароли»; политика организации `password_cache` — ADR-0020, предложено); «команда получения пароля» в профиле с шаблонами (1Password `op`, Bitwarden `bw`, KeePassXC `keepassxc-cli`, BearPass `bearpass get`, Пассворк `passwork-cli`); SSH-ключ из записи менеджера — по той же команде в память, на диск не пишется. **Файлы:** `sftp://` в панели — F5/F6 с очередью и докачкой, F7, F8, Shift+F6, права и владелец, F3/F4 удалённых (скачать → открыть → закачать при сохранении), сравнение и синхронизация локальная↔удалённая, ссылки. **Терминал:** сеанс через системный `ssh.exe` в ConPTY; пара «панель + терминал» к одному серверу (папка по OSC 7); подсветка вывода (ERROR/WARN, пути, URL, IP, даты, хэши — только неокрашенный текст, отключается) и уровней в логах F3; **мультивыполнение** — ввод сразу в несколько сеансов (явная группа, видимая метка, подтверждение); **запись сеанса** (asciicast v2, явный старт, просмотр в F3; политики `ssh.recording`, `ssh.multi_exec` — ADR-0020, предложено). Сеть — только по явному «подключиться». Опционально (v2): **«Один вход»** — флажок профиля для серверов с 2FA: терминал по PTY-каналу соединения Урфина вместо `ssh.exe`, код вводится один раз (№94); перенаправление портов и SOCKS, «держать удалённую папку в актуальном состоянии» по явной команде. Не делаем: X11, RDP/VNC-туннели, Kerberos, диск Windows из SFTP, обфускация. | S8 фаза 3 (`urfin-net`: `russh` + `russh-sftp`), S6 (ConPTY, OSC 7), S5 (операции), S7 (подсветка, tree-sitter) |
