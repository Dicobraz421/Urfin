# Urfin — для разработчиков

<img src="../assets/icon/urfin-256.png" width="96" alt="Иконка Urfin">

Состояние, устройство, сборка и замеры. Для пользователя — [README](../README.md).

Быстрый двухпанельный файловый менеджер: функции и раскладка DN/Far, визуальный язык Windows Fluent.
Rust, UI на GPUI (gpui-kit, [ADR-0018](adr/0018-ui-gpui.md)). Только Windows 10/11 (S0-decisions №57).

**Статус (2026-11-11):** M0–M4 и F-00…F-03 (политики, анализ места, пакеты, SSH и SFTP) готовы: код в `main`. Ручные проверки задачи не блокируют ([решение 2026-11-10](decisions/2026-11-10-manual-checks.md)), их шаги переводятся в автотесты — [#688](https://github.com/Dicobraz421/Urfin/issues/688). M5 почти готов: поиск Alt+F7, архивы (ZIP, TAR и сжатые, 7z, RAR, вложенные, пароли, распаковка, проверка, меню архива) и сравнение `cmp:` — в `main`; осталась S8-37 (бенч архивов); M5b (упаковка, поиск в архивах) — после. Релиза нет, подпись exe отложена. План-график — [проект «Урфин — план-график»](https://github.com/orgs/Dicobraz421/projects/2).

## Что уже есть

Всё ниже смёржено в `main`. Ручные проверки владельца ещё впереди ([manual-tests/](manual-tests/)), задачи они не блокируют.

- **Панели.** Две панели с табами, режимы Brief / Medium / Full / Wide и свои наборы колонок (тип, расширение, время создания и доступа, атрибуты), дерево, «Сведения», быстрый просмотр; путь с переходом по сегментам; сортировка, фильтр, скрытые файлы; закладки и история; автообновление по изменениям ФС; размер папок; быстрый поиск (Alt+буква).
- **Клавиатура.** Пресеты Far и DN, свой keymap, хоткеи с буквой — на любой раскладке; раздел настроек «Клавиатура»: список с поиском, правка клавиш из интерфейса, пояснения о конфликтах и рискованных сочетаниях ([keys.md](keys.md), [COMMANDS.md](COMMANDS.md)).
- **Операции.** Копирование и перенос с очередью и job-баром, вопросы о конфликтах строкой без модальных окон, журнал прерванных операций («Продолжить» после выхода), докачка крупных файлов на сеть и USB, клон блоков ReFS / Dev Drive, быстрая Корзина, удаление, создание папок (в т. ч. дерева), переименование и групповое переименование, ссылки, атрибуты и время, сравнение и синхронизация папок. Бенч против Проводника, robocopy и `rd` — [perf/ops.md](perf/ops.md).
- **Терминал.** Встроенный терминал на ConPTY за панелями (Ctrl+O), ConPTY поставляется рядом с exe; командная строка с правкой, undo, вставкой имён из панели, автодополнением (пути, команды, история) и историей по shell (Alt+F8); интеграция PowerShell, cmd, Git Bash и WSL (bash / zsh / fish): промпт shell в командной строке, каталог панели и shell синхронны в обе стороны; выделение, прокрутка, блоки команд и поиск по выводу, ссылки OSC 8; Enter по файлу — консольные программы в сеансе, остальные через Shell; Far внутри терминала (win32-input-mode).
- **Вьювер (F3).** Текст, hex, кодировки, поиск, переход, закладки, выделение, слежение за файлом, быстрый просмотр, соседние файлы, Markdown как документ.
- **Редактор (F4).** Свой движок для файлов любого размера ([ADR-0023](adr/0023-editor-engine.md)): потоковое сохранение, поиск, замена и переход, блочное выделение, свёртка, мини-карта, панель инструментов, Markdown-команды и предпросмотр рядом.
- **Подсветка.** Только видимое окно, размер файла не важен ([ADR-0024](adr/0024-windowed-highlight.md)): JSON, TOML, INI, XML, YAML, Markdown — в exe; Rust, C, C++, C#, Java, Go, JavaScript, TypeScript, TSX, Python, CSS, Lua, Diff, CMake, Make — пакеты грамматик рядом с exe. Bash, PowerShell и HTML — только до 16 МиБ, больше — без подсветки; кусок кода без границ длиннее 16 МиБ (например, минифицированный JS) — без цвета. Точность кода сверяется с tree-sitter ночной проверкой (на PR не влияет).
- **Поиск (Alt+F7).** Экран поиска: форма на месте панели, имена и содержимое (скорость вровень с `rg`), результаты по мере обхода, предпросмотр совпадения, F3/F4; панель `search:` с результатами — файловые операции из неё, вход в папки, Esc сохраняет найденное ([perf/s8.md](perf/s8.md)).
- **Архивы.** Архив как папка: ZIP (кодировки имён, ZIP64, AES и ZipCrypto), TAR и сжатые (`.tar.gz`, `.bz2`, `.xz`, `.zst` и одиночные), путь внутрь архива, колонка «Сжато», копирование и сравнение из архива; 7z (S8-32), RAR через UnRAR (S8-34, [решение 2026-11-11](decisions/2026-11-11-rar.md)), вложенные архивы со спиллом (S8-31), пароль при входе и `arc.test` (S8-35), распаковка `arc.extract` и её строка (S8-28, S8-29), меню команд архива и запрос пароля (S8-36).
- **Сравнение `cmp:`.** Рекурсивное сравнение папок (S8-38) и панель `cmp:` с результатом (S8-39).
- **Анализ места (F-01).** Вкладка `du:` по явной команде: список по размеру, карта, фильтры (крупные, типы, старые, дубликаты, временные), кэш снимков, живые изменения, дочитка журнала USN, досчёт недоступных папок с правами администратора. Подписи нет, UAC покажет «неизвестный издатель».
- **Пакеты (F-02).** Вкладка `pkg:` для найденных winget, scoop и choco: установленные, обновления, поиск сразу во всех, установка, обновление и удаление с выводом в сеансе терминала, проверка по расписанию Планировщика (выключена по умолчанию), настройки и важные программы.
- **SSH и SFTP (F-03).** Профили, импорт `~/.ssh/config` и PuTTY, ключи, пароль, 2FA, агент и Pageant, `known_hosts`, jump-host, менеджеры паролей через команду. Панель `sftp://`: F5/F6 с докачкой, F7, F8, Shift+F6, сравнение и синхронизация, F3/F4 удалённых файлов («Сравнить» в конфликте закачки пока открывает версию на сервере). Терминал через системный `ssh.exe`, пара «панель + терминал», подсветка вывода, мультивыполнение, запись сеанса и её просмотр, настройки SSH. «Один вход» и перенаправление портов не сделаны (опция v2).
- **Политики организации (F-00).** `policy.toml` и GPO, замки в настройках; ACL папки и ADMX — с установщиком (S9).
- **Оформление.** Темы светлая / тёмная / по системе и свои, акцент Windows, палитра B (цветные иконки, акценты), настройки во вкладке (F9 → «Настройки»), интерфейс EN и RU.
- **Бюджеты** (цели, меряются на стенде в release): первый кадр < 250 мс, кадр p50 ≤ 3 мс / p99 ≤ 6 мс на 100 000 строк, смена всего экрана в документе p99 ≤ 8 мс, 0 % CPU в простое. Размер exe — гейт CI 50 МиБ.
- **Замеры** (стенд владельца, release, UI-поток на кадр, p50 / p99, мс, 2026-11-06, [perf/s2.md](perf/s2.md), [perf/s7.md](perf/s7.md)): панель 100 000 строк — листание 1,54–1,91 / 3,30–3,78, PgDn 1,86–2,30 / 3,80–4,94; редактор, лог 10 ГБ — страница 1,9–2,2 / 2,5–3,2, прыжок 2,3–2,5 / 2,8–3,5. Вне бюджета: ресайз панелей 4,76–5,09 / 7,02–8,52, прыжок в файле в одну строку (JSON 16 МиБ) 10,8–12,2 / 14,6–19,5; остальное — [#310](https://github.com/Dicobraz421/Urfin/issues/310). Exe — 44,46 МиБ (CI, release, 2026-11-11, [perf/exe-size.md](perf/exe-size.md)).

## Сборка и запуск

Нужен Rust из `rust-toolchain.toml` (rustup подтянет его сам) и MSVC Build Tools.

```bash
cargo build --workspace
cargo clippy --workspace --all-targets -- -D warnings
cargo nextest run --workspace
cargo run -p urfin-app
```

- **Переносной режим:** файл `urfin.portable` рядом с `urfin.exe` — настройки и состояние в `data\` рядом, профиль пользователя не трогается.
- **Снимки экранов без человека:** `urfin.exe --screens <каталог>` — сцены демо-дерева в PNG ([screens/](screens/)).
- **Снимки для README** — [images/](images/): сцены `screen-quickview`, `screen-editor`, `screen-searchgrep`, `screen-archive`, `screen-cmppanel`, `screen-dumap`. Демо-дерево лежит в `%LOCALAPPDATA%\Temp`; чтобы в путях не было имени пользователя, запускать с `LOCALAPPDATA` на временном диске `subst`.
- **Замер:** `urfin.exe --bench [каталог]` — кадры, CPU, память, размер; `--bench-editor <файл>`, `--bench-viewer <файл>`, `--bench-sftp` ([perf/](perf/)).
