# Бюджет кадра при смене всего экрана: p99 ≤ 12 мс

(владелец, 2026-11-05) Дополняет [бюджет кадра](2026-10-29-frame-budget.md). Замеры S7-36 (#311): страница и прыжок в редакторе — p99 6,5–13,5 мс, из них 26–32 % кадра — `shape_line` DirectWrite всех рядов заново, остальное — рисование глифов.

Решение: для полной смены экрана (страница, прыжок) бюджет — p99 ≤ 12 мс. Для нажатия, построчной прокрутки и стационарного кадра остаётся p50 ≤ 3 мс, p99 ≤ 6 мс.

Отдельный путь рисования ASCII-строк в Урфине не делаем. Вместо него — замер быстрого пути в `layout_line` форка `pets-gpui-windows` на ветке, без включения в Урфин. Форк уже наш, правится там один файл, и выигрыш получат все экраны и Postman. Запрет «правки gpui ради бюджета не делаем» пока действует: если замер подтвердит выигрыш, владелец решает отдельно, а бюджет снижается по факту. Ядро `gpui-pre` не форкаем.
