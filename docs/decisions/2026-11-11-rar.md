# S8: UnRAR подключён — `unrar` под feature `rar`, исключение в `deny.toml` только для `unrar_sys`

(владелец, 2026-11-11) На вопрос «подключать ли UnRAR: исключение в `deny.toml` только для `unrar_sys`, текст лицензии — в `THIRD_PARTY.md`» — дословно: «Да, подключать». Исполняет №37 ([S0-decisions](../specs/S0-decisions.md)) и В7 из [«s8-answers»](2026-11-06-s8-answers.md); класс B (S8-33).

- `unrar` 0.5 — под feature `rar` у `urfin-arc`; app включает `rar` в официальной сборке. Без feature `rar` крейт собирается.
- `deny.toml`: `[[licenses.clarify]]` переводит `unrar_sys` (метаданные `MIT OR Apache-2.0`, внутри — C++ UnRAR) на `LicenseRef-UnRAR`; разрешено исключением только для `unrar_sys`, общий `allow` не расширяется.
- Лицензия UnRAR: только распаковка, RAR-совместимый архиватор не делаем. Полный текст — в `THIRD_PARTY.md` в корне, там же уведомление bzip2 (`libbz2-rs-sys`, [«arc-licenses»](2026-11-08-arc-licenses.md)).
