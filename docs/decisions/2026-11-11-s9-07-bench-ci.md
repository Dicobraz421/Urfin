# S9-07: счёт инструкций в бенчах — отдельный ubuntu-job только для `core` и `keymap`

(владелец, 2026-11-11, класс B) Вопрос карточки S9-07: счёт инструкций (gungraun, бывш. iai-callgrind, на valgrind) есть только на Linux, а CI — только Windows (№57). Решено: отдельный ubuntu-job со счётом инструкций — только для платформонезависимых крейтов `urfin-core` и `urfin-keymap`.

- Частичное исключение из №57 «только Windows» ([S0-decisions](../specs/S0-decisions.md)): продукт и остальной CI остаются только Windows. Linux-job — лишь счётчик инструкций для бенчей, не сборка и не проверка продукта.
- Инструмент — gungraun или iai-callgrind (что собирается под MSRV); A/B base/head в одном job, пороги [S9 §2](../specs/S9.md). Job вне `gate` (CI ≤ 7 мин): nightly и по метке `bench`.
- Остальные крейты (`vfs`, `term`, `view`, `ui` и др.) — criterion A/B на `windows-latest` (wall-time, мягкий порог).
