# Анализ места: «Сборки и кэши», колонки по папке, очистка временных

(владелец, 2026-11-02, F01-07…F01-09; ответы на вопросы PR #263) Уточняет F01 §2.1, §2.2, §3.4, §3.5, §3.6 и v6 №1.

1. **«Сборки и кэши» — как на макете `screen-dutypes`.** В «Типах» отдельная группа для всего внутри сборок и кэшей проекта (каталоги правил «Временных» по имени: `target` Cargo, `node_modules`, `.cache`); «Код» и прочие группы — без них. Скан копит вторые суммы по типам для файлов внутри сборок; формат кэша `ver` 2, снимки `ver` 1 пересчитываются один раз (файл удаляется, открывается как «нет кэша»). Делается вместе с F01-09 «Дубликаты».
2. **Колонки схемы — `Vfs::columns(dir)`** (класс B одобрен): набор колонок зависит от папки и вида (`du:/3?f=types` — «Файлов · Доля · Размер»). UI берёт колонки только у схемы, своей подмены колонок фильтров у UI нет. Зовётся из UI-потока — без I/O. Запись — `docs/CONTRACTS.md` «Изменения».
3. **«Временные» — только внутри анализа** (как сейчас, без мини-скана вне корня), но с **удобной очисткой**: у каждой строки и раздела — кто создаёт эти файлы и что будет после удаления (безопасно / пересоздастся / потеряете X: кэш сборки пересоберётся долго, кэш браузера не разлогинит и т. п.). «Очистить всё выбранное» → подтверждение со сводкой (сколько, сколько освободится, предупреждения) → удаление в Корзину существующим путём ops (как F8), отмена. Пояснения — Fluent EN+RU, данные — в таблице правил F01 §3.5. Само ничего не отмечается: отмечает только пользователь.
4. **Подписи системных строк — как на макете `screen-dutemp`, путь серым рядом**: понятное имя крупно («%TEMP%», «Кэш Microsoft Edge»), путь от корня — вторичным цветом; F3/F8 работают по пути.
5. **Фон вместо UI-потока:** обход снимка для каталогов «Временных» на карте — задачей Runtime, не в кадре; раскладка карты больше 5000 плиток — в cpu-pool (кадр рисует прежнюю).

## Почему

- Сборки и `node_modules` на макете — главное, что занимает место у разработчика; в «Коде» они прятали собственно код.
- Колонки вида — свойство адреса, а не UI: одна точка правды для всех схем (`du:`, `sftp:`, `pkg:`).
- Мини-скан системных папок вне корня — новый I/O без явной команды; очистка внутри анализа закрывает задачу «освободить место» без него.

## Дополнение (владелец, 2026-11-02)

6. **«Отметить все» во «Временных» — всё, кроме Корзины, включая строки «потеря данных».** Риск показан в подтверждении «Очистить временные?» (сводка по последствиям, как сейчас); отдельного исключения строк с потерей данных нет. Корзину очищают в самой Корзине.
7. **Метки дубликатов — две, как на макете `screen-dudups`** («✓ совпадает по хэшу» / «только размер»): группа после частичного хэша показывается как «только размер», третьей метки нет. Без изменений.
