# Поле `Location.authority` для сетевых ФС

(владелец, 2026-11-01) В `Location` есть поле `authority: Option<CompactString>` — сервер сетевой схемы; у `sftp` это имя профиля (F03 №1, S0 v6 №20). Строковая форма — `backend://authority/path`: `sftp://srv1/var/www` совпадает с показом URI (№87). В authority экранируются `%`, `>` и `/`. `parent` не выходит за корень сервера: `..` из `sftp://srv1/` некуда. У `local` и контейнеров — `None`; `//` в uri `local` по-прежнему путь.

Заменяет временную запись профиля первым компонентом пути (F03-04). Дети и соседи (`child_loc`, `vfs::walk::child`, вьювер) наследуют authority. Класс B (контракт core «Entry и пути»), отдельной волной.
