# Сборки — с машины владельца в облако: облачные сессии и снимки в CI

(владелец, 2026-11-11, «делай вариант А») Машина владельца слабая: два-три агента со своими `target` доводили диск до 0 МБ и занимали процессор. Разработку разгружаем так:

- **Задачи без окна** идут в облачных сессиях Claude Code (Ubuntu, 4 ядра / 15 ГБ / 30 ГБ; расход — в счёт подписки, отдельной платы за машину нет) — в тех крейтах, которые там проверяются. Агент делает `cargo fmt --all --check`, `cargo check`/clippy своего крейта с `--target x86_64-pc-windows-msvc` и nextest своих тестов, если крейт собирается под Linux. Всё остальное — CI на Windows (`gate`).
- **Что проверяется в облаке**: в окружении по умолчанию check под Windows проходят только `core`, `i18n`, `keymap`, `vfs`, `search`, `ops`, `pkg`, `term`, `testdata` — C-зависимостям остальных нужны заголовки Windows SDK. Владелец (2026-11-11, «Да, готовь») решил их поставить и принял лицензию Microsoft: создано окружение **Urfin** (`scripts/cloud/env-setup.sh`, xwin), в нём check проходит весь workspace. Тесты под Linux — только `core`, `keymap`, `i18n`.
- **Снимки сцен** делает CI: задача `screens` на каждом PR (dev-сборка, программная отрисовка WARP), PNG — артефактом `screens`. Локальный `--screens` — только когда вёрстке нужно много кругов подряд.
- **На машине владельца остаются**: замеры (release, числа привязаны к стенду), ручная проверка (exe — из артефакта `urfin-Windows` сборки main, не собирать), задачи с интерфейсом, которым нужны частые снимки. Локально — не больше одного агента со сборкой.
- **Уборка**: после слияния агент удаляет свои `target` и рабочую копию; устаревшие сборки (никто не трогал несколько дней) можно удалять без вопроса.

Дополняет решение 2026-11-02 «Проверки — на CI»: строка «снимки `--screens` затронутых сцен dev-сборкой (CI их не делает)» больше не действует. `screens` не входит в `gate`: сбой снимков слияние не блокирует.

## Почему

- Полная проверка и release уже шли в GitHub; локально оставалась только компиляция у агентов — её и выносим.
- Платный Managed Agent (2026-10-29…11-01) закрывал то же, но за отдельные деньги (~$66 за день); облачные сессии идут по подписке.
- Цена: ошибка, видимая только на Windows, всплывает в CI — лишний круг 7–9 минут вместо локальной сборки.
