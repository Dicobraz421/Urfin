# Лицензия — проприетарная

(владелец, 2026-11-11)

1. Код Урфина — проприетарный: «все права защищены», файл `LICENSE` в корне. Использовать, копировать, менять и
   распространять код без письменного разрешения правообладателя нельзя; коммерческие лицензии — отдельным договором.
2. В `Cargo.toml` — `license = "LicenseRef-Proprietary"`; в `deny.toml` она разрешена для своих крейтов.
   Политика лицензий зависимостей не меняется.
3. Версии, опубликованные до 2026-11-11 под MIT / Apache-2.0, остаются под прежней лицензией.
4. Чужие компоненты — по своим лицензиям (`THIRD_PARTY.md`).
5. Подпись SignPath Foundation (S0 №42) — только для открытого кода, больше не подходит; подпись кода —
   отдельным решением.

Заменяет «Лицензия: MIT OR Apache-2.0» (`docs/00-ARCHITECTURE.md`, S1 §3) и S0 №42.
