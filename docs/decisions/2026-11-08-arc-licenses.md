# S8: лицензии декодеров архивов в `deny.toml`

(владелец, 2026-11-08) Дополняет [«s8-answers»](2026-11-06-s8-answers.md): кроме `unrar_sys` (S8-33) в `deny.toml` — два точечных исключения для зависимостей S8-20.

- `libbz2-rs-sys` → `bzip2-1.0.6`: bz2-декодер на Rust, нужен bzip2 в zip, 7z и tar.bz2 (бэкенд включает feature `bzip2` у zip). Лицензия BSD-подобная, требует сохранить уведомление.
- `ppmd-rust` → `MIT-0` (крейт `CC0-1.0 OR MIT-0`): PPMd в zip и 7z (S8-32).
- Исключения только на эти крейты; общий список `allow` не расширяется.
