# Гейт `urfin.exe` — 50 МиБ

(владелец, 2026-11-11, класс B) На вопрос «Размер urfin.exe уже 44,46 МиБ при гейте 45 МиБ… Поднимаем гейт?» — дословно: «До 50 МиБ». Исполняет №80 ([S0-decisions](../specs/S0-decisions.md)): бюджет растёт вместе с функциями.

- Факт после S8-33 (#699): 46 620 672 Б = 44,46 МиБ; RAR (S8-34) даст ≈ +0,26 МиБ. Впереди 7z, вложенные архивы, M5b.
- Гейт — `LIMIT_MIB = 50` в `ci/size.py`; аргумент из `ci.yml` гейт не опускает. Замеры — [`docs/perf/exe-size.md`](../perf/exe-size.md).
- Обновлены CONTRACTS, `00-ARCHITECTURE.md`, `DEV.md`. Библиотеки ради размера по-прежнему не патчим.
