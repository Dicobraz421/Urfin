# S8: Esc сохраняет найденное, вход в папки из `search:`

(владелец, 2026-11-08) Уточняет [S8 §2.4–§2.5](../specs/S8.md#25-ux-и-команды) и поведение S8-06.

- **Esc на экране поиска отменяет поиск, найденное сохраняется.** Alt+F7 из обычной панели возвращает последний поиск: его запрос в форме и найденное (пока стор не вытеснен из недавних: 8 поисков, 64 МиБ). Новый запрос + Enter — новый поиск, прежний уходит в недавние. Ctrl+Break на экране — стоп без закрытия.
- **Класс B одобрен: правка core для `search:`.** У корня `search:/<id>` нет `..` (как у `du:`, `pkg:`). Enter и двойной клик по папке в виртуальной схеме ведут в настоящую папку: `OpenResolver::enter_dir`, резолвер регистрирует крейт схемы (`Core::add_open_resolver`); пригодится `cmp:` (S8-38).
