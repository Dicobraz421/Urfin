# Подсветка: CDATA по спецификации, ошибка — локально; свёртка списков и цитат Markdown

(владелец, 2026-11-02) Ответы на вопросы после S7-41 (#278, [ADR-0024](../adr/0024-windowed-highlight.md)).

1. **CDATA в XML** красится по спецификации XML: секция кончается на первом `]]>`, в том числе в `]]]>` и в пустой `<![CDATA[]]>`. Сканер `tree-sitter-xml` здесь ошибается (тянет секцию до следующего `]]>` в файле) — его ошибку не повторяем. Дифференциальные тесты против tree-sitter такие документы пропускают (`testkit::oracle_bug`) — разрешённое исключение: оракул неверен, верна спецификация.
2. **Синтаксически неверные файлы**: ошибка держится локально — как сейчас в лексерах окна (незакрытая строка JSON кончается на переводе строки и т. п., ADR-0024 §6 п. 5). Поведение полного разбора tree-sitter «перекрасить всё ниже ошибки» не повторяем и истиной не считаем.
3. **Свёртка Markdown**: кроме разделов заголовков и ограждённого кода — списки и цитаты:
   - пункт списка любого уровня, если с вложенным содержимым он больше строки;
   - весь список верхнего уровня (место — на первом пункте);
   - цитата `>` (и вложенная `> >`), если больше строки.

   Небольшая задача — сделана той же волной (S7-41, `syntax/lex/md/nest.rs`).
