# S8: страница и прыжок на экране поиска — бюджет смены всего экрана

(владелец, 2026-11-08) Ответ «Вариант а» на вопрос #345. Уточняет F6 в [S8 §2.7](../specs/S8.md).

Страница и прыжок в списке найденного (1M строк) — полная смена экрана: бюджет p99 ≤ 8 мс ([решение 2026-11-06](2026-11-06-dwrite-fast-path.md)). Нажатие, построчная прокрутка и стационарный кадр — p50 ≤ 3 мс, p99 ≤ 6 мс, как раньше.

Замер #350: страница p99 4,79–5,32, прыжок p99 4,26–5,06, строка p50 2,80–3,01 / p99 3,86–4,07 мс — F6 выполнен. Правки gpui ради p50 страницы не делаем.
