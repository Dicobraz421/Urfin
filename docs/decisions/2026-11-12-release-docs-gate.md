# Выпуск — только после полной сверки документации (гейт)

Владелец, 2026-11-12 (одно решение для Pets: Postman, Урфин, скилл pets-dev). Документы должны догонять код к каждому
выпуску, а не по случаю: в Postman после трея инструкция и страница выпуска ещё говорили «закройте программу».

- **Гейт выпуска:** тег `v<версия>` публикуется, только если в его коммите есть `docs/releases/<версия>.md` — сверка
  всей документации: каждый документ отмечен `[x]` и с итогом («обновлено: что, PR» или «без изменений»).
- **Какие документы:** все `*.md` в корне и в `docs/` (без подкаталогов), `ci/dist-readme.txt` (README.txt архива),
  `ci/release-notes.md`, `scripts/*/README.txt`. Новый документ гейт требует сам. Генерируемые (`docs/COMMANDS.md`,
  `docs/keys.md`) — пересобрать до тега, в сверке — «пересобран».
- **Проверка:** job `docs-gate` в `release.yml` (`ci/release_docs_check.py` — копия pets
  `skills/pets-dev/templates/release_docs_check.py`); `publish` его ждёт.
- **Порядок:** `docs/README.md` «Выпуск», шаблон — `docs/releases/TEMPLATE.md`.
