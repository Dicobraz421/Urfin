# Полоса прокрутки в редакторе — всегда

(владелец, 2026-11-02) Ответ на вопрос волны S7-33: на макете `screen-editor` полосы прокрутки не было, и экран редактора на движке (#258) вышел без неё — навигация мышью шла только по мини-карте, которая на длинном документе показывает лишь окно строк вокруг видимой части.

Решение: у редактора, как у вьювера, всегда есть полоса прокрутки 14 px справа от мини-карты — для файлов любого размера и при выключенной мини-карте (`editor.gutter = false`). Бегунок — видимая доля документа по байтам (как во вьювере на больших файлах), метки — совпадения поиска (`EdSearch::marks`), клик выше или ниже бегунка — страница, перетаскивание бегунка — `InboxMsg::ScrollTo` по всему документу, без чтения файла целиком.

Макеты: `screen-editor`, `screen-editreplace` (метки совпадений и на полосе), `screen-editgoto`, `screen-editor-md` (полоса — у исходника, перед предпросмотром), `screen-sftpedit`; `DESIGN.md` — строка `screen-editor.png`.

Почему: мини-карта — обзор текста рядом с курсором, а не навигация по документу на 10 ГБ; полоса — единый способ «прыгнуть в любое место» во вьювере и редакторе, метки поиска на ней видны по всему документу.
