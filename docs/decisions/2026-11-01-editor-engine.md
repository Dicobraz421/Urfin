# Редактор — свой движок для файлов любого размера

(владелец, 2026-11-01, класс B) «Подумай как сделать частичную обработку файла, чтобы не жрать память и при этом работать с любым размером» → выбран вариант «Свой движок для всех»: встроенный редактор (F4) для **любого** размера файла строится на собственном движке в `urfin-view` поверх частей вьювера (источник, кэш страниц, индекс строк, раскладка, поиск). `EditorState` gpui-kit из редактора уходит; лимит `editor.max_size_mb` снимается.

Суть ([ADR-0023](../adr/0023-editor-engine.md)): файл читается страницами и не меняется до сохранения; правки — piece table на персистентном дереве; текст правок — в кодировке документа; отмена — журнал операций; сохранение — потоком во временный файл и `ReplaceFileW`; большой файл на время правки закрыт для записи другим программам. Память на документ ≤ 64 МиБ при любом размере.

Почему: спайк S7-16 (`docs/perf/s7.md`) — `EditorState` держит весь текст в памяти (≈ 9–10 МБ на МБ текста) и замирает UI ≈ 15 мс на МБ при передаче текста; вьювер на своих частях открывает 100 ГБ за ≈ 1 мс.

Заменяет: ADR-0018 в части «редактор на gpui-kit» и решение 2026-10-30 «M4» №1 (текст редактора в UI). Контракт `ViewInbox`/команд редактора — предложение в ADR-0023 §9, строка CONTRACTS меняется в PR карточки S7-29.

Отвергнуто: два режима (gpui-kit до 16 МБ + свой для больших) — два редактора на поддержке, переход границы во время правки; патч gpui-kit в pets — память не уходит, 10 ГБ не открыть.

## Ответы (владелец, 2026-11-01, PR #243)

1. **Кодировка внутри** — как в файле (§3), не UTF-8.
2. **Большой файл (> 16 МиБ)** закрывается для записи другим программам **сразу при открытии** (§8 п. 2); пишущийся файл — «Править копию» (п. 3).
3. **История отмены** держится всегда, в том числе после сохранения больших файлов (§4): место старой версии на диске освобождается при закрытии документа.
4. **Подсветка** — только документы ≤ 16 МиБ, больше — без подсветки (§7); «по окнам» — нет.
5. **Блочное выделение — в M4** (Alt+Shift+стрелки и Alt+мышь, как в Far; §7, карточки S7-40/S7-40a); **мультикурсор — после M4**.

Контракт ADR-0023 §9 одобрен этими ответами (класс B).
