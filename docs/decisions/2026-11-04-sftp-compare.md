# «Сравнить» в конфликте закачки — пока вьювер версии на сервере

(владелец, 2026-11-04) Кнопка «Сравнить» в строке конфликта закачки (F03-08, #296) пока открывает вьювер на текущей версии файла на сервере.

- Строка конфликта остаётся; после Esc — снова «Перезаписать» / «Отмена».
- Настоящее сравнение двух версий — отдельной карточкой, когда в Урфине появится сравнение файлов.
