# Linux — вторая платформа (tier 2), выпуск AppImage + deb + rpm

(владелец, 2026-11-12) Урфин собирается и под Linux. Отменяет S0 №57 «Только Windows» в части Linux; macOS по-прежнему не собирается.

- **Статус — tier 2** до конца этапа «Запускается» (карточки `L2-*`): Linux собирается и тестируется в CI, ручной приёмки нет, задача CI для Linux не входит в `gate`. Потом статус пересматривается.
- **Окно и отрисовка** — штатный `gpui-pre-linux` (Wayland и X11, wgpu); под отдельные оконные менеджеры ничего не пишем. Системная интеграция — стандарты freedesktop (корзина, portal, `xdg-open`, inotify, UDisks2) в модулях `sys`.
- **Вид** — Fluent как на Windows; из системы берём только тёмную/светлую тему и акцент.
- **Выпуск** — AppImage, deb и rpm (x86_64); Flatpak не делаем: песочница мешает файловому менеджеру.
- **Бюджеты** производительности и размера на Linux — предупреждение, не блокируют.
- **Ручная проверка** — отложена: стенда с Linux нет, появится — проверим (GNOME Wayland, KDE).

## Почему

- Замер 2026-11-12 (нативный `cargo check` в облачной сессии): `core`, `keymap`, `i18n`, `search`, `testdata` собираются; `vfs` — 2 ошибки, `arc` — 2, `ops` — 14, `term` — 12 (нет PTY для unix); `view`, `pkg`, `net`, `ui`, `app` — за `term`, не измерены.
- Патчи Pets в `gpui-pre-windows` (кадры по запросу, старт без чёрного кадра, быстрый путь текста, перетаскивание из окна) на Linux не действуют — отсюда бюджеты без блокировки.
- Этапы: `L1-*` «Собирается», `L2-*` «Запускается»; дальше — родное для Linux (корзина по томам, inotify, монтирование, права, apt/dnf/pacman) и выпуск, карточки после замера `L1-07`.
