# Пакеты: дубли в «Обновлениях» и первая проверка без кэша

(владелец, 2026-11-02, F02-08…F02-10; ответ на вопрос PR #262) Уточняет F02 §2.4 и §2.5.

1. **Дубли в «Обновлениях» — только свой менеджер.** Если программу ведёт choco или scoop, а `winget upgrade` видит её же с источником, в «Обновлениях» остаётся строка менеджера, который ведёт программу (choco/scoop); дубль winget скрыт — как в «Установленных», где запись winget без источника сводится в строку choco/scoop. «Та же программа» — общий псевдоним имени или хвоста Id (§2.4).
2. **Первое открытие без кэша — проверка запускается сама.** При старте Урфина менеджеры не спрашиваются; при первом открытии вкладки `pkg:`, когда `state/pkg/cache.json` ещё нет, проверка идёт сразу; дальше — только по Ctrl+R.

## Почему

- Одна программа — одна строка обновления: обновлять её должен тот менеджер, который её ставил; второй «Обновить» через winget сломал бы учёт choco/scoop.
- Пустая вкладка без кэша ничего не говорит; фоновых запросов при старте по-прежнему нет.
