# Мерж без approve на GitHub

(владелец, 2026-10-26) Требование «Require review from Code Owners» в правилах main снято (Urfin, pets; в Postman его не было). Все PR мержатся очередью на зелёном `gate`. Класс B (контракты, решения, ADR) — согласие владельца в чате до PR, без кнопки на GitHub.

Заменяет в решении 2026-10-24 «класс B — с approve владельца». Мержить и пушить могут только аккаунты с правом записи (владелец, бот); прямой пуш в main закрыт, `gate` обязателен.
