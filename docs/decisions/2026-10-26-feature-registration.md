# Фичи окна регистрируются в своих модулях (ADR-0022)

(владелец, 2026-10-26) ADR-0022 принят: фича окна — модуль с `trait ShellFeature`, команды `ui.*` — handler на фичу, сцены `--screens` — в модуле фичи, флаги app — таблица; общие списки — по строке на фичу. Цель — меньше конфликтов параллельных волн в `gpui_shell/mod.rs`, `handler.rs`, `screens.rs`, `app/main.rs`. Межкрейтовые контракты не меняются.

Следствия:
- волна полосы `ui`: карточки `A22-01…A22-04`;
- новые фичи окна пишутся сразу по ADR-0022.
