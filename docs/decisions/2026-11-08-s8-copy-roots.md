# S8: F5 и F6 из поиска по нескольким корням — под имя корня

(владелец, 2026-11-08) Уточняет В2 А из [«s8-answers»](2026-11-06-s8-answers.md) для S8-12.

- **Вариант Б.** При нескольких корнях поиска F5 и F6 кладут файл под имя его корня: `C:\Dev\core\src\lib.rs` и `C:\Dev\ops\src\lib.rs` → `core\src\lib.rs`, `ops\src\lib.rs`. Раньше корень отрезался, и одинаковые пути разных корней сталкивались в назначении. При одном корне — как было: путь от корня.
- **Имя корня** — последняя часть его пути. Части — буква диска (`D`) или сервер и шара UNC, затем папки. Если имена совпадают, берётся ещё одна часть слева, пока не станут разными: `C:\a\src` и `D:\b\src` → `a\src`, `b\src`; `C:\x\src` и `D:\x\src` → `C\x\src`, `D\x\src`. Корень-диск `D:\` → `D`. Регистр не различается. Имя корня не может быть началом имени другого корня: `D:\a` рядом с `a\src` с другого диска → `D\a`. Вложенный корень (`C:\a` и `C:\a\src`) — та же папка, имена не растут; файл относится к самому длинному корню.
- В назначении — только обычные папки, за его пределы путь не выходит. F8, Shift+F8, Shift+F6 и атрибуты не меняются.
