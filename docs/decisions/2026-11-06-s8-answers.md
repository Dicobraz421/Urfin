# S8: ответы на вопросы §10, данные экрана в core, UnRAR, сравнение

(владелец, 2026-11-06, класс B для S8-00 и S8-01) Ответы на вопросы [S8 §10](../specs/S8.md#10-решения-для-владельца).

- **В1 — А.** Данные экрана поиска и архивов — `urfin_core::search`, `urfin_core::arc`. `urfin-ui` не зависит от `urfin-search`, `urfin-arc`, как у подключений и пакетов ([«net-model-core»](2026-11-02-net-model-core.md), [«pkg-model-core»](2026-11-03-pkg-model-core.md)).
- **В2 — А.** F5 и F6 из результатов поиска сохраняют относительную папку.
- **В3 — А.** В форме только поля макета, остальное — `[search]` в конфиге и аргументы команды.
- **В4 — Г.** Макет панели сравнения рисуем после S8-11, поверх готовой панели поиска (карточка D-12), затем собираем S8-38 и S8-39. `ops.compare { recursive }` и `cmp:` остаются в контракте. Функция остаётся в M5a.
- **В5 — А.** Список недоступных папок, `arc.commands` и запрос пароля собираем из готовых элементов.
- **В6 — А.** Поиск не занимает очередь устройств.
- **В7 — Б.** `unrar` берём, в S8-33 сверяем историю исправлений, при исправлениях памяти — свой форк `unrar_sys`.
- **В8 — отказ.** Сравнение двух файлов (diff) не делаем, отдельной фичи и карточки нет. Кнопка «Сравнить» в конфликте закачки остаётся вьювером версии на сервере. Это отменяет фразу «настоящее сравнение двух версий — отдельной карточкой» из [решения 2026-11-04](2026-11-04-sftp-compare.md).

Подтверждено:

- Зависимости карточек S8-00, S8-20, S8-33, S8-47. Исключение в `deny.toml` — только для `unrar_sys`.
- Контракты S8-01 и S8-21.
- CONTRACTS: запрет адресов с `outer` в `Engine::Vfs` остаётся только на запись, читать через `Engine::Vfs` можно. Это уточняет [решение «vfs-write»](2026-11-04-vfs-write.md).
- CONTRACTS: устаревшая строка «бинарь ≤ 30 МБ» заменена актуальным гейтом 45 МиБ.

Бюджеты поиска по замерам #335 (владелец, тот же день):

- Память: 1M попаданий ≤ 110 МиБ — только для поиска по имени с короткими путями. Для текстового поиска — около 240 МиБ: `Hit` 104 Б плюс фрагмент, замер 224 МиБ на весь процесс. Ужать `Hit` вернёмся, если на настоящих данных будет тесно.
- F4 «все кодировки»: кириллица без учёта регистра 2,0× F3 при бюджете ≤ 1,5× — известное отклонение, оптимизацию не делаем. Остальные режимы F4 в бюджете.
