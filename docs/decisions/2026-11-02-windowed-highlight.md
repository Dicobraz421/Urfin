# Подсветка — только видимое окно, для файлов любого размера, без неточностей

(владелец, 2026-11-02) Ответ на вопрос S7-35 о пороге подсветки (полный разбор tree-sitter на 16 МиБ: цвета после правки 0,2–3 с, дерево 0,6–0,8 ГБ): подсветка в редакторе и во вьювере — «как сам редактор: только видимый кусок», для файлов **любого размера**. «Никаких неточностей быть не должно» — в том числе для структуры (JSON на много экранов) и для строк и комментариев, начавшихся далеко выше экрана.

Суть ([ADR-0024](../adr/0024-windowed-highlight.md)): фоновый лёгкий проход по файлу хранит контрольные точки состояния (каждые 64 КиБ, ≈ 6 МБ на 10 ГБ); окно красится от ближайшей точки. JSON, TOML, INI, XML — свои лексеры; YAML и Markdown — tree-sitter по отрезку от «безопасной» строки, с которой разбор не зависит от текста выше. Точность — дифференциальные тесты против tree-sitter + `highlights.scm`. После правки на экране только доказуемо верные цвета, остальное — без цвета до нового окна (единицы мс). Свёртка — из тех же точек.

Заменяет: ответ 4 решения [2026-11-01 «Редактор — свой движок»](2026-11-01-editor-engine.md) («подсветка только ≤ 16 МиБ, по окнам — нет») и ADR-0023 §7 в части подсветки. Пакетные языки — пока по-прежнему (полный разбор ≤ 16 МиБ), перевод на окна — следующей волной.
