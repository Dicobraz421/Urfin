# Размеры 100–1023 Б — в байтах, «0,3 КБ» в макетах — дефект

(владелец, 2026-11-11) Расхождение из D-07 (#694): макеты показывали «0,3 КБ», «0,5 КБ», S2 §2.1 и код — «307 Б». Решено в пользу спеки и кода.

- Размер `< 1024` — в байтах («307 Б», «512 Б», «1023 Б»), от 1024 — КБ/МБ/ГБ с 3 значащими цифрами ([S2 §2.1](../specs/S2.md)). Код не меняется.
- `window.dc.html` поправлен: все размеры < 1 КБ из «0,N КБ» — в байты (поиск, архив, SFTP, SSH). Снимки `screen-archive`, `-searchpanel`, `-sftpcopy`, `-sftpsync`, `-sshpair` перерисованы `scripts/design/render_screens.py`.
- Там же, в пользу кода (D-07 #694, S8-26 #696): на `screen-searchpanel` отмечены 3 строки — статус «Выделено 3 из 23 · 2,6 КБ» вместо «0 из 23».
