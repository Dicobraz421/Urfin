# Markdown во вьювере — документ; панель инструментов в редакторе

(владелец, 2026-10-30, класс B) Спека — [S7 §3.10, §5.8, §5.9](../specs/S7.md), макеты — `screen-viewer-md.png`, `screen-editor.png`, `screen-editor-md.png`, правила — DESIGN.md «Панель инструментов редактора» и «Markdown-документ».

## 1. Markdown во вьювере — настоящий документ

Режим «Разметка» для `.md` (язык Markdown, файл ≤ 16 МБ) показывает документ, как GitHub или Typora:
- пропорциональный шрифт (Segoe UI Variable 14), заголовки H1–H6 крупнее, жирный, курсив, зачёркнутый, ссылки;
- списки, в том числе задачи `[ ]` / `[x]`; цитаты; таблицы; блоки кода моноширинно на подложке; горизонтальная черта;
- картинки из локальных файлов (путь — относительно `.md`). Сетевые картинки не грузятся (офлайн): на их месте плашка с alt-текстом.

Разбор — свой, на pulldown-cmark (крейт берётся через полосу deps, карточка S7-00b). Режим не ждёт tree-sitter и S7-21. Если файл больше 16 МБ, режим недоступен, как и сейчас. Для других языков «Разметка» по-прежнему означает подсветку S7-21. Переход к смещению, Hex-поиск и байтовое выделение работают через режим «Текст». F7 ищет по видимому тексту документа (ответ 1 ниже).

Заменяет «чистый Markdown» из прежнего S7 §3.4 (маркеры `#` скрыты, `•` вместо `-`, моноширинно) и из карточки S7-21.

## 2. Панель инструментов в редакторе

Под шапкой редактора идёт строка кнопок высотой 36 в стиле Fluent. Значки — Segoe Fluent Icons, как во всём окне. Каждая кнопка вызывает команду; подсказка показывает название и клавишу.
- **Всегда:** Сохранить, Отменить, Вернуть, Найти, Заменить, Перенос, Кодировка, Конец строки.
- **Для `.md` добавляются:** Жирный, Курсив, Заголовок (меню H1–H3), Список, Нумерованный, Задача, Ссылка, Код, Таблица и переключатель «Предпросмотр рядом». Предпросмотр стоит справа от текста, рендер тот же, что во вьювере, прокрутка синхронная.
- Панель выключается в настройках, раздел «Редактор» (`editor.toolbar = true` по умолчанию).

Кодировка и конец строки — кнопки со значением («UTF-8 ▾», «LF ▾»), как чип кодировки во вьювере. Пока панель видна, этих значений нет в строке состояния; если панель выключить, они возвращаются туда. Это правило «одна информация — одно место» (S0 №61).

## Ответы владельца (2026-10-30, S7 §13)

1. **F7 в документе** — ищет по видимому тексту документа, как браузер и Typora: совпадения подсвечиваются прямо в документе, «3 из 12», Регистр / Слово / Регулярное. Hex-поиск недоступен; он и Alt+F8 переключают в «Текст».
2. **Внешние ссылки** (`http(s)`, `mailto`) — Ctrl+клик открывает их программой Windows (браузер, почта). Сам Урфин в сеть не ходит, офлайн-правило не нарушено. Простой клик ничего не открывает, только показывает подсказку «Ctrl+клик — открыть в браузере».
3. **HTML в `.md`** — небольшой набор тегов сразу в первой версии документа (S7-22), а не отдельной карточкой позже:
   - `<br>` — перенос строки;
   - `<img src width height alt>` — картинка заданного размера, только из локальных файлов; сетевая — плашка, как у обычных картинок;
   - `<details>` + `<summary>` — раскрываемый блок (свёрнут, пока не нажать; `open` — раскрыт сразу);
   - `align="center"` / `"right"` у `<p>` и `<div>` — выравнивание блока;
   - `<kbd>` — клавиша, `<sub>` / `<sup>` — нижний и верхний индекс.

   Прочие теги показываются текстом, моноширинно, как и раньше. Скриптов, стилей и сети нет.
4. **Отстающие макеты** — перерисованы: `screen-viewer` (активен «Текст»), `screen-settings-viewer` («Markdown: Документ | Исходник»), `screen-settings-editor` («Панель инструментов»), `screen-editreplace` и `screen-editgoto` (с панелью).

## Почему

- `.md` в репозиториях и заметках читают как документ. Моноширинный «чистый» вид не показывает таблицы, картинки и ссылки, а это главное в README и CHANGELOG.
- Свой разбор, а не tree-sitter: документ нужен уже в M4, а грамматики и пакеты (S7-21a) идут последними. pulldown-cmark потоковый, отдаёт смещения в исходнике (нужны для синхронной прокрутки, позиции в истории и перехода в Текст) и быстро разбирает 16 МБ.
- Панель инструментов — для тех, кто не помнит клавиш Far. Markdown-кнопки и предпросмотр дают в редакторе привычную по GitHub и Typora правку README.

## Отвергнуто

- **Чистый Markdown моноширинно** (прежний §3.4). Таблицы, картинки и ссылки не видны, по сути это та же подсветка исходника, а она уже есть в «Разметке» через S7-21 (`viewer.markdown = "source"`).
- **Панель без Markdown-кнопок** (только общие команды). Тогда правка `.md` осталась бы без помощи, хотя это самый частый документ в репозиториях.
- **Панель во вьювере.** Вьювер только читает: режимы, кодировка и перенос уже есть в шапке и в keybar, а вторая строка кнопок отнимает высоту у текста.
- **`markdown` 1.0 (уже в дереве через gpui-kit) и `TextView` gpui-kit.** Они строят полный AST: для 16 МБ это большая память и разбор медленнее потокового. Вид у них свой, а нам нужны роли нашей темы, свои картинки (офлайн) и свои смещения для синхронизации.
