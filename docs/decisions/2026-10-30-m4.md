# M4: ввод редактора, подсветка, unsafe во view

(владелец, 2026-10-30)

1. **Ввод редактора (S7 §11 B1).** Текст, нажатия, undo и IME — в `EditorState` gpui-kit в UI. В core через `ViewInbox` идут только события документа: текст принят, изменён, снимок для сохранения. `editor.input` не регистрируется. CONTRACTS «Ввод и клавиатура» исправлен.
2. **Подсветка (S7 §11 B2, уточняет №53).** В exe — только конфиги и разметка: JSON, TOML, YAML, INI, XML, Markdown; гейт exe остаётся 30 МиБ. Остальные языки — пакеты грамматик в папке рядом с exe (в дистрибутиве, офлайн), грузятся по требованию. Формат пакета (`.wasm` через рантайм tree-sitter или нативная библиотека) выбирает S7-21a по замеру: рантайм wasmtime сам весит несколько МиБ, его берут, только если общий итог лучше. Плагины S10 (№48) — отдельно.
3. **`unsafe` в `urfin-view::sys`** (S7-02 mmap, S7-17 `ReplaceFileW`) — разрешено.
4. Поиск F7 в редакторе и вьювере — ряд «Найти» внизу, как на макетах; строка DESIGN правится в D-07.
