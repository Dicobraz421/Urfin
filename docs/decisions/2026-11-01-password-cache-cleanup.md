# Уборка кэша паролей при `password_cache = false` — разрешённое исключение

(владелец, 2026-11-01) При политике `password_cache = false` Урфин один раз на старте перечисляет записи Диспетчера учётных данных с префиксом `Urfin/ssh/` и удаляет их (`Vault::purge_if_forbidden`, F03 §2.5, §7 №2). Это разрешённое исключение из правила «при выключенной политике Урфин не пишет в Диспетчер и не читает из него»: других обращений к хранилищу при такой политике нет — ни чтения паролей, ни записи, «Запомнить» показан с замком.

Почему: иначе пароли, сохранённые до включения политики, остались бы в Диспетчере навсегда. Перечисление идёт по префиксу Урфина, значения паролей не читаются.
