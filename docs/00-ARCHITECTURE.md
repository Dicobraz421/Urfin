# Urfin — архитектура (ведёт S0 «Джарвис»)

Обновлено 2026-11-11 (по факту в `main`; M4 и F-00…F-03 готовы, M5 в работе, релиза нет).

## Решения (ADR-0)
- Rust stable (edition 2024). UI — **GPUI** через gpui-kit (снимок Zed `gpui-pre`, версия зафиксирована; [ADR-0018](adr/0018-ui-gpui.md)). Оконная платформа Windows — свой патченный `gpui-pre-windows` из репозитория pets: кадры по запросу (0 % CPU в простое), живой ресайз, шейдеры байткодом в exe, `GPUI_FORCE_WARP=1`, быстрый путь `layout_line` DirectWrite ([решение 2026-11-06](decisions/2026-11-06-dwrite-fast-path.md): единственная правка gpui ради бюджета, ядро `gpui-pre` не тронуто). egui/eframe/wgpu удалены (G-06).
- Платформа: **только Windows 10/11** (S0-decisions №57). Linux и macOS не собираются и не проверяются.
- Лицензия: **MIT OR Apache-2.0** (стандарт Rust-экосистемы).
- Ноль модальных окон. Все «диалоги» — inline-строки над cmdline или в панели. UI-поток не делает I/O.
- «Перекрыть системные» = свои алгоритмически быстрые реализации операций (каталог — S5). Системные хоткеи ОС не перехватываем.
- Хоткеи: пресеты DN и Far, пользовательский keymap; хоткеи с буквой — на любой раскладке (S0-contracts-v4 №5).
- Офлайн: никаких сетевых запросов в рантайме, телеметрии, CDN. Ресурсы вшиты (кроме системных шрифтов Segoe); пакеты грамматик — DLL рядом с exe, в дистрибутиве. Сеть — только по явному действию: SSH и SFTP (F-03) и внешние менеджеры пакетов (F-02).

## Крейты (`crates/*`, пакеты `urfin-*`)
| Крейт | Ответственность | Зависит |
|---|---|---|
| core | AppState (панели, табы, выделение, история), Command bus, события, job registry, Runtime (полосы Interactive/Bulk), `DeviceGate`, политики организации `PolicySet` (F-00), модели подключений, пакетов, поиска и архивов (ui не зависит от net, pkg, search, arc) | — |

| ops | движок операций, очередь, прогресс, конфликты, журнал, Корзина; локальная ФС пишет сама, другие схемы — через `Vfs` | vfs |
| term | ConPTY, VT-эмуляция (`alacritty_terminal`), shells и их интеграция, сеансы, строка ввода; подсветка вывода, группы мультивыполнения, запись сеанса (F-03) | core |
| keymap | реестр команд → сочетания, пресеты, конфиг, хук клавиш Windows | core |
| i18n | Fluent EN/RU | — |
| ui | окно и виджеты GPUI, темы, сцены `--screens`, `--bench` | core, vfs, term, keymap, i18n, view |
| net | SSH и SFTP (F-03): tokio current-thread на выделенном потоке, профили, импорт `~/.ssh/config` и PuTTY, секреты, `SftpFs` с записью через `Vfs`, мост к `ssh.exe` | core, vfs, term |
| pkg | менеджеры пакетов winget / scoop / choco (F-02) | core, vfs |
| view | вьювер, hex, движок редактора, Markdown, подсветка, плеер записи сеанса (M4) | vfs, term |

## Потоки
- UI: GPUI, события Core — через `MsgSink`/`poke`, кадр только по событию или анимации.
- Runtime core: полосы Interactive (листинг, запуск shell) и Bulk (операции, запись на диск), rayon — сортировка, хэши, поиск; `spawn_dedicated` — долгие задачи.
- term: поток-читатель и поток-писатель на каждый сеанс ConPTY.
- Любое действие пользователя → `Command` → bus → handler. UI только рисует снапшот состояния.
- Отмена: токен в каждой задаче. Прогресс: атомики + троттлинг событий ≤30/с.

## Вьювер и редактор
- Редактор — свой движок ([ADR-0023](adr/0023-editor-engine.md)): дерево кусков над файлом, правки в памяти и во временном файле, потоковое сохранение; цель — ≤ 64 МиБ на документ любого размера, замеры — [perf/s7.md](perf/s7.md).
- Подсветка и свёртка — видимое окно от контрольных точек ([ADR-0024](adr/0024-windowed-highlight.md)): фоновый лёгкий проход, окно красится от ближайшей точки. JSON, TOML, INI, XML — свои лексеры; YAML, Markdown — tree-sitter по отрезку; код из пакетов — трекер состояния и tree-sitter по кускам. Bash, PowerShell, HTML не перенесены: полный разбор ≤ 16 МиБ, больше — без подсветки.
- Сверка с tree-sitter: дифференциальные тесты и ночной прогон `hl-corpus.yml` (на PR не влияет).

## Бюджеты (S0-decisions №80; кадр — решения 2026-10-29, 2026-11-06)
- Первый кадр < 250 мс (своё время старта < 20 мс); каталог 100k записей < 200 мс (первые строки < 16 мс, стриминг).
- Кадр p50 ≤ 3 мс, p99 ≤ 6 мс при 100k строк (виртуализация; решение 2026-10-29 — цена кадра GPUI), смена всего экрана в документе (страница, прыжок) p99 ≤ 8 мс, ввод ≤ 1 кадр; сетка терминала 200×60 — полная пересборка ≤ 4 мс.
- Простой: 0 % CPU, своя память < 50 МБ, процесс ≤ 200 МБ private. Размер exe растёт вместе с функциями (№80), гейт CI — 50 МиБ.
- Не укладывается: [#310](https://github.com/Dicobraz421/Urfin/issues/310), [perf/s2.md](perf/s2.md), [perf/s7.md](perf/s7.md).

## Платформенный слой
Модули `sys` внутри vfs, ops, term, net, ui, view, app (Win32 через `windows-sys`). `unsafe` — только в `sys`.

## Конвенции
- Ошибки: thiserror в либах, anyhow в app. Логи: tracing.
- Тесты: cargo-nextest; бенчи: criterion, `urfin --bench` (кадр), `--bench-editor`, `--bench-viewer`, `--bench-sftp`, `bench_ops` (операции, [perf/ops.md](perf/ops.md)).
- Clippy pedantic = warn (в CI `-D warnings`), rustfmt по умолчанию.
- Процесс pets-dev ([решение 2026-10-24](decisions/2026-10-24-pets-dev.md)): полосы — `lanes.toml`, одна волна = одна полоса = один PR; межполосные правки — ветка `x/*`; мерж — очередь GitHub на зелёном `gate`.
- Документы в репо: `docs/specs/Sx.md`, `docs/adr/NNNN-*.md`, решения `docs/decisions/`, контракты `docs/CONTRACTS.md`, карточки задач `docs/tasks/<ID>.md`, ручные проверки `docs/manual-tests/<ID>.md`.

## Стенд
Windows 11 владельца, сборка нативно (MSVC). Проверка лестницей: L0 на стенде (fmt, check и clippy своего крейта, nextest новых тестов, снимки dev-сборкой) → L1 CI (полный clippy, nextest, doc-тесты, только windows; [решение 2026-11-02](decisions/2026-11-02-checks-on-ci.md)) → L2 ручная приёмка владельцем (файлы `docs/manual-tests/`; задачу не блокирует, шаги переводятся в автотесты — [решение 2026-11-10](decisions/2026-11-10-manual-checks.md), [#688](https://github.com/Dicobraz421/Urfin/issues/688)). Перф-бюджеты меряются на стенде в release. WSL Ubuntu — только для проверки интеграции shell в WSL.
