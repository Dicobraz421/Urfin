# S8-27 — Копирование и сравнение из архива

Статус: ⏳ (2026-11-11, PR x/s8-27-arc-copy)

Тестовая копия с `urfin.portable`. Песочница: zip, скачанный браузером (у него есть Mark-of-the-Web — «Свойства → Разблокировать»), с папками, пустой папкой и файлом больше 100 МБ; рядом — пустая папка для копий. 7-Zip — для сверки (`7z x` в отдельную папку).

| № | Действие | Ожидание |
|---|---|---|
| 1 | Enter на zip, курсор на папке, F5, Enter в пустую папку | Одна задача копирования, job-бар с байтами и файлами; содержимое как у `7z x` (сравнить Alt+F7 → «Сравнить папки» или `fc /b`), даты файлов и папок — как в архиве |
| 2 | Свойства любого скопированного файла | Внизу «Этот файл получен с другого компьютера…» — как у файлов, распакованных Проводником |
| 3 | То же F5 ещё раз | Вопрос «Файл уже есть» по каждому файлу; «Пропустить» — файл не тронут, «Заменить» — заменён |
| 4 | Во время копирования большого файла — пауза и отмена на job-баре | Пауза держит, отмена останавливает; `.urfin-part` от сжатого файла при следующей копии пишется заново |
| 5 | Активная панель — обычная папка, пассивная — внутри архива; F5, Enter | Отказ «zip: запись не поддерживается», задачи нет |
| 6 | F6 внутри архива | Открывается черновик копирования, не переноса; Enter копирует, в архиве ничего не пропадает |
| 7 | F7 и F8 внутри архива | Отказ «zip: запись не поддерживается» |
| 8 | Слева архив, справа распакованная в п. 1 папка (тот же уровень), «Сравнить папки» | Отличий нет: разница времени до 2 с у zip не считается |
| 9 | Справа изменить один файл и сравнить снова | Выделен изменённый файл |
| 10 | Архив с именами `CON.txt`, `a:b.txt` (собрать на Linux или 7-Zip из WSL), F5 всего архива | Эти имена — ошибки в отчёте задачи («Имя, которое Windows не откроет»), остальное скопировано, за пределы папки назначения ничего не вышло |
| 11 | Язык EN | Тосты и названия задач по-английски |
