# S7-35 — Подсветка и свёртка в редакторе (инкрементально)

Статус: ⏳ (2026-11-02, PR x/editor-hl)

Тестовая копия с `urfin.portable`, пресет Far. Файлы — копии в `%TEMP%`. Большой JSON — любой ≈ 15 МБ (например, выгрузка API или `npm ls --json` большого проекта; ≤ 16 МиБ — с подсветкой).

| № | Действие | Ожидание |
|---|---|---|
| 35.1 | F4 на `Cargo.toml` (копия) | Как `screen-editor.png`: заголовки таблиц — `keyword`, строки — `string`, числа и `true/false` — `number`, `#` — `comment`; в поле свёртки ▾ у каждой таблицы; мини-карта — штрихи цветами ролей |
| 35.2 | Печатать внутри строки `"0.4.2"`, затем перед ней `# ` в начале строки | Набранное внутри строки сразу цвета строки; после `# ` строка становится комментарием без заметной задержки (≤ 50 мс) |
| 35.3 | Клик по ▾ у `[workspace.dependencies]` | Строки таблицы скрыты, у заголовка ▸ и плашка `⋯`, номера идут дальше со следующей видимой строки; полоса изменений у видимых строк на месте |
| 35.4 | Стрелки ↓/↑ через свёрнутое, PgDn/PgUp, колесо | Курсор и экран идут мимо скрытых строк |
| 35.5 | Курсор в конец заголовка, → (или Alt+F8 на скрытую строку, поиск F7 слова из скрытого) | Свёрнутое разворачивается, курсор — на месте |
| 35.6 | Свернуть, затем Backspace в начале строки после свёрнутого | Свёрнутое разворачивается, правка — как обычно; Ctrl+Z возвращает |
| 35.7 | Палитра: «Свернуть / развернуть» (`editor.fold`) на строке внутри таблицы | Сворачивается объемлющая таблица; ещё раз на заголовке — разворачивается |
| 35.8 | Палитра: «Подсветка синтаксиса» (`editor.highlight`) дважды | Цвета и ▾ пропадают и возвращаются; настройка «Редактор → Подсветка синтаксиса» меняется вместе |
| 35.9 | F4 на JSON ≈ 15 МБ, печатать в середине | Первый экран сразу (без цветов до разбора — ≈ секунда), дальше цвета; набор без рывков, цвета после правки — сразу; у `{`/`[` ▾, закрывающая скобка при свёртке остаётся видна |
| 35.10 | F4 на файле > 16 МБ | Без подсветки и ▾, правка как обычно |
| 35.11 | F4 на 1251-копии конфига с кириллицей в строках и комментариях (F8 — windows-1251) | Подсвечено так же, как UTF-8-копия; F8 в другую кодировку — подсветка заново |
| 35.12 | F4 на UTF-16 LE `.json` / `.xml` | Подсвечено, как UTF-8-копия |
| 35.13 | `.md` в редакторе | Заголовки, код, ссылки — роли темы; ▾ у разделов заголовков и блоков кода, не у абзацев |
| 35.14 | Тёмная тема и высокая контрастность | Цвета — роли `[syntax]` темы; в высокой контрастности — цвет текста окна |
