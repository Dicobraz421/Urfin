# S7-17 — сохранение

Стенд: dev-сборка с экраном редактора (S7-16 — inline-строки вопросов); временная папка с файлами, не рабочие файлы.

- [ ] F4 на `.toml`, правка, F2: файл записан, ● на вкладке гаснет, полоса изменений пустеет. В папке нет `.<имя>.urfin~`.
- [ ] Файл с атрибутом «скрытый» и своей записью ACL (`icacls f /grant *S-1-1-0:(R)`): после F2 атрибут и ACL те же (`attrib`, `icacls`).
- [ ] Жёсткая ссылка (`mklink /H b a`): правка `a`, F2 — `b` видит новое содержимое.
- [ ] Открыть файл, изменить его в Блокноте, вернуться в Урфин на экран редактора: внизу «Файл изменён на диске: [Перезагрузить] [Сохранить поверх]». F2 при этом не пишет без ответа.
- [ ] Файл `windows-1251`, вставить «日本», F2: «2 символа нельзя записать в windows-1251: [Сохранить в UTF-8] [Заменить на ?] [Отмена]»; оба ответа пишут файл, «Отмена» — нет.
- [ ] Файл «только для чтения», F2: «Файл только для чтения… [Снять и сохранить] [Сохранить, атрибут оставить] [Отмена]».
- [ ] Файл > 8 МБ: F2 — задача в job-баре с прогрессом; до конца ввод заблокирован.
- [ ] Esc с правками: строка «“имя” изменён. Сохранить?»; Esc ещё раз — строка исчезает. Shift+F10 — сохранить и закрыть.
- [ ] Alt+F4 (выход) с несохранённым: вопрос «Не сохранено: N [Отмена] [Не сохранять]».
