# F03-05 — UI подключения: меню дисков, новое подключение, ключ сервера, пароль, «Подключения»

Статус: ⏳ (2026-11-02, PR x/net-ui)

Стенд Windows 11 с тестовым SSH-сервером (OpenSSH, SFTP), `~/.ssh/config` с парой `Host`, при возможности — PuTTY с сеансом. Снимки сцен (`--screens`) уже сверены с макетами; здесь — то, что видно только вживую.

| № | Действие | Ожидание |
|---|---|---|
| F0305.1 | Alt+F1 | Группа «SSH» между «Сетью» и «Местами»: профили из `connections.toml`, `~/.ssh/config` (метка `config`), PuTTY (`PuTTY`), «когда» — «N мин назад» / «вчера, ЧЧ:ММ» / «не подключались»; «+ Новое подключение… Ins» |
| F0305.2 | ↓ на профиль | Статус: «Профиль … · вход через …» слева, «SSH: N подключений» справа; keybar: Enter, Ins, F4, Del, Esc |
| F0305.3 | Enter на профиле с ключом в агенте (OpenSSH agent или Pageant, `auth = agent`) | Подключение без вопросов; панель `sftp://<профиль>/<начальная папка>`, чип «SSH», справа «N объектов · X мс»; колонки Права (моно) и Владелец |
| F0305.4 | Ins | Строка «Новое подключение» на ширину панели; набрать начало хоста | «Мешочек» подсказок вверх от поля: config, история, known_hosts; общая часть подсвечена, источник справа; статус «k из N» |
| F0305.5 | Alt+↓ в «Хосте»; ↑↓, Enter | Только история хостов; Enter подставляет хост |
| F0305.6 | Tab до «Вход», ← →; Tab до флажка, Пробел | Способ входа меняется; «Сохранить профиль» переключается |
| F0305.7 | Enter с новым хостом (ключа нет в known_hosts) | Строка `warning_bg` с отпечатком SHA256; Tab ходит по кнопкам; Ctrl+C (и в русской раскладке) копирует отпечаток |
| F0305.8 | «Доверять и подключить» | В `~/.ssh/known_hosts` дописана одна строка, остальные байты те же; статус «Подключение: ключ сервера · 2 из 3» до ответа |
| F0305.9 | Сменить ключ сервера, подключиться снова | Строка `danger_bg`: «Был … known_hosts:N», «Сейчас …»; фокус на «Отмена»; Enter — отмена |
| F0305.10 | Tab на «Заменить ключ и подключиться…», Enter; ввести неверное имя хоста, Enter; затем верное | Неверное — строка остаётся; верное — строка N заменена, рядом `known_hosts.urfin-bak`, подключение идёт |
| F0305.11 | Профиль `auth = password` | Строка пароля: поле маскировано; «Из менеджера паролей ▾» (Alt+↓) — шаблоны BearPass, Пассворк, 1Password, Bitwarden, KeePassXC |
| F0305.12 | Политика `password_cache = false` (GPO) | «Запомнить» недоступно, замок «Задано политикой организации · GPO» |
| F0305.13 | Без политики, `[ssh] password_cache = true`, «Запомнить», подключиться; отключиться (Del в меню дисков) и снова Enter | В Диспетчере учётных данных — `Urfin/ssh/<user>@<host>:<port>`; второй раз пароль не спрашивается |
| F0305.14 | Неверный пароль из Диспетчера | Запись удалена, строка пароля спрашивает снова |
| F0305.15 | Шаблон менеджера (CLI установлен) — Enter в «мешочке» | Пароль получен командой, команда сохранена в профиле (`password_cmd` или `[[override]]`) |
| F0305.16 | Настройки → SSH → «Подключения» | Таблица: источник (метки одной ширины), имя, хост, пользователь, вход, через, последнее; «Свойства» выбранного; статус «connections.toml · N профилей · K из ~/.ssh/config · M из PuTTY · Пароли в файл не пишутся» |
| F0305.17 | В «Подключениях»: буквы — поиск, ↑↓, Enter, F4, Ins, Del на своём и на импортированном | Поиск фильтрует; Enter подключает; F4 — строка с полями профиля; Del удаляет только свой профиль; файлы `~/.ssh/config` и реестр PuTTY не меняются |
| F0305.18 | «Импорт…» после правки `~/.ssh/config` | Профили перечитаны |
| F0305.19 | Сохранённый таб `sftp://` после перезапуска | Сам не подключается («нет связи»); Alt+F1 → профиль → Enter — подключается |
| F0305.20 | Вкладка анализа места (`du:`) | Колонки Доля · Размер · Изменён как раньше (общий механизм колонок схем) |
