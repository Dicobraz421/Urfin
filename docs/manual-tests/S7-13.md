# S7-13 — Быстрый просмотр и dock

Статус: ⏳ (2026-10-31, PR x/s7-11-13)

Тестовая копия с `urfin.portable`. Каталог с `.toml`, `.md` (с картинкой рядом), `.exe`, большим логом (100+ МБ), подкаталогами; файл OneDrive «только в сети» (значок облака) — если есть.

| № | Действие | Ожидание |
|---|---|---|
| 13.1 | Ctrl+Q, курсор на `Cargo.toml` | Правая панель: вкладка и шапка «Быстрый просмотр», справа «TOML», номера строк, моно-текст; в середине статуса «стр 1–N из M» |
| 13.2 | Держать ↓ по списку из сотен файлов | Просмотр не мигает и не тормозит курсор; по остановке — файл под курсором через ~50 мс |
| 13.3 | Курсор на `.exe` | Hex: смещения, байты, текст |
| 13.4 | Курсор на `.md` до 4 МБ | Документ (заголовки, списки, картинка) во всю ширину панели |
| 13.5 | Курсор на каталог | Имя, «F3 — размер папки»; F3 — размер считается, в просмотре — размер |
| 13.6 | Курсор на облачный файл OneDrive | «Файл в облаке — F3 для загрузки»; файл не скачивается (значок облака остаётся) |
| 13.7 | Колесо над просмотром | Текст прокручивается, фокус остаётся в панели |
| 13.8 | Tab | Шапка просмотра подчёркнута; ↑↓ PgUp PgDn прокручивают его, F7 — строка поиска внутри панели, F8 — кодировка, F4 — Hex, F2 — перенос |
| 13.9 | Tab ещё раз; затем Tab и Esc | Фокус вернулся к панели файлов, курсор там же |
| 13.10 | Tab, F3 | Тот же файл на той же позиции открыт во весь экран; Esc — назад к панелям, просмотр на месте |
| 13.11 | F3 на файле, палитра → «Window / panel» (`viewer.dock`) | Вьювер переехал в правую панель, фокус у него; курсор слева больше не меняет содержимое; ещё раз — обратно в окно |
| 13.12 | Ctrl+Q ещё раз | Панель снова со списком файлов |
| 13.13 | Мышью протянуть по тексту просмотра, Tab, Ctrl+C | Выделенное — в буфере |
| 13.14 | Большой лог в просмотре | Открывается сразу, «стр 1–N из ≈M»; Tab — номера и «из M» появляются по индексу |
| 13.15 | Тёмная тема | Цвета шапки, текста, выделения — по теме |
