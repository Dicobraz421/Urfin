# D-11 — Раздел «Клавиатура»: список и правка клавиш

Статус: ⏳ (2026-11-05, PR x/ui-keys)

Снимки `screen-settings-keys`, `settings-keys-ask`, `settings-keys-found` (`--screens`) сверены с макетом; запись, сброс, конфликт и раскладки покрыты тестами. Здесь — настоящие нажатия. Открыть: Настройки → Клавиатура.

| № | Действие | Ожидание |
|---|---|---|
| D11.1 | Листать таблицу колесом и PgDn/PgUp до конца | Без рывков; курсор и полоска положения на месте; команды без клавиши тоже в списке |
| D11.2 | Начать печатать в таблице, Ctrl+F, Esc | Символ уходит в поиск; Ctrl+F — фокус в поле; Esc очищает, второй Esc закрывает настройки |
| D11.3 | Поиск `ctrl+f`, затем по русскому названию команды | Находит по клавише и по названию |
| D11.4 | Enter на строке, нажать F5 | На время захвата строка `current_line` и рамка «Нажмите сочетание…»; копирование не запускается; появляется вопрос о конфликте |
| D11.5 | Во время захвата: одиночный Alt, Ctrl+Gray*, Num5, серые `+` `-` | Меню не открывается, команды не срабатывают; серые клавиши и Num5 захватываются под своими именами |
| D11.6 | Захват, Esc | Отмена, файл не меняется |
| D11.7 | Захват на русской раскладке: Ctrl+Ф; на AZERTY (если есть): клавиша с надписью A | `Ctrl+A` в обоих случаях; срабатывает на той же клавише |
| D11.8 | Захват Ctrl+Alt+K, потом AltGr+буква на раскладке с AltGr | Записывается сразу, без подтверждения; под командой пояснение про AltGr; баннера нет; клавиша работает, символ AltGr на этой клавише может перестать набираться |
| D11.9 | Конфликт: Enter — заменить; снова конфликт: Esc | Клавиша перешла, у прежней команды снята; Esc ничего не меняет |
| D11.10 | Назначить клавишу панели в команде просмотра (контексты не пересекаются) | Без вопроса, обе работают каждая у себя |
| D11.11 | Del на клавише, Ins — добавить вторую, ← → — выбор клавиши, Backspace | Снята; добавлена; сброс строки возвращает пресет |
| D11.12 | «Открыть user.toml», дописать комментарий и привязку, сохранить, вернуться в раздел | Файл открыт в редакторе; при входе в раздел привязка видна; новая правка из таблицы комментарий не теряет |
| D11.13 | Сделать файл `user.toml` только для чтения, назначить клавишу | Понятный тост с путём, таблица без изменений |
| D11.14 | Испортить TOML вручную, назначить клавишу | Тост «файл содержит ошибку», файл не перезаписан |
| D11.15 | Сегменты Urfin / Far / DN, «Сбросить всё к пресету» | Таблица перестраивается сразу; свои клавиши `user.toml` остаются поверх пресета до сброса |
