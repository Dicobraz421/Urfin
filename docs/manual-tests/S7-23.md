# S7-23 — Панель инструментов редактора

Статус: ⏳ (2026-11-01, PR x/s7-16-editor)

Тестовая копия с `urfin.portable`, пресет Far.

| № | Действие | Ожидание |
|---|---|---|
| 23.1 | F4 на файле без правок | Панель как на `screen-editor.png`: Сохранить, Отменить, Вернуть — серые; Найти, Заменить; Перенос; справа «UTF-8 ⌄», «LF ⌄» |
| 23.2 | Навести на кнопку и подождать | Через полсекунды подсказка «Найти F7», «Сохранить F2»; у серой — причина («Нет изменений», «Нечего отменить», «Нечего вернуть») |
| 23.3 | Правка, клик «Сохранить» | То же, что F2: ● пропала, счётчик в шапке исчез; курсор и фокус остались в тексте (можно сразу печатать) |
| 23.4 | Клик «Отменить», затем «Вернуть» | Правка отменяется и возвращается |
| 23.5 | Клик «Перенос» | Длинные строки переносятся, кнопка подсвечена; ещё клик — перенос снят; настройка запомнилась после перезапуска |
| 23.6 | Клик «LF ⌄» | «Мешочек» от кнопки: LF ✓ / CRLF / CR; выбрать CRLF — весь текст в CRLF одной правкой (Ctrl+Z возвращает), кнопка «CRLF ⌄» |
| 23.7 | Клик «UTF-8 ⌄» | «Мешочек» кодировок; ↑↓ Enter — выбор, Esc — закрыть |
| 23.8 | Палитра → «Toolbar» (`editor.toolbar`) | Панель спрятана, в статусе «… · UTF-8 · LF · Вставка»; ещё раз — панель вернулась |
| 23.9 | Файл только для чтения | Сохранить, Отменить, Вернуть, Заменить — серые, подсказка «Только чтение» |
