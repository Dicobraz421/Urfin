Статус: ⏳ (2026-11-02, PR x/du-2)

Тестовая копия с `urfin.portable`. Папка с вложенными каталогами на несколько ГБ (например, `C:\Dev`), анализ посчитан (F01-05).

| № | Действие | Ожидание |
|---|---|---|
| 7.1 | Во вкладке анализа Ctrl+Tab | Как `screen-dumap.png`: во второй панели таб «Карта», шапка «Карта · C:\Dev»; плитки — папки и крупные файлы, у крупных папок полоса «имя · размер» и их дети внутри; мелочь — «ещё N», мелкие файлы — серым блоком; легенда внизу |
| 7.2 | Стрелки в списке | Рамка 2 px курсора переходит по плиткам первого уровня |
| 7.3 | Ins на двух строках | Плитки отмеченных — со штриховкой, в легенде «Отмечено» |
| 7.4 | Клик по плитке; двойной клик по папке; Shift+клик | Курсор списка на её строке; вход в папку (карта — уже её); отметка строки |
