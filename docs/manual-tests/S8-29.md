# S8-29 — Строка распаковки (Shift+F2)

Статус: ⏳ (2026-11-11, PR w/s8-29-extract-strip)

Тестовая копия с `urfin.portable`. Песочница: обычный `.zip` (несколько файлов и подпапка), zip с паролем AES-256 (7-Zip: «Добавить в архив», zip, AES-256, пароль `1`), `.tar.gz`; в другой панели — пустая папка.

| № | Действие | Ожидание |
|---|---|---|
| 1 | Курсор на `.zip`, Shift+F2 | Строка на всю ширину: «Распаковать имя.zip · размер в» + путь другой панели с `\`; «В подпапку имя», «Если файл есть: Спросить», «Сохранять пути» включены; keybar — Tab «Следующее поле», Alt+↓ «История путей» |
| 2 | Enter | Задача распаковки, строка закрылась; в другой панели — папка `имя` с содержимым архива |
| 3 | Снова Shift+F2, снять «В подпапку», «Если файл есть» → Пропустить, Enter | Файлы — прямо в папку, существующие пропущены (вопроса нет) |
| 4 | Shift+F2, снять «Сохранять пути», Shift+Enter | Задача в фоне; все файлы — в одну папку без подпапок архива |
| 5 | Shift+F2, Alt+↓ | Список истории путей (прежние «куда»); выбор вставляет путь |
| 6 | Shift+F2, Esc | Строка закрылась, ничего не запущено |
| 7 | Отметить два архива, Shift+F2 | «Распаковать 2 архива · размер в», флажок «Каждый в свою подпапку» |
| 8 | Внутри архива выделить два файла, Shift+F2 | «Распаковать 2 объекта из имя.zip · размер в» |
| 9 | `.tar.gz`, Shift+F2 | Размер со знаком «≈» (распакованный не читали) |
| 10 | Zip с паролем, Shift+F2 | Ряд «Пароль»: поле с точками в фокусе, справа шифр (`AES-256`) |
| 11 | Tab, Tab | Фокус: путь → пароль → путь |
| 12 | Неверный пароль, Enter | Рамка поля и «Неверный пароль — осталось 2 попытки» — красным, строка открыта, пароль выделен |
| 13 | Пустой пароль, Enter | Та же ошибка, число попыток не уменьшилось |
| 14 | Три неверных | Строка закрылась, тост «Неверный пароль — попыток не осталось» |
| 15 | Верный пароль, Enter | Распаковка идёт, строка закрылась |
| 16 | Alt+↓ после шагов 12–15 | В истории путей пароля нет; в `data\` (сессия, история) и в логе поиск по паролю ничего не находит |
| 17 | Язык EN | Строки строки — по-английски |
