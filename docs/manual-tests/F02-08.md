# F02-08 — вкладка «Пакеты»: установленные и обновления

Статус: ⏳ (2026-11-02, PR x/pkg-tab)

Стенд с winget (и, если есть, scoop/choco). Обновлять ничего не нужно: действия — F02-10.

| № | Действие | Ожидание |
|---|---|---|
| 8.1 | Ctrl+F9 | Меню F9 на «Утилитах»: «Анализ места…», «Пакеты…» |
| 8.2 | «Пакеты…» (первый раз) | Новая вкладка «pkg:»; в заголовке «Пакеты» и найденные менеджеры с «…», по нижней кромке бежит отрезок; строки появляются по мере ответов; в конце — «N программ», справа внизу «Проверено сегодня в ЧЧ:ММ» |
| 8.3 | Сверить строки | Программа · Версия · Доступна (синим) · Менеджер · Издатель; программы без менеджера — «вне менеджера» серым; у scoop без издателя — «bucket main» |
| 8.4 | Ctrl+2 | «Обновления N»: в заголовке «N из M», важные (`[pkg] important`) сверху с меткой «важное» |
| 8.5 | Insert на двух строках | Внизу строка «Обновить 2 · Обновить Enter · Обновить все N Shift+Enter · Отмена Esc»; Esc снимает отметку |
| 8.6 | Закрыть Урфин, открыть, Ctrl+F9 → «Пакеты…» | Вкладка сразу со строками и прежней датой проверки; процессов winget/scoop/choco нет (Диспетчер задач) |
| 8.7 | Ctrl+R | Менеджеры снова с «…», дата обновилась |
| 8.8 | Переименовать `scoop` в PATH (или отключить сеть для winget) и Ctrl+R | Сломанный менеджер — красным со значком, в статусе «scoop: …»; строки других менеджеров на месте |
| 8.9 | Ctrl+1 / Ctrl+2 на русской раскладке; Ctrl+R на русской | Работают так же |
