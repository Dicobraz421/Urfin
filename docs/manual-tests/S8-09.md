# S8-09 — Предпросмотр на экране поиска, F3, F4

Статус: ⏳ (2026-11-07, PR x/s8-09)

Тестовая копия с `urfin.portable`. Папка с исходниками: тысячи файлов, например клон Urfin. Макет — `docs/design/screens/screen-search.png`.

| № | Действие | Ожидание |
|---|---|---|
| 1 | Alt+F7, «Имя» `*.rs`, «Текст» слово из кода, Enter | Справа шапка: папка корня поиска и путь файла, «стр N · предпросмотр»; текст файла с номерами строк |
| 2 | Сверить с макетом | Строка совпадения — фоном `current_line` во всю ширину, примерно на 2/5 высоты; совпадение — фоном `highlight`; номер строки — справа в поле 44, текст за ним |
| 3 | ↓ медленно по строкам | Предпросмотр идёт за курсором: другой файл или другая строка того же файла, шапка меняется сразу |
| 4 | Держать ↓ (автоповтор) по длинному списку | Интерфейс не замирает; файл читается, когда курсор встал (пауза ~50 мс), а не на каждой строке |
| 5 | Две строки одного файла подряд | Файл не мигает: тот же документ переходит на другую строку |
| 6 | Запрос без «Текста» (только имя) | Предпросмотр — начало файла, без строки совпадения и подсветки; в шапке только путь |
| 7 | Alt+T (папки) | Справа пусто: у папки предпросмотра нет |
| 8 | Строка с файлом в облаке OneDrive (не скачан) | «Файл в облаке — F3 для загрузки», файл не скачивается |
| 9 | Файл больше 4 МБ, совпадение в конце | Предпросмотр на строке совпадения, без заметной паузы интерфейса |
| 10 | Строка «Найти» не открывалась (F7 во вьювере ни разу) | Подсветка совпадения в предпросмотре всё равно есть |
| 11 | Колесо мыши над предпросмотром | Текст прокручивается; ↓ в списке возвращает предпросмотр на строку совпадения |
| 12 | F3 на строке | Вьювер на строке совпадения; Esc — снова экран поиска, курсор на месте, предпросмотр на той же строке |
| 13 | F4 на строке, Esc | То же для редактора |
| 14 | Пассивная панель в режиме быстрого просмотра (Ctrl+Q), затем Alt+F7, поиск, ↓ | Предпросмотр следует за списком поиска, а не за курсором панели; после закрытия экрана быстрый просмотр снова идёт за панелью |
| 15 | Документ перенесён в правую область (`viewer.dock`), затем Alt+F7 | Перенесённый документ не пропадает; предпросмотр — в другом слоте, на экране справа |
| 16 | Тема тёмная; язык EN | Цвета строки и подсветки по теме; «line N · preview» |
| 17 | Ресайз окна | Строка совпадения остаётся на своём месте, номера не обрезаются |
