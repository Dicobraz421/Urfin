# S8-11 — Панель результатов поиска

Статус: ⏳ (2026-11-07, PR x/s8-11)

Тестовая копия с `urfin.portable`. Папка с исходниками: тысячи файлов, например клон Urfin. Макеты — `docs/design/screens/screen-searchpanel.png`, `screen-searchgrep.png`.

| № | Действие | Ожидание |
|---|---|---|
| 1 | Alt+F7, «Имя» `*.toml`, «В» — большая папка (весь диск), Enter, сразу Ctrl+Enter | Новая вкладка «*.toml» в активной панели; заголовок: чип «Поиск», «*.toml в …», справа «найдено N · просмотрено M»; под заголовком бежит тонкий отрезок |
| 2 | Смотреть, пока поиск идёт | Строки прибавляются, счётчики растут; папка строки `dir\` приглушена, имя — обычным цветом; keybar: Ctrl+PgUp К папке файла, Alt+F7 Изменить запрос, Ctrl+Break Остановить поиск |
| 3 | Ctrl+Break | Поиск остановлен: отрезка нет, справа «N файлов · время»; keybar: F3 Смотр на совпадении, Ctrl+PgUp, Alt+F7, Ctrl+R Перепроверить |
| 4 | Статус-строка на строке | Слева только имя файла, размер, дата; посередине «Выделено 0 из N»; справа свободное место диска корня поиска |
| 5 | Insert на трёх строках, затем Ctrl+F3…F6 (сортировка) | Отметка и сортировка как в обычной папке; «Выделено 3 из N» |
| 6 | Alt+F7, «Текст» — слово из кода, Enter, Ctrl+Enter | Вкладка с текстом запроса; заголовок ««слово» в …»; колонки Имя · Стр · Первое совпадение; фрагмент моно, совпадение — фоном `highlight` |
| 7 | F3 на строке | Вьювер на строке первого совпадения этого файла; Esc — назад в панель |
| 8 | F4 на строке | Редактор на той же строке |
| 9 | Alt+F7 в панели поиска | Экран поиска с запросом этой панели («Изменить запрос»): имя, текст, папки «В» |
| 10 | Ctrl+PgUp на строке | Панель переходит в папку файла, курсор — на файле (дальше — снова панель поиска) |
| 11 | Удалить один из найденных файлов в Проводнике, Ctrl+R в панели | Строка исчезает; изменённый файл — новый размер и дата |
| 12 | F5 строки в другую панель | Копируется настоящий файл (с относительной папкой, решение В2) |
| 13 | Поиск по двум папкам («В» `C:\a;D:\b`) в панель | Строки с корнем впереди (`C:\a\…`), F3 открывает файл своего корня |
| 14 | Закрыть вкладку поиска | Остальные вкладки на месте; память не растёт от повторов (8 недавних поисков) |
| 15 | Тема тёмная; язык EN | Цвета по теме; «Search», «found N · scanned M», «N files · time» |
