# F02-11 — проверка обновлений по расписанию и баннер

Статус: ⏳ (2026-11-04, PR x/pkg-schedule)

Стенд с winget (и, если есть, scoop/choco). Выключателя расписания в настройках ещё нет (F02-12) — до него команды через свой слой клавиш: `config\keymaps\user.toml` и `[keymap] user = "user.toml"` в `config.toml`:

```toml
format = 1
extends = "far"
[context.global]
"Ctrl+Alt+Shift+F9" = { cmd = "pkg.schedule", on = true, at = "09:30" }
"Ctrl+Alt+Shift+F10" = { cmd = "pkg.schedule", on = false }
"Ctrl+Alt+Shift+F11" = "pkg.check_now"
```

| № | Действие | Ожидание |
|---|---|---|
| 11.1 | Ctrl+Alt+Shift+F9 | Тост «Проверка обновлений по расписанию: ежедневно в 09:30»; в Планировщике заданий — папка `Urfin`, задача `PkgCheck`: ежедневно 09:30, «Запускать только при входе пользователя», без наивысших прав; условия — «только от сети», «только при наличии сети»; параметры — «запускать при первой возможности после пропуска», «не дольше 30 мин», «не запускать новый экземпляр»; действие — этот `urfin.exe --pkg-check`. В `config.toml` — `[pkg.schedule] enabled = true`, `at = "09:30"` |
| 11.2 | В Планировщике «Выполнить» для `\Urfin\PkgCheck`, Урфин закрыт | Ни окна, ни мигающих консолей; через десятки секунд задача «Выполнено», код 0x0; появились `state\pkg\check.json` и `logs\pkg-check.*.log` |
| 11.3 | Запустить Урфин | Через полсекунды после старта внизу баннер «Доступно N обновлений · M важных — проверено по расписанию сегодня в ЧЧ:ММ» с «Показать» и «Позже» (как `screen-pkgbanner`); время старта на глаз не изменилось |
| 11.4 | «Позже», перезапуск Урфина | Баннера нет и после перезапуска |
| 11.5 | Урфин открыт, «Выполнить» задачу ещё раз | По окончании проверки баннер появляется сразу, окно не выходит вперёд |
| 11.6 | «Показать» | Вкладка `pkg:` на «Обновлениях», строки — свежие (дата в статусе — время проверки), баннер скрыт |
| 11.7 | Два раза подряд «Выполнить» (или `urfin.exe --pkg-check` в терминале во время проверки) | Второй запуск выходит сразу (`pkg-check: already running` в логе), итог один |
| 11.8 | Ctrl+Alt+Shift+F11 | Проверка в фоне; с обновлениями — баннер «… — проверено сегодня в ЧЧ:ММ» (без «по расписанию»), без обновлений — тост «Обновлений нет» |
| 11.9 | Ноутбук от батареи: «Выполнить» задачу | Задача не стартует (условие «только от сети») |
| 11.10 | Сеть выключена, дождаться времени задачи, затем включить | Задача стартует при появлении сети (`StartWhenAvailable`) |
| 11.11 | Ctrl+Alt+Shift+F10 | Тост «Проверка обновлений по расписанию выключена»; задачи `\Urfin\PkgCheck` в Планировщике нет; `enabled = false` |
