# S6-07 — Выделение, буфер, скролл терминала

Статус: ⏳ (2026-10-26, сборка PR w/term-01)

Тестовая копия с `urfin.portable`. Ctrl+O — панели спрятаны, видна сетка терминала.

| № | Действие | Ожидание |
|---|---|---|
| 7.1 | `dir /s C:\Windows\System32\drivers` (вывод длиннее экрана); протянуть мышью по двум строкам | Подсветка от точки нажатия до мыши через строки |
| 7.2 | Двойной клик по имени файла; тройной клик по строке | Выделено слово (до пробела, `\`, кавычек); строка целиком |
| 7.3 | Alt+протяжка прямоугольником | Выделен блок колонок; Ctrl+Shift+V в Блокнот — столбец строк |
| 7.4 | С выделением Ctrl+C; без выделения в `ping -t localhost` — Ctrl+C | Первое — текст в буфере, выделение снято, ping идёт; второе — ping остановлен |
| 7.5 | Ctrl+Shift+C / Ctrl+Ins с выделением; вставить в Блокнот | Текст тот же, что выделен |
| 7.6 | Скопировать в Блокноте две строки `echo A` / `echo B`, в cmd Ctrl+Shift+V (или Shift+Ins) | Над cmdline — вопрос «Вставка в cmd: строк — 2»; «Вставить» — обе выполнились; «Отмена» — ничего |
| 7.7 | То же в Git Bash или pwsh 7 | Без вопроса: строки встали в строку shell (bracketed paste), выполняются по Enter |
| 7.8 | Колесо вверх/вниз; Shift+PgUp/Shift+PgDn | Листается скроллбэк; набор любой клавиши — вид возвращается вниз, к курсору |
| 7.9 | `vim` или `less` (WSL/Git Bash): колесо | Двигается текст внутри программы (стрелки), не скроллбэк |
| 7.10 | В `mc` (WSL) клик по файлу; Shift+клик и протяжка | Клик — mc выбирает файл; с Shift — выделение Урфина |
| 7.11 | Git Bash: `printf '\e]52;c;%s\a' $(printf hello \| base64)`; затем `printf '\e]52;c;?\a'` | В буфере `hello`; запрос буфера ничего не печатает и не отдаёт |
