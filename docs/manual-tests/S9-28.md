# S9-28 — Шаблон групповой политики (ADMX/ADML) и пример policy.toml

Статус: ⏳ (2026-11-12, PR w/s9-ui2)

Машина с Windows Pro/Enterprise (есть `gpedit.msc`), права администратора. Тестовая копия Урфина с `urfin.portable`. Ручные шаги не блокируют мерж.

| № | Действие | Ожидание |
|---|---|---|
| 1 | Скопировать `assets\policy\urfin.admx` в `%SystemRoot%\PolicyDefinitions`, `en-US\urfin.adml` и `ru-RU\urfin.adml` — в одноимённые подпапки; открыть `gpedit.msc` | Открывается без ошибок разбора шаблона |
| 2 | Конфигурация компьютера → Административные шаблоны → Aahz → Урфин | Разделы «Внешний вид», «Файловые операции», «Анализ места», «SSH», «Обновление»; в них 11 параметров; в «Конфигурации пользователя» Урфина нет |
| 3 | Открыть каждый параметр | Название и справка по-русски; в справке имя значения реестра и ключ `policy.toml`; «Требования: Урфин 0.1 и новее» |
| 4 | «Удалять в корзину» → Включено, применить; `reg query HKLM\Software\Policies\Aahz\Urfin` | `DeleteToTrash REG_DWORD 0x1` |
| 5 | Тот же параметр → Отключено, затем «Не задано» | `0x0`, затем значения нет |
| 6 | «Минимальная проверка после записи» → Включено, «Хэш» | `Verify REG_SZ hash`; список — «Нет», «Размер», «Хэш (содержимое)» |
| 7 | «Запись сеансов SSH» → «Обязательна»; «Тема по умолчанию» → `blue` | `SshRecording REG_SZ required`, `Theme REG_SZ blue` |
| 8 | Запустить Урфин, F9 → Настройки → Политики | Заданные строки с источником «GPO»: удаление в корзину, проверка, запись SSH, тема |
| 9 | Язык Windows EN (или удалить `ru-RU\urfin.adml`), открыть `gpedit.msc` | Названия и справка на английском |
| 10 | Скопировать `policy.example.toml` в `%ProgramData%\Urfin\policy.toml` как есть | В «Политиках» ничего не задано (все строки закомментированы) |
| 11 | В файле убрать `#` у `delete_to_trash = true` и у `[ssh]` с `recording = "required"` | Строки с источником «TOML»; если те же ключи заданы в GPO — источник «GPO» |
| 12 | Вернуть всё: параметры «Не задано», удалить `policy.toml` и три файла шаблона | `HKLM\Software\Policies\Aahz\Urfin` пуст |
