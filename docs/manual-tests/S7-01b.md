# S7-01b — Настройки «Просмотр» и «Редактор»

Статус: ⏳ (2026-11-01, PR x/s7-01b-settings)

Тестовая копия с `urfin.portable`. Рядом открыть `%APPDATA%\Urfin\settings.toml` (или файл портативной копии) в Блокноте.

| № | Действие | Ожидание |
|---|---|---|
| 1b.1 | Настройки → «Просмотр» | Как `screen-settings-viewer.png`: группы «Открытие», «Текст», «Большие файлы и логи»; пояснения справа серым |
| 1b.2 | «Где открывать по F3» → «Панель», затем F3 на файле | В `settings.toml` — `[viewer] placement = "panel"`; файл открывается в панели |
| 1b.3 | «Перенос строк» → «По словам», «Табуляция» → 4, «Hex: байт в строке» → 16 | В конфиге `wrap = "words"`, `tab_size = 4`, `hex_cols = 16`; в просмотре — перенос по словам, Hex по 16 |
| 1b.4 | «Markdown» → «Исходник», F3 на `.md` | `markdown = "source"`; «Разметка» показывает исходник с подсветкой |
| 1b.5 | Клик по списку «Кодировка по умолчанию» несколько раз | По кругу: Авто — по содержимому → UTF-8 → Windows-1251 → CP866; `codepage` в конфиге меняется |
| 1b.6 | Снять флажки «Запоминать позицию», «Отображение в память», «Слежение за логом» | В конфиге `remember_pos`, `mmap`, `follow_reopen` = `false`; повторный клик — `true` |
| 1b.7 | Настройки → «Редактор» | Как `screen-settings-editor.png`: «Шрифт: Cascadia Mono, 13», табуляция 4, флажки, «Панель инструментов», «Файлы» |
| 1b.8 | Снять «Панель инструментов», открыть F4 любой файл | `[editor] toolbar = false`; панели кнопок под шапкой нет, кодировка и EOL — в статусе; включить обратно — панель вернулась |
| 1b.9 | «Табуляция» 8, «Переводы строк» LF, снять «Пробелы вместо табов» и «Подсветка синтаксиса» | В конфиге `tab_size = 8`, `eol = "lf"`, `expand_tabs = false`, `highlight = false`; в редакторе Tab вставляет таб, подсветки нет |
| 1b.10 | Клик по «Кодировка новых файлов», затем по «Автосохранение» | UTF-8 без BOM ↔ с BOM (`new_bom`); автосохранение по кругу Выключено → При уходе с экрана → Через секунду после правки (`autosave`) |
| 1b.11 | Тёмная тема, English | Цвета из темы; подписи по-английски без обрезки |
