# S7-14 — экраны, соседние файлы, история, внешний просмотр

Стенд: dev-сборка, папка с несколькими файлами и подпапками, README с ссылками на другие `.md` (с `#якорем`), на файл и на папку.

- [ ] F3 на файле, Gray+ / Gray−: следующий / предыдущий файл панели, папки пропускаются, вкладка одна; режим (Hex, Текст) и перенос сохраняются.
- [ ] Ctrl+F10 во вьювере: панели, курсор на просматриваемом файле; кнопка «две панели» и снова F3 — вьювер открывается.
- [ ] Прокрутить файл, Esc, перезапустить Урфин, F3 на том же файле — та же позиция (кодировка, выбранная вручную, и режим тоже). `%LOCALAPPDATA%\Urfin\state\view-history.json` есть.
- [ ] `config.toml`: `[viewer] remember_pos = false` + `app.reload_config`: после перезапуска файл открывается с начала.
- [ ] Alt+F3 на `.pdf` / `.png`: открывается программой Windows. В `config.toml` `[viewer] external = 'notepad.exe {path}'` + `app.reload_config`: Alt+F3 открывает Блокнот (путь с пробелами — тоже).
- [ ] `[[viewer.assoc]] mask = "*.log" cmd = "notepad.exe {path}"`: F3 на `.log` — Блокнот; Ctrl+Shift+F3 — встроенный вьювер.
- [ ] README: клик по ссылке на другой `.md` — открывается в той же вкладке; `файл.md#раздел` — сразу на заголовке; Alt+Backspace — обратно в README на прежнее место.
- [ ] README: клик по ссылке на файл / папку — панели, курсор на нём.
- [ ] Открытый документ `.md`, Настройки → «Markdown: Исходник» — документ сразу становится исходником на той же позиции; обратно «Документ» — документ. Ctrl+колесо — размер шрифта сохраняется после перезапуска.
- [ ] Файл UTF-32 с BOM: Hex и тост «UTF-32 не поддерживается — показано в Hex».
- [ ] F3 на двух файлах (между ними — кнопка «две панели»), F12 в панели: список «Экраны» — «Панели» с путём, ниже экраны (новый сверху), у текущего ✓; ↑↓ Enter или цифра — экран на месте, позиция та же; Esc — список закрыт, фокус там же.
- [ ] Во вьювере F12 и клик по «+» в заголовке — тот же список; клик по неактивной вкладке — её экран; наведение на «две панели» — подсказка «К панелям: путь».
- [ ] Alt+F11 (в панели и во вьювере): «История просмотра и правки» — новые сверху, папка и время; набор букв ищет по имени и папке (совпадение подсвечено), Backspace стирает; Enter — файл во вьювере на прежней позиции, F4 — в редакторе; клик мимо — закрыт.
- [ ] README с картинкой на сетевом пути (`\server\share\a.png`): плашка «картинка не на локальном диске».
- [ ] Настройки → Просмотр: у «Markdown» справа пояснение «вид .md в режиме «Разметка»».
