# F01-09 — Дубликаты; «Сборки и кэши» в «Типах»

Статус: ⏳ (2026-11-02, PR x/du-4)

Тестовая копия с `urfin.portable`. Анализ посчитан на папке разработки с копиями установщиков и архивов (одинаковые файлы в разных папках, пара файлов одного размера с разным содержимым). Клавиши — на любой раскладке.

| № | Действие | Ожидание |
|---|---|---|
| 9.1 | Ctrl+5 (чип «Дубликаты») | Как `screen-dudups.png`: колонки «Группа · где лежит · Изменён · Размер»; у группы — имя файла, «N копии», метка «только размер»; под ней — папки копий (корень анализа и путь), самая старая первой; ничего не отмечено. В job-баре коротко «Дубликаты: сравнение начала файлов» |
| 9.2 | Строка внизу | «N групп, хэшем проверены 0 · отмечено 0 · освободится 0 Б», «Проверить хэшем N групп Ctrl+H», «В Корзину F8»; в статусе — «N групп · M файлов» |
| 9.3 | Ctrl+H | Задача «Дубликаты: проверка хэшем»; совпавшие группы — метка «✓ совпадает по хэшу», отмечены все копии, кроме первой; файлы с одинаковым началом и разным хвостом — разошлись по группам или ушли |
| 9.4 | Ctrl+H на большой группе (ГБ), сразу Esc | Проверка остановлена за доли секунды; группы как были |
| 9.5 | Жёсткая ссылка на файл в анализе (`mklink /H`) | Ссылка и файл — не группа дубликатов |
| 9.6 | F3 на копии; F8 по отмеченному | Открывается настоящий файл; отмеченное — в Корзину, группа уменьшилась или пропала, итог в заголовке меньше |
| 9.7 | Ctrl+3 (Типы) на папке разработки | Первая группа «Сборки и кэши» (всё внутри `target`, `node_modules`, `.cache`), «Код» — без сборок; Enter раскрывает крупнейшие файлы сборок; в статусе — «Сборки и кэши: target node_modules .cache» |
| 9.8 | Открыть анализ, посчитанный до обновления (кэш старого формата) | Кэш не используется — анализ считается заново один раз, дальше открывается из кэша |
