# F03-07 — операции SFTP: F5/F6/F7/F8/Shift+F6, докачка, сравнение и синхронизация

Статус: ⏳ (2026-11-03, PR x/ops-sftp)

Стенд Windows 11 с тестовым SSH-сервером (OpenSSH, SFTP), который можно остановить (`net stop sshd`) и запустить снова. Слева — локальная папка, справа — `sftp://<профиль>/…`. Снимки `screen-sftpcopy`, `screen-sftpsync` (`--screens`) сверены с макетами; здесь — живое поведение.

| № | Действие | Ожидание |
|---|---|---|
| F0307.1 | Отметить 2 файла и папку, F5 | Строка «Копировать 3 объекта в» с `sftp://<профиль>/…`, «Если файл есть», «Сохранять права и даты» отмечен; Enter — job-бар «имя → sftp://…», скорость и «ещё N с» |
| F0307.2 | F5 файла 1 ГБ, на 50–60 % остановить sshd, через 10 с запустить | Строка задачи — «ждёт связи» (`context_remote`), после переподключения — «докачка с N %», дописывает; файл на сервере совпадает (`sha256sum`) |
| F0307.3 | Отмена (✕) посреди файла | Задача уходит сразу; на сервере остаётся `<имя>.urfin-part`; повторный F5 — «докачка с N %» |
| F0307.4 | Снять «Сохранять права и даты», F5 | Время файла на сервере — время копирования; с флажком — как у источника |
| F0307.5 | F6 внутри сервера (другая папка) | Мгновенно (`rename`); F6 с сервера на диск — копия и удаление на сервере |
| F0307.6 | F7 `a/b;c` на сервере, Shift+F6 файла | Папки созданы, курсор на `a`; переименование на месте, занятое имя — тост «уже есть» |
| F0307.7 | F8 на сервере | Строка «Удалить насовсем» (корзины нет); папки удаляются целиком |
| F0307.8 | Ctrl+F12 (сравнение) локальной папки и сервера | Файлы, отличающиеся по времени меньше чем на 1 с, — одинаковые; стрелки у того, что уйдёт |
| F0307.9 | Синхронизация (→) | Строка «→ N файлов · размер · на сервере лишних: M», «Удалять лишнее на сервере» снят; Enter — лишнее осталось. Отметить флажок — строка красная, Enter — лишнее удалено |
