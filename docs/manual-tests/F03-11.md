# F03-11 — Мультивыполнение

Статус: ⏳ (2026-11-05, PR x/term-multi)

Снимок `screen-sshmulti` (`--screens`) сверен с макетом; здесь — живое поведение. Нужны 3–4 SSH-сеанса (Shift+Enter на профилях в «Подключениях», «Новый сеанс» в меню шапки).

| № | Действие | Ожидание |
|---|---|---|
| F0311.1 | В SSH-терминале Ctrl+Alt+G (рус. и англ. раскладка) | Терминал на весь экран, слева колонка «Сеансы · группа ввода» шириной 200, сеансы с адресами; подсказка в keybar «Пробел — В группу / из группы» |
| F0311.2 | ↑↓, Пробел на двух-трёх сеансах, Enter | Флажки ставятся; с двух сеансов — чип «⚠ Ввод в N сеанса: … · Выйти Esc» в заголовке, терминал не сдвинулся; справа блоки сеансов; Enter уводит клавиши в ввод |
| F0311.3 | Набрать `uptime` | Символы видны во всех блоках одновременно и в одном порядке (Backspace, стрелки — тоже; на разных оболочках — bash и zsh — стрелки истории работают в обеих) |
| F0311.4 | Enter | Команда не ушла; над вводом строка «Отправить в N сеанса: `uptime`? Enter — да, Esc — нет» |
| F0311.5 | Esc | Строка исчезла, набранное стёрто во всех сеансах (`Ctrl+U`), команда не выполнилась; из группы не вышли |
| F0311.6 | Снова `uptime`, Enter, Enter | Команда выполнилась везде; статус «Группа: N сеанса из M», «первая команда подтверждена в чч:мм»; дальше Enter без вопросов |
| F0311.7 | Ctrl+Alt+G, Пробел на сеансе, Enter, Enter в вводе | Состав сменился — снова вопрос |
| F0311.8 | `[ssh] multi_exec_confirm = false`, новая группа | Первый Enter без вопроса |
| F0311.9 | На сервере: `PROMPT_COMMAND='printf "\e]133;D;%s\a" $?'`, `false` в группе | В заголовке блока «код 1» (`danger`), после `true` — «код 0» серым. На сервере без этой настройки кода в заголовке нет |
| F0311.10 | Много вывода: `seq 1 200`; блоков 3–4; окно узкое и низкое | Высота поровну, не меньше 6 строк; не влезло — прокрутка колёсиком; строки по ширине блока, PTY — ширины блока (статус показывает размер) |
| F0311.11 | Вставка Shift+Insert многострочного текста в группе до подтверждения | Вставка не выполнилась, вопрос; Esc — ничего не осталось в строке |
| F0311.12 | Закрыть один сеанс группы (`exit`, затем сеанс закрыт) | При двух оставшихся группа живёт; при одном — снова колонка; вышедший процесс ввод не перезапускает |
| F0311.13 | Ctrl+O на экране группы, набор в панелях и в терминале пары, снова Ctrl+O | С панелями ввод идёт как обычно, чипа нет; Ctrl+O возвращает экран группы и состав |
| F0311.14 | Esc вне строки вопроса; клик «Выйти» в чипе | Выход из группы; размер PTY снова как у окна (или пары) |
| F0311.15 | `policy.toml`: `[ssh] multi_exec = false` (на лету, при открытой группе) | Группа закрылась; Ctrl+Alt+G — отказ; в keybar пары Ctrl+Alt+G нет |
| F0311.16 | Обязательная запись и переполненный диск у одного сеанса группы | Ввод в этот сеанс заблокирован, остальные получают ввод |
