# F03-12 — Запись сеанса

Статус: ⏳ (2026-11-04, PR x/term-rec)

Снимок `screen-sshrec` (`--screens`) сверен с макетом; здесь — живое поведение.

| № | Действие | Ожидание |
|---|---|---|
| F0312.1 | Локальный pwsh: Ctrl+Alt+R (рус. и англ. раскладка), `dir`, Ctrl+Alt+R | Чип «Запись мм:сс · Остановить Ctrl+Alt+R» появляется и пропадает; в `%LOCALAPPDATA%\Urfin\recordings` — `pwsh-…cast` |
| F0312.2 | `asciinema cat <файл>` (WSL или другой ПК) | Вывод как в терминале, ошибок формата нет |
| F0312.3 | SSH: `sudo -k; sudo ls`, ввести пароль; затем открыть `.cast` в Блокноте | Пароля в файле нет (только «[sudo] password for …») |
| F0312.4 | `policy.toml`: `[ssh] recording = "required"`; открыть SSH-терминал | Запись идёт с баннера входа; чип с замком «обязательна · политика · TOML»; Ctrl+Alt+R — отказ; в keybar Ctrl+Alt+R нет |
| F0312.5 | `recording = "forbidden"` (на лету, при идущей записи SSH) | Запись SSH останавливается; Ctrl+Alt+R в SSH — отказ; локальный терминал пишется |
| F0312.6 | `required`, `[ssh] recordings_dir` на переполненный USB-диск | Баннер «Запись невозможна — ввод заблокирован»; набор в терминале не уходит |
| F0312.7 | Ресайз окна во время записи; F3 на `.cast` | В файле события `"r"`; статус «Запись в … · asciicast v2, N МБ» растёт раз в секунду |
