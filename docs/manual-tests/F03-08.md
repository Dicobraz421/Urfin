# F03-08 — F3/F4 удалённых файлов (`sftp://`)

Статус: ⏳ (2026-11-04, PR x/view-sftp)

Стенд Windows 11 с тестовым SSH-сервером (OpenSSH, SFTP), который можно остановить (`net stop sshd`) и запустить снова; второй сеанс к серверу (PuTTY или `ssh`) — править файлы «со стороны». Справа — `sftp://<профиль>/…`. Снимок `screen-sftpedit` (`--screens`) сверен с макетом; здесь — живое поведение.

| № | Действие | Ожидание |
|---|---|---|
| F0308.1 | F4 на `app.conf` (права 640) на сервере | Редактор: у таба чип «<профиль>», путь `sftp://<профиль>/…` в шапке, внизу «Файл с <профиль> · сохранение закачает его обратно»; копия — в `%LOCALAPPDATA%\Urfin\temp\sftp\<профиль>\<hash>\app.conf` |
| F0308.2 | Правка, F2 | Строка «Закачка app.conf → <профиль>» с полосой, затем «✓ готово · размер · время»; `ls -l` на сервере — новое содержимое, права те же (640), владелец тот же; `.urfin-part` не остался |
| F0308.3 | Открыть файл, во втором сеансе изменить его на сервере, в Урфине правка и F2 | Строка «Файл на сервере <профиль> изменился с момента открытия» — Перезаписать / Сравнить / Отмена; на сервере — чужая версия, пока не нажато «Перезаписать» |
| F0308.4 | На строке конфликта — «Сравнить» | Вьювер на файле сервера (текущая версия); Esc — снова редактор со строкой конфликта |
| F0308.5 | «Отмена», затем Esc | Вопрос «Сохранить?» (копия не на сервере); «Сохранить» — снова сверка и конфликт |
| F0308.6 | F4 на файле 50 МБ, правка, F2, на середине закачки остановить sshd, через 10 с запустить | Строка «Закачка … ждёт связи» (`context_remote`), после переподключения — закачка заново и «готово»; файл на сервере целый на всём пути (старый, пока не пришёл новый) |
| F0308.7 | Закрыть таб (Esc) | Папка копии в `%LOCALAPPDATA%\Urfin\temp\sftp\…` удалена |
| F0308.8 | F4 на файле больше 1 МиБ | Скачивание — задача в job-баре с прогрессом; в шапке «Скачивание… N %» |
| F0308.9 | F3 на логе 2 ГБ на сервере | Открывается сразу, в `temp` копии нет, прокрутка в конец (Ctrl+End) — подгружает только видимое; у таба чип «<профиль>» |
| F0308.10 | F4 на `/etc/nginx/sites-enabled/app.conf` (ссылка), F2 | Записана цель ссылки; `ls -l sites-enabled` — ссылка осталась ссылкой |
| F0308.11 | F4 на `отчёт.txt` в cp1251 с русским именем, правка латиницей, F2 | Имя на сервере то же; байты кириллицы не изменились (`iconv -f cp1251` читается) |
| F0308.12 | Запустить Урфин с остатком папки копии старше 7 дней в `temp\sftp` | Папка удалена при старте; свежие (моложе 7 дней) — на месте |
