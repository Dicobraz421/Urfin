# D-03b — Курсор и отмеченные как в Проводнике (№73)

Статус: ⏳ (2026-10-26, сборка PR w/ui-wave-03)

Тестовая копия с `urfin.portable`; светлая и тёмная тема.

| № | Действие | Ожидание |
|---|---|---|
| 1 | Походить стрелками по списку активной панели | Курсор — рамка 1 px цвета акцента без заливки; цвет текста и раскраска типов не меняются |
| 2 | Insert на трёх файлах, Ctrl+A, Num * | Отмеченные — заливка одного оттенка; текст обычный (не полужирный, не акцентный) |
| 3 | Курсор на отмеченный файл | Заливка и рамка вместе |
| 4 | Tab в другую панель | В неактивной панели курсора не видно; отмеченные там по-прежнему залиты |
| 5 | Num +, набрать `*.toml;*.json`; затем Esc | Пока строка открыта, совпавшие файлы уже залиты как отмеченные; Esc — отметка откатилась |
| 6 | Num − с маской при отмеченных файлах | Совпавшие сразу показаны без заливки; Enter — так и остаётся |
| 7 | Быстрый поиск (Alt+буква) | Совпавший префикс имени — фон `highlight` (не заливка строки) |
| 8 | Brief (Ctrl+2) и Medium | То же: заливка отмеченных и рамка курсора в колонках |
