# S8-12 — Операции из результатов поиска

Статус: ⏳ (2026-11-07, PR w/s8-12)

Тестовая копия с `urfin.portable`. Папка-песочница с копией репозитория (несколько `Cargo.toml` в разных папках, например `crates\*\Cargo.toml`) и пустая папка для копий. Свои файлы не трогать: всё — в песочнице.

| № | Действие | Ожидание |
|---|---|---|
| 1 | Alt+F7, «Имя» `Cargo.toml`, «В» — песочница, Enter, Ctrl+Enter | Панель `search:` со строками `crates\core\Cargo.toml`, `crates\ops\Cargo.toml`… |
| 2 | Пассивная панель — пустая папка; в поиске Ins на трёх `Cargo.toml`, F5, Enter | Одна задача копирования; в назначении `crates\core\Cargo.toml` и т. д. — папки воссозданы, файлы не перезаписали друг друга, вопроса о конфликте нет |
| 3 | То же, F5 ещё раз в ту же папку | Вопрос о конфликте по каждому файлу — как у обычной копии |
| 4 | Курсор на `crates\ops\Cargo.toml`, F8, «В корзину» | Удалён именно этот файл (остальные `Cargo.toml` на месте), он в корзине; строка ушла из панели поиска |
| 5 | Shift+F8 на другом `Cargo.toml` | Удаление насовсем, только этот файл; строка ушла |
| 6 | Отметить два файла, F6 в пустую папку | Файлы перенесены с относительными папками; в песочнице их нет; строки ушли из панели после окончания задачи |
| 7 | В песочнице отметить `crates\core` и `crates\ops`, Alt+F7, «Имя» `*.rs`, Ctrl+Enter; F5 файла `…\core\src\lib.rs` | Имя строки начинается с корня; в назначении `src\lib.rs` — путь от своего корня, без самого корня |
| 7a | Там же F5 обоих `src\lib.rs` (из `core` и `ops`) | У двух корней одинаковый путь — вопрос о конфликте на втором файле (известное следствие В2 А) |
| 8 | Shift+F6 на строке, новое имя (папку впереди не менять), Enter | Файл переименован в своей папке; после Ctrl+R старая строка ушла |
| 9 | Shift+F6, в поле другая папка (`other\x.toml`) | Отказ «В имени не может быть \ и /…», файл не тронут |
| 10 | Ctrl+A (DN — Alt+E) на строке, `+r`, Enter; в обычной панели проверить атрибут | Атрибут у настоящего файла |
| 11 | Обе панели — результаты поиска; F5 из одной | Отказ «search: запись не поддерживается», задачи нет |
| 12 | Обычная папка слева, поиск справа, F5 из обычной | Тот же отказ |
| 13 | F7 в панели поиска | Тот же отказ |
| 14 | Курсор на `..`, F5 | «Нечего делать», черновика нет |
| 15 | Язык EN | Тосты и названия задач по-английски |
