# T-term-inactive — Вывод терминала рисуется в неактивном окне

Статус: ⏳ (2026-11-06, PR x/term-inactive)

Тестовая копия с `urfin.portable`. Команда с непрерывным выводом: `cargo nextest run --workspace` со сборкой с нуля или `ping -t 127.0.0.1`.

| № | Действие | Ожидание |
|---|---|---|
| T.1 | Ctrl+O, запустить команду, переключиться в другое окно так, чтобы Урфин был виден (второй монитор, половина экрана) | Строки и строка прогресса идут сами, без фокуса и без движения мыши |
| T.2 | Там же перекрыть Урфин другим окном на минуту и вернуть, не активируя (мышью не трогать) | Экран догнал вывод сразу, замираний нет |
| T.3 | Свернуть Урфин на минуту, развернуть | После разворота — последний вывод, обновление идёт дальше |
| T.4 | Вывод кончился, окно без фокуса, диспетчер задач | 0 % CPU у Урфина в простое |
| T.5 | Во время вывода окно без фокуса, диспетчер задач | Нагрузка заметно меньше, чем в окне в фокусе (потолок 30 кадров/с) |
| T.6 | Окно в фокусе, та же команда | Плавно, как раньше; без фокуса и обратно — без рывков; автоповтор клавиш в cmdline не рвётся |
| T.7 | Вкладка `pkg:`, обновление пакета, Ctrl+O на ленту, окно без фокуса | Лента идёт сама; job-бар и строка пакета обновляются |
| T.8 | SSH: пара терминал + панель и экран группы, вывод на сервере (`ping`), окно без фокуса | Сетка пары и блоки группы обновляются сами |
| T.9 | F3 на растущем логе, `viewer.follow` (Shift+F), окно без фокуса | Хвост лога идёт сам |
| T.10 | Панель `sftp://`, оборвать связь, окно без фокуса | Панель показывает обрыв без фокуса |
