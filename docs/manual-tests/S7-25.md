# S7-25 — Меню «мешочком» от видимых кнопок (S7-25, S7-25a, S7-25b)

Статус: ⏳ (2026-11-01, PR x/s7-25-menus)

Тестовая копия с `urfin.portable`, пресет Far. Сверка с макетами — по снимкам `--screens`; здесь — мышь, клавиши и узкая панель.
