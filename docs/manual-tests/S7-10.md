# S7-10 — Строки «Найти» и «Перейти», закладки

Статус: ⏳ (2026-10-30, PR x/s7-10-find)

Тестовая копия с `urfin.portable`. Файлы: Markdown или лог на несколько тысяч строк, лог на 1+ ГБ (индексация идёт секунды), `.exe`. Проверять в пресете Far (по умолчанию) и на русской раскладке.

| № | Действие | Ожидание |
|---|---|---|
| 10.1 | F3 на логе, F7 | Внизу над статусом — строка «Найти»: поле с курсором, флажки Регистр / Слово / Регулярное .* / Hex; keybar — Shift+Enter Предыдущее, Alt+C/W/R/H, Esc Закрыть |
| 10.2 | Набрать слово (русское и английское), Enter | Первое совпадение — заливка `accent` на трети экрана, остальные на экране — жёлтый фон; справа от поля «1 из N»; риски на полосе прокрутки; в статусе «N отметок «…»»; фокус остаётся в поле |
| 10.3 | Enter ещё раз, затем Shift+Enter | Следующее / предыдущее совпадение, «2 из N» → «1 из N» |
| 10.4 | На русской раскладке Alt+C, Alt+W, Alt+R, Alt+H | Флажки переключаются (буква С/Ц/К/Р на месте C/W/R/H); при Hex «Регистр» и «Слово» серые, Регулярное снимается |
| 10.5 | Регулярное: `(` и Enter | Справа от поля красным «Ошибка в регулярном выражении…»; Hex: `ZZ` — «Hex: байты вида DE AD ?? EF» |
| 10.6 | Слово, которого нет | «Не найдено» красным |
| 10.7 | Поиск в большом файле | Под шапкой бежит полоса 2 px, в поле и статусе «Поиск… N %»; Esc — поиск остановлен, строка закрылась |
| 10.8 | Esc, затем Shift+F7 / Alt+F7 (или Пробел в Far) | Строка закрыта, следующее/предыдущее совпадение находится без неё; у конца файла — тост «Продолжено с начала» |
| 10.9 | Ctrl+V в поле, выделение мышью, IME (если есть) | Работают как в обычном поле ввода; F-клавиши панелей не срабатывают |
| 10.10 | Alt+F8 | Строка «Перейти к строке»: поле, «из N · строка», кнопки Перейти (Enter) / Отмена (Esc); keybar — F7 Поиск |
| 10.11 | `100` Enter; `+10`; `-5`; `50%`; `0x1F00`; `1F00h`; `$1F00` | Строка 100 — вверху экрана; сдвиги относительно текущей; процент и смещения — к началу строки; строка перехода закрывается |
| 10.12 | `12q` | Подсказка красным «Нужна строка, смещение (0x1F00, 1F00h) или процент», Enter ничего не делает |
| 10.13 | Alt+Backspace (Far: Ctrl+Z) несколько раз | Возврат к прошлым позициям по очереди |
| 10.14 | Большой лог: сразу после открытия Alt+F8, строка из конца файла, Enter | «Ждём индекс… N % · Esc — отмена» в строке и статусе; по готовности — переход и строка закрывается; Esc во время ожидания — отмена, позиция прежняя |
| 10.15 | `.exe` (Hex), Alt+F8 | «Перейти к смещению», «из 0x… · смещение»; `100` — смещение 100 (десятичное), `0x4E` — курсор на байте 4E |
| 10.16 | Ctrl+Shift+3, прокрутить, Ctrl+3 | Тост «Закладка 3 поставлена»; Ctrl+3 возвращает; Ctrl+5 без закладки — тост «Закладки 5 нет…» |
| 10.17 | В строке поиска F7 / Alt+F8 | Alt+F8 — строка перехода, F7 в ней — обратно к поиску с прошлым образцом |
| 10.18 | Тёмная тема | Строка, подсветка совпадений и полоса прогресса — цветами темы |
