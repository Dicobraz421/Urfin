# F01-10 — Живые изменения во вкладке `du:`

Статус: ⏳ (2026-11-02, PR x/du-live)

Тестовая копия с `urfin.portable`. Анализ посчитан на тестовой папке (`D:\du-test` или копия папки разработки), вкладка `du:` открыта. Диспетчер задач или Process Explorer — под рукой. Свои данные не трогать: создавать и удалять файлы только в тестовой папке.

| № | Действие | Ожидание |
|---|---|---|
| 10.1 | В Проводнике скопировать в подпапку анализа файл ~1 ГБ | Размер подпапки, её предков и итог в заголовке выросли не позже чем через 1 с после конца копирования; во время копирования растут ступеньками |
| 10.2 | Удалить этот файл в Проводнике (Shift+Del) | Размеры вернулись к прежним ≤ 1 с |
| 10.3 | Создать в анализе новую папку с вложенными папками и файлами (распаковать архив) | Папка появилась с размером, внутри — свои размеры; Enter внутрь работает |
| 10.4 | Переименовать папку внутри анализа | Старое имя исчезло, новое — с тем же размером; итог не изменился |
| 10.5 | Ничего не делать минуту с открытой вкладкой | CPU процесса — 0%, в Process Explorer у потока `du-live` нет активности |
| 10.6 | Распаковать архив на десятки тысяч мелких файлов в анализ | Окно отзывчиво (скролл, курсор без рывков); после конца распаковки итог совпадает с «Обновить» (Ctrl+Shift+R), либо у папок появились «●» (переполнение буфера наблюдения) |
| 10.7 | Закрыть вкладку `du:` | Поток `du-live` исчез (Process Explorer → Threads); папку анализа можно переименовать/удалить; повторный `du.open` открывает анализ из кэша уже с новыми размерами |
| 10.8 | F8 по файлу во вкладке, затем изменить ещё что-то в той же папке | Размеры уменьшились один раз (не вдвое), итог совпадает с «Обновить» |
