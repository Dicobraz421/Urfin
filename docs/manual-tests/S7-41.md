# S7-41 — Точная подсветка видимого окна для файлов любого размера

Статус: ⏳ (2026-11-02, PR x/hl-window)

Тестовая копия с `urfin.portable`, пресет Far. Файлы — копии в `%TEMP%`. Большие файлы: JSON ≈ 16 МБ в одну строку (выгрузка API, `npm ls --json`), JSON ≈ 1 ГБ (склеить копии массива), большой YAML (`kubectl get pods -A -o yaml`), большой `Cargo.lock`, README.md с кодом и списками.

| № | Действие | Ожидание |
|---|---|---|
| 41.1 | F3 на JSON 16 МБ, режим «Разметка», Ctrl+End, затем Ctrl+Home | Цвета на первом экране сразу; в конце — через мгновение; ключи — цвет текста, строки, числа, `true/false/null` — по ролям; ни одного неверного цвета |
| 41.2 | F3 на JSON 1 ГБ, сразу Ctrl+End | Пока проход не дошёл — без цвета и «подсветка N %» в статусе; дошёл — цвета; память процесса не растёт больше чем на десятки МБ |
| 41.3 | F4 на JSON 16 МБ, печатать внутри строки в середине | Цвета не мигают, набранное — цвета строки; кадр без рывков |
| 41.4 | Там же напечатать `"` перед ключом, затем удалить | От начала строки до конца экрана на мгновение без цвета, затем верные цвета (открытая строка — до конца строки); после удаления — как было |
| 41.5 | Там же в начале файла `/*`, затем `*/` через экран | Всё между — комментарий (и на экранах ниже — при прокрутке); после `*/` — как было |
| 41.6 | F4 на JSON 1 ГБ: Ctrl+End, правка в конце | Первый экран сразу, конец — цвета без ожидания прохода всего файла |
| 41.7 | YAML большой: ключи, списки, многострочные `|`, `"…"` через строки | Ключи — keyword, значения по типам, блочные скаляры — string; ▾ у ключей с вложенным, свёртка до следующего ключа того же уровня |
| 41.8 | README.md: заголовки, код в списке, `код` в абзаце, ссылки | Как раньше; код в обратных кавычках не «перетекает» в следующий абзац; ▾ у разделов и ограждённого кода |
| 41.9 | XML с `<!-- -->`, CDATA, `<?xml-stylesheet?>`, DOCTYPE | Комментарии, CDATA (string), DOCTYPE (keyword), теги; ▾ у элементов на несколько строк, `</тег>` при свёртке виден |
| 41.10 | `Cargo.lock` / большой TOML | Заголовки `[[package]]` — keyword, строки, числа; ▾ у каждой таблицы и многострочного массива |
| 41.11 | INI с секциями | `[секция]` — keyword, `;` комментарии; ▾ у секций |
| 41.12 | 1251-копия TOML/YAML с кириллицей; UTF-16 LE `.json` | Цвета как у UTF-8-копии |
| 41.13 | `.rs` ≤ 16 МБ и > 16 МБ | ≤ 16 МБ — как раньше (tree-sitter), больше — без подсветки |
| 41.14 | Настройки → Редактор → Подсветка | Подпись: JSON, TOML, YAML, XML, INI, Markdown — любого размера; прочие — до 16 МБ |
