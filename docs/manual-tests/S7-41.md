# S7-41 — Точная подсветка видимого окна для файлов любого размера

Статус: ⏳ (2026-11-02, PR x/hl-window)

Тестовая копия с `urfin.portable`, пресет Far. Файлы — копии в `%TEMP%`. Большие файлы: JSON ≈ 16 МБ в одну строку (выгрузка API, `npm ls --json`), JSON ≈ 1 ГБ (склеить копии массива), большой YAML (`kubectl get pods -A -o yaml`), большой `Cargo.lock`, README.md с кодом и списками.

| № | Действие | Ожидание |
|---|---|---|
| 41.1 | F3 на JSON 16 МБ, режим «Разметка», Ctrl+End, затем Ctrl+Home | Цвета на первом экране сразу; в конце — через мгновение; ключи — цвет текста, строки, числа, `true/false/null` — по ролям; ни одного неверного цвета |
| 41.2 | F3 на JSON 1 ГБ, сразу Ctrl+End | Пока проход не дошёл — без цвета и «подсветка N %» в статусе; дошёл — цвета; память процесса не растёт больше чем на десятки МБ |
| 41.3 | F4 на JSON 16 МБ, печатать внутри строки в середине | Цвета не мигают, набранное — цвета строки; кадр без рывков |
| 41.4 | Там же напечатать `"` перед ключом, затем удалить | От начала строки до конца экрана на мгновение без цвета, затем верные цвета (открытая строка — до конца строки); после удаления — как было |
| 41.5 | Там же в начале файла `/*`, затем `*/` через экран | Всё между — комментарий (и на экранах ниже — при прокрутке); после `*/` — как было |
| 41.6 | F4 на JSON 1 ГБ: Ctrl+End, правка в конце | Первый экран сразу, конец — цвета без ожидания прохода всего файла |
| 41.7 | YAML большой: ключи, списки, многострочные `|`, `"…"` через строки | Ключи — keyword, значения по типам, блочные скаляры — string; ▾ у ключей с вложенным, свёртка до следующего ключа того же уровня |
| 41.8 | README.md: заголовки, код в списке, `код` в абзаце, ссылки | Как раньше; код в обратных кавычках не «перетекает» в следующий абзац; ▾ у разделов и ограждённого кода |
| 41.9 | XML с `<!-- -->`, CDATA, `<?xml-stylesheet?>`, DOCTYPE | Комментарии, CDATA (string), DOCTYPE (keyword), теги; ▾ у элементов на несколько строк, `</тег>` при свёртке виден |
| 41.10 | `Cargo.lock` / большой TOML | Заголовки `[[package]]` — keyword, строки, числа; ▾ у каждой таблицы и многострочного массива |
| 41.11 | INI с секциями | `[секция]` — keyword, `;` комментарии; ▾ у секций |
| 41.12 | 1251-копия TOML/YAML с кириллицей; UTF-16 LE `.json` | Цвета как у UTF-8-копии |
| 41.13 | `.rs`, `.py`, `.go`, `.c`, `.js` ≤ 16 МБ и > 16 МБ (склеить исходники; нужны пакеты `grammars\\<язык>.dll`) | Цвета одинаковы на любом размере; прыжок в конец — цвета через доли секунды, «Подсветка N %» в статусе. `.sh`, `.ps1` — как раньше: > 16 МБ без подсветки |
| 41.14 | Настройки → Редактор → Подсветка | Подпись: JSON, TOML, YAML, XML, INI, Markdown — любого размера; прочие — до 16 МБ |
| 41.15 | F4 на `.md` со списками и цитатами (решение 2026-11-03): вложенные пункты, нумерованный список с пустыми строками в пунктах, `> >` | ▾ у списка верхнего уровня (на первом пункте — сворачивает весь список), у пункта с вложенным содержимым больше строки, у цитаты больше строки (и вложенной); у пункта и цитаты в одну строку ▾ нет; свёрнутое — ▸ и `⋯`, строка после списка видна; правка или курсор внутри свёрнутого — разворачивает; на файле в несколько МБ — те же ▾ после прокрутки с любого места |
| 41.16 | Редактор: длинный класс или функция, набор в теле (ADR-0024 §8) | Цвета выше строки правки не мигают, ниже — возвращаются за кадр-два; заголовок метода цвет не меняет |
| 41.17 | Открыть кавычку или `/*` в середине большого `.c` | Ниже — строка или комментарий; закрыть — всё вернулось |
| 41.18 | Свёртка `.rs`, `.py`, `.c`, `.lua`, `.diff`: функция, класс, блок, `#if`, многострочный комментарий, ханк | ▾ на месте, скрыто до закрывающей строки; вызов на несколько строк тоже сворачивается (новое: из событий трекера) |
| 41.19 | `.rs` при папке `grammars` без `rust.dll` | Открывается без цвета, без ошибок и без нагрузки на диск |
| 41.20 | `.java`, `.cs`, `.tsx` больше 16 МБ: открыть, перейти в середину, набрать в теле метода | Цвета есть, выше строки правки не мигают; свёртка методов и классов на месте |
| 41.21 | JSON в одну строку (16 МБ): F3 и F4, листать, прыгнуть в середину, перейти к концу ряда (`End`, горизонтальная прокрутка) (#310) | В конце ряда — `↩` цветом `text.tertiary` сразу за текстом, цвета на месте; выделение до конца ряда кончается перед маркером; набор в середине строки без рывков |
| 41.18 | `.html` ≤ 16 МБ и > 16 МБ (склеить страницы): теги, значения атрибутов, `<!-- -->`, `<script>`, `<style>` | Цвета одинаковы на любом размере; прыжок в конец — цвета сразу после прохода; `script` и `style` внутри без цвета |
| 41.19 | F4 на `.html` со списком без `</li>`, таблицей без `</td>`, абзацами без `</p>` | ▾ у `<ul>`, у `<li>` в несколько строк, у `<tr>`; свёртка `<li>` не прячет следующий `<li>`; `<br>` не ломает вложенность; правка тега (`<div>` → `<span>`) меняет свёртку ниже |
