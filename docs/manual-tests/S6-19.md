# S6-19 — Enter по файлу

Статус: ⏳ (2026-10-26, сборка PR w/term-01)

Тестовая копия с `urfin.portable`. Курсор панели — на файле, Enter (cmdline пуста).

| № | Действие | Ожидание |
|---|---|---|
| 19.1 | Enter на `.txt` | Открывается в редакторе по ассоциации ОС; Урфин не ждёт |
| 19.2 | Enter на файле на недоступном сетевом пути (`\\nohost\share\a.txt` через закладку или отключённый сетевой диск) | Окно Урфина отвечает сразу (курсор, Ctrl+O, ввод); ошибка ОС — окно оболочки или тост |
| 19.3 | Enter на `C:\Windows\System32\where.exe` (или другой консольной программе) | Панели гаснут (автопоказ), программа выполнилась в сеансе с выводом, shell в каталоге файла |
| 19.4 | Enter на `notepad.exe` | Блокнот открылся; сеанс свободен — сразу можно набрать команду |
| 19.5 | Активный shell cmd: Enter на `.ps1` | В транскрипте `pwsh -File ".\x.ps1"` (без pwsh 7 — `powershell`), скрипт выполнился |
| 19.6 | Активный shell pwsh: Enter на `.bat` и `.ps1` | `& '.\x.bat'`, `& '.\x.ps1'` — выполнены в сеансе |
| 19.7 | Файл без ассоциации (`a.urfinxyz`) | Окно ОС «Открыть с помощью» |
| 19.8 | Палитра (Ctrl+Shift+P) → «Open file» с `verb=runas` на `.exe`; `verb=openas` на `.txt`; `verb=new_window` на `.bat` | Запрос UAC; «Открыть с помощью»; новое окно консоли с выводом bat |
| 19.9 | В cmdline набрать `ping localhost`, Shift+Enter | Команда идёт в отдельном окне консоли ОС тем же shell; сеанс Урфина свободен |
| 19.10 | Git Bash: многострочная вставка (S6-07) и затем переход панели в другой каталог и Enter по `.bat` | Bat выполнился в каталоге панели (проверка тихого cd после вставки) |
