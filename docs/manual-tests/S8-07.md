# S8-07 — Экран поиска: Alt+F7, форма, результаты

Статус: ⏳ (2026-11-06, PR x/s8-screen)

Тестовая копия с `urfin.portable`. Папка с исходниками: тысячи файлов, например клон Urfin. Макет — `docs/design/screens/screen-search.png`. Предпросмотр справа — S8-09, панель `search:` — S8-10.

| № | Действие | Ожидание |
|---|---|---|
| 1 | Панель на папке с исходниками, Alt+F7 | Экран на месте панелей, фокус в поле «Имя», текст выделен; «В» — папка панели; «Подкаталоги» включены; командная строка видна |
| 2 | Отметить две папки, Alt+F7 | «В» — обе папки через `;` |
| 3 | «Имя» `*.rs`, Tab, «Текст» слово из кода, Enter | Строки появляются по мере поиска, под списком бежит отрезок `accent`, счётчики растут; интерфейс не замирает; в конце полоса целиком, статус «готово за X с» |
| 4 | Сверить строки с макетом | Слева `файл:строка`, справа фрагмент моно, совпадение подсвечено; курсор на первой строке, длинный фрагмент с многоточием |
| 5 | ↑↓, PgUp, PgDn, Home, End в списке | Курсор ходит, список следует за ним, за концом пустоты нет |
| 6 | Колесо и клик по строке, двойной клик | Колесо листает, клик ставит курсор; двойной клик — как Enter |
| 7 | Enter в списке | Экран закрыт, панель в папке файла, курсор на его имени |
| 8 | Поиск заново, F3 на строке, Esc из вьювера | Вьювер на строке совпадения; после выхода — снова экран, курсор на месте, клавиши работают |
| 9 | F4 на строке, Esc | То же для редактора |
| 10 | В форме: ←, →, Home, End, Shift+стрелки, Ctrl+A, Ctrl+C, Ctrl+V, Backspace, Del | Правят текст поля; курсор списка не двигается |
| 11 | В форме: ↑↓, PgUp, PgDn, F3 | Работают по списку; в поле ничего не вводится |
| 12 | Tab и Shift+Tab | Имя → Текст → В → список → Имя, рамка поля показывает фокус |
| 13 | Клик по Aa, .* и «Подкаталоги», затем набор в поле | Флажки переключаются, ввод остаётся в поле, текст не выделяется заново |
| 14 | Alt+C, Alt+R, Alt+S, в том числе на русской раскладке | Те же флажки; подсказки Aa и .* показывают клавишу |
| 15 | Поиск без подкаталогов и с регистром | Результат соответствует флажкам |
| 16 | Alt+↓ в пустом поле | История поля; в поле «В» с текстом — папки и история, Enter вставляет |
| 17 | Enter в списке дополнений, Esc в нём | Вставляет вариант, поиск не запускает; Esc закрывает только список |
| 18 | Alt+F7 при открытых результатах | Фокус в прошлом поле формы, текст выделен, результаты на месте |
| 19 | Запрос с пустым «Текстом» | Итог «Найдено N файлов» с верной формой числа: 1, 2, 5, 21 |
| 20 | Alt+T (DN) или Alt+F10 (Far), Enter, Enter на строке | Итог «Найдено N папок», панель в этой папке |
| 21 | Долгий поиск от корня диска, Esc | Экран закрыт сразу, поиск отменён, job исчез; CPU в ноль |
| 22 | Ошибочный запрос: `[` при включённом `.*` | Тост об ошибке, экран остаётся |
| 23 | Неверный путь в «В» | Тост о пути, экран остаётся |
| 24 | F9 на экране, Esc | Меню закрыто, экран и его клавиши на месте |
| 25 | Ресайз окна при длинном списке | Строки не обрезаются посередине экрана, курсор виден после нажатия стрелки |
| 26 | Тема тёмная, плотность 20 и 28 | Цвета по теме, строки по плотности, клик попадает в свою строку |
| 27 | Язык EN | Подписи формы, итог, статус и keybar на английском |
| 28 | Закрыть и запустить снова, Alt+F7 | Имя и Текст — из последнего запроса; состояние в `search_history.toml` каталога состояния |
