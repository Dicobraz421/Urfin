# S8-39 — Панель сравнения `cmp:`

Статус: ⏳ (2026-11-11, PR x/s8-39-cmp-panel)

Тестовая копия с `urfin.portable`. Две копии одной папки с исходниками (например клон Urfin и его копия, в копии часть файлов изменена, добавлена и удалена). Макет — `docs/design/screens/screen-cmppanel.png`. Ручные шаги не блокируют мерж.

| № | Действие | Ожидание |
|---|---|---|
| 1 | Левая панель — папка, правая — её копия; F9 → Команды → «Сравнить с подпапками» | Новая вкладка активной панели «папка ↔ копия»; в заголовке чип «Сравнение» и обе стороны; пока идёт — тонкий бегущий отрезок и «различий N · просмотрено M»; интерфейс не замирает |
| 2 | Дождаться конца | Справа «одинаковых N · по размеру и дате»; внизу панели строка итогов: значок, подпись и число на каждый статус их цветом |
| 3 | То же через «Сравнить с подпапками по содержимому» | Файлы с той же датой и размером, но другим байтом — «отличается»; в заголовке «по содержимому» |
| 4 | Пресет DN: Ctrl+Shift+C, в том числе на русской раскладке | То же, что п. 1 |
| 5 | Сверить строки с макетом | Приглушённое `dir\` + имя; «Статус» перед «Размер»: значок «две панели» (сторона с файлом залита, отсутствующая — пунктир, у «отличается» — обе контуром) и подпись; `только слева/справа` — зелёным, `новее …` — акцентом, `отличается` — красным; у корня нет `..` |
| 6 | Курсор на паре («новее слева») | Статус окна слева: «имя · слева X · дата · справа Y · дата»; у «только справа» — одна сторона |
| 7 | Отметить две строки | Середина статуса «Выделено 2 из N · размер»; keybar: F5 Копировать на другую сторону, Ctrl+PgUp К папке файла, Ctrl+R Сравнить заново |
| 8 | F5 | Строка «Копировать 2 объекта (…) на другую сторону» без поля пути; Enter — копирует, затем сравнение заново в той же вкладке, строки ушли |
| 9 | F6 на «только справа», Enter | Файл перенесён влево, сравнение заново |
| 10 | F8 на строке, подтвердить | Удалён именно файл строки (его сторона), сравнение заново |
| 11 | Ctrl+PgUp на строке | Панель в папке файла на его стороне, курсор на нём |
| 12 | Ctrl+R | Сравнение заново в той же вкладке |
| 13 | Enter на папке «только слева» | Панель в этой папке |
| 14 | Сторона — zip (Ctrl+PgDn в архив), вторая — распакованная копия | 0 различий у неизменённой копии |
| 15 | Тема высокой контрастности, отмеченная строка | Значок и подпись статуса — цветом текста строки |
| 16 | Язык EN | left only, right only, newer left, newer right, differs; Status, Compare; identical N · by content |
