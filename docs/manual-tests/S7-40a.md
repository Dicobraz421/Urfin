# S7-40a — Блочное выделение и полоса прокрутки редактора

Статус: ⏳ (2026-11-02, PR x/editor-2)

Тестовая копия с `urfin.portable`, пресет Far. Файлы — в `%TEMP%`: текст с табами, кириллицей и CJK (как `todo.txt` сцены `editor-block`), лог 10 ГБ — датасет V1 (`%LOCALAPPDATA%\Pets\testdata\urfin`). Notepad++ и VS Code — для обмена блоками через буфер.

| № | Действие | Ожидание |
|---|---|---|
| 40.1 | F4 на файле с табами и CJK; Alt+Shift+↓ ×3, Alt+Shift+→ ×5 | Прямоугольник ровный по колонкам (и на строках с табами и иероглифами); курсор — в углу; статус «Стр N, Кол M · Блок 4×5» |
| 40.2 | Alt+Shift+→ за концом короткой строки | Блок растёт за конец строки, курсор — в колонке за текстом |
| 40.3 | Alt+мышь: нажать и тянуть через несколько строк, за нижний край | Блок до колонки под мышью, у края — автопрокрутка |
| 40.4 | Ctrl+C на блоке, вставка в Notepad++ (Ctrl+V) | Вставилось колонкой (Notepad++ видит `MSDEVColumnSelect`) |
| 40.5 | Ctrl+C на блоке, вставка в VS Code | Вставилось колонкой или строками (как VS Code понимает признак) |
| 40.6 | В Notepad++ Alt+выделение, Ctrl+C; в Урфине курсор в середину строки, Ctrl+V | Вставилось колонкой от курсора; короткие строки добиты пробелами, недостающие — дописаны в конец |
| 40.7 | Блок, Del; затем Ctrl+Z | Колонки удалены в каждой строке (короткие не тронуты); одна отмена возвращает текст и блок |
| 40.8 | Блок, набрать «x» | Блок удалён, «x» — на строке курсора у левого края блока; Ctrl+Z — одной отменой |
| 40.9 | Блок, Ctrl+X, Ctrl+V в другом месте | Тот же прямоугольник на новом месте |
| 40.10 | Блок выше 64 тыс. строк (Alt+Shift+PgDn на логе), Del | Тост «Блок — больше 65536 строк…», текст не меняется |
| 40.11 | Полоса прокрутки справа от мини-карты: клик выше/ниже бегунка, тянуть бегунок на логе 10 ГБ | Страница вверх/вниз; бегунок ведёт по всему файлу без задержки |
| 40.12 | F7 образец на большом файле | Метки совпадений — на мини-карте и на полосе прокрутки |
| 40.13 | Настройки «Редактор» → снять «Поля» | Мини-карты нет, полоса прокрутки остаётся |
