# S7-12 — слежение за файлом (Shift+F)

Стенд: dev-сборка, PowerShell рядом, папка `C:\tmp`.

- [ ] Писатель в PowerShell: `1..100000 | % { "$_ строка"; Start-Sleep -Milliseconds 50 } | Out-File -Append -Encoding utf8 C:\tmp\f.log`. F3 на `f.log`, Shift+F: чип «Слежение» в шапке, новые строки появляются внизу без заметной задержки, номер строки в статусе растёт.
- [ ] PgUp — прилипание снято (строки не убегают), End — снова внизу и следует за файлом. Shift+F ещё раз — чип пропал, экран больше не следует за файлом.
- [ ] Во время слежения: `Clear-Content C:\tmp\f.log` — тост «Файл усечён — показан конец», дальше видны новые строки.
- [ ] Во время слежения: `Remove-Item C:\tmp\f.log` (удаляется, вьювер не мешает), писатель создаёт файл заново — тост «Файл заменён — открыт заново», видны новые строки.
- [ ] Файл больше 64 МБ, не менявшийся минуту (mmap): Shift+F — слежение работает, писатель может усечь файл.
- [ ] Диспетчер задач: при слежении за неизменным файлом Урфин ≈ 0 % CPU.
