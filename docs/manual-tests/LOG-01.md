# LOG-01 — Системный журнал и «Уровень журнала»

Статус: ⏳ (2026-11-12, PR x/log-levels)

Общий слой Pets `pets_shell::SystemLog` (правило уровней — `pets-shell/LOGGING.md` в репозитории pets). Тестовая копия
с `urfin.portable` в `%TEMP%`, `URFIN_LOG` не задан. Журнал — «Просмотр событий» → «Журналы Windows» → «Приложение»,
фильтр «Источник события» = `Urfin` (или `Get-WinEvent -FilterHashtable @{LogName='Application'; ProviderName='Urfin'}
-MaxEvents 20`). Запись ошибки (1001) и падения (1000) проверяет тест `crash_and_errors_go_to_windows_event_log` (`crates/app/tests/boot.rs`,
debug-сборка); остальное — владелец.

| № | Действие | Ожидание |
|---|---|---|
| 1.1 | Запустить Урфин, закрыть | Записи «Сведения», код 1004, строка `цель: сообщение поля`: `… starting version=…`, `startup: first frame …`, `… session saved on exit`; ошибок и предупреждений нет |
| 1.2 | Настройки → «О программе» | Под строкой «Журнал» — «Уровень журнала»: Ошибки · Предупреждения · **Сведения** (выбрано) · Отладка, справа «Со следующего запуска» |
| 1.3 | Выбрать «Отладка», перезапустить | В `config.toml` — `[log] level = "debug"`; в файле `logs\urfin.<дата>.log` есть строки `DEBUG`; в системном журнале — по-прежнему только «Сведения» и выше (DEBUG туда не идёт) |
| 1.4 | Копирование папки на флешку, флешку вынуть посреди копирования | «Ошибка», код 1001: `ops: item failed path=… error=…` на каждый не скопированный файл (или `job failed`), не больше 20 записей в минуту; пропуски, выбранные в вопросе («Пропустить»), ошибками не пишутся |
| 1.5 | Debug-сборка: `urfin.exe --crash-test` | «Ошибка», код 1000: `Urfin … crashed: crash test`, путь к crash-файлу; дубля с кодом 1001 нет |
| 1.6 | Выбрать «Ошибки», перезапустить, запустить и закрыть | Новых записей «Сведения» (1004) нет |
| 1.7 | `config.toml`: `level = "info,urfin_vfs=debug"`, перезапуск, «О программе» | Ни один сегмент «Уровня журнала» не выбран; клик по сегменту заменяет строку значением сегмента |
| 1.8 | Отключить сеть во время работы панели `sftp://` | «Предупреждение», код 1003: `net: connection lost`; после исчерпания попыток — «Ошибка» `net: reconnect failed, giving up` |
| 1.9 | Язык интерфейса — English | «Log level»: Errors · Warnings · Information · Debug, «From the next start»; название ОС в тексте не упоминается |
| 1.10 | Политикой ничего не задано | Строка без замка; содержимое файлов, пароли и токены ни в одной записи 1.1–1.8 не встречаются |
