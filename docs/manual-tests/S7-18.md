# S7-18: поиск, замена, переход в редакторе — ручные проверки

1. F4 на текстовом файле → F7: строка «Найти» внизу, фокус в поле; набор текста — подсветка всех совпадений, выделение встаёт на первое от курсора, «N из M».
2. Enter / Shift+Enter — следующее / предыдущее (с переносом); Shift+F7 / Alt+F7 — то же, и после Esc.
3. Alt+C / Alt+W / Alt+R на ru-раскладке переключают Регистр / Слово / Регулярное; ошибка regex — красным на месте счётчика.
4. Ctrl+F7: два ряда; Tab — между полями; regex `^(\w+) = "([\d.]+)"`, замена `$1 = { version = "$2" }`: Enter в «Заменить на» — заменяет текущее и встаёт на следующее; Ctrl+Alt+Enter — «Заменено: N», один Ctrl+Z возвращает всё.
5. Файл с CRLF: `^\w+$` находит строки целиком, `$` не захватывает `\r`; сохранение без правок — те же байты.
6. Alt+F8: «Перейти к строке», `29:7` → строка 29, колонка 7; `50%`, `+10`, `-3`; мусор — «Ожидается…» красным, Enter ничего не делает; Esc — курсор на месте.
7. Кнопки панели «Найти» и «Заменить» открывают те же строки; мини-карта — жёлтые метки строк совпадений.
8. Только чтение: замена не работает (кнопки бледные), поиск и переход — работают.
9. F8 без правок — перечитывание в следующей кодировке; с правками — тост «… будет при сохранении»; Shift+F8 — меню кодировок.
