# S8-36 — Меню команд архива и запрос пароля

Статус: ⏳ (2026-11-11, PR w/s8-36-arc-menu)

Тестовая копия с `urfin.portable`. Песочница: обычный `.zip` (несколько файлов, один испорчен — обрезать копию в HEX-редакторе), 7z с зашифрованными именами (7-Zip: 7z, AES-256, «Шифровать имена файлов», пароль `1`), zip с паролем AES-256 (пароль `1`).

| № | Действие | Ожидание |
|---|---|---|
| 1 | Курсор на `.zip`, F9 → «Утилиты» → «Команды архива» | Плашка у строки курсора: «Проверить архив», «Распаковать Shift+F2»; keybar — ↑↓, Enter, Esc |
| 2 | ↓, Enter | Плашка закрылась, открылась строка распаковки (как Shift+F2) |
| 3 | Снова меню, буква «П» (EN — «T») | Задача «Проверка архива» в job-баре; по концу — тост «Архив в порядке…», в списке задач (F11) — готово |
| 4 | То же на испорченном архиве | Тост с именами битых файлов; итог задачи — с ошибками (красный значок в сводке F11) |
| 5 | Меню на обычном файле (не архив) | Тост «не архив», плашки нет |
| 6 | Внутри архива (Ctrl+Shift+PgDn) — меню | Те же пункты; проверяется архив, в котором стоим |
| 7 | Enter на 7z с зашифрованными именами | Строка вопроса «Пароль для имя.7z»: поле с фокусом, «ОК Enter», «Отмена Esc»; набранное — точками |
| 8 | Неверный пароль, Enter | Вопрос снова, пояснение «Неверный пароль — осталось 2 попытки», поле пустое |
| 9 | Пустое поле, Enter | Вопрос снова, попыток столько же |
| 10 | Верный пароль, клик «ОК» | Листинг архива |
| 11 | Три неверных пароля | Тост «Неверный пароль — попыток не осталось», панель на месте |
| 12 | Esc в вопросе | Вопрос закрылся, вход отменён |
| 13 | F3 и F5 по файлу zip с паролем | Тот же вопрос; верный пароль — просмотр / копирование идут |
| 14 | «Проверить архив» на zip с паролем | Вопрос у job-бара; Esc — задача отменена |
| 15 | В поле вопроса: ←/→, Home, Backspace, Ctrl+V | Правка текста в поле, не выбор кнопок |
| 16 | После шагов 7–14: Alt+↓ в любом поле, `data\` (сессия, история) и лог | Пароля нигде нет |
| 17 | Вложенный архив сверх лимита памяти (zip в zip, «Распаковать») | Временная копия — в `data\cache\arc` переносной копии, не в `%TEMP%` |
| 18 | Язык EN | Строки — по-английски |
