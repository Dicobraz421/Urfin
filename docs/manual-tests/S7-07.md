# S7-07 — Экран вьювера

Статус: ⏳ (2026-10-30, PR x/s7-07-viewer)

Тестовая копия с `urfin.portable`. Файлы: текстовый лог на 50+ МБ, Markdown, `.exe`, файл в Windows-1251.

| № | Действие | Ожидание |
|---|---|---|
| 7.1 | F3 на Markdown-файле | Экран вьювера на месте панелей: вкладка с именем файла, шапка (значок, папка, «только чтение», «UTF-8 авто», сегмент «Разметка»), номера строк, внизу статус «Стр 1–N из M · K %» и клавиши F2/F7/F8/Alt+F8/Esc; командной строки нет |
| 7.2 | ↓, ↑, PgDn, PgUp, Home, End, колесо мыши | Прокрутка по строкам и страницам; End — последняя строка внизу экрана; колесо — 3 строки; номера и статус меняются |
| 7.3 | В длинной строке без переноса: →, ←, Shift+колесо | Горизонтальная прокрутка по колонкам; F2 — перенос, горизонталь пропадает |
| 7.4 | Ctrl+колесо | Меняется только шрифт вьювера (строки выше/ниже), строк на экране больше/меньше, позиция сохраняется |
| 7.5 | Развернуть/сузить окно | Строки и колонки подстраиваются без пустых полос; в Hex число байт в строке 8/16/32 по ширине |
| 7.6 | F3 на большом логе (50+ МБ), End, затем Home | Первый экран сразу; на End на миг — серые скелетоны строк, затем текст; окно не подвисает |
| 7.7 | F7, найти слово, которое есть в середине файла | Совпадение подсвечено и стоит примерно на трети экрана; риски на полосе прокрутки; в статусе «N отметок «…»» |
| 7.8 | Клик по чипу «UTF-8 авто» (или Shift+F8) | «Мешочек» от чипа: «Авто» сверху, группы Юникод / кириллица / западная / другие, текущая — ✓ и «авто»; в статусе «Смена кодировки перечитает файл с диска»; keybar — ↑↓ Выбор, Enter Применить, F8 По кругу, Esc Закрыть |
| 7.9 | В «мешочке»: ↓ до Windows-1251, Enter; затем снова открыть и F8 | Текст в 1251 перерисован, чип «Windows-1251»; F8 переключает по кругу, ✓ следует |
| 7.10 | Клик мимо «мешочка», колесо над ним | Мимо — закрывается; колесо листает список |
| 7.11 | F3 на `.exe` | Hex: смещения слева на подложке, линейка 00…1F, нули серые, справа текст; клавиши Shift+F4/F7/F8/Alt+F8 «Смещение»/Esc |
| 7.12 | F7 в Hex: Hex-режим поиска, `54` | Байт под курсором в рамке в обеих колонках, колонка линейки синяя; в статусе «Смещение 0x… · 54h = 84 · «T»» |
| 7.13 | Shift+F4 (пресет Far) | Меню режимов от сегментов; ↓ Enter — режим меняется; Разметка серая для файла без языка |
| 7.14 | Клик по сегментам «Текст / Разметка / Hex» | Режим меняется, позиция сохраняется |
| 7.15 | Кнопка «две панели» слева от вкладки | Панели вернулись, фокус в панели, командная строка видна (вернуться к экрану — F12, после `ui.screens`) |
| 7.16 | Клик по полосе прокрутки выше/ниже бегунка | Страница вверх/вниз |
| 7.17 | Тёмная тема (Настройки → Вид) | Цвета шапки, поля номеров, скелетонов и «мешочка» — из темы, контраст читаемый |
