# F00-01: Политики организации (ADR-0020)

Нужны права администратора (папка `%ProgramData%\Urfin`, ключ `HKLM`). После проверки — удалить файл и ключ.

1. Создать `%ProgramData%\Urfin\policy.toml` с `delete_to_trash = true` при открытом Урфине.
   Ожидается: без перезапуска в «Настройки → Политики» строка «Удалять в корзину» с замком, источник `TOML · delete_to_trash = true`; в «Операции» флажок недоступен, справа «Задано политикой организации»; Shift+F8 спрашивает про корзину, а не про удаление насовсем.
2. В админском терминале: `reg add HKLM\Software\Policies\Aahz\Urfin /v DeleteToTrash /t REG_DWORD /d 1 /f`.
   Ожидается: источник сменился на `GPO · DeleteToTrash = 1`.
3. `reg delete HKLM\Software\Policies\Aahz\Urfin /v DeleteToTrash /f`.
   Ожидается: без перезапуска снова `TOML · delete_to_trash = true`.
4. Под обычным пользователем открыть `policy.toml` в редакторе и сохранить.
   Ожидается: запись запрещена (ACL ставит установщик S9; до него — выставить вручную: запись только Administrators/SYSTEM).
5. Добавить `theme = "dark"` и `theme_locked = true`.
   Ожидается: тема тёмная, смена темы (Ctrl+Shift+T, карточки «Вида») — тост «Тема задана политикой организации».
6. Удалить файл и ключ.
   Ожидается: «Политики» — «не задано» у всех, «задано 0 из 10»; настройки пользователя вернулись.
