# S7-19 — внешний редактор, F6, новый файл, автосохранение

Стенд: dev-сборка, временная папка; для внешнего редактора — vim (или nvim) и VS Code в `PATH`.

- [ ] `[editor] external = ""`, `$EDITOR` не задан: Alt+Shift+F4 на `.txt` — программа Windows для типа.
- [ ] `set EDITOR=vim` до запуска Урфина: Alt+Shift+F4 — vim в сеансе терминала (нужен `term.exec` полосы term). Выход из vim — панели обновились (watcher).
- [ ] `[editor] external = "code -w {path}"`: Alt+Shift+F4 — VS Code отдельным окном, терминал свободен.
- [ ] `[editor] default = "external"`: F4 — внешний, Alt+Shift+F4 — встроенный.
- [ ] Shift+F4: строка имени; `заметки.md` — пустой документ, файла ещё нет; F2 — файл появился (UTF-8 без BOM, CRLF по умолчанию).
- [ ] F3 на длинном файле, перейти к строке 120 (Alt+F8), F6 — редактор на строке 120; F6 — вьювер снова на строке 120. С правками F6 сначала спрашивает «Сохранить?».
- [ ] `[editor] autosave = "delay"`: через ~1 с после правки ● гаснет, файл записан; изменить файл в Блокноте, продолжить правку — не перезаписывает, строка «Файл изменён на диске».
- [ ] `[editor] autosave = "focus"`: правка, Ctrl+O / переключиться в другое окно — файл записан (уход из окна требует от UI `InboxMsg::Blur`).
