# F03-03 — Секреты: менеджеры паролей, кэш, мост к ssh.exe

Статус: ⏳ (2026-11-01, PR x/net-12)

Стенд Windows 10/11 с OpenSSH-клиентом (`ssh -V` ≥ 8.9) и тестовым SSH-сервером. UI подключения (строки ввода, «Запомнить») — в F03-05: здесь проверяется то, что можно без него.

| № | Действие | Ожидание |
|---|---|---|
| F0303.1 | `bearpass --help` на стенде (если установлен BearPass CLI); сверить с шаблоном `bearpass get {id} --field=password` (`crates/net/src/pwcmd.rs`) | Синтаксис совпадает; иначе — поправить шаблон и записать верный здесь |
| F0303.2 | То же для Пассворка: `passwork-cli --help`, шаблон `passwork-cli get --password-id {id}` | Синтаксис совпадает; иначе — поправить шаблон и записать верный здесь |
| F0303.3 | Нет CLI менеджера: профиль `auth = "command"`, менеджер BearPass, подключиться | Ошибка «команда не найдена: bearpass», без окна консоли |
| F0303.4 | Команда, печатающая PEM-ключ (например `cmd /C type C:\keys\id_ed25519`), поднять агент Урфина на `\\.\pipe\urfin-agent-<nonce>`; в другой консоли `set SSH_AUTH_SOCK=\\.\pipe\urfin-agent-<nonce>` и `ssh-add -L` | Ровно один ключ; `ssh-add -D` — отказ, ключ остаётся |
| F0303.5 | `ssh -V` на стенде; затем `state\ssh\ssh_exe.toml` | Версия записана в кэш; повторный запрос не запускает `ssh` (кэш по размеру и времени файла) |
| F0303.6 | `set URFIN_ASKPASS=\\.\pipe\нет-такого` и `set SSH_ASKPASS_REQUIRE=force`, затем `urfin.exe "Password:"` | Окно не появляется, код выхода 1, лог и каталоги не трогаются |
| F0303.7 | Замер старта GUI до и после PR: `urfin.exe --bench-startup` ×5 | Медиана `startup.first_frame` не изменилась (в пределах шума); записать числа в PR |
| F0303.8 | Политика `password_cache = false` (`policy.toml` или GPO), в Диспетчере учётных данных заранее запись `Urfin/ssh/u@h:22` | Запуск: запись удалена; «Запомнить» (F03-05) — с замком |
| F0303.9 | Без политики, `[ssh] password_cache = true`, «Запомнить» пароль (F03-05) | В Диспетчере учётных данных — `Urfin/ssh/<user>@<host>:<port>`; при следующем подключении пароль не спрашивается |
