# F01-12 — Без прав и досчёт с правами (UAC)

Статус: ⏳ (2026-11-02, PR x/du-elevated)

Тестовая копия с `urfin.portable`, Урфин запущен без прав. Анализ места (Ctrl+F9 → «Анализ места…») корня `C:\` или `C:\Users` — так, чтобы были недоступные папки (`System Volume Information`, `C:\Users\<другой>`, `C:\Program Files\WindowsApps`). Клавиши — на любой раскладке.

| № | Действие | Ожидание |
|---|---|---|
| 12.1 | Дождаться конца подсчёта | Как `screen-dunoaccess.png`: после последней строки — «🔒 нет доступа: N папок · размер неизвестен» серым; внизу панели — баннер `warning_bg` «N папок без доступа — размер не учтён», «Досчитать с правами администратора» (щит) и «Закрыть Esc» |
| 12.2 | Enter внутрь папки без недоступных, затем назад | Строки «нет доступа» внутри нет (или число — только этой папки); у корня — снова N |
| 12.3 | «Досчитать с правами администратора» → в окне UAC «Нет» | Окно UAC — «urfin.exe», «неизвестный издатель»; после отказа — тост «Отменено в UAC — ничего не досчитано», размеры и N прежние, баннер на месте |
| 12.4 | Снова «Досчитать…» → «Да» | Job-бар «ждёт подтверждения UAC», затем «Досчитываю…»; через секунды — тост «Досчитано с правами администратора: N папок, X»; строка и баннер исчезают (или N уменьшилось); итог корня вырос |
| 12.5 | Сверить итог | Тот же анализ в Урфине, запущенном от администратора (Ctrl+R): итог корня совпадает (±жёсткие ссылки между папками) |
| 12.6 | 12.4 на большом недоступном (`WindowsApps`), сразу Esc | Задача отменена; в Диспетчере задач второй `urfin.exe` исчезает ≤ 1 с; снимок прежний |
| 12.7 | 12.4, во время досчёта закрыть Урфин | Повышенный `urfin.exe` выходит ≤ 1 с |
| 12.8 | Esc без досчёта | Баннер закрывается; строка «нет доступа» остаётся; Ctrl+R — баннер снова есть |
| 12.9 | 12.4 с вводом учётки другого администратора в UAC | Досчитано так же |
| 12.10 | Process Explorer во время 12.4 (большая папка) | У повышенного `urfin.exe` привилегии — только `SeBackupPrivilege` (вкл.) и `SeChangeNotifyPrivilege`; дочерних процессов нет; окон нет |
| 12.11 | Procmon (фильтр по повышенному `urfin.exe`, операции записи) | Запись только в `<state>\du\elevated\du-<nonce>.dures`; после досчёта файл удалён обычным Урфином |
| 12.12 | `policy.toml`: `du_elevated_helper = false` (или GPO `DuElevatedHelper` = 0), перезапуск | Кнопка с замком, недоступна; консоль администратора: `urfin.exe --du-elevated --out <state>\du\elevated\du-00000000000000000000000000000000.dures C:\Windows` → код выхода 3, файла нет |
| 12.13 | Тёмная тема, English | Тексты «no access: N folders · size unknown», «Count as administrator»; цвета из темы |
| 12.14 | Положить рядом с `urfin.exe` любой `test.dll` (копию любого файла). «Досчитать…», окно UAC не закрывать; во второй консоли без прав: `ren <копия>\urfin.exe x.exe`, `copy /y C:\Windows\notepad.exe <копия>\test.dll`, `ren <копия>\test.dll t.dll`, `del <копия>\test.dll`, `ren <копия> other` | Все команды — отказ («Процесс не может получить доступ к файлу…» / «Отказано в доступе»). В UAC «Нет» — `ren`/`del` для `test.dll` проходят (без досчёта работающий `urfin.exe` переименовать можно — так и было) |
| 12.15 | PowerShell без прав: `$f=[IO.File]::Open('<копия>\test.dll','Open','ReadWrite','ReadWrite')`, затем «Досчитать…»; потом `$f.Close()` и снова «Досчитать…» | Окна UAC нет; тост «Не удалось досчитать с правами администратора: urfin.exe или библиотеку рядом с ним держит на запись другая программа — закройте её и повторите»; после `Close()` — окно UAC есть |
