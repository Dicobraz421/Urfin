# S7-11 — Выделение и копирование во вьювере

Статус: ⏳ (2026-10-31, PR x/s7-11-13)

Тестовая копия с `urfin.portable`. Файлы: текст UTF-8 с кириллицей, тот же в 1251 и в UTF-16 LE (с BOM), лог 100+ МБ, `.exe`. Буфер обмена проверять вставкой в Блокнот.

| № | Действие | Ожидание |
|---|---|---|
| 11.1 | F3 на тексте, протянуть мышью по двум строкам | Выделение — заливка `accent`, белый текст; пустая строка внутри — клетка |
| 11.2 | Ctrl+C, вставить в Блокнот | Ровно выделенный текст, кириллица верная, переводы строк как в файле |
| 11.3 | Shift+клик ниже | Выделение расширяется от его начала до точки клика |
| 11.4 | Двойной клик по слову (русскому и английскому) | Выделено слово целиком; Ctrl+Insert — оно в буфере |
| 11.5 | Клик без движения | Выделение снято; Ctrl+C ничего не меняет в буфере |
| 11.6 | Ctrl+A, Ctrl+C на файле 1251 (F8 — Windows-1251) и на UTF-16 LE | Весь текст, Unicode верный, BOM в буфер не попал |
| 11.7 | F4 (Hex), протянуть по байтам и по колонке текста | Байты выделены в обеих колонках; Ctrl+C → `DE AD BE EF`-строка |
| 11.8 | Hex: клик по байту | Курсор на байте (рамка `accent`), в статусе «Смещение 0x… · XXh = D · «c»» |
| 11.9 | Лог 100+ МБ: Ctrl+A, Ctrl+C | Тост «Выделено больше 64 МБ — не скопировано», окно не замирает |
| 11.10 | Лог ~60 МБ: Ctrl+A, Ctrl+C | Копия меньше чем за полсекунды, прокрутка во время копирования не дёргается |
| 11.11 | F7, найти слово, Ctrl+C | Найденное (оно и есть выделение) — в буфере |
| 11.12 | Совпадение, начатое на строке выше экрана (прокрутить на одну строку вниз) | Хвост совпадения на первой строке подсвечен |
| 11.13 | Тянуть бегунок полосы прокрутки вверх-вниз | Текст следует за мышью; отпустить — позиция остаётся; клик выше / ниже бегунка — страница |
| 11.14 | Перейти Alt+F8 на строку 500, кнопка мыши «Назад» | Возврат на прежнюю позицию (как Alt+Backspace) |
| 11.15 | Markdown-документ: протянуть, Ctrl+C; Ctrl+A, Ctrl+C | Видимый текст без разметки; весь документ |
