# F02-06 — choco через UAC: согласие, отказ, журнал

Статус: ⏳ (2026-11-01, PR x/pkg-14)

Стенд с установленным choco (на машине агента его нет). Экрана `pkg:` и job-бара ещё нет (F02-08+), поэтому проверка — тестом из репозитория, он печатает строки ленты и итог:
`cargo nextest run -p urfin-pkg --run-ignored only stand_choco_uac --no-capture`.
Тест запускает `choco upgrade chocolatey -y --no-progress --noop` — пробный прогон, система не меняется.

| № | Действие | Ожидание |
|---|---|---|
| 6.1 | Запустить тест | Окно UAC: программа «Chocolatey» (choco.exe), издатель Chocolatey Software; не PowerShell и не Урфин |
| 6.2 | В UAC «Да» | Открывается отдельное консольное окно choco и закрывается само; в выводе теста строки `  \| …` из журнала choco (без `DEBUG`), затем `result: Ok(Ok)` |
| 6.3 | Запустить ещё раз, в UAC «Нет» | Окна choco нет; `result: Err(Elevation(Declined))` и строка «UAC declined → job Cancelled «отклонено»» |
| 6.4 | Запустить, UAC не трогать 30 с, затем «Да» | Тест ждёт решения; после «Да» — как 6.2 |
