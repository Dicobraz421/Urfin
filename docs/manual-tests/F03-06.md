# F03-06 — панель `sftp://`: заголовок, статус, обрыв связи

Статус: ⏳ (2026-11-03, PR x/net-sftppanel)

Стенд Windows 11 с тестовым SSH-сервером (OpenSSH, SFTP), который можно остановить и запустить снова (`net stop sshd` / `net start sshd` или выдернуть сеть ВМ). Снимки сцен `screen-sftppanel`, `screen-sftplost` (`--screens`) уже сверены с макетами; здесь — то, что видно только вживую.

| № | Действие | Ожидание |
|---|---|---|
| F0306.1 | Подключиться к профилю (Alt+F2 → профиль → Enter) | Заголовок: чип «SSH», путь `sftp://<профиль>/…` — подчёркивание активной панели не сдвигает путь относительно «N объектов · X мс» справа |
| F0306.2 | Курсор по строкам панели | Статус справа одной группой: «user@host · ssh-ed25519 · ключ из агента (Pageant)» (или «ключ id_ed25519», «пароль», «пароль из менеджера», «+ код» при 2FA) |
| F0306.3 | Отметить 2–3 файла (Ins), курсор на третий; остановить sshd | Через ≤ 2 keep-alive (или сразу при разрыве TCP) — список приглушён, не исчезает; справа в заголовке «N объектов · из кэша»; внизу панели строка `warning_bg` «Связь с … потеряна · переподключение через N с (попытка k из 5)», отсчёт идёт каждую секунду |
| F0306.4 | Tab, Shift+Tab | Рамка `accent` ходит между «Переподключить сейчас» и «Отключиться»; keybar — только «Tab Следующая кнопка» |
| F0306.5 | Запустить sshd до исчерпания попыток | Строка уходит, список снова яркий, перечитан на месте: курсор и отметка те же, новые файлы на сервере видны |
| F0306.6 | Остановить sshd и дождаться 5 попыток | Строка «Отключено от … · список — с последнего чтения», кнопка «Переподключить Enter»; запустить sshd, Enter — подключение, курсор и отметка на месте |
| F0306.7 | Во время обрыва — «Отключиться» | Строка «Отключено от …»; Enter («Переподключить») поднимает новое подключение в ту же папку |
| F0306.8 | Набрать команду в командной строке при строке обрыва, Enter | Выполняется команда, а не «Переподключить» |
| F0306.9 | Перезапустить Урфин с табом `sftp://` в сессии | Вместо списка «Не подключено к …», кнопка «Подключить Enter»; сам не подключается; Enter — подключение в папку таба |
| F0306.10 | Папка ~10 000 файлов на сервере, листать PgDn/End | Без рывков; кадр в пределах бюджета (замер `--bench` — только локальные папки, см. карточку) |
