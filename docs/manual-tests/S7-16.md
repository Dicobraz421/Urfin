# S7-16 — Экран редактора

Статус: ⏳ (2026-11-01, PR x/s7-16-editor)

Тестовая копия с `urfin.portable`. Файлы: Cargo.toml (LF), файл с CRLF, файл со смешанными концами строк, файл в Windows-1251 с байтами, недопустимыми в UTF-8, файл 10 МБ и 20 МБ. Пресет Far, раскладки ru и en.

| № | Действие | Ожидание |
|---|---|---|
| 16.1 | F4 на Cargo.toml | Экран редактора как `screen-editor.png`: вкладка с именем, шапка с путём к папке, панель инструментов, номера, мини-карта справа, статус «Стр 1, Кол 1 · N строк · TOML · Пробелы: 4 · Вставка», keybar F2/F7/Ctrl+F7/Alt+F8/Esc; курсор мигает |
| 16.2 | Набрать текст, стрелки, Home/End, Ctrl+←/→, PgUp/PgDn, Shift — выделение, мышь (клик, drag, двойной, тройной) | Работает; текущая строка подсвечена; «Стр/Кол» в статусе меняются; во вкладке появляется ● |
| 16.3 | Через полсекунды после правки | Слева от номеров — полоса: синяя у изменённой строки, зелёная у добавленной; в шапке «+N добавлено · M изменена» |
| 16.4 | Ctrl+C / Ctrl+X / Ctrl+V, Ctrl+Ins / Shift+Ins / Shift+Del на русской раскладке | Буфер обмена работает |
| 16.5 | IME японский / китайский / корейский: набрать и подтвердить | Окно кандидатов у курсора, текст вставляется |
| 16.6 | Ctrl+Z / Ctrl+Shift+Z (Far) | Отмена и возврат правок группами |
| 16.7 | Ctrl+Y | Удалена строка курсора, Ctrl+Z возвращает её одним шагом |
| 16.8 | Ins, набрать символы; Ins снова | В статусе «Замена», символы под курсором заменяются (в конце строки — дописываются); снова «Вставка» |
| 16.9 | Файл с CRLF: Enter, вставка многострочного текста из Блокнота; F2; открыть в hex-вьювере | Все новые строки — CRLF (0D 0A), смешанных нет |
| 16.10 | Файл со смешанными концами строк: открыть и сразу F2 (без правок) | Байты файла не изменились (сравнить `fc /b` с копией) |
| 16.11 | Tab / Shift+Tab с выделением нескольких строк; Alt+U / Alt+I (Far) | Блок сдвигается вправо / влево |
| 16.12 | Колесо мыши, клик по мини-карте | Текст прокручивается; рамка на мини-карте ходит за видимой частью; клик ставит курсор на строку |
| 16.13 | Файл 10 МБ | Пока грузится — «Загрузка… N %» в шапке и полоса под ней; потом текст; набор без задержек |
| 16.14 | Файл 20 МБ | В шапке «Файл слишком большой для редактора (20 МБ)» и кнопки «Открыть в просмотре» / «Внешний редактор» — обе работают |
| 16.15 | Файл 1251 с недопустимыми байтами, открыть как UTF-8 | Внизу строка «Есть байты, недопустимые в UTF-8…» с кнопкой «Сменить кодировку F8» — открывает меню кодировок |
| 16.16 | Правка, Esc | Внизу «“Cargo.toml” изменён. Сохранить?» с кнопками Сохранить S / Не сохранять N / Отмена Esc; буквы на русской раскладке (Ы, Т) работают |
| 16.17 | Файл с атрибутом «только чтение» | Чип «только чтение» в шапке, ввод не меняет текст, кнопки правки на панели серые |
| 16.18 | F12 в редакторе | Список экранов поверх редактора, Enter переключает экран |
| 16.19 | Переключиться в другое окно Windows при `autosave = "focus"` | Файл сохранён, ● пропала |
