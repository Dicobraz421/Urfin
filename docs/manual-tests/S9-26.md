# S9-26 — Автообновление (pets-update)

Статус: ⏳ (2026-11-11, PR x/self-update)

Нужен открытый ключ в `UPDATE_PUBLIC_KEYS` и подписанный выпуск новее установленной версии. Тестовая копия с `urfin.portable`. Ручные шаги не блокируют мерж.

| № | Действие | Ожидание |
|---|---|---|
| 1 | Сборка без ключа: F9 → Настройки → О программе | «Обновления»: «Проверять обновления · Раз в сутки», «Проверить сейчас», канал; справа «В этой сборке нет ключа обновления»; в журнале `update key is not set`, сетевых запросов нет |
| 2 | Сборка с ключом, выпуск новее: подождать минуту после старта | Внизу баннер «Вышла версия X · сейчас установлена Y», «Установить» / «Позже» |
| 3 | «Позже» | Баннер ушёл; после перезапуска в тот же день не появляется (проверка раз в сутки) |
| 4 | «Проверить сейчас» | Баннер снова; без новой версии — тост «Установлена последняя версия» |
| 5 | «Установить», затем отмена в job-баре (F11) | Задача «Урфин X» с ходом в байтах, отмена — баннер снова, недокачанное удалено |
| 6 | «Установить» до конца | Урфин закрывается с сохранением сессии, ставится и запускается снова: строка «Урфин обновлён до X · с Y», `urfin.portable` и `data\` на месте |
| 7 | Выключить «Раз в сутки», перезапустить | Фоновых запросов нет (журнал), «Проверить сейчас» работает |
| 8 | `HKLM\Software\Policies\Aahz\Urfin\AllowUpdate = 0` (или `allow_update = false` в `policy.toml`), перезапуск | Выключатель с замком «Задано политикой организации», кнопки нет; в «Политиках» строка «Обновление программы · Запрещено» |
| 9 | Язык EN | Updates, Check for updates, Once a day, Check now, Stable / Beta, «Version X is available» |
