# F02-09, F02-10 — поиск и действия во вкладке «Пакеты»

Статус: ⏳ (2026-11-02, PR x/pkg-act; вывод и вето — 2026-11-05, PR x/pkg-output)

Стенд с winget (и, если есть, scoop/choco). Тестовый пакет — небольшой, например `7zip.7zip` (winget), `main/7zip` (scoop), `7zip` (choco).

| № | Действие | Ожидание |
|---|---|---|
| 10.1 | Ctrl+F9 → «Пакеты…», Ctrl+3 | Внизу вкладки строка «Найти пакет [..] в [Все ▾] [Найти Enter]», фокус в поле |
| 10.2 | Ввести `7zip`, Enter | Под полем «winget ищет…», «scoop ищет…»; группы появляются по мере ответов; строка поиска остаётся; заголовок «N программ · M вариантов», чип «Найти «7zip»» |
| 10.3 | Пока ищет — новый запрос `peazip`, Enter | Прежние процессы winget/scoop/choco исчезают (Диспетчер задач), ответы — только по новому |
| 10.4 | Alt+↓ в поле | Мешочек «Все — параллельно / winget / scoop / choco» от кнопки; ненайденный — серым «не найден на компьютере»; ↑↓ Enter — область меняется, поиск заново |
| 10.5 | ↓ | Курсор в результатах, строка поиска закрыта; Пробел на группе — сворачивает/раскрывает варианты |
| 10.6 | Ctrl+3, Esc | Возврат к прежнему фильтру («Установленные» или «Обновления») |
| 10.7 | Запрос без результатов (`zzzzqqq`) | «Ничего не нашлось»; у сломанного менеджера — «… не ответил» красным |
| 10.8 | Enter на варианте winget `7zip.7zip` | В строке группы «устанавливается… N %», в job-баре «Установка · winget install 7zip.7zip» с ходом; по окончании «Установленные» обновились (только winget перечитан) |
| 10.9 | Insert на двух вариантах winget и одном scoop, F5 | Две job: winget — пакеты по очереди (вторая строка «в очереди»), scoop — параллельно |
| 10.10 | Вариант choco, Enter | Тост «choco требует прав администратора — будет запрос UAC»; job «ждёт подтверждения UAC» оранжевым; «Нет» в UAC — job «отклонено» |
| 10.11 | Ctrl+2, Enter на строке / Shift+Enter | Обновление строки / всех, кроме закреплённых |
| 10.12 | Ctrl+1, F8 на тестовом пакете | Строка вопроса «Удалить 7zip.7zip (winget)?» у панели; «Удалить» — job удаления, строка исчезает после перечитывания |
| 10.13 | Отмена winget-job (× в job-баре) во время установки | Процесс winget и его дети завершаются |
| 10.14 | Ctrl+3, Alt+↓, Пробел, Enter на русской раскладке | Работают так же |
| 10.15 | Во время установки — строка группы в поиске | После «устанавливается…» — мини-полоса хода, растёт вместе с процентом; в очереди и при ожидании UAC полосы нет |
| 10.16 | Ctrl+O на вкладке `pkg:` | Панели скрыты, вместо shell — лента «Пакеты»: заголовки `▸ winget install …`, строки вывода, `код выхода N`; прокрутка колесом, Ctrl+Shift+F ищет, ввод никуда не идёт |
| 10.17 | Ctrl+O ещё раз, затем команда в командной строке | Панели вернулись; команда уходит в прежний shell, его история не обрезана |
| 10.18 | В job-баре кнопка «Вывод Ctrl+O» (у второй задачи — «Вывод») | Открывается та же лента |
| 10.19 | F3 на строке winget, scoop и choco | Лента: `▸ winget info …` и вывод `winget show` (`scoop info`, `choco info`); «вне менеджера» — ничего |
| 10.20 | Установка пакета winget, инсталлятор которого просит UAC; окно UAC не закрывать 3 с | В строке и в job-баре «возможно, ждёт подтверждения UAC» оранжевым (`context_remote`); ответ в UAC и новый вывод подпись снимают |
| 10.21 | `[pkg] timeouts.silent_warn_min = 1` в конфиге, установка из 10.20, окно UAC держать больше минуты | В job-баре «нет вывода 1 мин» и кнопка «Прервать»; нажать — дерево процессов снято, job отменена |
| 10.22 | Установка несуществующего или ломающегося пакета, F11, «Повторить» | Новая job с теми же пакетами |
| 10.23 | Закрыть окно во время установки | Вопрос «Идёт установка: 1»: «Дождаться» — остаёмся, «Прервать и выйти» — дерево снято, окно закрылось |
