# S7-24 — Markdown-команды редактора и предпросмотр рядом

Статус: ⏳ (2026-11-05, PR x/ui-mdcmds)

Тестовая копия с `urfin.portable`, пресет Far. README на десяток экранов с заголовками, таблицей, задачами `- [ ]`, блоком кода и картинкой из файла рядом.

| № | Действие | Ожидание |
|---|---|---|
| 24.1 | F4 на `.md` | Панель как на `screen-editor-md.png`: Жирный, Курсив, «H ⌄», Список, Нумерованный, Задача, Ссылка, Код, Таблица, справа «Предпросмотр»; на `.txt` этих кнопок нет |
| 24.2 | Выделить слово, Ctrl+B, Ctrl+B | `**слово**`, затем исходный текст; Ctrl+Z после первого раза — одним шагом |
| 24.3 | Курсор внутри `**жирного текста**` | Кнопка «Жирный» подсвечена; Ctrl+B снимает весь жирный отрезок |
| 24.4 | Клик «H ⌄» | «Мешочек» от кнопки: Обычный текст, Заголовок 1–3; выбор ставит `## `, на кнопке «H2»; тот же уровень снимает |
| 24.5 | Выделить три строки, «Список», «Нумерованный», «Задача» | Префикс у каждой строки, номера подряд, другой тип заменяется; повтор снимает; Ctrl+Z — один шаг на команду |
| 24.6 | Выделить текст и Ctrl+K; выделить `https://…` и Ctrl+K | `[текст](|)` с курсором в скобках; `[|](https://…)` с курсором в квадратных |
| 24.7 | Код на части строки и на нескольких строках; «Таблица» в пустой строке | `` `…` ``; блок ```` ``` ```` с курсором на месте языка; шаблон 3×2, выделена первая ячейка |
| 24.8 | Ctrl+Shift+V | Тело делится пополам, мини-карта исчезает, справа документ как во вьювере; настройка запомнилась для следующего `.md` |
| 24.9 | Тянуть черту к краям | Каждая часть не уже 280; после перезапуска доля та же |
| 24.10 | Быстро печатать в длинном README | Текст не подтормаживает; документ обновляется после паузы, остальные блоки не мигают и не прыгают |
| 24.11 | Колесо над текстом, затем над документом, по очереди | Другая сторона идёт следом без дрожания и возврата; после остановки обе стоят на месте |
| 24.12 | Клик по флажку в предпросмотре | В тексте `[ ]` ↔ `[x]`, курсор на месте, Ctrl+Z возвращает; строка ниже не сдвинута |
| 24.13 | Картинка `![](img.png)` рядом с файлом и из сети | Своя показана, сетевая — плашка с причиной; при печати картинки не мигают |
| 24.14 | Файл > 16 МБ `.md` | «Предпросмотр» серый, подсказка «Файл больше 16 МБ»; Ctrl+Shift+V — тост, команды Markdown работают |
| 24.15 | Узкое окно | Кнопки уходят в «⋯» справа налево, в меню те же команды; «Сохранить», «UTF-8 ⌄», «LF ⌄» остаются |
| 24.16 | Файл только для чтения | Кнопки Markdown серые, подсказка «Только чтение»; клик по флажку ничего не меняет |
