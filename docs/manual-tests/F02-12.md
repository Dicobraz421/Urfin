# F02-12 — Настройки «Пакеты» и важные программы

Статус: ⏳ (2026-11-05, PR x/ui-pkgsettings)

Снимок `screen-settings-pkg` (`--screens`) сверен с макетом; логика порядка, важных и задачи покрыта тестами на подставном Планировщике. Здесь — то, что требует ввода и настоящего Планировщика. Рядом открыть `%APPDATA%\Urfin\config.toml` в Блокноте и `taskschd.msc` (папка `Urfin`).

| № | Действие | Ожидание |
|---|---|---|
| F0212.1 | Настройки → «Пакеты» | Как `screen-settings-pkg.png`: «Менеджеры», «Обновления», «Запуск»; пункт слева между «Политиками» и «Доступностью»; найденные менеджеры с версией (версия появляется после первой проверки), ненайденный — пунктир и «не найден» |
| F0212.2 | Перетащить чип `scoop` за ручку на место `winget` | Копия чипа идёт за указателем, чип под ним подсвечен рамкой; после отпускания порядок сменился, в конфиге `order = ["scoop", "winget", "choco"]` |
| F0212.3 | Отпустить чип мимо других чипов; перетащить чип на самого себя | Порядок и конфиг без изменений |
| F0212.4 | Найти пакет с вариантами у двух менеджеров (`7zip`), открыть настройки, сменить порядок, закрыть настройки | «Рекомендуется» и порядок вариантов следуют новому порядку без нового запроса |
| F0212.5 | «Поиск по умолчанию» кликами по кругу, открыть поиск пакета | В конфиге `search_in`; область поиска в строке «Найти пакет» — выбранная (пока запроса не было) |
| F0212.6 | «Проверять» вкл. | В `taskschd.msc` появилась `\Urfin\PkgCheck` на время из поля (по умолчанию 12:00), действие — текущий `urfin.exe --pkg-check`; тост; в конфиге `[pkg.schedule] enabled = true`; консоль не мигает, UAC не спрашивается |
| F0212.7 | Поле времени: ввести `9:05`, Enter | Задача пересоздана на 09:05, в поле `09:05`, `at = "09:05"`. Ввести `25:00` или буквы, Tab — поле вернулось к прежнему времени, задача не менялась. Esc — прежнее значение |
| F0212.8 | «Проверять» выкл. | Задача удалена, поле времени и «Ежедневно» недоступны, `enabled = false` |
| F0212.9 | Включить, закрыть Урфин, скопировать portable-папку в другое место, запустить копию → «Пакеты» | Под расписанием строка «Задача указывает на другой путь: …» и «Обновить»; после клика строка исчезла, в задаче новый путь |
| F0212.10 | Включить, удалить задачу в `taskschd.msc`, открыть раздел заново | Строка «Задачи нет в Планировщике заданий» и «Обновить»; клик создаёт задачу снова |
| F0212.11 | «Проверить сейчас» | Проверка в фоне, окно не блокируется; баннер «Доступно N · M важных» или тост «Обновлений нет» |
| F0212.12 | «+» у важных: набрать `fire`, ↑↓, Enter | Поле с подсказками среди установленных (с кэшем — сразу); чип добавился, поле закрылось, в конфиге `important = ["winget:Mozilla.Firefox"]`. Клик по подсказке — то же. Esc — ничего не добавлено |
| F0212.13 | Открыть `pkg:updates`, вернуться, «×» у чипа важной программы | Программа ушла из верха списка и из числа «важных» в чипах фильтров сразу |
| F0212.14 | В `pkg:updates` ПКМ по строке → «Важное» | Строка поднялась наверх с меткой «важное», чип появился в настройках; повтор — метка снята (галочка в меню отражает состояние). У строк «вне менеджера» пункта нет |
| F0212.15 | Важная программа с обновлением, «Проверить сейчас» | В баннере «… · 1 важных» |
| F0212.16 | Тёмная тема, English; окно 800 шириной | Цвета из темы; подписи по-английски; чипы и кнопка «Проверить сейчас» переносятся, без обрезки |
