# S7-22a — Markdown-документ во вьювере

Стенд: dev- или release-сборка, демо-дерево (`--screens` создаёт `%LOCALAPPDATA%\Temp\urfin-screens\tree`) или любой README.

- [ ] F3 на `Projects\urfin\README.md`: «Разметка» — документ, как `screen-viewer-md.png`; логотип из файла, плашка «CI · картинка из сети не загружается», в статусе «1 картинка из сети не показана».
- [ ] Картинки: локальная PNG/SVG, `data:` URI, `<img width="48">` (пропорции), широкая — не шире колонки; отсутствующая — «файл не найден», больше 20 МБ — «больше 20 МБ».
- [ ] `<details>`: клик по подписи раскрывает и сворачивает; F7 по тексту внутри свёрнутого — раскрывает.
- [ ] `<p align="center">` и `align="right"` — текст и картинки по центру / справа.
- [ ] Ссылки: наведение — подчёркивание и подсказка; `#якорь` — прокрутка к заголовку; `.md` — открывается во вьювере; файл / папка — курсор панели на нём; внешняя: клик — только подсказка «Ctrl+клик — открыть в браузере», Ctrl+клик — открывает браузер, UI не замирает.
- [ ] Выделение мышью, Ctrl+C — в буфере видимый текст без разметки; Ctrl+A, Ctrl+C — весь документ.
- [ ] F7 «Возможности»: совпадения подсвечены, «N из M», F3/Shift+F3 — переход с прокруткой.
- [ ] Ctrl+колесо меняет размер шрифта, значение пишется в `viewer.md_font_size`.
- [ ] Широкая таблица и длинная строка кода прокручиваются по горизонтали внутри блока (Shift+колесо / тачпад).
- [ ] Документ ↔ Текст (Shift+F4) — на той же позиции; PgDn/PgUp, Home/End в документе.
- [ ] Настройки → Просмотр → «Markdown: Исходник» — новый `.md` открывается исходником.
- [ ] Тёмная тема и высокая контрастность: текст, ссылки, плашки, код читаемы.
- [ ] README 16 МБ: прокрутка плавная (кадр p50 ≤ 3 мс, p99 ≤ 6 мс, release), в простое кадров нет.
