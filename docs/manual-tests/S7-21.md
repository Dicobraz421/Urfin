# S7-21 — Подсветка tree-sitter и пакеты грамматик (S7-21a, S7-21)

Статус: ⏳ (2026-11-01, PR x/s7-21-syntax)

Тестовая копия с `urfin.portable`, пресет Far. Пакеты — DLL из `assets/syntax/pack` в папке `grammars` рядом с `urfin.exe` (сборка — в `assets/syntax/pack/src/lib.rs`). Сверка с макетами — по снимкам `--screens`; здесь — живые файлы, кодировки, большие файлы.

| № | Действие | Ожидание |
|---|---|---|
| 21.1 | F3 на `Cargo.toml` | Открывается в «Разметке»: `[workspace]` и скобки — `keyword`, ключи — цветом текста, строки — `string`, `false` и числа — `number`, `# …` — `comment` (как `screen-quickview.png`) |
| 21.2 | F3 на `.json`, `.yaml`, `.ini`, `.xml` (`.csproj`, `.svg`) | Подсветка без задержки ввода; ключи JSON — текстом, значения по типу; ключи YAML и теги XML — `keyword` |
| 21.3 | Ctrl+Q, курсором по `Cargo.toml`, `package.json`, `README.md` | Область быстрого просмотра подсвечивает TOML и JSON; у `.md` — документ |
| 21.4 | README с блоком ```` ```toml ```` и ```` ```json ```` | В документе код блока цветной; блок ```` ```text ```` — без цвета |
| 21.5 | Без папки `grammars`: F3 на `.rs`, `.py`, `.ps1` | «Разметка» недоступна (сегмент серый), открывается Текст; в README блок ```` ```powershell ```` — без цвета |
| 21.6 | С `grammars\powershell.dll`, `rust.dll`, `python.dll` рядом с exe, перезапуск | `.ps1`, `.rs`, `.py` — в «Разметке» с подсветкой; блок ```` ```powershell ```` в README — `cargo` цветом `keyword` (как `screen-viewer-md.png`) |
| 21.7 | Положить в `grammars` пустой или чужой файл `lua.dll`, F3 на `.lua` | Урфин не падает: «Разметка» без цвета; в журнале `view.syntax` — причина (нет экспорта / версия формата) |
| 21.8 | Файл TOML/JSON в Windows-1251 и в UTF-16 LE с BOM, F8 по кольцу кодировок | Цвета стоят на своих местах (кириллица в строках не сдвигает подсветку), после смены кодировки перекрашивается |
| 21.9 | JSON 15 МБ, F3 | Текст виден сразу, первый экран окрашивается быстро, весь файл — в течение секунды; прокрутка и PgDn без рывков |
| 21.10 | JSON 17 МБ, F3 | Открывается Текстом, «Разметка» недоступна |
| 21.11 | Сменить тему (светлая, тёмная, «Сепия»), включить высокую контрастность Windows | Цвета подсветки — из `[syntax]` темы; в высокой контрастности — цвет текста |
| 21.12 | `viewer.markdown = "source"`, F3 на README | Исходник с подсветкой: заголовки и маркеры — `keyword`, код — `string`, ограды — `comment` |
