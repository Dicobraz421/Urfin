# S6-20 — Win32-input-mode: Far Manager внутри терминала

Статус: ⏳ (2026-10-26, сборка PR w/term-01)

Тестовая копия с `urfin.portable`. Нужен Far Manager 3 (`far.exe` в PATH или полный путь). `ConPTY` сам просит режим `CSI ?9001h`; Урфин отвечает записями клавиш `CSI Vk;Sc;Uc;Kd;Cs;Rc _`.

| № | Действие | Ожидание |
|---|---|---|
| 20.1 | Ctrl+O, в cmd или pwsh набрать `far` и Enter | Far во весь терминал (alt-screen), панели Урфина спрятаны |
| 20.2 | В Far: Ctrl+Space на файле | Файл помечается (как в отдельном окне Far), курсор идёт ниже |
| 20.3 | Alt+F7 | Открывается «Поиск файлов» Far |
| 20.4 | Shift+F1, Shift+F2, Shift+F4, Shift+F5, Shift+F6 | Архивация, распаковка, новый файл, копирование под курсором, переименование — диалоги Far; F-строка Far при зажатом Shift показывает Shift-подписи после нажатия |
| 20.5 | Ctrl+1…Ctrl+4 | Вид панели Far меняется (brief/medium/full/wide) |
| 20.6 | Немецкая раскладка: AltGr+Q, AltGr+7, AltGr+E в командной строке Far | `@`, `{`, `€` |
| 20.7 | Русская раскладка: набрать `файл` в командной строке Far, Alt+буква (быстрый поиск Far) | Кириллица набирается; Alt+буква открывает быстрый поиск |
| 20.8 | F10 (выход из Far) | Far закрыт, вернулся промпт shell, панели Урфина вернулись |
| 20.9 | В pwsh без Far: стрелки, Ctrl+←/→, Home/End, Tab-комплит PSReadLine | Работают как раньше (режим не ломает обычный ввод) |
