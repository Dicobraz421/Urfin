# S8-26 — Экран архива: Enter, метка, «Сжато», статус

Статус: ⏳ (2026-11-11, PR w/s8-26-arc-screen)

Тестовая копия с `urfin.portable`. Песочница: папка с настоящим `.zip` (несколько файлов и подпапка; например, архив исходников с GitHub), копия любого `.docx` и тот же zip, переименованный в `.bin`.

| № | Действие | Ожидание |
|---|---|---|
| 1 | Курсор на `.zip`, Enter | Панель внутри архива: путь `…\имя.zip`, рядом метка `zip`; таб — имя архива |
| 2 | Enter на папке внутри | Путь продолжается: `…\имя.zip\папка`; колонки «Размер · Сжато · Изменён», у папок «Сжато» пусто |
| 3 | Курсор на файле | Статус слева «имя · 1,2 КБ, сжато до 0,5 КБ · дата»; справа «архив N МБ · сжатие N %» |
| 4 | Клик по сегменту `имя.zip` в пути | Корень архива; клик по папке над архивом — обычная папка |
| 5 | Backspace (или `..`) в корне архива | Папка архива, курсор на файле архива |
| 6 | Enter на `.docx` | Файл открывается в приложении ОС, панель не входит |
| 7 | Ctrl+Shift+PgDn на `.docx` | Вход в `.docx` как в архив (`word\`, `[Content_Types].xml`) |
| 8 | Ctrl+Shift+PgDn на `.bin` (zip под другим именем) | Вход в архив; на обычном текстовом файле — тост «Неизвестный или неподдерживаемый формат архива» |
| 9 | Войти в большой zip (сотни мегабайт, тысячи файлов) | Пока читается оглавление — «Чтение архива» вместо списка, окно отзывчиво; затем список |
| 10 | Внутри архива закрыть Urfin, открыть снова | Таб внутри архива восстановлен |
| 11 | Закрыть Urfin, удалить архив, открыть | Таб — в папке, где был архив |
| 12 | Внутри архива удалить или заменить архив из Проводника | Панель уходит из архива (удалён) или перечитывает его (изменён) |
| 13 | Язык EN | «Packed», «archive … · ratio … %» — по-английски |
