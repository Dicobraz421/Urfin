# F03-10 — Подсветка вывода

Статус: ⏳ (2026-11-04, PR x/term-hl)

Снимок `screen-termhl` (`--screens`) сверен с макетом; здесь — живое поведение.

| № | Действие | Ожидание |
|---|---|---|
| F0310.1 | pwsh: `cargo test` в проекте с падающим тестом | Цвета cargo (`Compiling`, `ok`, `FAILED`) — как у cargo; пути подчёркнуты, `failed`/`panicked` — красным, `WARN` — оранжевым, дата — серым |
| F0310.2 | `ping 8.8.8.8`, `ipconfig` | IP подчёркнуты; промпт pwsh не меняется |
| F0310.3 | Ctrl+Alt+H (на русской и английской раскладке) | Подсветка выключается и включается; чип «Подсветка вывода» в заголовке пропадает/появляется; в статусе — ничего |
| F0310.4 | `vim`/`less` (alt-screen), затем выход | В TUI подсветки нет, после выхода — снова есть |
| F0310.5 | Пара SSH: `journalctl -n 30`, `git log --oneline` | Подсветка в терминале пары; чип справа в шапке «ssh srv1 ▾»; Ctrl+Alt+H в keybar |
| F0310.6 | F3 на `*.log` (режим «Текст»), Ctrl+Alt+H | ERROR/WARN/даты окрашены; Ctrl+Alt+H выключает |
| F0310.7 | Раскладка с AltGr (немецкая, польская, чешская): AltGr+H в терминале | Если раскладка печатает символ по AltGr+H — символ не должен теряться (риск исключения №88) |
| F0310.8 | Быстрый вывод (`dir /s C:\Windows`) | Нет рывков; кадр не хуже, чем без подсветки |
