# F01-05 — Вкладка `du:` и список

Статус: ⏳ (2026-11-01, PR x/du-ui)

Тестовая копия с `urfin.portable`. Папка для проверки — с вложенными каталогами на несколько ГБ (например, `C:\Dev`).

| № | Действие | Ожидание |
|---|---|---|
| 5.1 | В панели на папке: Ctrl+F9 → «Анализ места…» | Новая вкладка «du: C:\Dev», как `screen-duscan.png`: чип «Анализ», путь, справа «просмотрено N файлов · X ГБ», по нижней кромке бежит отрезок; размеры растут, недосчитанные — «≥ X» серым, полоса доли серая |
| 5.2 | Дождаться конца | Как `screen-dulist.png`: «N файлов · X ГБ», полосы синие, по размеру ↓, папки и файлы вперемешку; в статусе посередине «посчитано за …»; у корня анализа нет «..» |
| 5.3 | Повторить 5.1 на большой папке, через пару секунд Esc | Подсчёт остановлен, вкладка осталась, у недосчитанных «≥ X» |
| 5.4 | Enter на папке, затем Ctrl+PgUp (и Backspace) | Внутрь с долями этой папки; назад — курсор на папке |
| 5.5 | F3 на файле, F4 на файле | Открывается настоящий файл; правка сохраняется |
| 5.6 | Enter на файле | Открывается программой Windows |
| 5.7 | Ctrl+R | Пересчёт: снова «просмотрено…», затем итог |
| 5.8 | Закрыть вкладку, снова «Анализ места…» той же папки | Сразу из кэша, как `screen-ducached.png`: «посчитано N назад», «Обновить Ctrl+R»; клик — пересчёт |
| 5.9 | Оставить вкладку `du:` открытой, выйти и запустить снова | Вкладки анализа нет, на её месте — папка, откуда открывали |
| 5.10 | Узкая панель, тёмная тема, English | Колонки уходят с конца, подписи без обрезки, цвета из темы |
