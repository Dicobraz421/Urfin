# F01-08 — Фильтры «Крупные», «Типы», «Старые», «Временные»

Статус: ⏳ (2026-11-02, PR x/du-2)

Тестовая копия с `urfin.portable`. Анализ посчитан на папке разработки (с `target`, `node_modules`) и, отдельно, на диске C:. Клавиши — на любой раскладке.

| № | Действие | Ожидание |
|---|---|---|
| 8.1 | Ctrl+2 (или чип «Крупные файлы») | Файлы от 1 МиБ по размеру ↓, папка перед именем серым (`dir\name`); F3 / F4 / Enter открывают настоящий файл |
| 8.2 | Ctrl+3 (Типы) | Как `screen-dutypes.png`: колонки Группа · Файлов · Доля · Размер, группы по размеру, «Прочее» последней; слева в статусе у группы — её расширения, в середине «N групп · M файлов» |
| 8.3 | Enter на группе «Архивы», ещё раз Enter | Раскрыта: крупнейшие файлы группы с отступом и «ещё N файлов»; повторно — свёрнута, курсор на группе |
| 8.4 | Ctrl+4 (Старые), чипы «6 мес / 1 год / 2 года / 5 лет» | Файлы старше порога; смена порога — сразу, без подсчёта |
| 8.5 | Ctrl+6 (Временные) | Как `screen-dutemp.png`: предупреждение сверху, разделы «В C:\Dev» и «Система и профиль», у строк «что это» (сборки Cargo, пакеты npm, кэш браузера…); ничего не отмечено |
| 8.6 | Временные на диске C: | `%TEMP%`, загрузки Windows Update, кэши браузеров найдены; у папок без доступа — «нет доступа: N папок» цветом предупреждения |
| 8.7 | Enter на строке «Временных» с папкой; Ctrl+PgUp | Внутрь папки «По папкам»; назад — к «Временным» |
| 8.8 | В «Крупных» отметить файл, F8 | Файл в Корзине, строка ушла, итог в заголовке и размеры предков («По папкам») уменьшились без пересчёта |
| 8.9 | Ctrl+5 (Дубликаты) | Вид «Дубликаты» — проверки `F01-09.md` |
| 8.10 | Ctrl+1 | Снова «По папкам» корня анализа |

## Очистка «Временных» (2026-11-02, PR x/du-5)

| № | Действие | Ожидание |
|---|---|---|
| 8.11 | Ctrl+6 на диске C: | Системные строки — понятным именем («%TEMP%», «Кэш Microsoft Edge») и путём серым; после «что это» — метка «безопасно» / «пересоздастся» / «потеря данных»; слева в статусе — полное пояснение строки под курсором |
| 8.12 | Внизу «Отметить все» | Отмечены все строки, кроме Корзины; «Отмечено N · освободится X» |
| 8.13 | «Очистить выбранное…» | Вопрос: сколько строк и сколько освободится, по последствиям — что пересоздастся (сборки — долго), что потеряется; «Отмена» — ничего не удалено |
| 8.14 | Ещё раз, «В Корзину» (на тестовой папке со сборкой) | Отмеченное — в Корзине, строки ушли, итог в заголовке меньше; занятые файлы пропущены с отчётом в job-баре |
| 8.15 | Карта (Ctrl+Tab) на большом анализе (диск C:) | Карта появляется сразу, пометки «Временных» — через мгновение, интерфейс не замирает |
