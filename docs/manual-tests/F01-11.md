# F01-11 — Повторное открытие анализа: «●» и дочитка изменений

Статус: ⏳ (2026-11-02, PR x/du-fresh)

Тестовая копия с `urfin.portable`, анализ тестовой папки посчитан и вкладка закрыта (снимок в кэше). Менять только тестовую папку.

| № | Действие | Ожидание |
|---|---|---|
| 11.1 | Урфин без прав администратора. Закрыть вкладку анализа, в Проводнике добавить файл в одну подпапку и удалить другую подпапку; открыть анализ снова (Ctrl+F9 → «Анализ места…») | Как `screen-ducached.png`: сразу из кэша; через доли секунды — «посчитано N назад · ● изменено 2 папки» и «Обновить Ctrl+R»; «●» у размера изменённых папок (у удалённой — у её родителя) |
| 11.2 | Ctrl+R | В job-баре — «Анализ места, изменённые папки»; «●» исчезли, размеры как после Ctrl+Shift+R; заголовок без «изменено» |
| 11.3 | Дописать в существующий файл (размер вырос), закрыть вкладку, открыть снова | «●» нет — известное ограничение (рост файла не меняет дату папки); Ctrl+Shift+R показывает новый размер |
| 11.4 | Урфин от администратора (тестовая копия, правый клик → «Запуск от имени администратора»): посчитать, закрыть вкладку, изменить файлы, открыть снова | Размеры сразу новые (USN-журнал), «●» нет; в журнале `fresh: usn relisted=N` |
| 11.5 | Только стенд с отдельным тестовым томом X: (не рабочий диск): анализ X:\… посчитан под администратором; `fsutil usn deletejournal /d X:`, `fsutil usn createjournal X:`, изменить файлы, открыть анализ | Откат на `mtime`: «●» у изменённых, в журнале `fresh: mtime` |
