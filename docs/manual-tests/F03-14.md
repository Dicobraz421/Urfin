# F03-14 — Настройки «SSH» и строки политик

Статус: ⏳ (2026-11-05, PR x/ui-sshsettings)

Снимки `screen-settings-ssh`, `screen-settings-policies` (`--screens`) сверены с макетами; здесь — живое поведение. Рядом открыть `%APPDATA%\Urfin\config.toml` в Блокноте. Политики — файл `%ProgramData%\Urfin\policy.toml` и ключ `HKLM\Software\Policies\Aahz\Urfin` (нужны права администратора).

| № | Действие | Ожидание |
|---|---|---|
| F0314.1 | Настройки → «SSH» | Как `screen-settings-ssh.png`: «Вход», «Пароли», «Сеансы», «Подсветка вывода»; «SSH» — пункт слева, «Подключения» под ним с отступом; Tab и ↑↓ ходят по разделам |
| F0314.2 | Агент: запущен `ssh-agent` (служба), затем Pageant ≥0.75, затем оба выключены; открыть раздел заново | Пояснение: «найден OpenSSH · …», «найден Pageant · …», «агент не найден · …». Сегмент Pageant при запущенном только OpenSSH — «агент не найден» |
| F0314.3 | «Агент» → OpenSSH; подключиться профилем с входом через агент | В конфиге `[ssh] agent = "openssh"`; вход идёт через агент OpenSSH без перезапуска |
| F0314.4 | «Добавить» у ключей, ввести `~/.ssh/work`, Enter | Путь в строке и в `default_keys`; Esc в поле — ничего не добавлено; повтор существующего пути — без дубля |
| F0314.5 | Снять «Сеансы PuTTY», открыть «Подключения» | `import = { putty = false }` (или ключ в `[ssh.import]`); профили PuTTY исчезли без перезапуска; вернуть флажок — появились. Файлы `~/.ssh/config` и реестр PuTTY не менялись |
| F0314.6 | «Сохранять пароли» вкл., подключиться с паролем, «Запомнить» | Запись `Urfin/ssh/...` в Диспетчере учётных данных; выкл. флажок — следующий вход спрашивает пароль (без перезапуска) |
| F0314.7 | «Менеджер паролей» кликами по кругу | Поле команды показывает шаблон менеджера; «Не выбран», «Своя команда» — поле пустое или своя команда |
| F0314.8 | Ввести в поле команды свою, Enter; затем стереть, Enter | В конфиге `password_cmd` и `password_manager = "custom"`; пусто — `password_cmd = ""`. Esc в поле — прежнее значение; Ctrl+V вставляет; русская раскладка в поле не мешает |
| F0314.9 | «Переподключение» 3 и 5, «Keep-alive» 0, Tab | Значения в `[ssh]`: `reconnect`, `keepalive_s = 0`; буквы и минус — поле вернулось к прежнему числу, в конфиге без изменений |
| F0314.10 | После F0314.9 подключиться, разорвать сеть | Следующие подключения: 3 попытки с интервалом 5 с. Уже идущий сеанс живёт со старыми значениями до переподключения |
| F0314.11 | «Запись сеансов» → «Всегда», открыть новый SSH-терминал; → «Выкл», Ctrl+Alt+R | Запись с первого байта; при «Выкл» команда отказывает. `[ssh] recording` меняется без перезапуска, идущая запись по «Выкл» не рвётся (как `[ssh] recording` в F03-12) |
| F0314.12 | «Открыть» у папки записей (папки ещё нет) | Папка создана, настройки закрылись, активная панель в ней |
| F0314.13 | Снять «Подтверждать перед первой командой» при открытой группе (Ctrl+Alt+G, 2 сеанса) | Enter в группе без вопроса сразу; вернуть флажок — вопрос снова до первого подтверждения |
| F0314.14 | Снять «Включена» при открытом терминале с логом; снова включить | Подсветка погасла и вернулась сразу, чип в шапке следует; F3 на `.log` — уровни тоже. Ctrl+Alt+H меняет этот флажок и `enabled` в конфиге |
| F0314.15 | Клик по чипам «Ошибки», «Пути», «Хэши» | Чип снимается/ставится, ключ `term.highlight.rules.*` в конфиге; вывод перекрашен без новых строк |
| F0314.16 | `policy.toml`: `password_cache = false` при открытом разделе | Сразу замок у «Сохранять пароли», флажок снят и недоступен, «Задано политикой организации · TOML»; в статусе «1 параметр задан политикой»; «Запомнить» с замком |
| F0314.17 | Записи `Urfin/ssh/*` есть, политика из F0314.16 (или GPO `PasswordCache = 0`), перезапуск Урфина | Записи `Urfin/ssh/*` удалены из Диспетчера учётных данных при запуске, чужие целы (решение 2026-11-01 «password-cache-cleanup»). Во время работы, до перезапуска, записи не трогаются |
| F0314.18 | `[ssh] recording = "required"` в `policy.toml`, затем `"forbidden"`, затем `"user"` | Сегмент «Всегда» с замком · TOML; «Выкл» с замком; при `user` замка нет, выбор свой. Клик под замком ничего не меняет |
| F0314.19 | GPO `SshRecording = required` поверх TOML `forbidden` | Источник GPO, значение «Всегда» |
| F0314.20 | `[ssh] multi_exec = false` | «Мультивыполнение» с замком и источником; в «Политиках» строка «Запрещено» |
| F0314.21 | Настройки → «Политики» | Как `screen-settings-policies.png`: `password_cache`, `ssh.recording`, `ssh.multi_exec` заданные — с замком и «GPO · PasswordCache = 0» или «TOML · ssh.recording = "required"», незаданные — ключ и «не задано»; статус «задано N из 10 · Только чтение» |
