# Урфин — межкрейтовые контракты (действующее состояние)

Один текущий документ (скилл pets-dev, R-05): сведены изменения S0-contracts v2–v6 поверх `specs/S1.md` §2 с учётом
отменённого позже (egui → GPUI, только Windows). Менять — только PR класса B (CODEOWNERS) с записью в «Изменения».
История версий — `docs/archive/S0-contracts-v2…v6.md`; ссылки вида «v3 №5» в коде и документах ведут туда.

## Core: состояние и команды

- **Листинг.** `ListingUpdate::Chunk { entries, visible }` (core дописывает `visible` в `order` через `Arc::make_mut`); `ListingUpdate::Patch(Patch { base_len, seq, update, remove /*desc, swap_remove*/, append, order })` — применяется при совпадении gen/len/seq, правит selection, stats, держит курсор и `pending_focus`, иначе отбрасывается. `seq: u32` в `LoadReq`, `ArrangeReq`, `Order { order, for_len, seq }`; `Listing.arrange_seq` растёт на sort/filter/hidden. `ListingService::tab_event(TabEvent { Shown, Hidden, Closed, Left { tab, loc, entries } })`. Core дедуплицирует `panel.refresh` по табу в пределах pump. (v2 №1–4, №14)
- **Entry и пути.** `Attrs::ESCAPED_NAME = 1<<10`, `SIZE_KNOWN = 1<<11`, `SIZE_PARTIAL` (размер досчитывается, «≥ X»). Пути для ОС — только `vfs::name::{to_os, join_os}`. Нормализация `Location::local`: абсолютный; `\\?\C:\`→`C:\`, `\\?\UNC\s\sh`→`\\s\sh`; буква диска — заглавная; `/`→`\`; `.`/`..` лексически; без хвостового разделителя, кроме корня; регистр и symlink не трогать. `Location.outer` — глубина ≤ 8; `>>` в компонентах экранируется в `to_uri`. `Location.authority: Option<CompactString>` — сервер сетевой схемы (`sftp`: имя профиля), uri `backend://authority/path` (`sftp://srv1/var/www`), в authority экранируются `%`, `>`, `/`; `parent` не выходит за корень сервера; у `local` и контейнеров — `None`. (v2 №5–6, v5 №8, v6 №7, v6 №20, [решение 2026-11-01](decisions/2026-11-01-location-authority.md))
- **Расширения.** `AppState.ext: Extensions` — typemap `get/get_mut/insert`; мутации только в Handler/Msg; ключи — типы своих крейтов. Ext-состояние вкладок виртуальных схем (`DuState`, `PkgState`). Модель подключений SSH/SFTP для UI — `urfin_core::net::NetModel` (чистые данные: профили, история, сеансы, вопросы, строка «Новое подключение», `trait Ping`); наполняет `urfin-net` в handler и `Msg`, каналы — у него. Модель вкладки «Пакеты» для UI — `urfin_core::pkg::PkgModel` (чистые данные: пакеты и менеджеры, `View` со строками, поиском и ходом действий, сводка `PkgInfo`, `PkgFeed` — опубликованный вид и `rev`, `trait PkgFixture` для сцен `--screens`, метаданные команд `pkg.*`); наполняет книга и handler `urfin-pkg`, `PkgState` (конфиг и книга) — у него. Модель поиска для UI — `urfin_core::search::SearchModel` (чистые данные без grep и I/O: сторы `SearchStore` со строками `Hit` и рядом файлов, счётчики `SearchInfo` на атомиках, стор на экране, курсор списка, история запросов, `rev`); строки дописывает обход `urfin-search` из своих потоков, UI берёт окно строк и не держит блокировку. (v2 №10, v6 №3, [решение 2026-11-02 «net-model-core»](decisions/2026-11-02-net-model-core.md), [решение 2026-11-03 «pkg-model-core»](decisions/2026-11-03-pkg-model-core.md), [решение 2026-11-06 «s8-answers»](decisions/2026-11-06-s8-answers.md))
- **Значения команд.** `Value::List(Arc<[Value]>)`, `Args::list/locs`, текст `src=["a","b"]`; `Args::side(k) -> Option<SideRef>` (`left|right|active|passive`). `Value::Text` не вводим. (v2 №11, v3 №5, v5 №6)
- **Фокус.** `Focus { Panel, Cmdline, Prompt(PromptId), Viewer, Editor, Terminal, Overlay(OverlayKind) }`, `OverlayKind { Menu, QuickSearch, InlineEdit, Draft, Palette, Find, Search }`. Keymap поглощает в `Overlay`/`Cmdline` привязки своего контекста и `global`; в `Terminal` и `Prompt` — только своего контекста ([ADR-0015](adr/0015-global-context.md)); в `Editor` — `editor` + `global`, остальное — виджету. IME: Cmdline, Terminal, Editor и оверлеи с вводом; Viewer — без IME. (v3 №1–2, v4 №2, v5 №1–2)
- **Панель.** `panel.viewport { side, rows, cols, top }` (`top` — прокрутка, в Cursor, меняет `rev`); `panel.cursor.left/right/match {mask, dir}`, `panel.root`, `panel.mode {files|info|qview|tree}` (`Tab.mode`, в сессии), `panel.bookmark.set/go {n}`; `sel.move {motion}`, `sel.invert {dirs?}`, `sel.same {by, on}`, маска в `sel.add/remove` — опциональна. `ViewMode::Custom(u8)` — наборы колонок. (v3 №3–4, №6)
- **Задачи.** `JobSpec { kind, title, lane, priority: u8, owner_ns }`; `JobHandle::set_state(Queued|Running)`; `job.retry/priority {id}` — в handler `owner_ns`; `Waiting(PromptId)` — открыт вопрос, переходы повторяемы. `Progress`: `phase: AtomicU8` (`Scan, Transfer, Verify, Finalize, Recover`), `total_final`, `parked`; те же поля в `ProgressSnap`. (v2 №8–9)
- **Вопросы и баннеры.** `PromptSpec.detail: Option<PromptDetail>` (`Conflict { src, dst, index, total }`), `PromptSpec.secret` (маска, не логируется, не в историю/сессию). В конфликте «Прервать задачу» = `Choice { id: "abort", key: 'q' }`, Esc — «позже». `Banner.actions: SmallVec<[(CompactString, Command); 3]>`. (v2 №15–16, v3 №16, v5 №7)
- **Выход.** `Handler::on_quit(&mut self, cx) -> QuitDecision { Allow, Veto(PromptSpec) }`; `app.quit` опрашивает все handlers до `shutdown`. (v2 №13)
  Ответ на вопрос вето — тому же handler: `Handler::on_quit_reply(choice, cx) -> QuitReply { Quit, Stay }` (по умолчанию `Quit` на `quit`); `Quit` — опрос следующих handlers, `Stay` — остаёмся, отложенное действие само шлёт `app.quit`. (решение 2026-10-31 «quit-reply»)
- **Runtime.** `Lane::Bulk` — короткие задачи; долгие воркеры (ops, watcher, PTY) — `spawn_dedicated`; ops ограничивает потоки `ops.max_threads`. `MsgSink::poke()` и `Runtime::waker() -> Arc<dyn Waker>` через общий `WakeFlag` — разбудить UI без Msg. (v2 №7, v3 №7, v5 №6)
- **Очередь устройств.** `urfin_core::DeviceGate` — одна на процесс (`Runtime::devices`, `Core::devices`): копирование, удаление и скан du ждут слот физического устройства по `[ops.device_jobs]` (`DeviceJobs`); ключ и лимит — `urfin_vfs::volume::{device_key, jobs_for}`. (решение 2026-10-30)
- **Открытие файла.** `panel.enter` → `file.open { alt?, internal?, elevated? }`; резолв — `trait OpenResolver` (`Services.open_resolvers`): S8 → `[file.assoc]` → `term.open`. (v3 №9, v5 №9)
  Вход в каталог (Enter, двойной клик): первый `Some` из `OpenResolver::enter_dir(dir, entry, args)` (по умолчанию `None`) — вместо входа в `dir\entry`; так виртуальная схема ведёт в настоящий каталог (`search:` → `panel.go` по адресу `Vfs::resolve`, позже `cmp:`). Крейт схемы добавляет резолвер сам: `Core::add_open_resolver` — первым в списке. У корня `du:/<id>`, `pkg:/<фильтр>`, `search:/<id>` нет `..` (`Location::parent` — `None`). ([решение 2026-11-08 «s8-esc-nav»](decisions/2026-11-08-s8-esc-nav.md))

## VFS и операции

- `VolumeInfo` (носитель SSD/HDD/NVMe/USB/Net, ФС, caps: reflink, case_sensitive, trash, free) — `urfin_vfs::volume`. Watcher: debounce 50 мс / max 250 мс; ops шлёт refresh ≤ 1/с на таб. (v2 №12, №14)
- Trait `Vfs` (владелец — S4): `resolve(base, item: &Entry) -> Result<Location, VfsError>` — настоящий адрес элемента, через него viewer, editor и ops идут к файлу (по умолчанию ребёнок `base`: `local` с нормализацией и `ESCAPED_NAME`, прочие схемы — путь через `/`, `authority` и `outer` те же; `search:`, `cmp:` отдают адрес источника), `extract_plan` + `ExtractStream`, `Caps::{READ_ONLY, SEQUENTIAL, VIRTUAL}` (`VIRTUAL` — `du:`, `pkg:`, `search:`, `cmp:`). Колонки схемы: `Vfs::columns(dir) -> &'static [ColumnSpec]` — набор по папке и виду адреса, без I/O (`id`, ключ заголовка, ширина, `right`, `ColumnView::{Text, Size, Date, Bar, Snippet}`, `mono`); встроенные `id` (`size`, `mtime`, `ctime`, `atime`, `share`) — поля `Entry`, прочие — `Entry.ext`: ячейка `Vfs::ext(dir, entry, col) -> Option<ExtCell>` из памяти backend'а (UI-поток, без I/O), `ExtCell::Snippet { text, hl }` — фрагмент с подсвеченным совпадением (`hl` — байты в `text`); реестр для UI — `Schemes` в `AppState.ext`; и для не-виртуальных схем (`sftp`: права, владелец). Обходчик `urfin_vfs::walk` и `walk_with(&dyn DirLister)`. (v5 №14–15, v6 №1, №8, №21, [решение 2026-11-02](decisions/2026-11-02-scheme-columns.md), [«du-filters»](decisions/2026-11-02-du-filters.md))
- **Запись в схему — методами `Vfs`** ([решение 2026-11-04 «vfs-write»](decisions/2026-11-04-vfs-write.md)): `open_write(p, from: Option<u64>) -> Box<dyn VfsWrite>` (`None` — создать или обрезать; `Some(n)` — писать с байта `n`, байты до `n` не трогаются, хвост за `n` не гарантирован: докачка, дописывание), `VfsWrite: io::Write` + `finish()` (сброс на носитель, `fsync`, если умеет, и закрытие с ответом; без него — закрытие в `Drop` без подтверждения), `mkdir`, `remove` (файл, ссылка, пустой каталог), `rename(from, to, replace)` (в пределах схемы и `authority`; `replace` — атомарно, если умеет, иначе удаление и rename с записью в лог), `set_meta(p, mode, mtime)` (младшие 12 бит, нс Unix; `None` — не трогать), `link(at) -> Link::{Up, Waiting, Down}` («ждёт связи»), `transfer_channels()`. По умолчанию — `VfsError::NoWrite(scheme)`, `Link::Up`, 1 канал. Вызовы блокирующие — из потоков job. Ops берёт backend схемы из `Schemes` (как для чтения); `Caps::READ_ONLY` — отказ до задачи; запись в `Caps::VIRTUAL` и адреса с `outer` — не через `Engine::Vfs`. Читать адрес с `outer` через `Engine::Vfs` можно, элемент `search:` ops разрешает через `resolve` в настоящий адрес ([решение 2026-11-06 «s8-answers»](decisions/2026-11-06-s8-answers.md)). Локальная ФС в ops пишет сама. Крейт схемы от `urfin-ops` не зависит.
- `VfsWriteTxn` (архивы, позже) — надстройка над теми же методами, не второй путь: `Vfs::writer(at) -> Box<dyn VfsWriteTxn>` (по умолчанию — обёртка, каждый шаг сразу методами записи, `commit` — пустой); схема-контейнер (`zip`, `7z`) переопределяет: шаги (`open_write(None)`, `mkdir`, `remove`, `rename`, `set_meta`) копит, `commit` перепаковывает один раз, отмена — без следа; запись с позиции (`Some(n)`) у неё — `NoWrite`, докачки нет. Методы записи такой схемы без транзакции — тоже `NoWrite`. Ops пишет через транзакцию всегда, когда она появится; до того — методами напрямую.
- Схемы: `search:`, `cmp:`, `du:` (`/<snap_id>/<rel>`, `f=`), `pkg:` (`/installed|/updates|/search?…`) — в сессии не сохраняются; `sftp://<профиль>/путь` — таб сохраняется без подключения (`user@host:port` — только ввод). (v5 №8, v6 №5–6, №20)
- Ops: `ops.delete/copy/move` без `confirmed=true` → `UiEvent::Ext { id: "ops.draft" }`; `ops.copy/move/delete { current? }`, имя в `ops.mkdir` опционально, `file.clip.copy/cut/paste`; `Engine::Vfs` для не-локального источника; `ops.move` из `READ_ONLY` → черновик копирования; `ops.compare { recursive? }`. (v3 №15, №17, v5 №16, №19)
- Форматы на диске (фиксированы, смена — с `ver`): кэш `du` v2 (`%LOCALAPPDATA%\Urfin\state\du\*.du`; v2 — суммы «Сборок и кэшей», [решение 2026-11-02 «du-filters»](decisions/2026-11-02-du-filters.md); бит 7 `NodeFlags` — `ELEVATED`, «досчитан с правами»: итог поддерева без имён внутри — без смены версии, старые кэши читаются, решение владельца 2026-11-02); `connections.toml` v1, `state/ssh/…`, записи `*.cast` (asciicast v2); `~/.ssh/known_hosts` — только дописывание. (v6 №9, №26)

## Терминал (urfin-term)

- Слои окна снизу вверх: терминал → панели → cmdline → вьювер/редактор → оверлеи; видимость панелей не меняет размер PTY. (v3 №11, v5 №3)
- Ввод при фокусе на панели: печатный текст → `cmdline.insert`; в `Focus::Terminal` не поглощённое keymap → `term.key`/`term.input` (имена клавиш — gpui-kit `Keystroke`). (v3 №13, ADR-0018)
- Публичные безопасные API (`unsafe` — только `term::sys`): `term::proc::spawn_piped(argv, cwd, env, flags) -> PipedChild` (job object, `kill_tree`, `wait_timeout`), `session_has_process(name, since)`; `TermApi::feed_session(title) -> FeedSink`; `SessionKind::External { argv, env, title }`; `TermApi::broadcast(ids, bytes)`, `TermApi::tap(id) -> TapRx`; флаг «цвет по умолчанию» у ячейки снапшота. (v6 №15, №22)

## Ввод и клавиатура

- **Хоткеи с буквой — на любой раскладке и языке (обязательно).** Раскладка даёт латиницу на клавише — сравнение по символу (Dvorak, AZERTY, QWERTZ); иначе (кириллица, греческий, иврит, арабский, CJK, IME) — по физической позиции US-QWERTY; модификаторы не влияют; для всех контекстов и аккордов. Быстрый поиск и ввод в cmdline — по набранному тексту; при совпадении с привязкой — привязка. `keymap.match = auto|physical|logical`. (v4 №5)
- Подписи keybar — Fluent `keybar-<id>`, иначе `cmd-<id>`; поля в `CommandMeta` нет. (v3 №14)
- Пространства команд: `viewer.*`, `editor.*`, `search.*`, `arc.*` (v5 №19), `du.*`, `pkg.*`, `ui.utilities` — Ctrl+F9, `ssh.*`, `sftp.*`, `term.highlight.toggle`, `term.record.toggle`, `viewer.cast.*`. Флаги/контексты keymap: `in_search`, `in_archive`, `in_du`, `pkg`, `in_sftp`, `in_sshpair`, `ssh_term`, `ssh_group`, `cast_view`. (v6 №10–13, №25)
- Текст редактора — `EditorDoc` в `urfin-view` (piece table, ADR-0023): куски, курсор и выделение, отмена — у handler `editor`. Клавиши правки и движения — команды `editor.*` через keymap (контекст `editor`); набранный текст и commit IME (`InboxMsg::Input`), мышь (`Caret`; `block: Option<u32>` — Alt+мышь, блочное выделение до экранной колонки, [решение 2026-11-01](decisions/2026-11-01-editor-engine.md) №5), окно текста (`Viewport`), прокрутка (`Scroll`, `ScrollTo`) — `ViewInbox` (UI → handler, разбор в `on_pump`), не через Command bus. UI рисует видимые строки из снимка документа (`TextView: ByteView`) и не меняет его; `editor.input` нет. (v5 №4, [ADR-0023](adr/0023-editor-engine.md) §9, решение владельца 2026-11-01; до S7-34 экран ещё на прежнем пути — `EditorState` gpui-kit и события «текст принят / изменён / снимок»)
- Окно текста вьювера — событие `InboxMsg::Viewport { doc, cols, rows }` в тот же `ViewInbox` (при открытии, ресайзе, смене режима и шрифта); прокрутку, вывод найденного и подгрузку видимых страниц делает handler по нему. (решение 2026-10-30 «viewer-viewport»)

## Крейты, платформа, ресурсы

- Крейты: core, vfs, ops, term, keymap, i18n (листовой, Fluent en/ru; тосты и промпты — только ключами), ui, view, search, arc, testdata (dev); фаза 3 — `urfin-net` (без `unsafe`; `urfin-ui` от него не зависит, связывает `urfin-app`), `urfin-pkg` (без `unsafe`; `urfin-ui` от него не зависит, связывает `urfin-app`). (v3 №8, v5 №13, v6 №14, №23)
- UI — GPUI (gpui-kit, ADR-0018); только Windows (решение №57). `unsafe` — только в `sys` крейтов vfs, ops, term, ui, view, app. (v4 №1, v5 №5)
- Шрифты: Segoe UI Variable, Segoe Fluent Icons, моно — системный Cascadia Mono (→ Consolas), с диска ОС; рамки и Powerline терминал рисует сам. (владелец 2026-10-17; отменяет v3 №12, v4 №3–4)
- Манифест exe: `longPathAware`, `PerMonitorV2`, `activeCodePage=UTF-8` (`winresource`). Флаги app: `--bench-startup`, `--bench [каталог]`, `--screens <каталог>`, `--smoke`; ранний выход до GPUI — `--pkg-check`, `--askpass`, `--du-elevated --out <файл> <корень>…` (без окна и IPC единственного экземпляра; `--du-elevated` — до конфига и логов, тот же exe через UAC, [решение 2026-11-02](decisions/2026-11-02-du-elevated-same-exe.md)). Features `profile`, `dhat-heap`, `count-alloc` — запрещены в release (CI). (v5 №10–12, v6 №17, №24)
- **Стабильные имена tracing-спанов — контракт:** `startup.*`, `frame`, `list.*`, `ops.job`, `term.build`, `view.*`, `du.*`, `pkg.*`, `net.*`, `ssh.term.spawn`, `term.record`, `term.highlight`, `viewer.cast.seek`; секретов в полях нет (тест). (v5 №10, v6 №19, №27)

## Политика и бюджеты

- Бинарь `urfin.exe` ≤ 45 МиБ (гейт `ci/size.py` в CI; растёт с функциями, №80; DLL ConPTY не входят). Пороги регрессий: CI — 3 % по инструкциям и аллокациям, 20 % A/B по времени; стенд — 10 % при CV ≤ 5 %; PR в горячие пути vfs/ops/term/ui-render — JSON прогона в `docs/perf/runs/`. Заголовки PR — Conventional Commits. (v5)
- Зависимости одобрены списками v3, v5, v6 (`alacritty_terminal`, `base64`, `memmap2`, `zip`, `sevenz-rust2`, `russh`, `tokio`, `keyring`, `windows-registry` и др.); прочие — без согласования при чистом `cargo deny` (решение №58).
