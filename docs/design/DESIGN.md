# Дизайн Урфина — передача в разработку

Утверждён владельцем 2026-10-20 (S0-decisions №59–№62). Источник — холст «Урфин — темы оформления» (Claude Design); его исходник окна — `window.dc.html` (HTML/CSS: точные отступы, размеры, цвета ролей), снимки — `screens/*.png` (1280×760, 100 %). Пересобрать снимки после правки исходника: `python scripts/design/render_screens.py docs/design/window.dc.html docs/design/screens` (Playwright + Chromium). Палитры и роли — `docs/THEMES.md`. Расхождение кода с этим документом решается в пользу документа, кроме противоречий с S0-decisions.

Интерфейс на GPUI уже сделан (#88); приведение к этому дизайну — пакет `docs/TASKS-DESIGN.md` (D-01…D-08), колонка «Задача» ниже — область кода.

Снимки — образец раскладки, пропорций и цвета, не попиксельный эталон: шрифт на снимках — заменитель Segoe UI (рендер не на Windows). Исключение — `screen-viewer-md.png`, `screen-editor.png`, `screen-editor-md.png` (2026-10-30): они отрисованы на Windows, шрифты и значки Segoe Fluent Icons на них настоящие; без Windows значки панели не нарисуются.

## Общие правила
- **Верх — навигация, низ — события** (№63). Тост — только пассивное сообщение без кнопок; всё, где есть действия, — встроенная строка (как F5): на ширину активной панели, если касается её, или на всю ширину, если обеих. Сверху только табы и пути. Всё событийное — внизу, снизу вверх: keybar → статус → командная строка → job-бар → строка-вопрос/баннер; тосты — справа снизу над этой зоной (отступ 12 от её верхнего края, стопка ≤3 вверх).
- Без модальных окон: всё, что спрашивает, — **встроенная строка внизу**, она **накрывает** нижнюю часть панелей (список не перестраивается; если курсор оказался под строкой — список прокручивается так, чтобы курсор был виден). Исключение — job-бар: живёт долго, поэтому **занимает место** над командной строкой и сдвигает панели.
- **Одна информация — одно место** (№61): имя файла — во вкладке; путь — в заголовке экрана/панели; размер, кодировка, переводы строк, тип — в статус-строке; переключатели режимов — в заголовке экрана; клавиши встроенной строки — подписями на её кнопках и **не** повторяются в keybar (keybar в это время показывает только дополнительные клавиши: Tab, F3 и т. п.).
- **Автодополнение — во всех полях ввода** (№70): пути, маски, имена, команды, поиск; «мешочек» от поля, правила и клавиши — как в командной строке (`screen-cmdcomplete.png`); Alt+↓ — история поля. **История — источник подсказок везде, где Урфин её хранит** (хосты, пути, маски, имена, поиск, команды): в списке вариантов — значок часов и «история · когда»; сырой ввод SSH-терминала — история самой оболочки, не Урфина.
- **Состояние сеанса терминала** (№91): чипы в пустом заголовке окна слева, рядом с местом для меток контекста (как «Администратор»): высота 26, `warning_bg`, рамка `context_remote`, значок 14, текст 12,5, действие (Выйти Esc) — в чипе через разделитель, замок политики — серым; терминал не сдвигается. Сначала предупреждения (`warning_bg`), за ними режимы — нейтральный чип (`header`, рамка `border`): «Подсветка вывода Ctrl+Alt+H»; в статусе это не дублируется (№61). Касается любого терминала на весь экран — SSH и локального. В режиме «панель + терминал» те же чипы — в шапке терминала рядом с «ssh srv1 ▾». Просмотр записи (F3) — не терминал, а просмотрщик: по его образцу — слева файл (путь, «только чтение»), справа настройки показа (кнопка-переключатель «Подсветка», Запись / Текст / Hex), тип и размер — в статусе (№61).
- **Статус: одна сущность — одной группой** (№92). Сведения об одном объекте (например, о записи: кто, размер окна, когда, длительность, тип, размер) идут подряд слева через « · », а не раскладываются по трём ячейкам статуса; центр и правый край — для других сущностей.
- **Keybar показывает все сочетания экрана** (№88): если на экране работают сочетания с модификаторами (Ctrl+Alt+H и т. п.), они выводятся в keybar; заблокированное политикой — не выводится.
- **Адрес сервера** (№87): везде `sftp://<профиль>/путь`; полный `user@host` — в подсказке пути и строке состояния.
- **Всплывающие объекты — с тенью** (№65): «мешочек» целиком (корешок + список), контекстное меню, плашки — тень `shadow` (смещение 8, размытие 16 + 1/3); без тени они сливаются с панелью. Есть от чего — «мешочек» с корешком из самого якоря (ячейка заголовка, путь, кнопка); нечем привязать — плашка без корешка у места вызова.
- **Всплывающий список и его кнопка — одна фигура** («мешочек»): меню F9, выпадающие поля, кнопки со списком. Открытая кнопка становится корешком цвета `panel` без нижней границы и перетекает в список; корешок — в любом месте верхнего края списка, как удобнее для компоновки (подробно — `screen-menu.png`). Контекстное меню без кнопки-якоря — обычная плашка.
- **Издатель**: в технических идентификаторах — `Aahz` (CompanyName exe, `HKLM\Software\Policies\Aahz\Urfin`, id пакета winget); имя «Антон Антропов» — только в текстах для человека («О программе», `LegalCopyright` exe — добавить в D-08).
- Цвет — только роли темы; литералы запрещены (T-01-6). Акцент — только для фокуса/курсора/основной кнопки; красный (`modified`) — для опасного действия; `context_remote` (янтарь) — для «ждёт ответа».
- **Строки с вопросом**: предупреждение (баннер журнала, конфликт) — весь фон `warning_bg` + черта `context_remote`; опасное действие (F8) — фон `danger_bg` + черта `modified`; обычные (F5, отметка, переименование, сравнение) — фон `header` + черта `accent`. **Кнопки — сразу за текстом/полями**, не прижаты к правому краю: мышь не ходит через всю ширину.
- Шрифты: интерфейс Segoe UI Variable 13 px; моно Cascadia Mono 12,5–13 px; вторичные подписи 12 px; заголовки колонок 11,5 px. Цифры — tabular.
- Иконки — Segoe Fluent Icons, монохром `secondary` (на курсоре — `cursor_text`); цветной режим — по ролям типов.

## Движение (`screen-motion.png`)
Анимации работают, если включены `ui.animations` (по умолчанию — да, №72) и «Эффекты анимации» Windows (`SPI_GETCLIENTAREAANIMATION`, перечитывать по `WM_SETTINGCHANGE`); иначе все длительности 0, вспышка баннера — ровная подсветка 1 с, неопределённый прогресс — неподвижная штриховка. Кадр — только по событию, в простое 0 кадров.

| Элемент | Длит., мс | Кривая | Что меняется | Кадры |
|---|---|---|---|---|
| «Мешочек», плашка — появление / закрытие | 167 / 83 | decelerate (0,0,0,1) / accelerate (1,0,1,1) | opacity, сдвиг 4 от корешка | команда не ждёт анимации |
| Встроенная строка — выезд / уход | 167 / 83 | decelerate / accelerate | сдвиг снизу | фокус в поле сразу |
| Тост | 167 + 4000 + 167 | decelerate, accelerate | opacity, сдвиг 8 справа | жизнь — один таймер, 0 кадров |
| Баннер — вспышка | 300 + 1400 | ease-in-out | фон `header` ↔ `accent` 22 % | один раз на событие |
| Прогресс задачи | — | ступень | ширина, %, ETA | снапшот раз в 33 мс, кадр — если изменился |
| Неопределённый прогресс | цикл 1500 | standard (0.33,0,0.67,1) | сдвиг полоски 30 % | ≤ 30 кадр/с, пока идёт поиск |

## Доступность (`screen-a11yfocus.png`, `screen-a11ysheet.png`)
- Порядок Tab во встроенной строке — слева направо, по кругу; Shift+Tab — назад; Esc — фокус в панель. Фокус-кольцо — только при клавиатуре: 2 `text` снаружи + 1 `panel` внутри, скругление элемента + 2; у курсора панели — своя рамка `accent`.
- UIA: панель — List (Selection), строка — ListItem (SelectionItem: «отмечен» — состояние, не имя), встроенная строка — Group, кнопка — Button (клавиша в AcceleratorKey, не в имени), «мешочек» — Button + Menu/List (ExpandCollapse), тост — LiveSetting Polite, баннер — Assertive только для ошибок, прогресс — ProgressBar (RangeValue), keybar — ToolBar. **Зависит от моста gpui → UIA/AccessKit — отложено (№72), вопрос к ADR-0018.**
- Контраст: текст ≥ 4,5:1 во всех темах (палитры подправлены 2026-10-21: accent бирюзы/травяной/сепии, secondary всех светлых тем и тёмной, exec), компоненты UI ≥ 3:1; рамка поля — не единственный признак: нижняя кромка поля — `secondary`.
- Цель клика ≥ 24 по высоте; плотность 20 — исключение (включает пользователь, всё доступно с клавиатуры). Флажок — цель вся подпись.
