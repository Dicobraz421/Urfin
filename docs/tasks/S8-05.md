## Сделать
- `TextQuery`, `ContentSearcher`: Literal, Regex, Hex, регистр, слово, Auto, Named, All, бинарные, `invert`.
- Sink собирает строки файла до `max_per_file`: номер, диапазон совпадения, фрагмент ≤ 120 символов в кодировке совпадения.
- Чтение кусками с проверкой отмены; без mmap.

## Приёмка
- «Привет» находится в UTF-8, UTF-16LE с BOM, cp1251, cp866 в режиме All, «привет» и «ПРИВЕТ» — без учёта регистра;
- фрагмент читается правильно во всех кодировках, номер строки верен и в UTF-16;
- Auto не даёт ложных срабатываний на бинарниках;
- `scan.rs` с двумя совпадениями даёт две записи.
