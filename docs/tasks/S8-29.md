## Заметки S8-28
- Shift+F2 → `arc.extract` (без аргументов): handler читает заголовки не в UI-потоке и шлёт `UiEvent::Ext { id: "arc.draft", args }`. Строку открывать только по нему; на что распаковывать нечего — отказ тостом, события нет.
- `stage = "open"` — черновик: `name` (файл первого архива), `count` (архивов; >1 — заголовок `arc-extract-title-many`, флажок — `arc-extract-subdir-each`), `items` (только внутри архива: выделено — `arc-extract-title-items`), `size` (байт; `estimate = true` — это размер файлов сжатого tar, распакованный не читали), `subdir` (имя подпапки первого архива), `dest` (другая панель с `\` на конце; можно брать и свой `path_text`), `encrypted`; при `encrypted` — `cipher` (`AES-256`, `AES-128`, `ZipCrypto` → `arc-pw-names-encrypted`/подпись) и `left` (3); `names_encrypted` пока всегда `false` (7z — S8-32).
- Подтверждение (Enter / Shift+Enter): `arc.extract confirmed=true dest=<текст> subdir=<bool> conflict=<ask|overwrite|skip|newer> paths=<bool> [queue=bg] [password=<текст>]`. Строку **не** закрывать самой (`ui.cancel` не слать): ответ придёт событием.
- `stage = "wrong"`, `left = N` — неверный (или пустой) пароль: строка остаётся, ошибка `modified` `arc-pw-wrong` с `$left`. Пустой пароль попытку не тратит.
- `stage = "close"` — закрыть строку: задачи запущены (`ops.copy` на архив) или попытки кончились (тост `arc-pw-exhausted` шлёт handler).
- Esc: `arc.extract cancel=true` и закрыть строку самой — ничего не запускается.
- Пароль — только в аргументе `password`; в историю поля и в сессию не класть.
