## Сделать
- Открытие (`edit/open.rs`): детект §3.2 → один кусок `Original`; ≤ 16 МиБ — в память (`Guard::Memory`); больше — `File` с share `READ | DELETE` (`Guard::Locked`), при `ERROR_SHARING_VIOLATION` — без запрета (`Guard::Unlocked`) и вопрос на первой правке «Файл пишет другая программа…» → «Править копию» (`Guard::Copy`: block clone на ReFS того же тома, иначе копия задачей) / «Открыть в просмотре». Лимит `editor.max_size_mb` и `EdState::TooLarge` сняты (конфиг, снимок конфига).
- Правка в handler: `Selections` (курсор + потоковое или блочное выделение — тип `Block` заводится здесь, операции блока — S7-40; мультикурсора нет), `top`/`top_sub`/`hscroll` и вывод курсора по `InboxMsg::Viewport`; команды §7 — `editor.move {to, select?}`, `editor.delete {to}`, `editor.newline` (автоотступ), `editor.tab`, `editor.overwrite`, `editor.select_all`, `editor.copy/cut/paste`; `editor.undo/redo`, `delete_line`, `block.shift_*`, `eol` — в handler, а не `UiEvent::Ext`. Движения — по раскладке S7-06 (визуальные ряды, память колонки), слова — `unicode-segmentation` по окну ≤ 64 КиБ; упёрлось в `Missing` — завершается по `PagesMsg`.
- `InboxMsg::Input { doc, text }` и `Caret { doc, off, extend, unit }`: ввод кодируется в кодировку документа; нет символа — `EdAsk::NoChar` («Перевести документ в UTF-8» / «Вставить «?»» / «Отмена»), перевод — `Op::Root` (≤ 16 МиБ в памяти, больше — задача в `Rewrite`). EOL при вставке → `eol_new`.
- Буфер обмена (`edit/clip.rs`, `view::sys`): чтение `CF_UNICODETEXT` на Interactive lane, потоком в `Add`, одна группа; копирование ≤ `viewer.copy_limit_mb`, больше — тост; вырезание = копирование + удаление одной группой.
- Прежний путь (`loaded`, `Adopted`, `Edited`, `Snapshot`) остаётся до S7-34; новый включается, когда UI шлёт `Viewport` для редактора.
- CONTRACTS «Ввод и клавиатура» — строка редактора по ADR-0023 §9, запись в «Изменения» (класс B).

## Приёмка
- открытие → сохранение без правок = те же байты по новому пути (13 кодировок V5 × 4 EOL, BOM, lossy — байты сохраняются);
- 10 ГБ (V1) открывается ≤ 50 мс до готовности документа (тёплый), правка сразу; второй процесс не может открыть файл > 16 МиБ на запись, читать и переименовать — может;
- символ вне 1251 → вопрос; «Перевести в UTF-8» и отмена перевода возвращают кодировку и текст;
- команды движения на CRLF/CR/UTF-16, слова на кириллице, вверх/вниз с переносом — тесты через core.

## Заметка
- Класс B: `docs/CONTRACTS.md` и `crates/view/src/sys/` (CODEOWNERS); конкретику контракта владелец видит в PR.
- Риск: носитель пропал (USB, сеть) — строки с ошибкой чтения, документ только для чтения; тест на ошибку `read_at`.

## Сделано (2026-11-01, x/view-22)
- `edit/open.rs`: открытие на движке — stat → выборка 64 КБ → детект → `TextDoc` из кусков `Original` после BOM. ≤ 16 МБ — `OwnedSource` и индекс сразу (`Guard::Memory`, концы строк и `lossy` — по всем байтам); больше — `FileSource` по handle `sys::open_locked` (share `READ | DELETE`, `Guard::Locked`), `ERROR_SHARING_VIOLATION` → handle без запрета (`Guard::Unlocked`), индекс — фоновый `Indexer` (`IndexMsg` теперь доходит и до редактора), переводы строк неизвестных кусков — `lf_patch` фоном. Не-локальные — источник вьювера без запрета.
- `edit/input.rs`: `Engine` (текст, `enc`/`eol` документа, `Selections { caret, sel: None | Stream | Block }`, `top`/`top_sub`/`hscroll`, `overwrite`, `Journal<Selections>`, `Guard`), движения по раскладке S7-06 (`col_of`/`off_at_col` добавлены в `layout.rs`): символ (CRLF — шаг; UTF-8/UTF-16/однобайтовые — назад сразу, прочие многобайтовые — от начала сегмента), слова — UAX#29 по окну сегмента ≤ 64 КБ, вверх/вниз/страницы — визуальные ряды с памятью колонки, Home/End — ряд; вывод курсора. Правка: ввод (кодирование в кодировку документа, EOL → `eol_new`, режим замены), Backspace/Del/по словам, Enter с автоотступом, Tab (пробелы до остановки; при многострочном выделении — сдвиг), `block.shift_*`, `delete_line`, `select_all`, мышь `Caret { Char | Word | Line, extend }`. `Missing` → действие ждёт страниц (`Engine::wait`) и повторяется по `PagesMsg` движка; после правки повтора нет (вывод курсора — отдельно).
- Вопросы движка — `input::Ask { NoChar, Writer }` в `Engine::ask` (ответ — тот же `editor.answer`): «Перевести в UTF-8» — задача `write::rewrite` (≤ 16 МБ в памяти, больше — временный файл `Rewrite`), одна группа `Op::Root` с кодировкой (отмена возвращает кодировку и текст), «Вставить «?»»; «Править копию» — копия исходника задачей во `%TEMP%\Urfin`, `TextDoc::replace_orig`, `Guard::Copy`; «Открыть в просмотре» — вьювер на строке курсора.
- `edit/clip.rs` + `sys::clip_read/clip_write` (`CF_UNICODETEXT`, Interactive lane): вставка — `Act::Paste` одной группой, копирование ≤ `viewer.copy_limit_mb` (больше — тост `ui-edit-copy-too-big`, вырезание не выполняется), вырезание = копия снимка + удаление одной группой.
- `edit/write.rs`: потоковый писатель снимка (`blocks` по 4 МБ, `Recode` — смена кодировки и концов строк по единицам кода, `rewrite` → `Rewrite` с отметками курсора); `editor.eol` на движке — та же задача, одна группа (`Op::Root.eol`, `Step.eol`).
- Handler: команды `editor.move {to, select?}`, `delete {to}`, `newline`, `tab`, `overwrite`, `select_all`, `copy`/`cut`/`paste`; `undo`/`redo`/`delete_line`/`block.shift_*`/`eol` — handler, если документ на движке (иначе прежний `UiEvent::Ext`). `InboxMsg::Input`, `Caret`; `Viewport`/`Scroll`/`ScrollTo` редактора. Первый `Viewport` редактора переводит документ на движок (прежняя загрузка отменяется, файл перечитывается `open`; `editor.reload`/F8 без правок — тоже `open`).
- Ключ `editor.max_size_mb` снят (конфиг, снимок); у прежнего пути — константа `load::ROPE_MAX` = 16 МБ до S7-34. `docs/CONTRACTS.md` «Ввод и клавиатура» — строка по ADR-0023 §9 + «Изменения».
- Тесты: `open_tests.rs` — открытие → запись снимка без правок = те же байты (13 кодировок × 4 EOL, вручную и по детекту), lossy и нечётный хвост UTF-16 сохраняются, концы строк по единицам, большой файл — `File` + `Locked`, ошибка `read_at` → `read_failed`, правка не принимается; `#[cfg(windows)]` — чужая запись отказана, чтение и переименование можно, пишущийся файл — `Unlocked` (прогонит CI). `input_tests.rs` через core: CRLF, CR, UTF-16 с суррогатами, слова на кириллице, вверх/вниз с переносом, 1251 + эмодзи → вопрос → UTF-8 → отмена ×2 = исходные кодировка и байты, «?», набор/отмена/●, режим замены, автоотступ, Tab, сдвиг, буфер обмена, `editor.eol`, мышь. `tests/heavy.rs`: 10 ГБ (разреженный) готов ≤ 50 мс (`#[ignore]`, release).
- Проверено на Windows (стенд, 2026-11-01, x/view-22 после rebase на main): nextest view зелёный, тесты share mode (чужая запись отказана, чтение и переименование можно, пишущийся файл — `Unlocked`) проходят; clippy под Windows; тесты буфера обмена — на буфере процесса (`sys::clip_fake`), системный буфер владельца стенда не трогается.

## Осталось
- `EdAsk::NoChar`/`Writer` и `EdState::Replacing` не добавлены в `EdAsk`/`EdState`: экран UI сопоставляет их полностью (crates/ui не трогаем) — вопросы движка в `Engine::ask`, слить в S7-34.
- «Править копию»: block clone на ReFS (`FSCTL_DUPLICATE_EXTENTS_TO_FILE`) не сделан — всегда копия задачей.
- Вставка из буфера: текст кодируется и дописывается в `Add` на UI-потоке (одним сообщением), не потоком вне UI — для 100 МБ (бюджет S7-36) перенести дописывание в задачу.
- Замер «10 ГБ ≤ 50 мс» на стенде (release, `#[ignore]`) — в S7-31 вместе с замерами сохранения.
