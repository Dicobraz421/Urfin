## Сделать
- `Owned`, `File` (`seek_read`), `Mapped` (memmap2, `Mmap::map` — только `view::sys`, политика §0), `Seek`, `Spool` (temp в `cache_dir/view-spool`, удаление при закрытии и при старте); `open_source` с выбором по `VolumeInfo` и `Caps`.

## Приёмка
- `read_at` всех источников побайтно совпадает на случайных диапазонах (proptest на tempfile);
- sparse 4,5 ГБ открывается ≤ 20 мс;
- `Mapped` не выбирается для сети/USB, mtime < 60 с и follow;
- `Spool` отдаёт данные до конца копирования (мок-VFS без SEEK).

## Заметка
- Класс B: новый `crates/view/src/sys/` (CODEOWNERS).

## Сделано
- `source/`: `ByteSource` (+ `map()` для страниц без копии, `seq_file()` — handle с `FILE_FLAG_SEQUENTIAL_SCAN`), Owned / Mapped / File / Seek / Spool; `choose(&Facts)` — выбор по тому, `Caps`, размеру, mtime и follow; `open_source` → `Opened { src, pump }`: насос Spool — долгий воркер, вызывающий (S7-08) запускает его через `spawn_dedicated`.
- `sys/` (`unsafe` только здесь, `// SAFETY:`): `Mmap::map`, `seek_read`/`seek_write`, временный файл Spool с `FILE_FLAG_DELETE_ON_CLOSE` (ОС удаляет и при падении), остатки старше часа убирает `sweep_spool` при первом Spool в процессе.
- `read_at` из потока, помеченного UI (`mark_ui_thread` в `on_pump` handler'а `viewer`), — паника в debug.
- Тесты: proptest `read_at` пяти источников на tempfile; `choose` (сеть, USB, SMB, mtime < 60 с, follow, `mmap = false`); Spool на мок-VFS без SEEK отдаёт скопированное до конца копирования и удаляет файл при закрытии.
- Замер (release, `tests/heavy.rs`): sparse 4,5 ГБ, `open_source` + первые 64 КиБ + чтение за 4 ГиБ — лучшее из 5 — 1,0 мс (≤ 20 мс).

## Осталось
- Носитель тома: `volume::of` пока различает только сеть и USB (SSD/HDD/NVMe — S5-02); локальный фиксированный том (`Media::Unknown`) допускается к mmap.
