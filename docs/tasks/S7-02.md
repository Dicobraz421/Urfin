## Сделать
- `Owned`, `File` (`seek_read`), `Mapped` (memmap2, `Mmap::map` — только `view::sys`, политика §0), `Seek`, `Spool` (temp в `cache_dir/view-spool`, удаление при закрытии и при старте); `open_source` с выбором по `VolumeInfo` и `Caps`.

## Приёмка
- `read_at` всех источников побайтно совпадает на случайных диапазонах (proptest на tempfile);
- sparse 4,5 ГБ открывается ≤ 20 мс;
- `Mapped` не выбирается для сети/USB, mtime < 60 с и follow;
- `Spool` отдаёт данные до конца копирования (мок-VFS без SEEK).
