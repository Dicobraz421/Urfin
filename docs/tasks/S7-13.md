Чтение — не больше одного на сторону: новый курсор отменяет прошлое открытие токеном, следующее стартует по его ответу (`qflight`); `DocId` — новый (ответы прошлого файла — страницы, индекс, разбор — без поколения). Облако: `Attrs::OFFLINE` листинга или атрибуты `OFFLINE | RECALL_ON_OPEN | RECALL_ON_DATA_ACCESS` по `stat` на Interactive — файл не открывается, «Файл в облаке — F3 для загрузки» (`qnote`). Ошибка открытия — текстом в области, без тоста. Режим `qview` выключен — документ закрыт.
- view: `focus=true` (Tab) — `ViewState.qfocus`, `active_viewer()` — документ области: прокрутка, F7, F8, режимы, перенос, копирование. Новый экран (F3, F4) фокус у области забирает. `viewer.dock` — вьювер окна ↔ область пассивной панели (без следования за курсором); F3 в фокусе быстрого просмотра — тот же документ в окно. Markdown в области — документ до 4 МБ (`md_mode`).
