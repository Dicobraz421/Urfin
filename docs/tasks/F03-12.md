## Приёмка
- файл проходит `asciinema cat` (фикстура-эталон) и валидатор формата в тесте;
- ввод `"i"` не пишется;
- `required` — запись с первого байта, стоп недоступен;
- `forbidden` — команда выключена;
- при диске без места при `required` ввод блокируется.

## Сделано (2026-11-04, ветка x/term-rec)
- term: отвод сырого вывода `session::Tap` (`TermApi::tap`, S0 F03 №3) — байты PTY до эмулятора и resize; ставится у слота до старта reader — подписка видит первый байт. `Slot::tap() -> TapRx`.
- term: `rec` — asciicast v2 (заголовок с `env`, `"o"`, `"r"`; `"i"` не пишется), поток записи Runtime (`spawn_dedicated`, спан `term.record`): буфер 64 КБ, сброс раз в 1 с, `sync_all` (`FlushFileBuffers`) при остановке; файл `<recordings_dir>\<профиль>-YYYY-MM-DD-HHMM[-N].cast` (`%VAR%` раскрываются, папка создаётся). UI-поток без I/O.
- Политика `ssh.recording` (только SSH) и `[ssh] recording`/`recordings_dir` — на лету: `required` — запись с первого байта, стоп отклоняется; `forbidden` — команда отклоняется, идущие записи останавливаются; `user` → `off` (команда выключена) / `manual` / `always`. Локальные терминалы — по Ctrl+Alt+R.
- Ошибка записи: обязательная — баннер `danger_bg` «Запись невозможна — ввод заблокирован», ввод в сеанс отклоняется; необязательная — тост, запись снимается.
- `term.record.toggle`; keymap: Ctrl+Alt+R в `terminal` и `cmdline`, исключение из `AltGrRisk` (№88).
- ui: чип «● Запись мм:сс» (`warning_bg`, рамка `context_remote`) в заголовке окна и в шапке пары; при `required` — «🔒 обязательна · политика · TOML/GPO», иначе «Остановить Ctrl+Alt+R»; статус одной группой «Запись в <путь> · asciicast v2, 1,2 МБ»; Ctrl+Alt+R в keybar пары (кроме обязательной и запрещённой). Сцена `screen-sshrec` сверена с макетом. Строки EN+RU.
- Тесты: эталон `rec_golden.cast` и валидатор формата; ввод после «Password:» не попадает в файл (живой pipeline); диск без места — ошибка и блок ввода при `required`; правила Ctrl+Alt+R; настройки и политика; имена файлов.

## Осталось
- `asciinema cat` на стенде не гоняется (нет asciinema для Windows офлайн) — эталон сверен по формату asciicast v2 вручную; ручная проверка — `docs/manual-tests/F03-12.md`.
- В сцене `screen-sshrec` нет шапки «ssh srv1 ▾» и клавиш терминала в keybar (терминал на весь экран показывает сетку `preview`, внизу клавиши панелей) — как у `screen-termhl` (F03-10, «Осталось»).
