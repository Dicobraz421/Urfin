## Сделать
- ADR-0024 и решение 2026-11-02: подсветка и свёртка — видимое окно от контрольных точек, любой размер, без неточных цветов.
- Каркас: проход по файлу потоком (`ByteSource`/`TextSnap`, не-UTF-8 — перекодирование с картой), контрольные точки каждые 64 КиБ, стек глубже 64 уровней — по сводкам; окно от ближайшей точки; правка — пересчёт до совпадения состояния.
- Лексеры JSON, TOML, INI, XML; YAML и Markdown — tree-sitter по отрезку от безопасной строки. Дифференциальные тесты против tree-sitter + `highlights.scm`.
- Свёртка встроенных языков — из событий структуры (скобки, таблицы, элементы, отступы, разделы).
- Вьювер и редактор — на окно для встроенных языков; пакетные — как было (≤ 16 МиБ).
- Замеры release на 16 МиБ и 1 ГБ JSON — `docs/perf/s7.md`.

## Приёмка
- роли окна = роли tree-sitter на корпусе и генераторах (непробельные байты); окно с любой точки = проход с начала; точки после правок = проход с нуля;
- правка в JSON 16 МиБ и 1 ГБ: новые цвета ≤ 50 мс, кадр p99 ≤ 6 мс, память подсветки ≤ 64 МиБ;
- сцена `hl-big-json`: окно в середине многоэкранного объекта — ключи без цвета, значения по ролям.

## Сделано (2026-11-02, x/hl-window)
- ADR-0024 и решение 2026-11-02; ADR-0023 §7, ответ 4 и S7 §5.7 — со ссылкой на них.
- Каркас (`view/src/syntax/lex`, `marks.rs`, `win.rs`): единицы по кодировке (UTF-8 и однобайтовые — байты, UTF-16 — единица, многобайтовые — посимвольно; ISO-2022-JP — без подсветки), проход потоком, точки каждые 64 КиБ (состояние, глубина, минимум глубины куска), роли стека глубже 64 уровней и глубже памяти прохода — по сводкам; правка — точки «под вопросом» и пересчёт до совпадения состояния; окно от ближайшей точки; свёртка из событий структуры; якоря и инертные зоны для правки.
- Лексеры JSON, TOML, INI, XML; трекеры YAML (строки ключей и элементов, многострочное) и Markdown (безопасные строки, ограждения и HTML в пунктах списка, метаданные) — tree-sitter по отрезкам. Строчный Markdown — по каждому узлу `inline` отдельно (исправлено и для полного разбора).
- Вьювер: проход в выделенном потоке, окно на `Lane::Interactive`, «подсветка N %» в статусе, «Разметка» — для встроенных языков любого размера. Редактор (`edit/hlwin.rs`): задача окна, пересчёт до конца — в выделенном потоке; на экране только верные цвета (инертная правка — сдвиг, иначе — до якоря). Пакетные языки — как S7-35 (≤ 16 МиБ).
- Тесты: лексер = tree-sitter (корпус репозитория, генераторы, случайные токены; внешний корпус — JSON 3135, TOML 2002, XML 2255, MD+YAML 3497 файлов без расхождений), окно = полный разбор, окно с любой точки = проход, точки после правок = проход с нуля, якоря и инертные зоны (роли до якоря после любой правки не меняются), свёртка одинакова в любом окне, вложенность 70 000 уровней. Замер — `docs/perf/s7.md`. Сцена `hl-big-json` (демо `Projects/urfin/assets/big.json`). Ручные — `docs/manual-tests/S7-41.md`.
