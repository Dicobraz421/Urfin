## Сделать
- ADR-0024 и решение 2026-11-02: подсветка и свёртка — видимое окно от контрольных точек, любой размер, без неточных цветов.
- Каркас: проход по файлу потоком (`ByteSource`/`TextSnap`, не-UTF-8 — перекодирование с картой), контрольные точки каждые 64 КиБ, стек глубже 64 уровней — по сводкам; окно от ближайшей точки; правка — пересчёт до совпадения состояния.
- Лексеры JSON, TOML, INI, XML; YAML и Markdown — tree-sitter по отрезку от безопасной строки. Дифференциальные тесты против tree-sitter + `highlights.scm`.
- Свёртка встроенных языков — из событий структуры (скобки, таблицы, элементы, отступы, разделы).
- Вьювер и редактор — на окно для встроенных языков; пакетные — как было (≤ 16 МиБ).
- Замеры release на 16 МиБ и 1 ГБ JSON — `docs/perf/s7.md`.

## Приёмка
- роли окна = роли tree-sitter на корпусе и генераторах (непробельные байты); окно с любой точки = проход с начала; точки после правок = проход с нуля;
- правка в JSON 16 МиБ и 1 ГБ: новые цвета ≤ 50 мс, кадр p99 ≤ 6 мс, память подсветки ≤ 64 МиБ;
- сцена `hl-big-json`: окно в середине многоэкранного объекта — ключи без цвета, значения по ролям.
