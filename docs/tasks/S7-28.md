## Сделать
- `Journal`: `Op::Splice { at, removed, inserted }` (куски, без копии текста) и `Op::Root { before, after, enc }` для массовых правок; группа = операции + выделение до/после; `undo`/`redo` применяют обратные операции.
- Группировка: пауза ≥ 1 с, переход курсора, смена вида (ввод ↔ удаление), любая команда правки — новая группа; API `begin_group(kind)` для команд («Заменить все», `editor.eol`, `md.*` — одна группа).
- Память — по объёму (≈ 24 Б на кусок + размер `Root`), потолок 16 МиБ, старые группы отбрасываются.
- `saved_at`: позиция последнего сохранения; «изменён» = позиция ≠ `saved_at`; `can_undo`/`can_redo` для панели; отбрасывание групп, ссылающихся на источник (сохранение «на месте», S7-31).

## Приёмка
- proptest: N правок → отмена всех = исходный документ, повтор всех = последний; отмена восстанавливает выделение;
- отмена до сохранённого состояния снимает «изменён», новая правка после отмены отрезает повтор;
- журнал при 1 млн нажатий укладывается в 16 МиБ, старые группы отброшены без ошибок.

## Сделано (2026-11-01, x/view-21)
- `edit/undo.rs`: `Journal<S>` (`S` — выделение документа, S7-29 подставит `Selections`); `Op::Splice { at, removed, inserted }` (куски, без текста; `From<Splice>` из правки `TextDoc`) и `Op::Root { before, after, enc: Option<(Enc, Enc)> }`; группа — операции + выделение до/после; `undo`/`redo` применяют обратные операции к `TextDoc` (`splice`, `set_tree`) и возвращают `Step { sel, enc }` (кодировка — у массовой правки с переводом).
- Группировка: пауза ≥ 1 с (`PAUSE`), `break_group()` — переход курсора, смена вида (`Kind::{Input, Delete, Command}`), `begin_group(kind)` — команда (все её операции — одна группа, следующая правка — новая); `mark_saved` тоже закрывает группу. Подряд идущие правки группы сливаются в одну операцию (вперёд — набор, Del, режим замены; назад — Backspace), куски в ней — `join`: серия нажатий — O(1) памяти.
- Память — оценка по объёму (`size_of::<Op>()` + куски сверх встроенных, у `Root` — куски обоих деревьев, + группа), потолок `CAP` = 16 МБ: сверх — старые группы с начала (текущая остаётся), `tracing::debug`.
- `is_modified` — позиция (абсолютная, с учётом отброшенных) ≠ позиции сохранения; отрезанный повтор с сохранённым состоянием — «изменён» до нового сохранения; `can_undo`/`can_redo`; `drop_src(src)` — сохранение «на месте» (S7-31): отбрасывает ссылающиеся группы и всё, что за ними не достать (и в повторе).
- Тесты (`undo_tests.rs`): proptest — правки, паузы, переходы, команды, `Root` на LF/CRLF/CR/UTF-16 → по каждой отмене документ = состоянию перед группой и выделение = до группы, отмена всех = исходник (не изменён), повтор всех = последний (прогон 2000 случаев — без падений); правила группировки; сохранённая позиция и отрезание повтора; `Root` с кодировкой; `drop_src`; 100 тыс. нажатий с потолком 256 КБ; `journal_cap_million` (`#[ignore]`, release): 1 млн нажатий (переходы курсора, Backspace) — журнал 16 777 096 Б ≤ 16 МБ, 72 тыс. групп держится, 290 тыс. отброшено, отмена/повтор оставшихся — без ошибок.
