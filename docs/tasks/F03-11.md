## Сделать
- §3.4 — группа, колонка сеансов, блоки вывода, `broadcast`, подтверждение первого Enter, Esc, чип, политика `ssh.multi_exec`.

## Приёмка
- ввод попадает во все PTY группы в одном порядке;
- первый Enter задержан до подтверждения, Esc шлёт `Ctrl+U` во все сеансы;
- при `ssh.multi_exec=false` команды выключены и отсутствуют в keybar;
- «код N» — только при OSC 133/633;D.

## Заметка
- Межполосная (term, ui, net): при планировании волны разбить или вынести контракт в PR класса B.

## Сделано (2026-11-05, ветка x/term-multi)
- core: модель `net::Group` в `NetModel.group` — состав, курсор колонки, задержка первого Enter (`feed`, `reject`), набранное для вопроса; контекст `ssh_group`, `multi_exec_allowed`. UI от `urfin-net` не зависит.
- term: `TermApi::broadcast` (`urfin_term::broadcast`, `Manager::broadcast_with`): байты в порядке вызовов во все сеансы, клавиша кодируется режимами каждого сеанса (app cursor, win32-input-mode); вышедшие и с заблокированным вводом пропускаются. `term::group` — `edit`, `toggle`, `leave`, маршрут `term.input/key/paste`, снятие группы по политике на лету.
- net: `ssh.group.edit/toggle/leave`, `[ssh].multi_exec_confirm`.
- keymap: Ctrl+Alt+G в `terminal` и `cmdline`, исключение из `AltGrRisk` (№88); Esc в `terminal && ssh_group`. Ctrl+Tab на экране группы выключен. `keys.md` — генератором.
- ui: экран группы (колонка 200, стопка блоков, «код N» только из OSC 133/633;D, строка подтверждения), чип в заголовке окна с кнопкой «Выйти», статус, keybar; Ctrl+Alt+G в keybar пары при разрешающей политике. PTY группы — шириной блока, высотой области терминала (`term.pin`). Сцены `screen-sshmulti` (сверена с макетом), `sshmulti-ask`. Строки EN+RU.
- Клавиши колонки: Ctrl+Alt+G на экране группы — колонка ↔ ввод; ↑↓ Home End, Пробел, Enter — ввод. Space идёт через `term.input`, а не привязкой keymap: контекста «фокус в колонке» в контрактах нет, в режиме ввода пробел должен уйти в PTY.
- Ctrl+O на экране группы: группа ждёт, ввод идёт как обычно (`Group::on_screen`), повторный Ctrl+O возвращает экран.
- Вставка до подтверждения: скобочная держится целиком, обычная — с первого перевода строки.
- Тесты: `group_tests` — фейковые PTY и настоящие reader/writer (порядок ввода, задержка Enter, Esc → `Ctrl+U`, политика, закрытый сеанс); `net::group`, `ssh_group`, код из OSC в фикстуре.
