## Сделать
- `arc.extract`: выделенное внутри архива и архивы в панели без входа; `UiEvent::Ext { id: "arc.draft" }` с размером, именем подпапки, признаком пароля (чтение заголовка не в UI-потоке).
- Подтверждение строки → `ops.copy` с опциями S8-27; несколько архивов — job на архив.
- Неверный пароль: ответ в строку, три попытки.

## Приёмка
- 3 архива → 3 подкаталога в пассивной панели;
- Esc ничего не запускает;
- неверный пароль оставляет строку открытой, «осталось N».

## Заметки S8-27
- Запуск: `ops.copy { src, dest, conflict?, paths? }` — `dest` обязателен, черновика нет. `src` — uri каталога источника целиком (`root_of(scheme, file).to_uri()` — весь архив, без входа); без `src` — выделенное в активной панели внутри архива. Несколько архивов — по команде на архив.
- С `src` и с `paths=false` назначение — всегда папка: создаётся один уровень (родитель должен быть). «В подпапку <имя>» — имя добавляет сам `arc.extract`.
- `paths=false` («Сохранять пути» выкл.): каталоги не создаются, файлы — прямо в назначение; одноимённый из другой папки — «пропущено» (остаётся первый, как `7z e -aos`).
- «Если файл есть» → `conflict`: `ask`, `overwrite`, `skip`, `newer`.
- Пароль ops не спрашивает: запись без пароля — ошибка элемента «нет доступа» (вопрос «Повторить/Пропустить»). Пароль положить в `ArchiveIndex::ctx()` до `ops.copy`.
- Название задачи — «Копирование» (`ops-job-copy`), не `arc-job-extract`.
