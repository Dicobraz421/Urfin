## Сделать
- `viewer.open/close/wrap/wrap_mode/hex/mode/codepage/codepage_menu`: детект при открытии, `lang` (имя, расширение, shebang), выбор режима (binary → Hex; язык и ≤ 16 МБ → Разметка), восстановление из истории, смена режима с сохранением позиции, кольцо F8.

## Приёмка
- 100 ГБ sparse — первый экран ≤ 50 мс (интеграция core + view + tempfile);
- Text ↔ Hex сохраняет позицию;
- смена 1251 ↔ 866 не сбрасывает индекс, UTF-8 ↔ UTF-16 — сбрасывает.

## Сделано
- `viewer.rs`: `ViewerDoc` — источник, `kind`, `len`/`len_final`, детект, `enc`, `eol`, `mode` и последний текстовый режим, `wrap`/`wrap_kind`, `lang`, позиция `top`/`top_sub`/`hscroll`, `sel`, `search`; `layout(width_cols)` → `LayoutSpec`, `pos(&spec)` (в Hex — `top` вниз до `hex_cols`); `OpenState::{Opening, Ready}`.
- Открытие (§3.1): `viewer.open` (путь или файл под курсором; каталог → `vfs.dir_size`; `placement`) кладёт документ `Opening`, ставит экран и `Focus::Viewer`; задача `view.open` на Interactive: `open_source` → 64 КБ → `detect` (tld по языку интерфейса) → `lang` → `OpenedMsg`. Выборка становится первой страницей кэша (первый экран без второго чтения). Spool: насос — `spawn_dedicated`, детект ждёт 64 КБ (≤ 500 мс) в своём потоке. Ошибка — тост `core-command-failed`, документ закрывается.
- Режим: binary → Hex; язык и ≤ 16 МБ → Разметка; иначе Текст. Индексатор (S7-05) стартует при открытии, если `!quick` и режим текстовый; для Spool дочитывает прирост; дельты с поколением (`IndexMsg.epoch`).
- `viewer.close` (запись в историю, отмена всего фонового, фокус — на верхний экран или панели), `viewer.wrap` (F2: off ↔ последний вид), `viewer.wrap_mode`, `viewer.hex` (F4), `viewer.mode mode=` (без аргумента — `UiEvent::Ext` «меню режимов»), `viewer.codepage cp=` (имя WHATWG или `auto`; без аргумента — кольцо F8, одинаковые кодировки пропускаются), `viewer.codepage_menu` (`UiEvent::Ext` для «мешочка»; группы — `codepage_menu()`).
- Позиция при смене режима: Text → Hex — `top` не меняется (рисуется с `top` вниз до `hex_cols`), Hex → Text — к началу строки по кэшу; страниц нет — `realign`, выравнивание после `PagesMsg`.
- Кодировка: BOM по выборке, EOL заново для другой кодировки; индекс сбрасывается только при смене разделителя (UTF-16 ↔ байтовые, LE ↔ BE, `Cr` ↔ `Lf`).
- `lang.rs`: язык по имени файла, расширению и shebang (имена gpui-kit и свои `powershell`/`xml`/`ini`).
- `history.rs`: `ViewHistory` в памяти (`history_max`): позиция, ручная кодировка, режим, перенос; восстановление при открытии, если `top < len`.
- `register_env` + `ViewEnv` (реестр VFS, каталог кэша для Spool); `register`/`register_with` — локальная ФС без Spool.
- Тесты (`viewer_tests.rs`, через core): открытие текст/бинарный/Markdown, первая страница из выборки, индекс; ошибка открытия; Text ↔ Hex и Hex → Text с середины строки; 1251 ↔ 866 без сброса индекса, UTF-8 ↔ UTF-16 — со сбросом; кольцо F8; история; поиск командой.
- Замер (release, `tests/heavy.rs`): 100 ГБ sparse, `viewer.open` → документ готов и страница `top` в кэше — лучшее из 5 — 1,5 мс (≤ 50 мс).
