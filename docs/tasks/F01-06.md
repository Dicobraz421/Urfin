## Сделать
- строка «Отмечено N · освободится X» + «Удалить в Корзину F8», F8 → `ops.delete`, вычитание по перечитыванию вкладки §3.7 ([решение 2026-11-01](../decisions/2026-11-01-du-subtract-reread.md)).

## Приёмка
- вложенная отметка не считается дважды;
- политика `DeleteToTrash=1` (ADR-0020) — Shift+F8 недоступен и в `du:`;
- после удаления размеры предков уменьшились без пересканирования.

## Заметка
- Межполосная (ui, vfs): при планировании волны разбить или вынести контракт в PR класса B.

## Сделано (2026-11-01, PR x/du-ui)
- Строка внизу вкладки: «☑ Отмечено N · освободится X», «Удалить в Корзину F8» (`Btn::Danger`, клавиша из keymap), «Снять отметку» (`sel.none`); список строк уменьшается на её высоту.
- «Освободится» — `du_view::frees`: отмеченный каталог поглощает отмеченных потомков (путь `dir\name` плоских фильтров), тест.
- F8/Shift+F8 → `ops.delete` по настоящему каталогу (`localize` в `OpsHandler::request`); политика `DeleteToTrash` — штатная ветка ops, без изменений.
- Вычитание без пересчёта: после операции ops перечитывает вкладку `du:`, `DuRegistry::list` сравнивает с прошлым листингом — исчезнувшие подкаталоги (их суммы, узел обнуляется) и файлы вычитаются из каталога и всех предков; снимок помечается и пишется в кэш (не чаще 1/30 с). Тесты: `dvfs_tests.rs`, `ops/tests/du_delete.rs` (F8 насовсем → предки уменьшились, скан один).
- Ручная проверка — `docs/manual-tests/F01-06.md`.
