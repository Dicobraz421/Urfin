## Сделано (2026-11-01, x/s7-16-editor)
- Спайк: `--bench-editor <файл>` (флаг app, фича меряет и выходит); таблица — `docs/perf/s7.md`; `editor.max_size_mb` = **16** (`set_value` gpui-kit ≈ 15 мс/МБ на UI-потоке, ≈ 9 МБ памяти на МБ текста; 64 МБ — ≈ 1 с без отклика). Замер dev-сборкой (зависимости O2), release — когда на C: будет ≥ 15 ГБ.
- Концы строк: `EditorState` текст не нормализует (CRLF, CR, смешанные — как в файле; тест `editor_state_keeps_line_endings`), строки делит по LF.
- Фича `Editor` (`view/editor.rs`, `Main::Replace`): `Entity<EditorState>` на документ — `loaded` → строка в фоне → `set_value` → `Adopted`, повторный `loaded` — замена текста; курсор `start`, `set_readonly`; `Edited`, `Snapshot { then: Diff }` через 300 мс после правки; ответ на `editor.snapshot`, `editor.saved`, `InboxMsg::Blur`.
- Шапка (путь, «только чтение», счётчик правок; загрузка — проценты и полоса; «слишком большой» — «Открыть в просмотре» / «Внешний редактор»), полоса изменений 3 (`gutter.rs`), номера gpui-kit, мини-карта 88 с рамкой и кликом (`minimap.rs`), текущая строка, статус, вкладка с ● (общие вкладки экранов), keybar по макету.
- Строки внизу: вопрос документа `EdAsk` (кнопки и буквы, Enter, Esc → `editor.answer`), `caution` при `lossy` (F8 — меню кодировок).
- `editor.undo/redo/delete_line/block.shift_*` — handler `editor` шлёт `UiEvent::Ext`, фича выполняет в `EditorState`; Ins — режим замены (статус «Замена»); Enter и вставка — с концом строк документа; `editor.eol` — весь текст одной правкой; `searchable(false)`.
- Список экранов F12 рисуется поверх редактора (`Main::Over`). Хук `ShellFeature::key_in` (клавиша с окном и контекстом).
- Сцены: `screen-editor`, `editor-eol-menu`, `editor-no-toolbar`, `editor-ask-close`.

- ~~Release-замер нажатия на 64 МБ~~ — снят: `EditorState` уходит, нажатие на любом размере меряет S7-36.
- Свёртка — S7-35 (по дереву грамматики, после S7-21).
- Undo/Redo на панели и ● после отмены — S7-28 (журнал: «нечего отменить» и сохранённая позиция точные).
