## Сделать
- Относительные пути строк `du` (`views`, `dvfs`, `fresh`, `filters`, `cache`) — через разделитель платформы; один источник разделителя, без обратной косой в литералах.
- Кэш `du`: формат на Windows не меняется; на Linux — свой, старого кэша там нет.
- Что из публичного API меняется для UI — перечислить в теле PR (карточка L1-12).

## Приёмка
- тесты `du` зелёные под Linux и Windows; тест на Linux: путь строки содержит `/` и не содержит обратной косой.
