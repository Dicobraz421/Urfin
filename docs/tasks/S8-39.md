## Заметки S8-38
- Backend `cmp:` в приложении не зарегистрирован (полоса ui): в `vfs_registry` (`crates/app/src/main.rs`) — `reg.register(Arc::new(urfin_search::SearchVfs::cmp(search_stores())))`. Без него `cmp:/<id>` — «нет backend'а».
- `..` у корня `cmp:/<id>`: в `Location::parent` (`crates/core/src/loc.rs`, список `du | pkg | search`) добавить `cmp`.
- Запуск: `ops.compare recursive=true mode=content|quick` (стороны — панели); привязки и меню — здесь. Ход — `SearchInfo` стора (`dirs`, `files`, `done`), итоги и режим — `UiEvent::Ext ops.compare.result { id, recursive, mode, only_left…differs, equal, precision_s? }`: держать по `id` (у `SearchInfo` полей для них нет).
- Колонка «Статус»: `Vfs::ext(dir, e, "status")` → `ExtCell::Text("only_left" | "only_right" | "newer_left" | "newer_right" | "differs")`. `SearchVfs::columns` у `cmp:` пока Размер · Изменён — `ColumnSpec` статуса и строки i18n добавить здесь.
- Статус окна: другая сторона пары — `ext "size2"` (`ExtCell::Size`) и `"mtime2"` (`ExtCell::Date`); у `only_*` — `None`. Сторона строки: `only_left`, `newer_left`, `differs` — левая.
- F5/F6 в `cmp:` без `confirmed` → `ops.draft { command, cmp: true[, current] }` — подтверждение «на другую сторону» без поля, Enter → `ops.copy confirmed=true`. Строки из архива или с сервера F5 пропускает (пишет только на локальную сторону).
- Ctrl+R (`panel.refresh`) и `panel.refresh` после F5/F8 — сравнить заново: новый `cmp:/<id>` в том же табе. `?f=errors` у сравнения не ведётся — только счётчик `denied`.
