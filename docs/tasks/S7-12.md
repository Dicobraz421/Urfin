## Сделано (2026-10-31)
- `viewer.follow` (Shift+F) — вкл/выкл у активного документа; `ViewerDoc::follow` и `follow_stick` — данные чипа «Слежение» (чип рисует UI). Включение — в конец, прилипание к концу; документ Markdown переходит в Текст.
- Источник: `File` — рост включается на месте (`ByteSource::set_follow`), Owned / Mapped заменяются задачей `view.follow.open` (Interactive) на `File` с ростом; кэш страниц — `PageCache::replace_source` (ответы прежнего loader'а не кладутся). Handle std — `FILE_SHARE_READ|WRITE|DELETE`; в follow индексатор читает своим handle (по пути после ротации — уже другой файл).
- Поток `view.follow.<doc>` (`spawn_dedicated`) раз в `follow_interval_ms` (50…5000, по умолчанию 250): `refresh_len()` по своему handle; рост → `Grew` с хвостом (≤ 2 страницы, прочитаны потоком — без круга loader'а), индексатор дочитывает прирост (готовый индекс — `Indexer::resume`); усечение → страницы и индекс заново, позиция в конец, тост `ui-view-truncated`; ротация (по пути другой `file_id`, свой не растёт) → при `follow_reopen` поток открывает файл заново, `Rotated`, тост `ui-view-rotated`; удалённый файл — следим дальше, новый по тому же пути — ротация.
- Прокрутка вверх (Up, PgUp, Home) снимает прилипание, End возвращает.
- `sys::file_id` (`GetFileInformationByHandle`) — `view::sys`.
- Тесты `follow_tests.rs`: рост через core (V6), прилипание, усечение → удаление → новый файл, закрытие; шаг опроса — юнит.
