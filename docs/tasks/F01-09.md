## Сделать
- §3.6: группы по размеру, частичный xxh3-64 64 КиБ, Ctrl+H — полный xxh3-128, порядок, автоотметка в `Full`.

## Приёмка
- жёсткие ссылки и OFFLINE не попадают в группы;
- файлы с общим префиксом 64 КиБ и разным хвостом — разделяются только после Ctrl+H;
- отмена хэширования ≤ 100 мс.

## Сделано (2026-11-02, PR x/du-4)
- vfs `du::dups`: группы крупных файлов по логическому размеру (≥ `[du] dup_min`, без `OFFLINE`, жёсткие ссылки — одна запись), частичный xxh3-64 первых 64 KiB (`FILE_FLAG_SEQUENTIAL_SCAN`; до 64 KiB — сразу `Full`), полный xxh3-128 потоком по 1 MiB с отменой между кусками; порядок — самый старый первым, группы по размеру ↓.
- Реестр: группы считаются при первом показе вида (вне UI-потока — в листинге), задача `du.dups` (очередь устройства) при входе в фильтр и по Ctrl+H (`du.verify_hash`); совпавшие по полному хэшу — отмечаются (все копии, кроме первой) handler'ом, когда листинг вида загружен; Esc (`du.stop`) отменяет хэширование.
- «Сборки и кэши» (решение 2026-11-02 «du-filters» №1): скан копит суммы кандидатов (`NodeFlags::BUILD_CAND`), заморозка решает по правилам имени (`BUILD`, `FileRec::IN_BUILD`, `DuSnapshot.build`); в «Типах» — группа «Сборки и кэши», типы — без сборок («Код» вместо «Код и сборка»); вычитание удалённого — и из сумм сборок. Кэш `ver` 2, v1 — пересчёт.
- Колонки «Дубликатов» — у схемы (`Vfs::columns(dir)`): Изменён · Размер; ui: заголовок группы (значок и цвет файла, «N копии», метка «✓ совпадает по хэшу» / «только размер»), копии — где лежит, строка внизу «N групп, хэшем проверены M · отмечено K · освободится X» с «Проверить хэшем N групп Ctrl+H» и «В Корзину F8», статус «N групп · M файлов». Ctrl+H в `panel && in_du`.
- Тесты: `dups.rs` (разбиение, отмена), `views_tests.rs` (`dups_levels_and_marks`: жёсткие ссылки, общий префикс разделяется только полным хэшем, отметки; «Сборки и кэши» в «Типах»), кэш v1 → `version`; сцены `dudups-plain`, `screen-dudups` (фикстура: уровни заданы, без хэширования). Ручная проверка — `docs/manual-tests/F01-09.md`.

## Осталось
- Ctrl+H — все непроверенные группы; «группа под курсором» и Shift+Space «Отметить группу» (подсказки keybar макета) — нет.
- «Частичный» уровень показывается как «только размер» (на макете две метки).
- Замер «частичный хэш 10k кандидатов ≤ 3 с» — на стенде, не делали.
