## Сделать
- §3.3 USN-путь (права, journal_id, усечение) и mtime-перепроверка, «●», «посчитано N назад · ● изменено N папок», Ctrl+R по изменённым.

## Приёмка
- с правами: изменения между сессиями видны без полного скана (стенд, `#[ignore]`);
- без прав: изменённые каталоги помечены, Ctrl+R пересчитывает только их, итог = полному скану (кроме роста файлов — задокументировано);
- журнал пересоздан → корректный откат на mtime.

## Заметка
- Межполосная (vfs, ui): при планировании волны разбить или вынести контракт в PR класса B.

## Сделано (2026-11-02, PR x/du-fresh)
- Скан запоминает позицию USN-журнала тома (`DuSnapshot.usn`, только NTFS и с правами администратора — открытие `\.\X:`) и `FileId` корня; sys `win_usn`: позиция журнала и чтение номеров записей (сам файл и родитель), без имён.
- Открытие из кэша → задача `du.recheck` (Runtime, вне UI-потока): журнал тот же и не усечён — записи с сохранённой позиции, родители → каталоги снимка по `FileId` → перелистывание (как live, F01-10), позиция обновляется; нет прав / журнал пересоздан / усечён — `mtime` каждого каталога снимка (потоки `[du] threads`), отличие — «●», исчезнувший — «●» у родителя (`fresh::plan`, `fresh::check`).
- «●» хранится в снимке (`NodeFlags::CHANGED`, переживает кэш); `DuInfo.changed`; заголовок — «посчитано N назад · ● изменено N папок» + «Обновить Ctrl+R» (и при «●» после переполнения наблюдения); точка `context_remote` у размера изменившейся папки (`screen-ducached`).
- Ctrl+R при «●» — задача «Анализ места, изменённые папки» перелистывает только их (новые поддеревья — досчётом); «●» больше половины снимка — полный скан; Ctrl+Shift+R — всегда полный.
- Тесты: `fresh::plan` (тот же журнал; пересоздан, усечён, позиция из будущего, нет прав → `mtime`), `reopen_marks_changed_and_relist_matches_scan` (без прав: «●» у изменённых, Ctrl+R только по ним, итог = полному скану; с правами — то же по USN), `many_changed_means_full_rescan`; `win_usn::read_tail_of_c` — `#[ignore]` (стенд, админ, только чтение). Сцена `screen-ducached` — фикстура с тремя «●».

## Осталось
- Ограничение (принято, F01 §8): без прав рост существующего файла не меняет `mtime` папки — виден только live, по USN или полным пересчётом (Ctrl+Shift+R). Подсказки об этом в UI нет — только здесь и в ручной проверке.
- Замеры «USN-дочитка 10k изменений ≤ 1 с» и «mtime 300k каталогов ≤ 5 с» — на стенде.
