## Сделать
- `EDITOR_COMMANDS`: `editor.wrap`, `editor.eol_menu`, `editor.toolbar`, `editor.preview`, `editor.md.bold`, `editor.md.italic`, `editor.md.heading {level?:Int}`, `editor.md.list`, `editor.md.numbered`, `editor.md.task`, `editor.md.link`, `editor.md.code`, `editor.md.table`. Выполняются в UI через `UiEvent::Ext` (как `editor.undo`); `editor.md.*` и `editor.preview` отклоняются вне Markdown.
- `[editor]`: `toolbar = true`, `preview = false`, `preview_split = 0.5`; `editor.wrap`, `editor.toolbar`, `editor.preview` пишут свои ключи.

## Приёмка
- новые id в реестре, аргументы — по §7; ключи читаются и пишутся (тест конфига);
- `editor.md.bold` в документе не на Markdown → `Rejected` с понятным текстом.

## Сделано
- view: в `EDITOR_COMMANDS` — `editor.eol_menu`, `editor.wrap`, `editor.toolbar`, `editor.preview`, `editor.md.{bold,italic,heading,list,numbered,task,link,code,table}` (`heading` — `level?:Int` 0–3, иначе ошибка аргумента). Handler шлёт `UiEvent::Ext` с id команды и `doc` активного редактора; переключатели меняют `[editor]`, пишут ключ через `settings::set` и кладут в Ext новое `on`. `editor.md.*` и `editor.preview` вне Markdown — `Rejected` «Только для Markdown-файлов»; без редактора на экране — ничего.
- `[editor]`: `toolbar = true`, `preview = false`, `preview_split = 0.5` (снимок конфига, тест разбора и записи).
- keymap: новые id — в `known_commands.rs` (привязки — S7-24a).
