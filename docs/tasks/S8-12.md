## Сделать
- Элементы панели `search:` разрешаются через `Vfs::resolve` в реальные адреса; `OpRequest` группирует их по каталогу.
- F5, F6, F8, Shift+F6, атрибуты; цель в `search:` — отказ `ops-no-write`.
- После операции панель обновляется через `Patch`.

## Приёмка
- F5 из результатов не теряет файлы с одинаковыми именами (В2: относительная папка сохраняется);
- F8 удаляет именно тот `Cargo.toml`, что под курсором;
- ручная проверка `docs/manual-tests/S8-12.md`.

## Заметка
- В2 — вариант А, [решение «s8-answers»](../decisions/2026-11-06-s8-answers.md).
- `Vfs::resolve` у `search:` (S8-10) даёт настоящий адрес. Относительная папка (В2) — имя строки без файла; у поиска по нескольким корням имя начинается с корня (`C:\Dev\src\a.rs`), корень надо отрезать (`urfin_search::svfs`, ops от него не зависит — решить при задаче).
- Обновить панель после F8/F6 — `panel.refresh` вкладки `search:`: перепроверка уберёт удалённые патчем.
