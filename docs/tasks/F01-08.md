## Сделать
- §3.5: чипы, Ctrl+1…6, таблица типов, порог «Старые», правила «Временные» с пояснениями (Fluent).

## Приёмка
- таблица типов: тест покрытия (каждое расширение → ровно один тип);
- «Временные» ничего не отмечают; переменные окружения раскрываются;
- смена порога «Старые» без I/O.

## Заметка
- Межполосная (vfs, ui): при планировании волны разбить или вынести контракт в PR класса B.

## Сделано (2026-11-02, PR x/du-2)
- vfs `du::filters`: таблица типов §3.5 (тест покрытия: расширение — ровно один тип; `ts` — «Код»), `~*` — временные; вид вкладки в адресе `du:/<id>?f=…` (у «Старых» `&age=`), вход в папку из строки фильтра — снова «По папкам»; правила «Временных» по пути (`%VAR%` раскрываются один раз, `*`, `{a,b}`) и по имени каталога (`target` Cargo, `node_modules`, `.cache`), одиночные `*.tmp`, `~$*`, `*.dmp`.
- vfs `du::views`: «Крупные», «Старые», «Типы» (группы, Enter раскрывает — крупнейшие файлы и «ещё N файлов»), «Временные» (разделы, подсказки, «нет доступа: N папок») — из снимка без I/O; повторный листинг того же вида после операций вычитает удалённое (решение 2026-11-01); во время подсчёта — «Крупные» (текущий топ).
- handler: `du.filter` (Ctrl+1…6, чипы; `group` — раскрыть группу «Типов»), `du.old_age` (чипы 6m/1y/2y/5y), разрешитель Enter для строк без файла; «Дубликаты» — пока тост (F01-09).
- ui: чипы по виду, пороги «Старых», предупреждение «Временных», колонки вида (Группа · Файлов · Доля · Размер; Где · Доля · Размер), папка перед именем серым, группы с треугольником и отступом, разделы с суммой, подсказки после имени; статус: расширения группы, «N групп · M файлов», «Найдено N · X».
- Fluent EN+RU. Тесты: `filters.rs`, `views_tests.rs` (без I/O при смене порога, правила, вычитание), `du_tab.rs` (через core); сцены `screen-dutypes`, `screen-dutemp`. Ручная проверка — `docs/manual-tests/F01-08.md`.

- Фильтры — от корня анализа (суммы по типам — на весь снимок), не от подпапки.
- Совпадения «Временных» в «По папкам» не подсвечиваются; Ctrl+PgUp «К папке файла» из вида фильтра — нет.
- `docs/keys.md`, `docs/COMMANDS.md` не обновлены (полоса docs-gen).
