## Сделать
- `End::of`: адрес с `outer` — источник; цель отвергается по `Caps::READ_ONLY`.
- `vfs_copy`: данные через `extract_plan`, если есть; докачка только при `Caps::SEEK`.
- Опции: «без путей», весь архив как источник (для `arc.extract`).
- Проверка имён назначения, `LinkMode`, Mark-of-the-Web (§6).
- `ops.move` из архива — черновик копирования. `compare`: сторона-архив, допуск времени §4.

## Приёмка
- копия каталога из zip побайтно равна `7z x`, время сохранено;
- конфликты, пропуск, job-бар работают как для `sftp`;
- zip-slip-запись не выходит из цели;
- F5 в архив — отказ до задачи;
- ручная проверка `docs/manual-tests/S8-27.md`.

## Заметки S8-24
- `ArcVfs::extract_plan` без I/O; `None`, если индекса нет в кэше или в списке каталог.
- zip (S8-25): план — до `min(parallel, 4)` потоков, у каждого свой дескриптор архива, записи по порядку оглавления; `transfer_channels() = 4`. `SEEK` — только у stored без шифрования, докачка — по нему.
- `End::device()` — ключ устройства по файлу архива; `transfer_vfs` → `extract_plan`.
- `ops.move` из архива = черновик копирования (решение S8-21).
- Зашифрованная запись без пароля — `VfsError::Io` с `PermissionDenied` (`arc-error-no-password`); пароль — `ArchiveIndex::ctx()` (S8-35).
- `arc.extract`, `arc.commands`, `arc.test`, `arc.add` пока отвечают `Rejected` (`ops-not-yet`).
