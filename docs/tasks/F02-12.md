## Сделать
- раздел настроек по `screen-settings-pkg`:
- порядок менеджеров перетаскиванием, ненайденный — пунктир;
- «поиск по умолчанию — все»;
- расписание — выключатель и время;
- важные программы — чипы с поиском по установленным;
- строки «вывод — терминал» и «права — UAC менеджера» как пояснения;
- `pkg.important.toggle` в контекстном меню строки.

## Приёмка
- изменения применяются сразу;
- смена порядка переранжирует открытые результаты;
- важные поднимаются в «Обновлениях» и считаются в баннере.

## Заметка
- Межполосная (ui, pkg): при планировании волны разбить или вынести контракт в PR класса B.

## Сделано
- core: `[pkg]` (`PkgConfig`, `Timeouts`, `Schedule`) и `parse_at` — в `urfin_core::pkg`, `urfin_pkg` реэкспортирует (как `SshCfg`, решение «pkg-model-core»); `PkgModel.config` вместо `order` — действующий `[pkg]`; `MgrLine.version`; у `pkg.important.toggle` аргумент `id?`.
- pkg: `[pkg]` на лету (`handler_conf.rs`): новый конфиг и своя правка идут одним путём — книга, модель, `PkgState`, вкладки; `Env.config` меняется, потоки берут снимок. `PkgBook::configure` переранжирует открытые результаты (`SearchMerge::reorder`: «рекомендуется», варианты, группы) и берёт `search_in`, пока запроса нет. `pkg.important.toggle` — по `id` или со строки под курсором, снимает и двойников (`PkgBook::family`), пишет `[pkg].important`. `pkg.schedule` без `on` — ещё и кэш и найденные менеджеры в модель, без запросов к менеджерам (`known` теперь сверяет с системой); без каталога состояния (`--screens`) — ничего.
- ui: раздел «Пакеты» (`gpui_shell/settings_pkg.rs`, логика без окна — `pkg_settings.rs`) по `screen-settings-pkg`: порядок чипами с перетаскиванием (`on_drag`/`on_drop`, не найденный — пунктир), поиск по умолчанию, расписание, «Проверить сейчас», строка о задаче и «Обновить», чипы важных с поиском по установленным (↑↓, Enter, клик), пояснения о выводе и правах. Вход в раздел — `pkg.schedule` (сверка). Поле — `settings_ssh::Field<K>` на оба раздела; `select_w` — список заданной ширины. Контекстное меню строки `pkg:` — «Важное» с галочкой, у «вне менеджера» пункта нет.
- Строки EN+RU (`pkg.ftl`). Сцены `screen-settings-pkg` (сверена с макетом), `settings-pkg-add`.
- Тесты: `reorder`, `configure`, `known`, `family`; через Core на подставном Планировщике — сверка, `pkg.important.toggle`, `app.reload_config`; логика раздела — `pkg_settings`.

## Осталось
- Ручные проверки — `docs/manual-tests/F02-12.md` (перетаскивание, настоящий Планировщик).
- Отличия снимка от макета: кнопка «Проверить сейчас» в строке расписания (на макете её нет, команда §2.5 — «настройки»); строка 36 вместо 43 макета (DESIGN.md, как во всех разделах); время слева в поле, файл настроек в статусе в сцене пуст (`--screens` без каталога настроек, как в остальных разделах); `Ctrl+F` в keybar и раздел «Терминал» — не этой волны.
- Порядок менеджеров — только мышью; с клавиатуры — `[pkg].order` в конфиге.
- Время меняется только при включённом расписании (макет: поле `disabled`).
- Запись в конфиг из настроек идёт отложенно: перечитывание, запущенное до правки важных, на миг вернёт прежний список, следующее — поправит (`AppState.config` — снимок файла).
