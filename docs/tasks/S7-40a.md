- Рисование (`edit_view.rs`): прямоугольник `accent.subtle` по колонкам (`x = (колонка − hscroll) × ширина колонки`), без скругления, в т. ч. за концом коротких строк; при переносе — часть каждого ряда от начала логической строки; пустой по ширине блок — черта 2; курсор — в углу блока (колонка может быть за текстом).
