## Сделано
- Помощник `--pkg-elevated`, pipe с nonce и ADR не делались: отменены владельцем (F02 §8, S0 v6 №17). По решению: строка «choco требует прав администратора — будет запрос UAC», choco через UAC в своём окне, ход — по `chocolatey.log`, итог — по коду. `crates/app` не тронут.
- `choco.rs`: запросы `--limit-output` (v2 ещё `--no-color`); v2 `list`/`outdated`/`search`, v1 `list --local-only` и `list <q>`; коды запроса 0 и 2 (`useEnhancedExitCodes`); строки не `id|…` отбрасываются. `action_plan`: `install|upgrade|uninstall <id> -y --no-progress`, `elevate: true`, перезагрузка 1641/3010. `whitelisted`: тот же `choco.exe`, три глагола, id по регэкспу, флаги только `-y --no-progress --noop`. `LogFilter`/`log_record`: записи log4net без `DEBUG` и его продолжений.
- `elevated.rs` без `unsafe`: обёртка — Windows PowerShell 5.1 с `Process.Start(UseShellExecute, Verb=runas)` (= `ShellExecuteExW(runas)`), отказ 1223 → `PkgError::Elevation(Declined)`, маркеры `<<URFIN>> started/exit/declined/failed`; журнал читается с конца на момент запуска, построчно в `RunCx::lines`; отмена убивает обёртку (`Cancelled`, повышенный choco живёт дальше). UAC показывает настоящий `choco.exe`, не шим `bin\choco.exe`.
- `ChocoAdapter` (Windows): `PackageManager` + `run_action` (белый список → UAC). Строки Fluent EN+RU: `pkg-choco-uac`, `pkg-uac-declined`, `pkg-cancel-elevated`.
- `fake-pkgmgr --log` — запись в формате журнала choco. Тесты: фикстуры v1/v2 (`fixtures/choco`), белый список, журнал, скрипт и маркеры; на подставке без UAC (скрытое окно) — строки журнала в ленту, коды 3010/5/0, путь с пробелом, отмена, отказ белого списка без запуска.
- Ручная проверка UAC — `docs/manual-tests/F02-06.md` (`#[ignore]` тест `stand_choco_uac`, `--noop`).
