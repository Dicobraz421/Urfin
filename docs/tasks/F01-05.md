## Приёмка

- кадр ≤ 2 мс при 100k строк;
- `du:` не попадает в сессию.

## Сделано (2026-11-01, PR x/du-ui)
- vfs: `du::dvfs` — реестр анализов `DuRegistry` (один на процесс: листинг, handler, UI, ops), backend `DuVfs` схемы `du:/<id>/<rel>`: подкаталоги из снимка (`SIZE_KNOWN`, недосчитанные — `SIZE_PARTIAL`), файлы — живым листингом одного каталога; `stat`/`open_read`/`local_path` — к настоящему пути; Ext `DuState`, `localize` (du → путь на диске); флаг keymap `in_du` — в `FlagRegistry::with_builtin`.
- handler: `du.open` (кэш — в задаче Interactive, есть — сразу «посчитано N назад», нет — скан), `du.refresh`, `du.stop`; тики скана → `panel.refresh` вкладок; конец — снимок в реестр и кэш (Bulk); новая вкладка — по размеру ↓, файлы и папки вперемешку.
- core: `Attrs::SIZE_PARTIAL`; у корня `du:/<id>` нет `..`; `du:` не попадает в сессию.
- keymap: `panel && in_du` — Ctrl+R `du.refresh`, Ctrl+Shift+R `full=true`; Esc — `du.stop` (без подсчёта — ничего).
- ui: колонки Имя · Доля (полоса 120×6 `accent` на `current_line` + %) · Размер · Изменён, «≥ X» `secondary`; заголовок — чип «Анализ», путь от корня, «просмотрено N файлов · X» / «N файлов · X» / «посчитано N назад» + «Обновить Ctrl+R», неопределённый прогресс по кромке; чипы фильтров; таб «du: C:\Dev»; статус — «считается», «посчитано за 1 мин 08 с», свободно на томе; промпт — каталог на диске.
- F3/F4/Enter/F5 из `du:` — настоящие файлы (`localize` во вьювере, редакторе, ops); после операций ops перечитывает вкладку `du:` того же каталога.
- Тесты: `vfs/src/du/dvfs_tests.rs`, `vfs/tests/du_tab.rs` (открытие, Enter/Ctrl+PgUp, сессия, пересчёт, стоп); сцены `screen-duscan`, `dulist-plain`, `screen-dulist`, `screen-ducached` (`screens.du` — фикстура без скана ФС). Ручная проверка — `docs/manual-tests/F01-05.md`.

## Осталось
- Кадр ≤ 2 мс при 100k строк — не мерили (release-сборки на этом диске нельзя); в кадре добавлена сумма каталога для доли — O(n) только при перерисовке списка.
- Чипы «Крупные/Типы/Старые/Дубликаты/Временные» видны и шлют `du.filter`, сами фильтры — F01-08 (пока тост «Пока недоступно»).
- Строка подсказок «Esc Остановить подсчёт · Enter Внутрь · Ins Пометить» с макета: keybar у нас — F-клавиши.
- Свежесть (RDCW, USN, «●») — F01-10/11; Ctrl+R пока всегда полный пересчёт. Запись изменённого снимка — раз в 30 с, при выходе не дописывается.
- Терминал (`term::session_cwd`) во вкладке `du:` каталог не знает: `cmdline.exec` идёт в прежнем каталоге shell (промпт показывает верный).
- Контракт `Vfs::columns()`/`Entry.ext`/`Caps::VIRTUAL|READ_ONLY_DIR` в коде не реализован: доля и колонки `du:` — в UI (`columns::for_tab`).
