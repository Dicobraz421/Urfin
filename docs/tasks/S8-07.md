## Сделать
- Регистрация handler `search` в app — строка в `register_handlers`.
- Фича окна `Main::Replace`: форма 2 ряда (Имя, Текст, Aa, .*, В, Подкаталоги) на общем поле с автодополнением и историей (№70), `OverlayKind::Search`.
- Список на месте левой панели: «Файл | Совпадение», виртуальный, окно строк из `SearchStore`, подсветка `highlight`, курсор и прокрутка клавишами и мышью.
- Низ: полоса 2 `accent`, итог; статус-строка и keybar по макету.
- Enter в форме — `search.run`, Enter в списке — `search.goto`; Alt+F7 — к форме; Esc — отмена и закрытие.
- Сцена `screen-search` в модуле фичи. Правая половина пока пустая, её закроет S8-09.

## Приёмка
- Alt+F7 → запрос → Enter: строки появляются по мере поиска;
- снимок левой половины совпадает с макетом;
- 1M строк: кадр p50 ≤ 3 мс / p99 ≤ 6 мс;
- ручная проверка `docs/manual-tests/S8-07.md`.
