## Сделать
- Страницы 64 КиБ, LRU по бюджету, `want()` → коалесцированные запросы (последний выигрывает), прогрев ±1 экран, «прикосновение» к mmap-страницам, Msg `Pages`.

## Приёмка
- UI-поток не вызывает `read_at` (debug_assert по thread-id);
- 1000 прыжков подряд — не больше 2 запросов в полёте;
- бюджет памяти не превышается; criterion `get()` ≤ 50 нс.

## Сделано
- `cache.rs`: `Page` (Owned / Mapped без копии), `PageCache` (LRU по бюджету, `get` → 1–2 среза, `want` — последний запрос побеждает, `take_request` — видимые, экран ниже, экран выше; не больше 2 запросов в полёте), `Loader` (касание страниц mmap в воркере), `PageCache::pump` → `Lane::Interactive`, `Msg` `PagesMsg`; `ByteView` для раскладки и индекса (кэш и срез).
- `ViewerDoc`: `pages`, `index`, `cancel`.
- Тесты: 1000 прыжков — ≤ 2 в полёте и последний загружен; бюджет и LRU; рост Spool/follow перечитывает неполную страницу; mmap без копии. Bench `benches/cache.rs`.
- Замер (release): `get` строки экрана — 5–6 нс (≤ 50 нс).
