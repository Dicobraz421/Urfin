## Сделано (2026-10-31)
- Поток: `editor.save` / `save_as {path?}` / `save_close` / `save_all` → `UiEvent::Ext { id: "editor.snapshot", args: { doc, then, path? } }` (`After::to_args` / `from_args`) → фича UI шлёт `InboxMsg::Snapshot` → `on_pump` → запись вне UI-потока → `UiEvent::Ext { id: "editor.saved", args: { doc, readonly } }`. `save_as` без пути и не-локальный файл — черновик имени `ui.draft command=editor.save_as`.
- Диск (`edit/save.rs`): сверка `DiskStamp` → атрибут «только чтение» → кодирование (непредставимые — вопрос или `?`) → `.<имя>.urfin~` → `sync_all` → `ReplaceFileW` (ACL, время создания, потоки), при ошибке `MoveFileExW(REPLACE_EXISTING | WRITE_THROUGH)`; атрибуты (скрытый, системный, только чтение) возвращаются. `nlink > 1` и нет прав на каталог — на месте; symlink — в цель. `view::sys`: `file_info` (nlink, атрибуты), `replace_file`, `move_replace`, `attrs`, `set_attrs` — фичи `windows-sys` те же.
- Больше 8 МиБ — задача `editor.save` (Bulk, job-бар, прогресс, отмена); меньше — Interactive. До конца `EdState::Saving(Option<JobId>)`.
- Вопросы — состояние документа `EditorDoc.ask: Option<EdAsk>` (`Close`, `Changed`, `Unmappable{count}`, `ReadOnly`), текст `EdAsk::text`, кнопки `EdAsk::choices` (id, ключ i18n, клавиша); ответ — новая команда `editor.answer {choice, doc?}`, Esc — `cancel`. Ответы копятся (`Flags`) и перезапускают запись того же снимка.
- Внешнее изменение: перед записью и при возврате фокуса на экран редактора (фоновая сверка `DiskStamp`). `editor.close` с правками — вопрос `Close`; Esc при вопросе — убрать его. `on_quit` — вето «Не сохранено: N [Отмена] [Не сохранять]».
- i18n EN+RU: `ui-edit-keep-readonly`, `cmd-editor-answer`.
- Тесты (`edit/save_tests.rs`): ACL и «скрытый» после `ReplaceFileW`; сбой после temp (fault-injection) — исходный файл цел, следующий раз temp перезаписан; жёсткая ссылка; symlink (пропуск без права); сверка/только чтение/непредставимые; поток через core (F2, «изменён на диске» → «Сохранить поверх», Esc → «Сохранить» → закрыт, вето выхода); UTF-8 по ответу; задача 9 МиБ.
