## Сделать
- Таблица всех привязок и команд без клавиш, поиск, колонка «Где», виртуальная прокрутка.
- Захват сочетания, добавить/заменить/снять, сброс; запись в `keymaps/user.toml` с сохранением комментариев.
- Конфликт в пересекающихся контекстах — по макету, с подтверждением. Рискованные сочетания — пояснение, без запрета.
- Описание, «Открыть user.toml», файл и число конфликтов в статусе.
- Пока идёт захват, диспетчер клавиш нажатие не получает.

## Приёмка
- запись сохраняет комментарии и порядок; повторное чтение = записанное; сброс возвращает пресет;
- конфликт только в пересекающихся контекстах; `Ctrl+Alt+K` записывается, читается, срабатывает, баннера нет;
- захват на любой раскладке даёт ту же клавишу, что поиск keymap (матрица раскладок, AZERTY).

## Сделано (2026-11-05, x/ui-keys)
- `urfin-keymap`: `edit` (план и применение правок, `Target`), `catalog` (таблица, места, конфликты, `clashes`), команды `keymap.bind`, `keymap.unbind`, `keymap.reset`, `keymap.open`; запись по одной на `Lane::Bulk`, атомарно. `KeyInput::set_capture`: нажатие только запоминается той же логикой, что поиск (раскладка, записки), без сторон модификаторов; одиночный Alt, текст и автоповтор зажатой клавиши не срабатывают.
- `Keymap` хранит реестр и привязки до пользовательского файла (`preset_bindings`) — по ним сброс и признак «изменено». `When::overlaps`. Пресет `urfin`: `extends = "far"`, пока без отличий (сегмент макета).
- `urfin-ui`: `keys_settings` (состояние, `ui.keys`, статус, клавиши), `gpui_shell::settings_keys` (поиск, таблица, рисуются только видимые строки). Захват в мосте ввода: `key_down` и записки subclass идут в конвейер, команды — только `ui.keys chord=…`.
- Отличия от макета: добавлена строка описания со ссылками, кнопки действий в строке под курсором. «Где» — по настоящему контексту: `Ctrl+O`, `Alt+F7` — «Панели» (на макете «Окно»), потому что в пресетах они в контексте `panel`.

## Осталось
- Сочетание из нескольких нажатий (`Ctrl+K Ctrl+H`) захватом не задаётся — только в файле; показывается и снимается как обычное.
- Часть вариантов команд с аргументами показывает значение аргумента («Вставить имя (full)»): своих подписей `keys-*` пока мало.
- Подсказки при наведении на кнопки действий (в gpui-kit нет готовой): их значения — в строке клавиш.
- Ручная проверка владельцем (`docs/manual-tests/D-11.md`).
