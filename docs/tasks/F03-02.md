## Сделать
- `conn/` (пул, `direct-tcpip` для jump до 3, keep-alive, переподключение §2.3);
- `hostkey.rs` (§2.4);
- агент OpenSSH и Pageant, ключи, пароль, keyboard-interactive (§2.5, без менеджеров);
- `testsrv` (russh server + russh-sftp server, ключи и пароль, 2FA-заглушка).

## Приёмка
- подключение к `testsrv` по ключу, паролю и 2FA;
- jump через второй `testsrv`;
- неизвестный ключ → событие `HostKeyUnknown` с SHA256;
- изменившийся → `HostKeyChanged`, без автоподключения;
- «Доверять» дописывает одну строку, остальные строки файла байт-в-байт те же;
- хэшированные `|1|` находятся;
- обрыв (kill сервера) → 5 попыток с интервалом 3 с, затем «Отключено»;
- UI-поток не блокируется.

## Заметка
- Полосы `net` ещё нет в lanes.toml — добавить PR класса B.

## Сделано (2026-11-01, ветка x/net-12)
- Зависимости (№58): `russh` 0.65 (Apache-2.0; крипто `ring`, без `aws-lc`), `hmac` 0.13 + `sha1` 0.11 (MIT/Apache-2.0, `|1|`); dev — `russh-sftp` 3.0 (Apache-2.0, `testsrv`).
- `hostkey.rs`: `known_hosts` + `known_hosts2`, `|1|`, шаблоны `*`/`?`/`!`, `@revoked`, `@cert-authority` (сертификат хоста); `Verdict` Known/Unknown/Changed{file,line}/Revoked; `append` (одна строка в конец, прочие байты те же), `replace` (строка N, атомарно, `.urfin-bak`); `[host]:port` при порте ≠22; отпечаток `SHA256:`.
- `conn/`: `chain` (`via` — профиль или `user@host:port`, jump ≤3), `Pool` (соединение на профиль, jump переиспользуется), узел через TCP или `direct-tcpip`; таймауты TCP 10 с и рукопожатие+аутентификация 60 с без ожидания пользователя; keep-alive `keepalive@openssh.com` с RTT (`Conn::rtt`), 2 пропуска — обрыв; `session` — переподключения `tries × interval` с секретами из памяти сеанса, «Переподключить сейчас»/«Отключиться» (`Control`); «Только в этот раз» — `state/ssh/run/<nonce>/known_hosts`, удаляется при отключении.
- Вопросы UI — события `Event` с `oneshot`-ответом: `HostKeyUnknown`, `HostKeyChanged`, `Prompt` (пароль, фраза-пароль, keyboard-interactive), `Connected`, `Lost`, `Failed`, `Disconnected`.
- `auth/`: `none` → методы сервера; агент (OpenSSH pipe, затем Pageant; `[ssh].agent`), ключи OpenSSH (RSA — `rsa-sha2-*`, `.ppk` пропускается), пароль, keyboard-interactive, второй фактор по `partial_success`.
- `tests/testsrv`: russh-сервер + SFTP (russh-sftp, пока `realpath`), ключи, пароль, 2FA, `direct-tcpip`, `kill`. `tests/conn.rs` — приёмка карточки (ключ, пароль, 2FA, jump, Unknown/Changed/Trust/Once, 5 попыток → «Отключено», подъём сервера, UI-поток не ждёт).

## Осталось
- `#[ignore]`-тесты агента OpenSSH и Pageant стенда не написаны: проверить вручную в F03-05 (подключение с `auth = agent`).
- Pageant ≥0.75 по pipe: используется `connect_pageant` из `russh` (WM_COPYDATA); отдельный pipe Pageant — нет.
- Фразы-пароли ключей: путь есть, теста с зашифрованным ключом нет (в песочнице не сгенерировать фикстуру).
- `Auth::Command` пока спрашивает пароль строкой — менеджеры паролей в F03-03.
