## Приёмка
- подключение к `testsrv` по ключу, паролю и 2FA;
- jump через второй `testsrv`;
- неизвестный ключ → событие `HostKeyUnknown` с SHA256;
- изменившийся → `HostKeyChanged`, без автоподключения;
- «Доверять» дописывает одну строку, остальные строки файла байт-в-байт те же;
- хэшированные `|1|` находятся;
- обрыв (kill сервера) → 5 попыток с интервалом 3 с, затем «Отключено»;
- UI-поток не блокируется.
