- Строки — один `canvas`: `rows_down` по `TextView`, кэш `ShapedLine` `rows.rs` (правка перестраивает только свои строки), скелетоны на `Missing` + `want()`; перенос (`editor.wrap`), длинные строки — сегменты `max_line`; поверх — выделение, текущая строка, совпадения поиска (текущее — `accent.fill`/`accent.on`).
- Номера 40 — из `line_of` (неточный — пусто), полоса изменений 3 — `LineChanges` видимого диапазона (при переносе — на всех рядах строки), полоса прокрутки с метками поиска (`scrollbar.rs` вьювера).
- Мини-карта 88: окно строк вокруг видимой части из кэша страниц (2 px на строку, окно едет пропорционально на длинном документе), цвета подсветки при наличии, рамка видимой части, клик — `ScrollTo`.
- Статус: «Стр ≈N», «Кол ≈N» (строка длиннее 1 МиБ), задачи документа справа.
