## Сделать
- строка «нет доступа: N папок · размер неизвестен» (замок), баннер `warning_bg`, `du.elevate` → тот же `urfin.exe --du-elevated` через UAC (ADR-0021, [решение 2026-11-02](../decisions/2026-11-02-du-elevated-same-exe.md)), слияние итогов в снимок.

## Приёмка
- по ADR-0021 (только чтение метаданных; один файл ответа в `state\du\elevated\`; отказ UAC — тост, снимок не меняется; отмена — процесс выходит); итог после досчёта = скану от администратора.

## Сделано
- `urfin_vfs::du::elevated`: аргументы `--du-elevated --out <файл> <корень>…` и их проверка, файл ответа v1 (magic, версия, nonce, `xxh3`, корни — только запрошенные), повышенный режим (политика, укрепление, обход `scan`, файл), ожидание и отмена в обычном процессе; `sys::win_elev` — привилегии (Backup), запрет дочерних процессов, файл по итоговому пути.
- Реестр: пути недоступных, «нет доступа» под каталогом, слияние итогов (`ELEVATED`, `PARTIAL_DENIED`), баннер закрыт / задача досчёта.
- Handler: `du.elevate` (задача `du.elevate`, политика `DuElevatedHelper`, тосты), Esc — отмена досчёта или закрыть баннер; `du.refresh` ждёт конца досчёта.
- UI: строка с замком после последней строки, баннер «N папок без доступа» + «Досчитать с правами администратора» / «Закрыть Esc»; сцена `screen-dunoaccess`; `urfin_ui::sys::runas` (`ShellExecuteExW runas`).
- App: ранний выход `boot::du_elevated`, флаг в `flags.rs`, `register_full` с досчётом.
- Тесты: unit (аргументы, файл, слияние, кавычки командной строки), повышенный код на временном каталоге без `runas` (vfs `serve`, бинарь `urfin.exe --du-elevated`), handler — подставки «в потоке» и «отказ UAC».

## Осталось
- Ручная проверка с настоящим UAC — `docs/manual-tests/F01-12.md`.
- `CONTRACTS.md` (класс B): флаг `--du-elevated` в списке ранних выходов app и снять «`du.elevate` выключен до ADR-0021» — вопрос владельцу.
- F8/отметка у досчитанных с правами не запрещены (ADR-0021 исходный): удаление и так упрётся в «нет доступа» ops.
