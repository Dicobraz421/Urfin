## Сделано
- `detect.rs`: `Probe`/`SystemProbe`, `detect(mgr, probe)`, `detect_all()`, `detect_all_in(probe)` — без процессов и логов: winget — PATH, иначе `%LOCALAPPDATA%\Microsoft\WindowsApps` (алиас `APPEXECLINK` — по метаданным точки повторной обработки); scoop — `%SCOOP%\shims\scoop.ps1`, иначе `%USERPROFILE%\scoop\shims`; choco — `%ChocolateyInstall%\bin\choco.exe`, иначе `%ProgramData%\chocolatey\bin`.
- Версия лениво: `version_argv` (`--version` у winget и choco), `parse_version`, `caps_for` (choco < 2 → `CHOCO_V1`), `query_version` (Windows, через `proc::run_query`, пишет версию и возможности в `Detected`).
- Кэш `managers.toml` — `Managers::{load, save (атомарно), refresh (версия остаётся при том же exe), get}`; insta-снапшот формата.
- `arp.rs`: `ArpEntry { scope, key, name, publisher, version }`, `ArpEntry::from_values` (без имени, `SystemComponent=1`, `ParentKeyName` — скрыты), `Arp::load()` — HKLM, HKLM `WOW6432Node`, HKCU через `windows-registry`.
- Тесты: подставные PATH/env, кэш, разбор версий, фильтр ARP; стенд — `#[ignore]` `stand_detect_all` (≤5 мс), `stand_load_cold` (≤30 мс).
