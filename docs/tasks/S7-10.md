## Сделать
- `OverlayKind::Find`: строка «Найти» внизу (Регистр/Слово/Регулярное/Hex, Alt+C/W/R/H, «N из M»), Enter / Shift+Enter, Shift+F7 / Alt+F7, подсветка видимых совпадений, метки на скроллбаре, итог в статусе.
- Строка перехода (§3.5, вид `screen-editgoto`), парсер goto, `viewer.back`, закладки 0–9. Строки общие с редактором (S7-18).

## Приёмка
- unit парсера goto: `50%`, `0x…`, `1F00h`, `$1F00`, `+N`/`-N`;
- переход на строку до готовности индекса — ожидание с прогрессом, Esc отменяет;
- `back` возвращает к прошлой позиции.
