## Сделать
- `OverlayKind::Find`: строка «Найти» внизу (Регистр/Слово/Регулярное/Hex, Alt+C/W/R/H, «N из M»), Enter / Shift+Enter, Shift+F7 / Alt+F7, подсветка видимых совпадений, метки на скроллбаре, итог в статусе.
- Строка перехода (§3.5, вид `screen-editgoto`), парсер goto, `viewer.back`, закладки 0–9. Строки общие с редактором (S7-18).

## Приёмка
- unit парсера goto: `50%`, `0x…`, `1F00h`, `$1F00`, `+N`/`-N`;
- переход на строку до готовности индекса — ожидание с прогрессом, Esc отменяет;
- `back` возвращает к прошлой позиции.

## Сделано
- view: `goto::parse` — разбор строки перехода, общий с редактором (S7-18): `123`, `строка:колонка`, `0x1F00` / `1F00h` / `$1F00`, `50%` / `12,5%`, `+N` / `-N`, разделители разрядов (`1 000`). Модуль `viewer/jump.rs`: `viewer.goto to=` (Hex — число и сдвиг в байтах, курсор на смещении), строка — от метки индекса счётом по кэшу страниц, дальше индекса — ожидание (`goto_wait`, повтор на `IndexMsg`/`PagesMsg`, Esc — `viewer.search_cancel`), за концом — последняя строка; `viewer.back` (стек 16 позиций, кладут переход и закладка), `viewer.bookmark.set/go n=0..9` (тосты). Тост «Продолжено с начала» при переносе поиска.
- view: фокус строк — `Focus::Overlay(Find)`: `viewer.search` без текста, `viewer.goto` без цели и ожидание индекса открывают строку (`UiEvent::Ext`), `viewer.search_cancel` и состоявшийся переход закрывают.
- ui: `view/find.rs` — переиспользуемая строка `FindBar` (поле `InputState`: IME, буфер обмена; флажки, разбор клавиш в действия, ряды «Найти» и «Перейти» по `screen-editreplace` / `screen-editgoto`). Хост: `ShellFeature::input` (поле фичи в кадре) и `editing` (клавиши — полю, не keymap). Alt+C/W/R/H — по месту клавиши (`input::stroke_key`), на любой раскладке.
- ui: вьювер — строка над статусом (окно текста меньше на 52), Enter / Shift+Enter (тот же образец — `search_next/prev`, иначе новый `viewer.search`), F7 / Shift+F7 / Alt+F7 / Alt+F8 в строке, «N из M», ошибки regex/hex и «Не найдено» — `critical`; подсветка всех совпадений на экране (matcher по видимым байтам ≤ 64 КБ, фон `highlight`; Hex — в обеих колонках); полоса прогресса 2 px под шапкой и перерисовка 33 мс, пока идёт поиск; «Ждём индекс… N %» в статусе и строке.
- Сцены `viewer-find`, `viewer-goto` (после `screen-viewer`). Ручная проверка — `docs/manual-tests/S7-10.md`.
