## Сделать
- §5.6: резолв (`external` → `$VISUAL` → `$EDITOR` → `file.open`), консольный → сеанс `SessionKind::External`, GUI → `term.open`; `editor.default`; `editor.new` (Shift+F4, имя черновиком); `viewer.to_editor` / `editor.to_viewer` с позицией; `editor.autosave`.

## Приёмка
- `$EDITOR=vim` открывается в терминале S6, `code -w` — отсоединённо (фейковые редакторы-скрипты);
- F6 туда-обратно сохраняет строку;
- автосохранение `delay` пишет через 1 с, при конфликте `DiskStamp` — нет.

## Сделано (2026-10-31)
- Резолв (`edit/external.rs`): `[editor] external` (`{path}` — в кавычках, `{line}` — строка; без `{path}` путь дописывается) → `$VISUAL` → `$EDITOR` → программа Windows (`file.open` под курсором / `term.open path=`). Консольный (`external_console = "auto"`: vim, nvim, vi, nano, micro, hx, kak, ne, `emacs -nw`, `emacsclient -t`; `true`/`false` — явно) → `term.exec cmd= cwd=` (как Alt+F3 в S7-14); GUI → отсоединённый процесс (`DETACHED_PROCESS`, у `.cmd`/`.bat` — `CREATE_NO_WINDOW`; программа по `PATH`+`PATHEXT`) на Interactive, ошибка — тост `ui-edit-external-failed`. `term.open` не принимает параметров шаблона, поэтому не он.
- `editor.default = "external"` меняет F4 и Alt+Shift+F4 местами (`alt` XOR `default`, `internal` — всегда встроенный).
- `editor.new` (Shift+F4): без пути — `ui.draft command=editor.new arg=path`; с путём — пустой документ (`new_codepage`, `new_bom`, EOL по `editor.eol`), `is_new`, файл создаётся первым сохранением; уже есть — открывается.
- `viewer.to_editor` (F6): редактор на строке верха экрана, вьювер закрыт; `editor.to_viewer`: вьювер на строке курсора (`viewer.open line=` — новый аргумент), с правками — сначала вопрос «Сохранить?».
- Автосохранение: `delay` — снимок `then=autosave` через 1 с после последнего `Edited{dirty}`; `focus` — при уходе редактора с фокуса/экрана и по `InboxMsg::Blur` (новое событие: окно потеряло фокус). Только локальные; конфликт `DiskStamp` — не пишет, строка «изменён на диске»; без вопросов про кодировку и атрибут.
- Тесты: резолв и порядок, разбор командной строки, `which`; через core — `vim` → `term.exec`, фейковый GUI-редактор `.cmd` запускается отсоединённо с `-w "путь"`, `default = external`; новый файл; F6 туда-обратно на строке 120; автосохранение через ≥ 0,9 с и отказ при конфликте.

## Осталось
- ~~`term.exec` не выполняется~~ — сделано 2026-10-31 (x/term-exec-quit): строка в сеансе у промпта (занят — новый сеанс shell по умолчанию), `cwd` через ленивую синхронизацию, фокус в терминал, по концу команды (`D` после промптов cd или выход процесса) — обратно в редактор/вьювер. Отдельного `SessionKind::External` нет — обычный сеанс shell.
- UI: `InboxMsg::Blur` при потере фокуса окном; черновик `editor.new` / `editor.save_as` уже работает через `ui.draft`.
- Ручная проверка — `docs/manual-tests/S7-19.md`.
