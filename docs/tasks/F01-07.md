## Сделать
- squarified 2 уровня, «прочее», кэш раскладок, отрисовка во второй панели, курсор/отметка/hover, клик, Ctrl+Tab, легенда (§3.4).

## Приёмка
- proptest: плитки не пересекаются, покрывают rect, площадь ∝ размеру (±1 px²);
- средний aspect ≤ 2 на случайных данных;
- раскладка 5000 ≤ 1 мс; кадр ≤ 2 мс; простой — без перерисовок.

## Сделано (2026-11-02, PR x/du-2)
- ui `treemap`: `squarify(sizes, rect, out)` (Bruls–Huizing–van Wijk, O(n) на отсортированном), два уровня с полосой подписи каталога, мельче 16 px² — в «ещё N», мелкие файлы каталога — серым блоком; кэш раскладок LRU на 8 (ключ: каталог, номер изменения снимка, размер, масштаб).
- vfs: `DuRegistry::map` — дети каталога и их дети из снимка (без I/O), совпадения «Временных» помечены (считаются один раз до изменения снимка).
- ui `du_map`: карта во второй панели вместо списка (таб «Карта», шапка «Карта · путь»): цвета по типу из ролей подсветки (папки — `accent`), границы 1 px `panel`, подписи — где помещаются; курсор — рамка 2 px `text`, отмеченные — штриховка, наведение; в «Типах»/«Временных» вне фильтра — бледнее; легенда. Клик — курсор на строку, двойной — внутрь, Shift+клик — отметка.
- `du.map` (Ctrl+Tab в `in_du`) — показать/убрать карту.
- Тесты: proptest (не пересекаются, покрывают, площадь ∝ размеру ±1 px²), средний aspect ≤ 2, раскладка 5000 (≤ 1 мс — проверка в release), кэш, данные карты (`views_tests.rs`); сцены `dumap-plain`, `screen-dumap`. Ручная проверка — `docs/manual-tests/F01-07.md`.

## Осталось
- Замеры release (раскладка 5000 ≤ 1 мс, кадр ≤ 2 мс) не делали; criterion-бенч `treemap` не добавлен — нужен `[[bench]]` в `crates/ui/Cargo.toml` (полоса deps).
- > 5000 плиток — раскладка на cpu-pool: нет, раскладка в кадре (O(n), из кэша).
- Ctrl+Tab показывает/убирает карту; клавиатурного фокуса на карте (стрелки по плиткам, Enter) нет — карта идёт за курсором списка.
- Во время подсчёта карты нет (подсказка); строка подсказок keybar с макета («Ctrl+Tab К карте») — keybar у нас F-клавиши.

## Сделано (2026-11-02, PR x/du-5)
- Каталоги «Временных» для карты — задачей Runtime (`DuRegistry::take_temp_wanted` / `compute_temp`, снимок — `Arc`, правка при чужой ссылке — копия), не в UI-потоке; до результата карта без пометок.
- Больше 5000 элементов — раскладка в фоновом пуле gpui, кадр рисует прежнюю раскладку каталога (`Cache::last_of`); тест `layout_cache_last_of_dir`.

## Осталось
- Замеры release и criterion-бенч `treemap` (нужен `[[bench]]`, полоса deps); клавиатурный фокус на карте.
