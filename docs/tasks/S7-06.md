## Сделано
- `layout.rs`: `rows_down`, `row_up`, `line_start_before`, `render_row` (Text, перенос Chars/Words по UAX#29, Hex), сегменты `max_line` по абсолютным кратным (подвинуты к границе символа; поиск назад ≤ `max_line`), табы, `·` управляющих, `␍` в `Mixed`, U+FFFD (`RowText.bad`), UTF-16 и BOM, окно `hscroll`, `RowText.map` (опорные точки, `byte_at`), `hex_geom` (смещение 12 цифр при > 4 ГиБ), `hex_cols_auto`.
- `render_row` возвращает `Result<(), Missing>` (строки может не оказаться в кэше).
- Тесты: proptest — обратимость вверх/вниз, смежность строк, `line_start_before` = прямой проход, начала строк = начала сегментов (UTF-8 с порчей, UTF-16, все EOL, перенос); hex на 5 ГиБ; insta-таблица строк. Bench `benches/layout.rs`.
- Замер (release, V2 — строка 50 МБ, 160 колонок, 60 строк): без переноса 3,1 мкс, перенос по символам 19,9 мкс, по словам 29,4 мкс на строку экрана (≤ 50 мкс).
