## Приёмка
- копия 1251/866/UTF-16 даёт верный Unicode (unit на границах страниц);
- 64 МиБ копируются ≤ 300 мс без фриза UI;
- hex-копия — `DE AD BE EF`.

## Заметка
- Межполосная (ui, view — декодирование диапазона): в той же волне.

## Сделано (2026-10-31)
- view: `InboxMsg::Select { doc, sel }` (выделение мышью, байты источника) и `InboxMsg::ScrollTo { doc, off }` (бегунок; в Тексте — к началу строки), `ViewerDoc::select / select_all / scroll_to` (`viewer/select.rs`). `viewer.select_all` — весь файл (в Тексте — без BOM), `viewer.copy` — `decode_range` на Interactive lane кусками по 1 МБ потоковым декодером `encoding_rs` (символ на границе куска и страницы 64 КБ не рвётся; UTF-16 — по единицам, BOM не копируется), Hex — `DE AD BE EF`; сверх `viewer.copy_limit_mb` — тост «Выделено больше N МБ — не скопировано». Текст — фиче окна `UiEvent::Ext` `viewer.copy`, она пишет буфер обмена; у документа Markdown — `Ext` без текста, копирует проекцию UI.
- ui: `rows.rs` — `HitMap` прошлого кадра (строки, `ShapedLine::closest_index_for_x` + опоры `RowText`), `TextView` (кэш строк, мышь, бегунок) на экран в окне и на каждую область панели. Drag — выделение от якоря, Shift+клик — от начала выделения, двойной клик — слово (буквы, цифры, `_`); Hex — байт под мышью в колонке байтов или текста, клик — байт-курсор; пустые строки внутри выделения — клетка. Перетаскивание бегунка полосы прокрутки (S7-07). Кнопка мыши «Назад» — `viewer.back`. Выделение, пока handler не подтвердил, — своё (без мигания).
- Совпадение поиска = выделение (S7-09/S7-10) — копируется так же. Подсветка совпадений на экране заходит за его края на длину образца (до 4 КБ): совпадение, начатое выше первой строки или кончающееся ниже последней, подсвечено (S7-10).
- Сцены `viewer-select-hex`, `viewer-select` (после `screen-viewerhex`). Ручная проверка — `docs/manual-tests/S7-11.md`.
