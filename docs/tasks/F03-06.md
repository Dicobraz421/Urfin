## Сделать
- заголовок (чип «SSH», путь №87, «N объектов · ping»), статус одной группой (№92), «не подключено — Enter» для таба из сессии, обрыв (`screen-sftplost`): приглушение, строка с отсчётом, «Переподключить сейчас»/«Отключиться».

## Приёмка
- путь в заголовке стоит на одной линии с текстом справа (подчёркивание без сдвига);
- обрыв не стирает листинг;
- после переподключения курсор и отметка сохранены;
- кадр ≤2 мс при 10k строк.

## Заметка
- Межполосная (ui, net): при планировании волны разбить или вынести контракт в PR класса B.

## Сделано (2026-11-03, ветка x/net-sftppanel)
- core (`net.rs`, продолжение решения «net-model-core»): `Live.algo` (ключ сервера), `Live.login: Vec<Login>` (агент/Pageant, ключ, пароль, команда, код, без входа — `Login::text`), `LiveState::Lost.retry_at` (отсчёт), `NetModel::is_connected`.
- net: алгоритм принятого ключа сервера (`Client`) и чем вошли (`auth::authenticate`) — на `Conn`; после подключения и переподключения табы профиля перечитываются на месте (`panel.refresh` — курсор и отметка сохраняются), переход — только если панель не на профиле; `ssh.reconnect` без живого сеанса (отключились сами, не подключились) — новое подключение в папку таба; `sftp::demo::DemoFs` — папка сцен из памяти (только `--screens`).
- ui: заголовок — «N объектов · X мс», без связи — «N объектов · из кэша», чип «SSH» `secondary`; статус справа одной группой (№92) «admin@srv1.corp.local · ssh-ed25519 · ключ из агента (Pageant)»; без связи список и строка колонок приглушены (0.5), листинг не стирается; строка обрыва `warning_bg` (фича окна `gpui_shell::sftp`): «Связь с srv1 потеряна · переподключение через N с (попытка k из M)», «Переподключить сейчас Enter» / «Отключиться», Tab — между кнопками (keybar «Tab Следующая кнопка»); после исчерпания попыток — «Отключено от srv1», «Переподключить Enter»; таб из сессии без связи — «Не подключено к srv1», «Подключить Enter». Строки EN+RU.
- Сцены `screen-sftppanel`, `screen-sftplost`, `sftp-off` (фикстура `screens.ssh kind=sftp|lost|off`).
- Тесты: `net/tests/panel.rs` — core + `testsrv`: подключение, обрыв (сервер упал) — листинг и отметка на месте, подъём на том же порту — переподключение, курсор и отметка те же, новые файлы видны; unit — модель строки обрыва, статус, «Не подключено», `Login::text`, `DemoFs`.
- Кадр ≤2 мс при 10k строк: отдельного `--bench` для `sftp://` нет (`--bench` — локальный датасет 100k). Отрисовка панели та же, что у локальной (только видимые строки); добавки на кадр — ячейки «Права»/«Владелец» из памяти (`Details`, ≤16 каталогов, поиск по хэшу — на видимых строках) и прозрачность слоя.
