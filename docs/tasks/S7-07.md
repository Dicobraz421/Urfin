- Шапка 36 (значок, путь, «только чтение», чип кодировки, сегменты Текст/Разметка/Hex), поле номеров 52, строки 22 одним `canvas`, кэш `ShapedLine`, скелетоны, скроллбар 14 с метками, статус; колесо и клавиши → `viewer.scroll`, Ctrl+колесо — размер шрифта.

## Приёмка
- снимки совпадают с макетами (Разметка — после S7-21);
- кадр p50 ≤ 3 мс, p99 ≤ 6 мс на полном экране (release, стенд), в простое кадров нет.

## Сделано
- view: `InboxMsg::Viewport { doc, cols, rows }` (решение 2026-10-30 «viewer-viewport», строка в CONTRACTS); `ViewerDoc::view_cols/view_rows`, `viewport()`, `view_layout()`. Модуль `viewer/viewport.rs`: `viewer.scroll dir=up|down|page_up|page_down|home|end|left|right n=` (через непрочитанные страницы — `pending`, повтор после `PagesMsg`; вниз — не дальше «последняя строка внизу»; Hex — по `hex_cols`, точный конец), `reveal` — найденное на трети экрана, `settle` — видимые страницы `want` + `pump` в handler и `Msg` (ошибка чтения — без повторного запроса). `hex_cols = auto` — по колонкам из Viewport.
- view: `viewer.open path=` относительный — от каталога активного таба; поиск, заданный до открытия, идёт после детекта (под его кодировку).
- app: `urfin_view::register_from` с `ViewEnv` (общий реестр VFS, `<cache_dir>` — Spool); демо-дерево `--screens` — `Projects\urfin\CHANGELOG.md` и `urfin.exe`.
- ui: фича `Viewer` (`gpui_shell/view`): `Main::Replace`, хук вкладок заголовка (`ShellFeature::tabs`: «две панели» → `panel.focus`, вкладки экранов, × у активной), cmdline скрыт, статус и keybar окна — внутри экрана (клавиши по макетам текста, Hex, «мешочка»). Шапка 36 (значок, папка, «только чтение», чип «UTF-8 авто ▾», сегменты Текст/Разметка/Hex), поле номеров 52 (номер — только точный по индексу), строки `row_h` (22 при 13 px) одним `canvas`, кэш `ShapedLine` на два экрана (ключ: байты строки, `hscroll`, раскладка, стиль, выделение), скелетоны на `Missing`, Hex — смещения в поле, линейка `00…1F` с колонкой курсора, нули и непечатаемые `text.secondary`, курсор `fill.cursor` + рамка `accent`. Полоса прокрутки 14: бегунок `top/len`, метки поиска, клик выше/ниже — страница. Статус: «Стр a–b из N · k %» (оценка «стр ≈N · индексация k %»), Hex — диапазон смещений; середина — итог поиска / «Смещение 0x… · XXh = D · «c»» / подсказка «мешочка»; справа размер · EOL.
- ui: колесо → `viewer.scroll` (3 строки, Shift — горизонталь), Ctrl+колесо — размер моно-шрифта вьювера; Viewport — `ShellFeature::inbox` в проходе Core и в кадре.
- ui: «мешочек» кодировок по `UiEvent::Ext` `viewer.codepage_menu` (группы, ✓ и «авто», ↑↓ Enter F8 Esc, колесо, клик мимо закрывает) → `viewer.codepage cp=`; меню режимов по `viewer.mode` → `viewer.mode mode=`.
- Сцены `screen-viewer`, `screen-viewerenc`, `screen-viewerhex` (+ `viewer-closed`); готовность сцены ждёт документ, страницы, индекс и поиск.
