## Сделать
- шаг сборки дистрибутива скачивает `Microsoft.Windows.Console.ConPTY` из NuGet (свежая сборка, №76), кладёт `conpty.dll` и `OpenConsole.exe` рядом с `urfin.exe`; в git их нет; офлайн-правило — только для рантайма
- term: свой ConPTY с откатом на системный (№28), выбор `[term] conpty = auto|bundled|system`

## Приёмка
- дистрибутив содержит DLL нужной версии, `urfin.exe` грузит их и откатывается на системный ConPTY без них
- DLL не входят в бюджет бинаря (№54)
