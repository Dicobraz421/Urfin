## Сделать
- строка «Найти пакет [..] в [Все ▾]» внизу, мешочек менеджеров от поля (`pkg.search_in`), параллельные запросы, группы с вариантами (менеджер, версия, источник), новейшая `accent`, «рекомендуется», выбор варианта `pkg.pick`; поле — общий компонент с историей (№70).

## Приёмка
- первые результаты появляются, как только ответил самый быстрый менеджер;
- новый запрос отменяет процессы прежнего;
- Esc возвращает к прежнему фильтру;
- пустой результат и «менеджер не ответил» различимы.

## Заметка
- Межполосная (pkg, ui): при планировании волны разбить или вынести контракт в PR класса B. Полосы `pkg` ещё нет в lanes.toml — добавить PR класса B.

## Сделано
- `urfin-pkg`: `search.rs` — запрос, область («Все» или менеджер), ответы по мере готовности (`SearchMerge`, `keep` = группа под курсором + 1), ответ менеджера `Busy / Found(n) / Failed` — пустой результат и «не ответил» различимы; строки — группа (треугольник, число вариантов, издатель) и варианты (менеджер, версия, источник; новейшая `accent`, «рекомендуется» по порядку); свёрнутые группы. Модель — в `PkgBook` (`View::search`), backend `pkg:/search` с колонками Версия · Источник · Менеджер · Издатель.
- handler: `pkg.search q? in?` — новый запрос отменяет процессы прежнего (`CancelToken`), поток на менеджер с таймаутом `search_s`; без найденных менеджеров — сначала обнаружение; `pkg.filter name=search` / Ctrl+3 / чип «Найти» — вкладка на поиск и строка «Найти пакет» с прежним запросом; `pkg.search_in` — мешочек менеджеров; `pkg.pick` (Пробел) — свернуть/раскрыть группу, на строке — отметка.
- UI: строка «Найти пакет [..] в [Все ▾] [Найти Enter]» у панели (черновик `ui.draft command=pkg.search`, поле с историей `FieldKind::Package`, №70), строка ответов «winget · 4 · scoop ищет… · choco не ответил», мешочек менеджеров вверх от «Все ▾» (ненайденный — «не найден на компьютере», порядок внизу), Alt+↓ / ↑↓ / Enter / Esc; ↓ — к результатам, Esc — к прежнему фильтру; Enter строку не закрывает. Строки поиска: группа полужирно с треугольником и плашкой числа, варианты с отступом, «рекомендуется» — метка `accent` в колонке издателя; заголовок «4 программы · 8 вариантов», чип «Найти «7zip»», клавиши внизу как на макетах.
- Тесты: `search.rs` (ответы, устаревший ответ, свёрнутая группа, уникальные имена), Core с подставными менеджерами 50/300/1000 мс (первые строки — после самого быстрого, отмена прежнего запроса, Пробел на группе, область `in=winget`, фильтр возврата).
- Снимки `--screens` (dev, фикстура `screens.pkg step=search`): `screen-pkgsearch`, `screen-pkgmgrpick` сверены с макетами.
