## Сделать
- Разбор S7-21 (tree-sitter по `ByteView`) в редакторе: правка → `Tree::edit` (точки — из сумм строк дерева кусков) → разбор в фоне по снимку со старым деревом, прежний отменяется; запрос подсветки — видимый диапазон (`QueryCursor::set_byte_range`); стили — `TextRun` в `rows.rs`, цвета мини-карты. Только документы ≤ 16 МиБ (`MARKUP_MAX`), `editor.highlight`.
- UTF-16 — `InputEncoding::UTF16`; однобайтовые — ASCII-заглушка на месте не-ASCII байта (смещения 1:1).
- Свёртка: диапазоны из узлов дерева на видимой части (столбец 14), свёрнутое — слой отображения (`fold.rs`: набор скрытых диапазонов, раскладка их пропускает), правка внутри — разворачивает.

## Приёмка
- правка в файле 16 МиБ — кадр p99 ≤ 6 мс, новые цвета ≤ 50 мс; память дерева — строкой в `docs/perf/s7.md`;
- 1251-файл с кириллицей в строках и комментариях подсвечен как UTF-8-копия;
- снимок `screen-editor` с подсветкой и свёрткой совпадает с макетом.

## Сделано (2026-11-02, x/editor-hl)
- Разбор (`view/src/syntax/edit.rs`): текст снимка документа ≤ 16 МиБ (`MARKUP_MAX`) → прежнее дерево правится одной правкой (`Tree::edit`: общее начало и конец прежнего и нового текста по границам символов, точки — счётом переводов строк по тексту, а не по суммам дерева кусков: суммы на UI-потоке требуют страниц у шва, текст в задаче уже есть) → `parse_with_options` с прежним деревом и отменой. UTF-16 — `parse_utf16_le/be` (смещения узлов — байты документа), прочие кодировки — заглушка `a` на месте байта ≥ 0x80 (1:1). Запрос — `QueryCursor::set_byte_range` по видимой части ± 64 КиБ; Markdown — строчная грамматика по узлам `inline` в ней.
- Задача и состояние (`view/src/edit/hl.rs`): одна задача `edit.syntax` на `Lane::Interactive`; правки за время разбора его не отменяют, а сливаются в следующую задачу по свежему снимку (отмена на каждое нажатие на большом файле не давала цветов вовсе — `docs/perf/s7.md`). До ответа отрезки и места свёртки сдвигаются правками (`TextDoc::take_log`: набранное внутри отрезка — его цвета, задетое удалением — обрезается); прокрутка за посчитанное — запрос без разбора. `editor.highlight` — переключатель `[editor] highlight` (команда, конфиг).
- Свёртка (`view/src/edit/fold.rs`): `Folds` в `TextDoc` — скрытые строки (слой отображения), `fold::rows_down`/`row_up` пропускают их; ими ходят движения, вывод курсора, прокрутка, видимые байты и кадр. Правка внутри скрытого (или шва с заголовком) и курсор в нём — разворачивают, правка выше — сдвигает; новое дерево кусков — всё разворачивает. Места свёртки — внешний именованный узел, начинающийся на строке и занимающий больше строки (кроме абзацев Markdown), закрывающая скобка в начале последней строки и пустые строки в конце остаются видны. `editor.fold at=` (поле свёртки) / без `at` — строка курсора или объемлющее место.
- UI: роли `[syntax]` в `TextRun` строк (ключ кэша — роли по символам строки, правка выше не перестраивает), поле свёртки 14 — ▾/▸ (клик — `editor.fold at=`), за свёрнутым — плашка `⋯`, номера и полоса изменений после разрыва — по `line_of`; мини-карта — штрих цветом роли первого символа слова. Сцены: `screen-editor` (▾ у таблиц, цвета, как макет), `editor-fold` (свёрнута `[workspace.dependencies]`). `--bench-editor`: `hl_first_ms`, `mem_hl_mb`, `hl_p50/p99/max`.
- Тесты: инкрементальный разбор = разбор с нуля = подсветка вьювера; 1251 и UTF-16 LE/BE с кириллицей = UTF-8-копия; места свёртки TOML/JSON; сдвиг отрезков и свёрнутого правками; через core — цвета после правки, `editor.highlight`, `editor.fold`, движения мимо свёрнутого, курсор в нём разворачивает. Ручные — `docs/manual-tests/S7-35.md`.

## Осталось
- **Бюджет «новые цвета ≤ 50 мс» на 16 МиБ не выполнен** (`docs/perf/s7.md`, «Подсветка в редакторе»): разбор tree-sitter с прежним деревом на плоском документе — JSON 0,16–0,23 с, TOML 1,3–2,9 с; дерево — 0,5–0,7 ГБ памяти. Порог подсветки редактора — решение владельца (вопрос в отчёте S7-35).
- Кадр нажатия p99 на 16 МиБ JSON — 7,6–13 мс (бюджет 6; `.txt` той же JSON — 9,9 мс, т. е. в основном не подсветка) и прокрутка p99 14–24 мс — к S7-36.
- Ручная проверка владельцем (`docs/manual-tests/S7-35.md`).
