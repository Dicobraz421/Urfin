## Сделать
- `secrets.rs` (zeroize, TTL), `pwcmd.rs` (шаблоны §2.5, без shell), `vault.rs` (keyring, политика `password_cache`);
- `--askpass` и агент Урфина на pipe (§2.7), поиск и версия `ssh.exe`.

## Приёмка
- подстановки не дают инъекций (имя с `;`, `&`, кавычками — одно значение argv);
- таймаут 30 с;
- stderr ≤200 символов в строке ошибки, stdout не логируется;
- PEM-ключ из команды принимается агентом Урфина, `ssh-add -L` с `SSH_AUTH_SOCK=<pipe>` видит один ключ;
- `--askpass` без окна и без GPUI, время старта GUI не изменилось (замер в PR);
- `password_cache=false` (политика) — Credential Manager не вызывается ни разу (мок `keyring`), «Запомнить» с замком;
- синтаксис CLI BearPass и Пассворка сверен на стенде и записан в шаблоны.

## Заметка
- Межполосная (net, ui, term): при планировании волны разбить или вынести контракт в PR класса B. Полосы `net` ещё нет в lanes.toml — добавить PR класса B.

## Сделано (2026-11-01, ветка x/net-12)
- Зависимости (№58): `zeroize` 1.8, `shell-words` 1.1, `keyring` 3.6 (только `windows-native`) — все MIT/Apache-2.0; ребро net → term (`proc::spawn_piped`).
- `term::proc::spawn_piped(argv, cwd, env, flags) -> PipedChild` (контракт v6 №15): пайпы, job object на Windows (`sys::conpty::job_for`/`terminate_job`), `wait_timeout`, `kill_tree`, `CREATE_NO_WINDOW`.
- `secrets.rs`: `Secret`/`SecretBytes` на `Zeroizing`, `Debug` без значений; `Secrets` сеанса с TTL `[ssh].secret_ttl_min` — заменили временную память из F03-02 (пароли, фразы-пароли).
- `pwcmd.rs`: шаблоны §2.5, `argv` — слова `shell-words`, затем подстановки внутри слов (proptest: любое значение — один элемент argv), запуск без shell с таймаутом 30 с (`spawn_blocking`, вне UI), пароль — первая строка, PEM — ключ, ошибка — хвост stderr ≤200 символов без stdout, «команда не найдена». `auth = "command"` в `auth/` (ответ живёт в памяти сеанса).
- `vault.rs`: `Vault` с политикой `password_cache` (сильнее `[ssh]`) и флажком профиля, `locked()` для замка «Запомнить», `purge_if_forbidden` по префиксу `Urfin/ssh/`; `WinCredStore` (`keyring` + `CredEnumerateW` в `sys.rs`); мок в тестах — при выключенной политике хранилище не вызывается.
- `bridge/`: `askpass` (кадры, помощник, pipe-сервер с DACL «только владелец» — `sys::pipe_server`, ответы из памяти сеанса или `Event::Prompt`), `agent` (агент Урфина: только переданные ключи, только список и подпись), `ssh_exe` (поиск System32 → PATH, `ssh -V` с кэшем `state/ssh/ssh_exe.toml`, мост с 8.9), `ssh_options`/`askpass_env`.
- app: `boot::askpass()` в начале `main` — до каталогов, логов и GPUI; `--askpass <запрос>` или `SSH_ASKPASS` с `URFIN_ASKPASS` + `SSH_ASKPASS_REQUIRE`.
- Тесты: unit (подстановки, хвост, TTL, мок `keyring`, askpass-протокол и ответ из памяти, агент), `tests/pwcmd.rs` (фейковые команды: пароль, ошибка, таймаут, не найдена, PEM → агент видит один ключ), `tests/conn.rs` — подключение `auth = "command"`.

## Осталось
- Сверка CLI BearPass и Пассворка на стенде, `ssh-add -L` по pipe, Диспетчер учётных данных, замер старта GUI — `docs/manual-tests/F03-03.md`.
- Подключение моста к терминалу (`ssh.exe` с `ssh_options`/`askpass_env`, жизнь pipe с сеансом) и строка «Запомнить» — карточки терминала SSH и F03-05; там же вызов `Vault::purge_if_forbidden` при старте и `Vault::get/remember` в строке пароля.
- Вызов `purge_if_forbidden` обращается к хранилищу (перечисление) при политике `false` — это по решению №2; остальные операции при такой политике хранилище не трогают.
- Тесты `term::proc` и Windows-ветки фейковых команд (`cmd /C …`, `ping`) в песочнице не запускались — проверит CI Windows.
