- `secrets.rs` (zeroize, TTL), `pwcmd.rs` (шаблоны §2.5, без shell), `vault.rs` (keyring, политика `password_cache`);
- `--askpass` и агент Урфина на pipe (§2.7), поиск и версия `ssh.exe`.

## Приёмка
- подстановки не дают инъекций (имя с `;`, `&`, кавычками — одно значение argv);
- таймаут 30 с;
- stderr ≤200 символов в строке ошибки, stdout не логируется;
- PEM-ключ из команды принимается агентом Урфина, `ssh-add -L` с `SSH_AUTH_SOCK=<pipe>` видит один ключ;
- `--askpass` без окна и без GPUI, время старта GUI не изменилось (замер в PR);
- `password_cache=false` (политика) — Credential Manager не вызывается ни разу (мок `keyring`), «Запомнить» с замком;
- синтаксис CLI BearPass и Пассворка сверен на стенде и записан в шаблоны.
