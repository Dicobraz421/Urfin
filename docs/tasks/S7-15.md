## Приёмка
- загрузка → кодирование без правок = те же байты (все кодировки V5, BOM, mixed EOL);
- загрузка 64 МБ ≤ 1 с;
- diff: вставка/правка/удаление строк дают верные `added`/`modified` (proptest против наивного).

## Сделано (2026-10-31)
- `EditorDoc` (§2): `state` (`Loading{done,total}` / `Ready` / `TooLarge{size}` / `Failed`), `loaded: Option<Rope>`, `enc` (+ `auto`), `bom`, `eol`, `eol_new`, `lang`, `readonly`, `lossy`, `stamp: DiskStamp {size, mtime, file_id}`, `changes: LineChanges`, `start` (курсор после загрузки), `dirty`/`cursor` из `Edited`.
- Загрузка (`edit/load.rs`, Interactive lane): локальный файл — своим handle `FILE_FLAG_SEQUENTIAL_SCAN`, иначе `open_read` VFS; выборка 64 КБ → детект §3.2 или кодировка вручную → `Decoder` кусками по 1 МиБ в `RopeBuilder`; BOM пропускается и помнится; лимит `editor.max_size_mb` (по размеру и по прочитанному); прогресс — не чаще 10 раз/с; попутно хэши строк и счёт LF/CRLF/CR → `eol` (`Mixed` при разных) и `eol_new` (`editor.eol` или доминирующий, без переводов — CRLF).
- Кодирование (`edit/save.rs::encode`): кодировка и BOM «как были», EOL не трогаются; UTF-16 — вручную; непредставимые → `?` и счёт (для S7-17).
- `LineChanges` (`edit/diff.rs`): построчный diff по хэшам (Myers, общий префикс/суффикс, > 1024 правок — один блок) в фоне по `Snapshot { then: Diff }` → `added` / `modified` / `deleted` и метки строк.
- Inbox: `Adopted` — `loaded` пустеет; `Snapshot{Diff}` — полоса изменений; сохранение — S7-17.
- Команды: `editor.open {path?, line?, col?}` (уже открытый — его экран наверх; курсор и кодировка — из записи правки в истории), `editor.close` (без правок; запись `HistKind::Edit` — строка и колонка), `editor.codepage {cp?}` / кольцо F8 (без правок — перечитать с диска, с правками — кодировка сохранения и тост `ui-edit-cp-on-save`), `editor.codepage_menu` и `editor.eol {to}` — `UiEvent::Ext` для UI, `editor.reload`.
- История: записи просмотра и правки одного файла — раздельно (`get_kind`), выход пишет и позиции редакторов.
- Тесты `edit/tests.rs`, `edit/diff.rs`: roundtrip 13 кодировок × 4 вида EOL (вручную и по детекту), EOL, `lossy`, лимит; proptest diff против LCS и на разнесённых правках; команды через core.
