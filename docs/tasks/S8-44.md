## Заметки S8-32
- Сейчас том `.7z.001` (расширение из трёх цифр, `formats/sevenz.rs::is_volume`) при ошибке разбора даёт `arc-error-multivolume`; однотомный `.001` открывается как обычный архив.
- `sevenz-rust2` читает любой `Read + Seek`: склеивающий reader томов достаточно отдать из `ArcSource::open` (им пользуются и разбор, и распаковщик); смещения блоков — от начала первого тома.

## Заметки S8-34
- RAR: листинг в `RAR_OM_LIST_INCSPLIT`, продолжения (`SPLITBEFORE`) номера не получают — их сжатый размер прибавляется к файлу (`formats/rar.rs`). UnRAR сам открывает следующий том (`UCM_CHANGEVOLUMEW`/`RAR_VOL_NOTIFY` → 1).
- Нет тома: колбэк `RAR_VOL_ASK` → `-1`, имя тома — в `Fail::missing`. Листинг кончается на прочитанном (только `tracing::warn`), чтение файла с продолжением — `arc-error-corrupt: missing volume <имя>`. Понятная ошибка «нет тома» (своя строка i18n) — здесь.
- Вход через не первый том: UnRAR листает с него, файл, начатый в прошлом томе, пропускается. Детект первого тома (`.partN.rar`, `.rNN`) — здесь; `OuterKey` сейчас — только открытый том.
- Фикстура — только `tests/fixtures/rar/archive.part1.rar` (второго тома нет); полный набор нужен от WinRAR (`rar a -v…`).
