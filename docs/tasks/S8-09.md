## Заметка
- Команда: `viewer.quick { side, path, line: hit.line, hit: &preview[hl.0..hl.1] }`; при `hit.line == 0` — без `line` и `hit`. Рисовать `ViewerDoc::preview`: `start` — строка `current_line`, `hit` — `highlight`, независимо от `FindBar::shows_hits` (`Rows::hits` с `on = false` их не даст).
- `following` в `view/quick.rs` на экране поиска должен быть `false`, иначе курсор панели в `qview` спорит с предпросмотром за слот.
- Слот с перенесённым вьювером (`!d.quick`) команда не занимает: брать сторону, где его нет.
- `panel_shows` на слоте предпросмотра `true`, `Viewport` идёт как у быстрого просмотра.
