## Сделать
- `editor.md.*` по §5.9 выполняет handler `editor` над кусками документа (`view/edit/md.rs`, ADR-0023), одна группа отмены на команду (обернуть или снять, префиксы строк, ссылка, код, таблица); `md_edit.rs` — меню заголовков от кнопки «H ▾» и состояние кнопок.
- Markdown-группа панели: значки по DESIGN (Нумерованный — свой значок 16); active — по контексту курсора (разбор текущей строки); только для языка Markdown.
- Предпросмотр рядом (`editor.preview`, Ctrl+Shift+V):
  - деление пополам перетаскиваемой чертой (каждая часть ≥ 280, доля — `preview_split`), справа — элемент документа S7-22a, мини-карта скрыта;
  - разбор после паузы 150 мс по снимку документа (текст ≤ 16 МБ — в строку для pulldown-cmark);
  - синхронная прокрутка по смещениям блоков, ведёт сторона, прокрученная последней;
  - клик по флажку задачи меняет `[ ]` ↔ `[x]`;
  - для файлов > 16 МБ кнопка disabled.
- Сцена `screen-editor-md`.

## Приёмка
- снимок совпадает с макетом;
- proptest: команда дважды = исходный текст (bold, italic, heading, list, numbered, task), один undo на команду;
- ввод в README 1 МБ с предпросмотром — кадр p99 ≤ 6 мс, предпросмотр обновляется ≤ 250 мс после паузы;
- ручной чек-лист: синхронная прокрутка в обе стороны без «эха», флажки задач, картинки относительно файла.

## Заметка
- Межполосная (view — `edit/md.rs`, ui): в той же волне.
