## Сделать
- `DirLister`, `NtLister` (FileIdFullDirectoryInformation, открытие относительно родителя), `FindLister`, `VfsLister`; `walk_with`; дедуп ссылок (`links.rs`); пропуск reparse; учёт `DENIED`; размер на диске §3.1.

## Приёмка
- сумма = `dir /s /a` (логический) на tempdir-деревьях;
- жёсткая ссылка ×3 — учтена 1 раз; junction-цикл не зацикливает;
- сжатый (NTFS compress) файл: disk < logical;
- cloud-placeholder не гидратируется (`#[ignore]`, стенд с облачным диском);
- `walk` для `dir_size` не изменился (тесты S4 зелёные).

## Сделано (2026-10-30)
- `walk_with(&dyn DirLister, …)` и `walk` — на общем планировщике (LIFO-очередь); `DirVisitor` с накопителем на каталог (без атомиков на каждый файл). Тесты S4 (`dir_size`) зелёные.
- `du::lister`: `NtLister` (`FileIdFullDirectoryInformation`, буфер 64 KiB на поток, подкаталог — `NtCreateFile` с `RootDirectory` родителя), `FindLister` (снимок `APPROX`, размер на диске — до кластера), `VfsLister`; выбор по ФС корня. `unsafe` — `sys/win_du.rs`.
- Размер на диске: `AllocationSize`; сжатые/разреженные/WOF ≥ `track_min` — `GetCompressedFileSizeW`; `OFFLINE`/`RECALL_*` — 0, файл не открывается.
- `du::links`: битсет по записи MFT (сегменты по 2^20 бит), прочие ФС — шардированный `FxHashSet`.
- Ссылки — `LINK_SKIPPED`, нет доступа — `DENIED`/`PARTIAL_DENIED`/`denied`.
- Тесты `tests/du_walk.rs`: сумма = `dir /s /a` (Nt/Find/Vfs), жёсткая ссылка ×3, junction-цикл, `compact /c`, `icacls /deny`, отмена `walk_with`.

## Осталось
- Облачные заглушки — проверено 2026-10-30 на стенде (Яндекс.Диск, 1403 файла «только в облаке» в дереве): скан не гидратирует, `cloud_placeholders_stay_dehydrated` зелёный.
- ReFS: дедуп по 64-бит `FileId` из `FileIdFullDirectoryInformation`; 128-бит id (`FileIdExtdDirectoryInformation`) — при появлении ReFS-стенда.
- Отличие от API спеки: `DirLister::list` возвращает хэндл для детей (`Option<Parent>`), `out` возвращает `bool` (стоп при отмене).
