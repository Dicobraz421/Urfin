## Сделать
- `merge.rs` §2.4 — сводный список установленных, «вне менеджера», издатель, группировка поиска, ранжирование, «рекомендуется», сравнение версий, инкрементальное слияние (ответы менеджеров приходят по одному).

## Приёмка
- набор из ≥30 реальных троек (winget/scoop/choco: Firefox, 7-Zip, Git, VS Code, Python…) группируется верно;
- порядок «рекомендуется» следует `[pkg].order`;
- добавление ответа менеджера не переставляет уже показанные группы выше курсора.

## Сделано
- `version.rs`: `Version::parse` / `compare` — сегменты через `.` `-` `+` `_` и границы букв и цифр (`rc10` → `rc`, `10`), числа без переполнения, буквы ниже чисел (пре-релиз ниже релиза), хвостовые нули не значат (`1.0` = `1`), ведущее `v` снимается; `Unknown`, `< x`, `> x`, строки без цифр — `None`. proptest: антисимметрия, согласованность с `Eq`, транзитивность.
- `merge.rs`: `norm` — NFKC (`icu_normalizer`, уже в графе через idna; Cargo.lock — одна строка), нижний регистр, без скобок, разрядности и хвостовых версий, `+` → `plus`. Псевдонимы: имя, без ведущего слова издателя (`Mozilla Firefox` → `firefox`) и хвостового `desktop`/`client`/`app`/`msvc`/`gnu`; хвост и весь Id winget; scoop — имя без бакета, choco — без `.install`/`.portable`/…, оба — ещё и без хвостовых цифр (`python312`, `vcredist2022`); семь известных расхождений (`vscode`, `pwsh`, `powershell-core`, `golang`, `libreoffice-fresh|still`, `notepadpp`).
- `InstalledMerge` (`set` по менеджеру, `rows`): choco, затем scoop + запись winget без источника с общим псевдонимом — одна строка менеджера choco/scoop (`twins` — Id ARP/MSIX), пара одна на пакет; без пары — `outside`; издатель: winget — ARP `Publisher` записи с тем же именем, иначе префикс Id; scoop/choco — ARP по псевдониму, иначе пусто.
- `SearchMerge` (`add(mgr, hits, keep)`): группа — общий псевдоним; разные издатели winget — разные группы, scoop/choco примыкают к первой; вариант, связавший две незакреплённые группы, сливает их. Варианты: `[pkg].order`, у winget `winget` раньше `msstore`, совпадение, новее, короче Id. `Group::recommended`, `Variant::newest` (`accent`), `newest_elsewhere` (№4), постоянный `Group::id`. Порядок групп: совпадение, число менеджеров, имя; первые `keep` групп (выше курсора и под ним) не переставляются. Повторный ответ менеджера заменяет прежний, `answered()` — пустой ответ отличим от «не ответил».
- Тесты: `fixtures/merge/search.txt` — 37 программ (Firefox, 7-Zip, Git, VS Code, Python, Node.js, Chrome, PowerShell, Windows Terminal…): каждая — одна группа при любом порядке ответов, все разом — не смешиваются; порядок «рекомендуется» при разных `order`; новейшая; закрепление выше курсора; подгруппы издателей; сводный список установленных с ответами по одному.
