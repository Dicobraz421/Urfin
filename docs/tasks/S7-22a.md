## Сделать
- `doc.rs`: элемент документа на `gpui::list` (блок — элемент; длинные таблицы и код режутся по 64 строки), стили — DESIGN «Markdown-документ», только роли темы. Заголовки, абзацы, строчные стили, списки и задачи, цитаты, таблицы и код со своей горизонтальной прокруткой, черта, сноски.
- Картинки — `gpui::img` из пути (GPUI грузит в фоне), скелетон 24, плашки с причиной; число непоказанных — в середину статуса. У `<img>` — размер из `width` / `height`, не шире колонки.
- HTML-набор (§3.10, DESIGN «Markdown-документ»): `<details>` — строка-подпись с шевроном, клик раскрывает и сворачивает (состояние — в UI, на документ; совпадение F7 внутри раскрывает); выравнивание блоков `center` / `right`; `<kbd>` — клавиша; `<sub>` / `<sup>` — индексы; `RawHtml` — моноширинно `secondary`.
- Ссылки: при наведении подчёркивание и подсказка с целью. Клик: якорь; `.md` — в этом же вьювере (`viewer.back`); файл или папка — курсор панели. Внешние (`http(s)`, `mailto`; решение §13, вопрос 2) — Ctrl+клик открывает программой Windows (`ShellExecuteExW` вне UI-потока, как `file.open` и Enter по файлу S6 §7; UI не ждёт), простой клик — подсказка «Ctrl+клик — открыть в браузере».
- Выделение по проекции, Ctrl+C / Ctrl+A — видимый текст; подсветка совпадений F7; Ctrl+колесо — `viewer.md_font_size`; статус «Стр A–B из N» по исходнику.
- Быстрый просмотр: документ для `.md` ≤ 4 МиБ, картинки — только для видимых блоков.
- Настройки «Просмотр → Текст»: строка «Markdown: Документ | Исходник» (`viewer.markdown`) по образцу соседних.
- Сцена `screen-viewer-md`.

## Приёмка
- снимок совпадает с макетом;
- прокрутка README 16 МБ — кадр p50 ≤ 3 мс, p99 ≤ 6 мс (release, стенд), в простое кадров нет;
- ручной чек-лист: картинки (локальные, `data:`, сетевые — плашкой, `<img width>`), `<details>` раскрывается и сворачивается, `<p align="center">`, ссылки (Ctrl+клик по внешней открывает браузер), выделение и копирование, Документ ↔ Текст на той же позиции, тёмная тема и высокая контрастность.
