## Сделать
- `ViewState.screens` ↔ вкладки экранов и `ui.screens` (F12), `viewer.next_file/prev_file/reveal/history`, `view-history.json` (debounce 2 с, cap 500, `remember_pos`), `viewer.open {alt}` (пусто — `file.open`, шаблон — `term.open`) и `[[viewer.assoc]]`, F3 на каталоге → `vfs.dir_size`.

## Приёмка
- 3 вьювера и 2 редактора видны в F12, переключение без потери позиции;
- история переживает перезапуск;
- Gray+ пропускает каталоги.

## Заметка
- Межполосная (view, ui — список F12): в той же волне или строкой в волне ui.

## Сделано (2026-10-31)
- Экраны: `ViewState::activate` / `screen_list`, команда `viewer.screen doc=` (экран наверх, фокус — ему) — для вкладок и списка F12; документ, открытый из панели, помнит таб-источник (`ViewerDoc::source`).
- `viewer.next_file` / `prev_file` (Gray+ / Gray−): соседний файл в видимом порядке таба-источника, каталоги пропускаются; документ переоткрывается на том же экране, режим и перенос сохраняются, кодировка — `auto`, позиция — из истории; прежний файл — в историю.
- `viewer.reveal {path?}` (Ctrl+F10; ссылка на файл или папку в документе): панель-источник идёт в папку и ставит курсор на имя, фокус — в панель, вьювер остаётся экраном (S7 §3.9). Клик по ссылке в `doc.rs` — `LinkTarget::command()` вместо трёх команд UI.
- История: `ViewMemo` с `kind` (просмотр / правка) и `ts`; файл `state_dir/view-history.json` (массив `{uri, kind, pos, hscroll, frac, enc, mode, wrap, ts}`, свой маленький JSON — `serde_json` во вьювере нет), чтение в первом pump (Bulk), запись через 2 с после изменения (Bulk), при выходе — позиции открытых документов и запись сразу (выделенный поток, его ждёт shutdown); cap — `history_max`, выключатель — `remember_pos`. `state_dir` — сосед `cache_dir` (`ViewEnv::history_file`). `viewer.history {kind?}` (Alt+F11) — `UiEvent::Ext` для списка, пусто — тост.
- `viewer.open {alt}`: `[viewer] external` пусто — `file.open` (под курсором) / `term.open path=` (по пути); шаблон — `term.exec` с `{path}` в кавычках и каталогом файла. `[[viewer.assoc]]` (маски Far) уводят F3 наружу, `internal=true` — нет. F3 на каталоге — `vfs.dir_size` (было).
- Ссылка `.md` (`viewer.open placement=here anchor=`): файл открывается в том же экране, прежний — в `files_back`; `viewer.back` (Alt+Backspace) — сначала позиции в файле, потом прежний файл с его позицией и режимом; якорь в другом файле — верхний блок после разбора; тот же файл — переход к якорю с «назад».
- Перечитывание `[viewer]` / `[editor]` по `app.reload_config` (`ui.setting`): новые значения — в `ViewState` (`md_font_size` и прочее для UI), открытым документам — `markdown` (документ ↔ исходник на той же позиции), `md_image_max_mb` (новый разбор), `tab_size`, `hex_cols`; `history_max`.
- Тост «UTF-32 не поддерживается» при открытии (`detected.utf32`, кроме быстрого просмотра).
- i18n EN+RU: `ui-md-img-not-local` (плашка `NotLocal`), `ui-set-viewer-markdown-note` (пояснение у «Markdown»), `ui-view-external-local`.
- Тесты (`screens_tests.rs`): соседние файлы с каталогами, reveal (файл, путь, папка), экраны, история через перезапуск (debounce и выход), Alt+F3 и маски, шаблон, ссылка `.md` с якорем и «назад», перечитывание конфига, UTF-32; JSON истории — roundtrip и мусор.

Приёмка «3 вьювера и 2 редактора в F12» — с этим списком и редактором (S7-15).
