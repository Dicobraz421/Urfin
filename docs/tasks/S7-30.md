## Сделать
- Поиск в редакторе — `Matcher` и `scan` S7-09 по `TextHay` снимка (литерал, regex по байтам, HIR для однобайтовых, transcode для UTF-16, `^`/`$` с CRLF), фоном с `SearchState` (счёт до `count_limit`, метки); `regex-cursor` по Rope (S7-18, `edit/find.rs`) снимается.
- «Заменить» — обычная правка; «Заменить все» — задача по снимку (прогресс ≤ 30/с, отмена), документ на время задачи только для чтения (`EdState::Replacing`), итог — одна группа `Op::Root`: ≤ 64 тыс. совпадений — куски (без групп — один `Add` на все), больше — поток результата во временный файл `Rewrite` (общий писатель с S7-31, `edit/write.rs`). Группы `$1`, `$2`.
- `editor.eol` на большом документе — та же задача (замена `\r?\n|\r`).

## Приёмка
- proptest: замена по кускам = `regex` по `String` (литерал, regex, группы, CRLF, 1251, UTF-16), совпадение через границу кусков находится;
- 100 тыс. совпадений в 50 МБ ≤ 1 с, одна отмена возвращает исходник;
- 1 млн совпадений в 1 ГБ — результат через `Rewrite`, память документа ≤ 64 МиБ, отмена задачи ≤ 100 мс.

## Сделано (2026-11-01, x/view-22)
- `edit/replace.rs`: поиск на движке — `compile` S7-09 по кодировке документа и проход `search::scan` по `TextHay` снимка (`spawn_cpu`, `SearchState`, прогресс в атомике), как во вьювере: совпадение → выделение и вывод курсора, затем счёт до `count_limit` (метки, «N из M»); правка во время поиска — итог отбрасывается, поиск повторяется; правка документа сбрасывает метки (`search_edited`).
- «Заменить» (`editor.replace text= with=`) — выделение совпадает с найденным → замена одной группой (`Engine::replace_range`), затем следующее; иначе — поиск. «Заменить все» (`all=true`) — задача Bulk по снимку (`ReplaceJob`: прогресс, отмена Esc — `editor.search_cancel`), документ только для чтения (`Engine::busy`); итог — одна группа `Op::Root`: ≤ 64 тыс. совпадений — куски (без групп — один кусок `Add` на все совпадения, с группами — замены одним блоком `Add`), больше — второй проход потоком в `Rewrite` (`write::RewriteOut`, память до 16 МБ, дальше временный файл).
- Группы `$1`, `${name}`, `$$`, `$0` (`Repl::Groups`): совпадение декодируется, образец (Unicode) сопоставляется с ним целиком, подстановка кодируется в кодировку документа (непредставимые — `?`).
- `search::scan::each` — все совпадения без перекрытий по порядку (окна S7-09). `compile` S7-09: `^`/`$` — по строкам, CRLF — один конец строки (`multi_line` + `crlf`; было — только начало/конец окна), общее с вьювером.
- Команды: `editor.search` и `editor.replace` получили аргументы (`text`, `kind`, `case`, `word`, `back`; у замены — `with`, `all`): с `text` и документом на движке — handler, без `text` — строка «Найти» UI (прежний путь); `editor.search_next`/`_prev` — после поиска на движке; `editor.search_cancel` останавливает поиск и «Заменить все». Строка `ui-edit-replaced` («Заменено: N»).
- Тесты (`replace_tests.rs`): proptest (200 случаев) — замена по кускам (и путём `Rewrite`) = модель `meta::Regex` по `String`: литерал, без учёта регистра (кириллица), regex с группой, `\r?\n` (CRLF), группа `$1$1`, `^a|c$` по строкам; UTF-8, 1251, UTF-16LE; документ из исходника и правок, окна поиска 4–64 байт; совпадение через границу кусков; через core — поиск, счёт, «Заменить», «Заменить все» + одна отмена/повтор, Esc во время задачи. `tests/heavy.rs`: `engine_replace_all_speed` (`#[ignore]`, release).
