## Заметки S8-32
- `sevenz-rust2` без feature `compress` писать не умеет: A-архивы 7z для бенча — 7-Zip (`7z a`) или `compress` в dev-зависимостях (полоса deps).
- A6: F3 файла в середине solid-блока распаковывает в никуда всё перед ним, затем отдаёт файл через `Pump`; LZMA2 — `available_parallelism` потоков (помогает только блокам, сжатым многопоточно).
- A3 (план): блоки делятся между ≤ 4 читателями по распакованному размеру нужных файлов, у каждого свой дескриптор; потоки LZMA2 — ядра / число читателей. Блок проходится один раз, после последнего нужного файла бросается (`formats/sevenz.rs`, тест `plan_of_one_block_is_one_pass` считает проходы).
- Отмена видна между файлами: распаковка в никуда одного большого ненужного файла не прерывается.

## Заметки S8-34
- RAR — свой FFI к UnRAR 7.1.0 (`crates/arc/src/formats/rar/sys.rs`): `RAR_TEST` + `UCM_PROCESSDATA`, данные порциями по 256 КиБ через `Pump`. Один читатель на архив (`transfer_channels` = 1): выборка — один проход по порядку записей, записи до нужной — `RAR_SKIP` (у solid UnRAR распаковывает их в никуда сам).
- F3 файла в середине solid-rar — распаковка всего перед ним (как A6 у 7z). Отмена — между записями и по закрытию читателя (колбэк возвращает `-1`).
- A-архивы RAR для бенча создать нечем: нужен WinRAR (`rar a`) на стенде, UnRAR создавать не умеет (и нельзя по лицензии).
