## Сделать
Расхождения кода с макетами (сверка 2026-11-01, макеты не меняются):
- История команд Alt+F8 (S6-16) и дополнение Tab (S6-17), `term_menu.rs`: сейчас плашка 720 у левого края над командной строкой (`pouch::pouch(.., None, ..)`). По `screen-cmdhistory.png` — мешочек вверх от поля командной строки: корешок — значок часов и фильтр с кареткой, список над ним, переключатель «pwsh | Все shells» (Ctrl+R) сверху. По `screen-cmdcomplete.png` — мешочек вверх, корешок — набранное слово с кареткой (по его x), список 400. Корешок — `pouch::Notch` по раскладке поля, не константой.
- Список «Если файл есть» строки F5/F6, `conflict_list` в `mod.rs`: сейчас плашка над кнопкой. По общему правилу — мешочек с корешком из самой кнопки (`pouch::Notch` по `field.drop`), список вверх или вниз — как помещается над зоной событий.
- Ручная проверка — `docs/manual-tests/S7-25b.md`: Alt+F8, Tab, кнопка «Если файл есть» — у каждого корешок из своего источника, клик мимо и Esc закрывают.

## Приёмка
- снимки сцен совпадают с `screen-cmdhistory`, `screen-cmdcomplete`;
- ни одной плашки без корешка там, где есть источник (DESIGN «Общие правила»);
- новых строк i18n нет.

## Сделано (2026-11-01, волна `x/s7-25-menus`)
- `term_menu.rs`: Alt+F8 — «мешочек» вверх (`pouch_up`), корешок — часы и фильтр с кареткой от начала ввода (по раскладке строки: промпт моно-ячейками или `путь>`); Tab — мешочек 400 вверх, корешок — слово под курсором с кареткой по его x.
- `conflict_list` (`mod.rs`): «Если файл есть» — мешочек вверх, корешок — сама кнопка по `field.drop`.
- Мешочки вверх рисуются поверх командной строки и нижней зоны (порядок детей окна).
- Сцены `screen-cmdcomplete`, `screen-cmdhistory` (история в демо пустая — «Ничего не найдено»). Unit: начало слова дополнения.

## Осталось
- Переключатель «pwsh | Все shells» сегментами и клавиши в keybar вместо строки внизу мешочка (`screen-cmdhistory.png`): нужны строки «Все shells», «Вставить», «Выполнить», «Закрепить» — новая карточка i18n; пока заголовок «История · shell» + «Ctrl+R» и строка клавиш внизу.
