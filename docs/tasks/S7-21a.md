## Сделать
- Решение 2026-10-30: в exe — JSON, TOML, YAML, INI, XML, Markdown; гейт `ci/size.py` остаётся 30 МиБ.
- Остальные языки — пакеты грамматик в папке рядом с exe, загрузка по требованию. Формат — по замеру: `.wasm` (рантайм tree-sitter `wasm` = wasmtime, его вес) или нативная DLL; выбрать меньший итог при равной безопасности (папка установки, без загрузки из профиля пользователя).
- В описании PR — прирост exe, вес рантайма и пакетов.

## Сделано (2026-11-01)
- В exe — JSON, TOML, YAML, INI, XML, Markdown: `tree-sitter` 0.26, `tree-sitter-language`, `tree-sitter-json`, `-toml-ng`, `-yaml`, `-ini`, `-xml`, `-md` у `urfin-view` (MIT, `tree-sitter-ini` — Apache-2.0; `cargo deny check` чист без правок `deny.toml`). Не через features gpui-kit: его `SyntaxHighlighter` не используется (ADR-0023).
- Формат пакетов — **нативная DLL** по замеру: рантайм `wasm` tree-sitter (wasmtime 36 + cranelift) — +9,6 МиБ к exe (пробник: 1,62 → 11,18 МиБ), загрузчик DLL — ≈ 0; грамматики в `.wasm` и в DLL — таблицы разбора, по размеру близки. Пакет — `grammars\<язык>.dll` рядом с exe, экспорт `urfin_grammar_abi`/`urfin_grammar`/`urfin_highlights`, крейт `assets/syntax/pack` (отдельный workspace, в сборку exe и CI не входит). Загрузка — `LoadLibraryExW` по абсолютному пути (папка пакета, папка exe, System32), имя — только `[a-z0-9_]`, версия формата проверяется; без сети и профиля пользователя.
- Размер: `urfin.exe` 29,1 → 31,85 МиБ (+2,75); по языкам и пакетам — таблица в S7 §5.7 и в PR.

## Осталось
- **Гейт**: exe 31,85 МиБ (было 29,1) > 30 → в `.github/workflows/ci.yml` шаг «Binary size ≤ 30 MB» — `ci/size.py "$BIN" 34` (№80; правка `.github` — не этой волной, release-джоб на main до неё красный).
- Пакеты в дистрибутив: шаг «Dist» в `ci.yml` — собрать `assets/syntax/pack` по языку (`cargo build --release --features <язык>`) и положить `grammars\<язык>.dll` рядом с exe (вне бюджета exe, как ConPTY). Сейчас пакеты собираются вручную.
