## Сделано (2026-11-05, ветка x/view-cast)
- view: модуль `cast` — разбор asciicast v2 потоком (`Lines`, чужие записи и битые строки не мешают), вывод без VT (`Strip`, состояние между событиями), проход `scan` на своём потоке: ключи раз в 5 с и раз в 256 КБ вывода, карта «смещение текста → время» (шаг 100 мс), текст без VT — во временный файл (`SpoolSource::create`). Файл в память не читается.
- Перемотка — от ключа (`Replay`, спан `viewer.cast.seek`), 10 МБ — 2,2 мс в dev-сборке (`benches/cast.rs`), бюджет 50 мс.
- Поток плеера (`spawn_dedicated`): часы, 1×/2×/4×, кадры ≤30 в секунду сообщениями, UI только красит снимок. `Mode::Cast`, команды `viewer.cast.play/seek/speed`, смена источника между режимами (Запись и Текст — вывод без VT, Hex — файл).
- Поиск — штатный по тексту без VT: совпадение даёт время, метки — доли шкалы; `.cast` без заголовка v2, быстрый просмотр и файл из архива — обычный текст.
- ui: шапка (путь, «только чтение», «Подсветка», Запись/Текст/Hex), панель 46 (▶, время, шкала с метками и перетаскиванием, скорость, поле поиска, «N из M», ↑↓), совпадения на экране плеера (`highlight`, текущее — `accent`), статус одной группой с UTC-поправкой (№92), keybar по макету. Сцены `viewer-cast-first`, `screen-sshrecview`, `viewer-cast-text`; строки EN+RU.
- Зависимость `urfin-view → urfin-term` (эмулятор, снимок).

## Сделано (2026-11-05, ветка x/view-casttail)
- keymap: контекст `cast_view` — флаг `urfin_view::cast_view` (фокус у экрана вьювера в режиме «Запись»; в `when.rs` заглушка, настоящий регистрирует app), привязки в `base.toml`: Пробел, ← →, 1/2/4; `Viewer::cast_key` убран. Цифры — на любой раскладке (по положению клавиши), подписи keybar — из keymap, свои привязки видны. Шпаргалка `docs/keys.md` и `docs/COMMANDS.md` — генераторами.
- Ключ — полное состояние эмулятора (`urfin_term::vt::image`): обе сетки с атрибутами и признаками переноса, курсоры с пером и таблицами символов, сохранённые курсоры, режимы, DECSTBM, табуляции, палитра OSC, вид курсора, активная таблица, символ REP. Поток VT (`key::synth`) убран. Посреди последовательности и внутри DEC 2026 ключ откладывается до границы события. Основной экран за альтернативным снимается при входе, resize после входа воспроизводятся.
- Инвариант «перемотка к любому моменту = проигрывание с нуля»: proptest `seek_equals_play_from_zero` (DECSTBM, alt-screen, режимы, resize, разрезы последовательностей) и `golden_seek_law` на `rec_golden.cast`. Новый плеер тоже выводит события момента 0 при первой перемотке.
- Сцена `screen-sshrecview`: курсор — `accent`, OSC 12 записи сильнее.
- Ручные проверки — `docs/manual-tests/F03-13.md`.

## Осталось
- Alt+↓ листает историю поиска прямо в поле; выпадающего списка №70 нет: строка «Найти» не на компоненте поля панелей.
- Сцена: путь шапки — временная папка, на макете `%LOCALAPPDATA%\Urfin\recordings`.
- Настройки «Клавиатура» показывают только пресет: списка клавиш в настройках нет ни у одного контекста; клавиши плеера — в `docs/keys.md`, `keymap.dump`, переназначение — `keymaps/user.toml`.
- Вне инварианта (следы смены размера, `urfin_term::vt::image`): стоп табуляции в самой последней колонке; фон очистки цветным пером, который `alacritty` оставляет на экране после смены размера, из ключа следующая очистка убирает полностью.
