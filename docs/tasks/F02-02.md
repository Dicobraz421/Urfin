## Сделать
- `proc.rs`/`decode.rs` поверх `term::proc`: запуск с pipes и `CREATE_NO_WINDOW`, построчный поток, UTF-8 → OEM-откат, снятие `\r`/VT, таймауты, отмена дерева; тестовый бинарь `fake-pkgmgr` (urfin-testdata), который повторяет фикстуру с паузами и кодом выхода.

## Приёмка
- CP866 и UTF-8 в одном потоке декодируются верно;
- отмена дерева из 3 процессов ≤100 мс;
- таймаут даёт `PkgError::Timeout`, потоков после — 0;
- UI-поток не блокируется.
