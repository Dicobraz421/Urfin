## Сделать
- `proc.rs`/`decode.rs` поверх `term::proc`: запуск с pipes и `CREATE_NO_WINDOW`, построчный поток, UTF-8 → OEM-откат, снятие `\r`/VT, таймауты, отмена дерева; тестовый бинарь `fake-pkgmgr` (urfin-testdata), который повторяет фикстуру с паузами и кодом выхода.

## Приёмка
- CP866 и UTF-8 в одном потоке декодируются верно;
- отмена дерева из 3 процессов ≤100 мс;
- таймаут даёт `PkgError::Timeout`, потоков после — 0;
- UI-поток не блокируется.

## Заметка
- Межполосная (pkg, term, ci): при планировании волны разбить или вынести контракт в PR класса B. Полосы `pkg` ещё нет в lanes.toml — добавить PR класса B.

## Сделано
- term: `term::proc::spawn_piped(argv, cwd, env, PipedFlags)` → `PipedChild` (`stdout`/`stderr`, `kill_tree`, `wait_timeout`, `active_processes`, `pid`); `sys::piped` — `CreateProcessW` приостановленным, вход в job до первой инструкции, `ResumeThread`; наследуются только пайпы ребёнка (`PROC_THREAD_ATTRIBUTE_HANDLE_LIST`); stdin — пустой пайп (EOF); флаги `no_window` (`CREATE_NO_WINDOW`), `merge_stderr`, `kill_on_drop` (`KILL_ON_JOB_CLOSE`). Тесты на `cmd.exe` (`piped_tests.rs`).
- pkg `decode.rs`: `Decoder` — строка UTF-8 строго, иначе OEM (`oem_cp`: 437, 850, 866…; `encoding_rs`: 932/936/949/950, 125x, KOI8); `clean` — BOM, VT (CSI, OSC, DCS, `ESC (`), управляющие, backspace, `\r` → последний сегмент; `LineSplitter` — строки по `\n`, незавершённая строка ≤64 КБ. Unit + proptest (произвольные байты и нарезка).
- pkg `proc.rs` (Windows): `run_query(argv, cx) -> Output { code, lines }` (`Output::ok` → `PkgError::Exit` с хвостом), `run_action(plan, cx) -> ActionDone::{Ok, Reboot}` по `success_codes`/`reboot_codes`; строки — в `cx.lines` из потока-читателя; таймаут и отмена — `kill_tree` и ожидание читателя (шаг 20 мс); запрос после выхода процесса добивает дерево, действие — нет (программа, запущенная инсталлятором, живёт; вывод бросается через 2 с). `OEMCP` — из реестра. Новый `PkgError::Spawn`.
- testdata: пример `fake-pkgmgr` (фикстура построчно, `--line`, паузы, `--spawn N` — дерево, `--exit`, `--stderr`). Тесты `proc_tests.rs`: CP866+UTF-8+`\r`+VT+stderr в одном потоке, отмена дерева из 3 процессов ≤100 мс, таймаут → `Timeout` и читатель завершён, запрос в `spawn_dedicated` не держит вызывающий поток, коды действий.

## Осталось
- `term::proc::session_has_process` (контракт v6 №15) — для эвристики UAC winget, F02-10; ленточный сеанс `feed_session` — F02-10.
- Повышенные планы (`elevate`, choco через runas) `run_action` не исполняет (`PkgError::Spawn`) — F02-06/F02-10.
- Пайпы ребёнка наследуемы на время `CreateProcessW`: параллельный `std::process::Command` в другом потоке Urfin может их унаследовать — тогда EOF ждёт выхода того процесса.
- Тесты `proc_tests.rs` и `piped_tests.rs` — только Windows (CI); в песочнице не запускались.
