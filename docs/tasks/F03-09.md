## Сделать
- `SessionKind::External` (запрос №3), argv §3.1, мост askpass/агент, шапка «ssh srv1 ▾», пара §3.2, Ctrl+Tab, OSC 7 → панель, `ssh.cd_here`, выход сеанса.

## Приёмка
- `ssh.exe` к `testsrv` (OpenSSH-клиент стенда) с паролем через askpass — пароль вводится один раз для SFTP и терминала;
- ключ из менеджера работает через агент Урфина;
- `ssh.exe` не задаёт вопрос о ключе сервера;
- OSC 7 меняет папку панели;
- Ctrl+Tab переключает фокус, сочетание в keybar.

## Заметка
- Межполосная (term, ui, net): при планировании волны разбить или вынести контракт в PR класса B.

## Сделано (2026-11-03, ветка x/term-ssh)
- term: `SessionKind::External { argv, env, title }` (запрос №3) — `urfin_term::open_external`, без интеграции (вид «экран», ввод сырой), OSC 7 с хостом в `Slot.remote`; `Slot.origin` — сеанс узнаётся после перезапуска; свой размер PTY сеанса (`term.pin`, размер окна его не меняет); `ssh.exe` с кодом ≠ 0 — «[соединение закрыто, код N]» и «Enter — переподключить», Enter перезапускает тот же argv; TUI во внешнем сеансе панели не прячет, скроллбэк в фоне не урезается.
- net: память секретов и папка «Только в этот раз» — общие у сеанса профиля и его терминалов (`conn::Share`, `secrets::Shared`); PEM-ключ менеджера паролей — в памяти сеанса для агента. `ssh.terminal {profile, side?, session?, new?}`: пара во второй половине окна, терминал стартует после подключения панели (ключ сервера проверен, пароль в памяти); `ssh.exe` ищется и проверяется задачей, pipe `--askpass` и агента создаются до запуска; argv §3.1 (`ssh.exe <Host>` для ssh_config, `-p/-i/-J user@host` для своих, `UserKnownHostsFile` с файлом сеанса, `StrictHostKeyChecking=yes`, `IdentityAgent` при ключах менеджера); OpenSSH < 8.9 — тост «обновите OpenSSH», без моста. `ssh.pair_focus`, `ssh.cd_here` (Ctrl+U, `cd -- '<путь>'`); OSC 7 → панель (путь нормализуется, первый хост запоминается, другой — вложенный `ssh`, панель не двигается); без OSC 7 5 с — «папка: сервер не сообщает».
- core: `NetModel.terms` (`TermLink`, `TermLogin`), `NetModel.pair` (`Pair`, `PairCwd`), флаг `in_sshpair`, `pair_term_focused`, `posix_normalize`, `same_host`.
- keymap: Ctrl+Tab → `ssh.pair_focus` в `panel && in_sshpair && !in_du` и `terminal && in_sshpair` (сильнее `du.map`, без конфликта).
- ui: терминал пары под панелью (45/55), шапка «ssh srv1 ▾» — сеансы профиля, «Новый сеанс», «Перейти в терминале сюда»; клик в терминал — фокус ему; фокус у терминала — без cmdline, статус «ssh.exe · ключ ed25519 из агента | папка: … ↔ панель | UTF-8 · 79×18» и клавиши Ctrl+O, Ctrl+Tab; Shift+Enter в «Подключениях» — терминал выбранного профиля. Сцена `screen-sshpair` сверена с макетом. Строки EN+RU.
- Тесты: настоящий внешний сеанс (OSC 7 с хостом, выход 5, перезапуск под тем же `origin`, `term.pin`); argv, `cd_here`, подписи входа; стенд `net/tests/term_ssh.rs` (`#[ignore]`, OpenSSH Windows): `ssh.exe -N` к `testsrv` — пароль из памяти через `--askpass` без вопроса (неверный — не входит), ключ через агент Урфина, ключ сервера без вопроса.
