## Сделать
- §3.2: BOM, UTF-16 без BOM, binary, UTF-8, chardetng + tld, KOI8-R/U, EOL; `Enc`, таблицы 256 для однобайтовых.

## Приёмка
- корпус V5 ≥ 95 % верных, 1251/866/KOI8 на русском тексте ≥ 2 КБ — 100 %;
- ≤ 1 мс на 64 КиБ;
- крайние случаи: ASCII, короткий файл, обрезанный UTF-8.

## Сделано
- `detect.rs`: BOM (UTF-32 → hex, флаг `utf32`), UTF-16 без BOM, бинарный (hex-текст — 1251 при `tld = ru`, иначе 1252), UTF-8 с обрезанным хвостом выборки, chardetng + `tld_for_lang`, KOI8-U → KOI8-R без украинских букв, EOL (`CrLf` — и для файла без переводов строк).
- `enc.rs`: `Enc`, таблицы 256 однобайтовых (`ByteTable::of`, один раз на процесс), посимвольный `CharDecoder` (UTF-8, UTF-16 с суррогатами, однобайтовые, прочие многобайтовые через `encoding_rs::Decoder`).
- Корпус V5 фикстурой (`detect_tests.rs`, свои тексты): 29 случаев — 100 %, 1251/866/KOI8-R на русском ≥ 2 КБ — 100 %; крайние случаи.
- Замер (release, 64 КиБ): 1251 — 0,63 мс, UTF-8 — 0,11 мс, лог ASCII — 0,06 мс (≤ 1 мс); chardetng получает первые 16 КиБ выборки (на 64 КиБ — 2,3 мс).

## Осталось
- UTF-16 без BOM с нелатинским текстом (кириллица) правило §3.2 п. 2 не ловит (нулевых байтов нет) — такой файл уходит в hex; при необходимости — уточнить правило в S7-08.
