## Сделать
- Решение владельца 2026-11-01: блочное выделение в M4, как в Far. `Selections::Block { lines, cols }` — логические строки × экранные колонки (табы раскрыты, `unicode-width`, широкие символы — целиком); `editor.move {to, select: "block"}` (Alt+Shift+стрелки/Home/End/PgUp/PgDn), `InboxMsg::Caret` с флагом блока (Alt+drag).
- Операции: копирование — строки блока через `eol_new` + формат буфера `MSDEVColumnSelect` (как VS/Notepad++); вырезание и Del/Backspace — удаление колонок в каждой строке (короткие строки не трогаются); ввод при блоке — удалить блок и печатать у курсора; вставка буфера с `MSDEVColumnSelect` — колонкой от курсора (недостающие строки дописываются, короткие — добиваются пробелами). Каждая операция — одна группа отмены.
- Блок выше 64 тыс. строк — фоновой задачей через `Rewrite` (писатель S7-30/S7-31) с прогрессом и отменой; копирование — до `viewer.copy_limit_mb`.

## Приёмка
- proptest: удаление/вставка блока = модель по строкам `Vec<String>` (табы, CJK, CRLF, 1251, UTF-16), отмена возвращает исходник;
- копия блока → вставка блока в другое место даёт тот же прямоугольник;
- блок 1 млн строк в 10 ГБ удаляется задачей, память документа ≤ 64 МиБ.

## Сделано (2026-11-02, x/editor-2)
- Модель — `Sel::Block { anchor, anchor_col, col }` движка (`edit/block.rs`, дочерний модуль `input`): прямоугольник — логические строки (сегменты без переноса) × экранные колонки, колонки виртуальные (за концом короткой строки тоже); колонки строки → байты — `layout::col_span` (широкие и табы — целиком, нулевой ширины — с соседом).
- Движения `editor.move select=block` (Alt+Shift+стрелки/Home/End/PgUp/PgDn, привязки в `base`) — по логическим строкам с памятью колонки; мышь — `InboxMsg::Caret { block: Some(col) }`.
- Операции одной группой отмены, сначала чтение из кэшей (нет страниц — ждёт весь диапазон блока одним запросом), затем правки снизу вверх: копирование (`Act::BlockCopy`, строки через `eol_new`, лимит `viewer.copy_limit_mb`) — буфер `CF_UNICODETEXT` + `MSDEVColumnSelect` и `Borland IDE Block Type` (`sys::clip_write(text, column)`); вырезание, Del/Backspace — колонки прочь (короткие строки не трогаются); ввод, вставка обычного текста, Enter — блок прочь, текст на строке курсора у левого края; вставка блочного буфера — колонкой от курсора (короткие строки — пробелы, недостающие — в конец документа); Tab, `block.shift_*` — сдвиг строк блока.
- Приёмка: proptest «удаление и копия = модель по строкам» и «вставка колонкой = модель» (табы, CJK, CRLF/LF, UTF-8, 1251, UTF-16 LE; отмена — исходник и блок), копия → вставка колонкой в другом месте — тот же прямоугольник, через core — Alt+Shift, `editor.cut`/`editor.paste` с признаком блока.

## Осталось
- Блок выше 64 тыс. строк — сейчас тост «Блок — больше 65536 строк…» (`ui-edit-block-too-big`), текст не меняется; фоновая задача через `Rewrite` с прогрессом и отменой (строки `ui-edit-block-big`, `ui-edit-block-run` уже есть) и приёмка «1 млн строк в 10 ГБ, память ≤ 64 МиБ» — отдельной волной.
