## Сделать
- `urfin --version` → `urfin 0.x.y (abc1234, 2026-11-11)`: sha из `GITHUB_SHA` или `git rev-parse --short HEAD`, дата — из `SOURCE_DATE_EPOCH` или даты коммита; без git — `unknown`.
- `build.rs`: `rerun-if-env-changed` для обеих переменных; локальная сборка не пересобирается на каждый коммит.
- То же значение — в «О программе», если там показывается версия.

## Приёмка
- тест `version_smoke` проверяет формат; release-сборка CI печатает sha коммита.
