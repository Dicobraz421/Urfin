## Сделать
- Первым — проверка на стенде: `ReplaceFileW` при открытом нами handle (share `READ | DELETE`). Если отказ — запасной путь ADR-0023 §8 п. 4 (закрыть handle → `ReplaceFileW` с `lpBackupFileName` → открыть резервную копию тем же share, `FileDispositionInfo` на удаление); итог — строкой в ADR.
- Писатель (`edit/write.rs`): снимок → куски (исходник — `read_at` блоками 4 МиБ, не через `PageCache`; `Add` — из памяти/временного файла) → `.<имя>.urfin~`; та же кодировка — копия байт, другая — `Encoder` потоком + BOM, непредставимые — `EdAsk::Unmappable`. Память ≤ 8 МиБ буферов. Свободное место ≥ размера — иначе вопрос с цифрами.
- Дисковый слой S7-17 без изменений (`ReplaceFileW` → `MoveFileExW`, атрибуты, nlink, symlink); «на месте» — временный файл в `%TEMP%`, затем запись в исходный (снять свой запрет, записать, открыть заново), группы журнала на старых байтах — отбросить.
- После записи: новый файл открывается с запретом записи; корень не менялся — документ = один кусок нового файла, `saved_at`; правка во время записи разрешена (снимок). Вход — снимок дерева вместо `Snapshot { Rope }` (прежний путь — до S7-34).

## Приёмка
- сохранение без правок и с правками = собранный буфер (все кодировки V5, BOM, lossy);
- 1 ГБ с одной правкой ≤ 3 с NVMe, память + ≤ 8 МиБ; обрыв после temp (fault-injection) не портит исходник; ACL, атрибуты, hardlink — как S7-17;
- после сохранения отмена работает (старые куски читаются через handle старой версии), закрытие документа освобождает место старой версии.
