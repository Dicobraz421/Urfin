## Сделать
- `sys/pty_unix.rs` за тем же API, что `conpty`: `openpty`, запуск оболочки с управляющим терминалом, изменение размера (`TIOCSWINSZ`), завершение дерева процессов, чтение/запись без блокировки UI-потока.
- Общее имя модуля для `feed`, `manager`, `rec`, `session`, `vt` (сейчас импортируют `sys::conpty`).
- Оболочки: `$SHELL`, `/etc/shells`; `procs`, `registry`, `shell_open` — Linux-ветки или заглушки с ошибкой.
- Нужны новые фичи rustix/зависимость — карточка в полосу `deps`.
