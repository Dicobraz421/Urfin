## Сделать

## Приёмка
- снимки совпадают с макетами;
- замена 100k совпадений в 50 МБ ≤ 1 с, один undo;
- `^`/`$` по строкам верны на CRLF (proptest против `regex` по `String`).

## Движок (ADR-0023, 2026-11-01)
- Сужен: строки «Найти»/«Заменить на»/«Перейти к строке» и команды переиспользуются; поиск по Rope (`regex-cursor`) и `TextDecorationCollection` — временные, их заменяют S7-30 (поиск и «Заменить все» по кускам) и S7-33 (подсветка совпадений в рендере).

## Заметка

## Сделано (2026-11-01, x/s7-18-find)
- Строки на `FindBar` (`view/find.rs`): у редактора — без Hex, второй ряд «Заменить на» (Заменить Enter / Заменить все Ctrl+Alt+Enter, подсказка `$1, $2` в «Регулярном»), Tab — между полями, Ctrl+F7 — ряд замены, подписи рядов одной ширины; keybar строк — по макетам.
- Handler `editor`: `editor.search/replace/goto` (без `to`) — фокус `Overlay(Find)` и `Ext` фиче; `editor.goto to=…` — разбор `goto::parse` (`строка:колонка`, смещение, %, ±N), фокус редактору; новая `editor.search_cancel` (Esc строки); `search_next/prev`. Заглушек у редактора больше нет (тест `stubs_reject_with_toast` → `find_without_editor_is_quiet`).
- Кнопки панели «Найти»/«Заменить» открывают строки (та же команда). F8/Shift+F8 — как было в ядре (S7-15): без правок перечитывание, с правками — кодировка для сохранения.
- Поиск (`view/edit/find.rs`): `regex-cursor` по Rope (свой `RopeCursor` по `ChunkCursor` ropey 2), режимы `m`+`R` (CRLF), литерал экранируется, «Слово» — `\b`, группы `$1`/`${name}`/`$$`; proptest `^`/`$` на CRLF против `regex-automata::meta` по `String` при любых стыках чанков. UI (`view/edit_find.rs`): поиск в фоне по снимку при смене образца или текста, до 10 000 совпадений, «N из M», подсветка `TextDecorationCollection`, метки на мини-карте, «Заменить» — выделенное совпадение, «Заменить все» — `replace_all` одной undo-группой (длинный текст — в фоне).
- Сцены `screen-editgoto`, `screen-editreplace` (`screens.edit kind=goto|replace`).

## Осталось
- Решение владельца 2026-11-01: редактор уходит с gpui-kit `EditorState` на свой движок (piece table + виджет на рендере вьювера). **После нового движка** переделать: подсветку совпадений (сейчас `TextDecorationCollection`), курсор `regex-cursor` (сейчас по Rope gpui-kit), метки мини-карты, «Заменить все» одной undo-группой, применение перехода и выделение совпадения. Строки, клавиши, команды handler'а, разбор `goto` и сцены переиспользуются.
- Приёмка «100 000 замен в 50 МБ ≤ 1 с»: замер ядра — `replace_all_budget` (`--release --run-ignored only`), release не собирали; на UI-потоке передача текста gpui-kit ≈ 15 мс/МБ (лимит редактора 16 МБ) — после нового движка.
- За 10 000-м совпадением «следующее» ищется `find_from` на UI-потоке (редкий случай).
- Макет `screen-editreplace`: по его же образцу совпадений 8 (строка 7 `edition = "2024"` тоже), на макете подсвечено 7 и «3 из 7»; у нас «4 из 8». Статус макета «Кол 1» при каретке в конце выделения — у нас «Кол 15». На `screen-editgoto` подсвечено `a41c9e0` (подсветка слова) — не делали.
