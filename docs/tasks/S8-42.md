## Заметки S8-31
- Вложенный архив и архив на сервере открываются тем же `Location` с `outer`: `ArcVfs` читает внешний через реестр (`ArcCache::set_vfs`, ставит `urfin_arc::register`). Stored-запись с `Caps::SEEK` — поддиапазоном, остальное (сжатая запись, rar, `sftp`) — спиллом в `ArcCache::set_spill_dir` (без вызова — `%TEMP%\urfin-arc`).
- Поиск в архивах не должен спиллить без спроса: спилл сверх `[arc] spill_max`/`ratio_max` спрашивает `Ask::spill`: из потока поиска — общий `UiAsk` (inline-вопрос, не из UI-потока); своя ручка задачи — только внутри `urfin-arc` (`password::scoped`, как у `arc.test`). Без спрашивающего — ошибка с причиной; отказ помнится 3 с (`DECLINE_FOR`).
- Глубина — `MAX_NEST` = 8 архивов в цепочке (`avfs::chain`); глубже — ошибка `arc-error-too-deep`.
- Спилл живёт, пока жив индекс (`OpenCtx`): обход, держащий `Arc<ArchiveIndex>` вложенного архива, держит и файл спилла.
