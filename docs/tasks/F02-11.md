## Приёмка

- время старта GUI-режима не изменилось (бюджет старта, замер в PR);
- двойной запуск — второй выходит сразу;
- баннер «Доступно N · M важных» с Показать/Позже, «Позже» не показывает его до новой проверки;
- задача видна в Планировщике в папке Urfin и удаляется выключателем.

- Баннер сразу и в открытом Урфине (TASKS-F).

## Сделано
- `urfin.exe --pkg-check` (`boot::pkg_check`): ранний выход до GPUI, без окна и IPC единственного экземпляра; лог — `logs/pkg-check.*.log`. Проверка (`check::run`, её же делает `pkg.check_now`): эксклюзивный `state/pkg/check.lock` (занят — выход сразу с кодом 0), все найденные менеджеры параллельно с таймаутами §2.3 — установленные и обновления, чтобы дубли сводились как во вкладке; атомарно `cache.json`, `managers.toml` и `check.json` (`checked_at`, `managers`, `updates`, `important`, `dismissed_at`, `manual`). Ни один менеджер не ответил — прежние файлы остаются, код 1. Урфин в сеть не ходит.
- Расписание (`schedule.rs`): XML задачи (Task Scheduler 1.2, UTF-16 с BOM; `InteractiveToken`, `LeastPrivilege`, Daily в `at`, `StartWhenAvailable`, не на батарее, только с сетью, `PT30M`, `IgnoreNew`), `schtasks /Create|/Delete|/Query /XML` через `%SystemRoot%\System32\schtasks.exe` с `CREATE_NO_WINDOW`; сверка пути — `<Command>` задачи против текущего `urfin.exe` (`Task::OtherPath`). `pkg.schedule on at?` создаёт/удаляет задачу, сверяет и пишет `[pkg.schedule]`; без `on` — только сверка (для раздела настроек F02-12; аргумент `on` стал необязательным). Политик F00-01 на расписание пакетов нет.
- Баннер: модель — `urfin_core::pkg::Notice` и `Task` в `PkgModel` (UI не зависит от `urfin-pkg`). Итог `check.json` читается через 0,5 с после старта (один будильник, без опроса), по звонку `CheckBell` — `--pkg-check` сообщает открытому Урфину по IPC (`Request.pkg_checked`, окно не выходит вперёд; решение владельца §8 «сразу в открытом Урфине») и после `pkg.check_now`. «Показать» открывает `pkg:updates`, «Позже» — скрывает; оба пишут `dismissed_at` — баннер не вернётся до новой проверки. Открытая вкладка после проверки перечитывает кэш.
- UI: `gpui_shell::pkg::notice_bar` — строка 40 над командной строкой (`screen-pkgbanner`): значок пакета, «Доступно 7 обновлений · 2 важных», «проверено по расписанию сегодня в 09:00», Показать / Позже. Строки `pkg-banner-*`, `pkg-check-*`, `pkg-schedule-*` — EN+RU.
- Тесты: XML-снапшот, разбор записанного вывода `schtasks /Query /XML` и `\r\r\n`; `check.json` (снапшот, roundtrip, баннер, «Позже»); проверка на подставных менеджерах (дубли, ошибки, замок — второй запуск сразу) и на `fake-pkgmgr` (записанные `choco list`/`outdated`, `schtasks` через процесс); через Core — баннер при старте, «Показать»/«Позже», `pkg.check_now`, звонок, `pkg.schedule` на подставном Планировщике; IPC — звонок первому экземпляру.
