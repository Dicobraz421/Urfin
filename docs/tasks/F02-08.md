## Сделать
- Vfs `pkg:` (§2.5), колонки, фильтры Ctrl+1/2, кэш `cache.json` с датой, Ctrl+R, чип «Пакеты» и строка менеджеров «winget · scoop», «важное» сверху, строка «Обновить N» и «Обновить все»; пункт «Пакеты…» в меню «Утилиты» (Ctrl+F9, №83).

## Приёмка
- открытие таба с кэшем — первый кадр таба ≤16 мс, без запуска процессов;
- Ctrl+R показывает ход в чипах менеджеров, ошибка одного не мешает остальным;
- «вне менеджера» — `secondary`, «Доступна» — `accent`;
- кадр ≤2 мс при 1k строк.

## Заметка
- Межполосная (pkg, ui): при планировании волны разбить или вынести контракт в PR класса B. Полосы `pkg` ещё нет в lanes.toml — добавить PR класса B.

## Сделано
- `urfin-pkg`: `book.rs` — модель вкладки `PkgBook` (одна на процесс, общая у backend, handler и UI): ответы менеджеров, сводные строки «Установленные» (`InstalledMerge`, «вне менеджера», «Доступна» у строки своего пакета) и «Обновления» («важные» из `[pkg].important` сверху, в том числе по двойнику ARP), ход менеджеров (`Run::Idle/Busy/Failed`), дата проверки; строки пересчитываются в потоке ответа, UI берёт готовый вид (`Arc`, без I/O). Кэш `state/pkg/cache.json` (`PkgCache`: ответы, ARP для издателей, ошибки, дата; снапшот формата) и `managers.toml`.
- `vfs.rs` — backend `pkg:` (`Caps::VIRTUAL | READ_ONLY`) на общем механизме колонок (#260): `pkg:/installed`, `pkg:/updates`, колонки Версия · Доступна · Менеджер · Издатель, источник (у scoop без издателя — «bucket main»); фильтр — корень вкладки (`..` нет), в сессию вкладка не попадает (CONTRACTS, v6 №5; core `loc.rs`, `session.rs`).
- `handler.rs` — `pkg.open` (Ctrl+F9 → «Пакеты…»: активировать имеющуюся вкладку или открыть новую), `pkg.filter` (Ctrl+1/2; Ctrl+3 «Найти» — тост до F02-09), `pkg.refresh` (Ctrl+R): обнаружение и ARP — задача Interactive, затем поток на менеджер (установленные → сразу в вкладку, затем обновления); ошибка одного менеджера — `Failed` у него, остальные отвечают; повторный Ctrl+R во время проверки — ничего. Открытие с кэшем — ни обнаружения, ни процессов; первое открытие без кэша — проверка.
- UI (`pkg_view.rs`, `gpui_shell/pkg.rs`): чип «Пакеты», строка менеджеров «winget · scoop» (запрос — «winget…» и бегущий отрезок `accent`, ошибка — `modified` со значком, текст ошибки — в статусе), «16 программ» / «7 из 16», чипы фильтров с числом обновлений `accent`, колонка «Программа», значок пакета, «Доступна» — `accent`, «вне менеджера» — `secondary`, метка «важное» в «Обновлениях», строка «Обновить N · Обновить Enter · Обновить все N Shift+Enter · Отмена Esc» при отметке (без размера — §8), статус «Mozilla.Firefox · winget · Выделено N из M · Проверено сегодня в 09:00», клавиши внизу как на макетах, таб «pkg:», пункт «Пакеты…» в меню «Утилиты».
- keymap: флаг `in_pkg`; Ctrl+1/2/3, Ctrl+R, F3, F5, F8, Ctrl+O, Shift+Enter, Enter/Esc при отметке — в контексте вкладки (№84). F3/F5/F8/Ctrl+O/Enter/Shift+Enter ведут на команды F02-10 (пока тост «ещё не сделано»).
- Тесты: модель (строки, «вне менеджера», важные, уникальные имена, ошибка менеджера, кэш), Core с подставными менеджерами (открытие из кэша без процессов, Ctrl+R, ошибка одного, фильтры, повторный Ctrl+R) и с процессами `fake-pkgmgr` (фикстура `choco list`, второй менеджер — код 1).
