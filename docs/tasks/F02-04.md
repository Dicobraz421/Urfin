## Сделано
- `table.rs`: строка из `-` (≥10) открывает таблицу, границы колонок — начала слов заголовка в ячейках экрана (`unicode-width`: широкие символы — две); строка, где перед границей не пробел или границу пересекает широкий символ, не в сетке; несколько таблиц подряд (заголовок следующей — не данные).
- `winget.rs`: Name/Id/Version — первые три колонки, остальные по содержимому (известные источники `winget`/`msstore`/`winget-font` — Source, `:` — Match поиска, последняя после ещё одной — свой источник, иначе Available); строка данных — Id без пробелов (локальный `ARP\`/`MSIX\` — может с пробелами) и непустая версия, хвосты отбрасываются; вторая таблица `winget upgrade` («требуют явного указания») → `Update::pinned`.
- `parse_export` (схема 2.0, BOM), `repair`: Id `…` — по единственному продолжению в `export` того же источника или среди Id ARP (`ARP\Machine\X64|X86`, `ARP\User\X64`), версия — из `export`, имя — из своей записи ARP или единственной по началу (при нескольких — с той же версией); неоднозначное остаётся усечённым (действие его отвергнет).
- `--output`: `knows_output` по `winget list --help` → `MgrCaps::JSON_OUTPUT` (вместе с версией, в кэш `managers.toml`); `json_rows` — терпимый разбор, не разобрался — текст.
- `action_plan` → `winget <install|upgrade|uninstall> --id <id> --exact` + флаги неинтерактивности, `--accept-package-agreements`/`--silent` у install/upgrade; локальный Id — только uninstall. Таблица кодов `exit_codes(op)` (успех: 0, `UPDATE_NOT_APPLICABLE`, у install — `PACKAGE_ALREADY_INSTALLED`; перезагрузка: `INSTALL_REBOOT_REQUIRED_TO_FINISH`, `INSTALL_REBOOT_INITIATED`); `NO_APPLICATIONS_FOUND` у запроса — пустой список.
- `api.rs`: `valid_id` (регэкспы winget/scoop/choco в доке), `PkgId::checked`, `PkgError::BadId`, `MatchKind::of`. `found.rs` — общий для адаптеров кэш обнаружения и версии. `WingetAdapter` (Windows) — `PackageManager` поверх `proc::run_query`, `export` во временный файл только при усечённых Id/версиях.
- Тесты: фикстуры `crates/pkg/fixtures/winget` (list/upgrade/search EN и RU, search без Match, export) — insta-снапшоты, RU = EN; proptest `table.rs` на произвольных ширинах колонок; регэксп Id по разобранным строкам; argv и планы.

## Осталось
- Фикстуры собраны по формату winget вручную, не сняты со стенда: заменить/дополнить настоящим выводом EN и RU Windows (`winget list|upgrade|search firefox|export`), снапшоты обновить.
- Усечённые Id в `winget search` чинить нечем (пакет не установлен, `export` его не знает): такой вариант не ставится (`BadId`). Путь через `Microsoft.WinGet.Client` (`MgrCaps::PS_MODULE`, решение №2) не сделан.
- Формат `--output json` неизвестен (в известных версиях флага нет) — `json_rows` угадывает ключи; сверить, когда появится.
